Phase 3: Test and Explore More

Test Your Board!

Press F5 to play!

  • The board shows a heart as soon as the game starts
  • Click button A — the display switches to a happy face
  • Click button B — the display switches to a sad face

If Something Looks Wrong

What you seeLikely cause
No board at all in the roomThe object's name must start with microbit (check for a typo), or its room instance is missing
The micro:bit blocks don't appear in BlocklyThe extension isn't ticked: File > Project Settings… > Extensions > micro:bit
Clicking A or B does nothingThe events must be on the board's own object — each micro:bit action works on the micro:bit that runs it
The display stays blankCheck the spelling of the image name (HEART, HAPPY, SAD) — an unknown name is silently ignored

Try This Next

The board can do much more than two buttons — all with the same pattern of an Extension event plus a micro:bit action:

  • Shake — choose the Shake event, then Show Image something different, like SKULL
  • Touch the logo — choose Logo Touched, then try Play Melody POWER_UP
  • Sensors — Read Sensor can put the light level, temperature, compass heading or accelerometer tilt into a variable
  • Two boards talking to each other — copy the object as microbit_2, put both in the room, and use Set Radio Group and Send Radio Message

You Built a Virtual micro:bit!

  • Any object named microbit… becomes a working simulated board
  • The micro:bit's own events and actions program it exactly like any other object
  • No hardware, no extra setup beyond ticking the extension
