Phase 2: Program the Buttons

Open microbit_1, click the Blockly tab, and add these events. All micro:bit blocks live in the micro:bit action category, and all of its events are chosen from the same generic "Extension event" dropdown — that one block covers every event any installed extension provides.

Button A: a Happy Face

Extension event: Button A Pressed
Show Image — Image HAPPY Hold (ms) 0
  1. From Events, snap in Extension event
  2. In its dropdown, choose Button A Pressed
  3. From the micro:bit category, snap in Show Image and type HAPPY into its Image field
No quotes here. Show Image's Image field is a plain name, not an expression — unlike text you draw with Draw Text or Scroll Text, you do not put quotes around HAPPY.

Button B: a Sad Face

Extension event: Button B Pressed
Show Image — Image SAD Hold (ms) 0

Same as button A, but choose Button B Pressed and type SAD.

Start With a Heart

When created
Show Image — Image HEART Hold (ms) 0

So the board shows something the moment the game starts, instead of a blank display.

64 built-in images. HEART, HAPPY and SAD are three of 64 names Show Image understands (YES, NO, SKULL, ARROW_N…) — hover the action in Blockly to see the full list, or light individual LEDs yourself with five rows of brightness digits like 09090:99999:99999:09990:00900.
