Phase 1: Build the Board

A micro:bit is just an object — the engine recognizes it by its name and draws the board on top of it. No sprite is needed: the board's own drawing is its appearance.

Create a New Project

  1. Go to File > New Project
  2. Name it MyMicrobit and choose the "Empty Project" template

Create the micro:bit Object

  1. Create a new object and name it microbit_1
  2. Leave its sprite empty — the board draws itself
The naming rule: any object whose name starts with microbit becomes a micro:bit automatically. (If you want a different name, you can tick the room instance's is_microbit property instead — but starting the name with microbit is the easiest way, and what this tutorial uses.)

Turn On the Extension

  1. Go to File > Project Settings… > Extensions
  2. Tick micro:bit
This is what makes the micro:bit events and actions appear in Blockly. A project that never uses a micro:bit action keeps them hidden — and the first time you add one, the extension turns itself on automatically.

Place It in a Room

  1. Create a room named room_main
  2. Place one instance of microbit_1 anywhere in the room
Try it right now: press F5. You should see the board, with its 5×5 LED display dark, sitting in the room — even before you add a single event. Click its buttons and drag its sensor sliders; nothing happens yet, but the board is already alive. We program it on the next page.
