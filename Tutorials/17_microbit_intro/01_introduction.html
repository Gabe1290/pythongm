micro:bit: Program a Virtual Board

🤖

A real BBC micro:bit, simulated right inside your game — no hardware needed.

A 5×5 LED display, two buttons, a touch logo and more, all drawn on screen and programmed the same way as everything else in PyGameMaker.

What We'll Build

The micro:bit extension puts a simulated BBC micro:bit on screen as an ordinary game object. It isn't a picture — it is a working board you can click, and one you program with events and actions, exactly like any other object in your game.

Why a micro:bit in a game engine? Many classrooms already use real micro:bits. This lets you build and test micro:bit programs — buttons, the LED display, shaking it, its sensors — without owning the hardware, and the same project can later be shared with students who do have a board.

How This Tutorial Works

Phase 1 — Build the Board
Create an object that becomes a micro:bit and place it in a room.
Phase 2 — Program the Buttons
Make button A show a happy face and button B show a sad one.
Phase 3 — Test and Explore More
Play it, then see where to go next: shaking, the logo, sound, sensors and talking to a second board.

What You'll Learn

  • How any object becomes a micro:bit, just by its name
  • Turning the micro:bit extension on for a project
  • The Show Image action and the board's built-in pictures
  • The micro:bit's own events, like Button A Pressed
Time Required: About 15 minutes. You should already know how to create objects and rooms, and add events in the Blockly editor (see Tutorial 1).
