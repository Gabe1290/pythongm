Phase 4: Winning the Game

Right now you can collect fruit and avoid bombs, but there's no way to win. We'll fix that by checking after every step: "Is there any fruit left?" — if not, we go to a brand-new win room.

Create the Win Sprite (Optional)

If you want a celebration look, create a sprite called spr_win_text. This step is optional — the text drawn in the next step works without a sprite.

Create the Win-Text Object

  1. Right-click Objects → Create New Object
  2. Name it obj_win_text
  3. Open the Blockly tab and add these two events:

Show the win message:

When drawing
Draw text YOU WIN! at x:412 y:320
Draw text Press SPACE to play again at x:340 y:400

Restart on space:

Key press: space
Restart Game

Create the Win Room

  1. Right-click Rooms → Create New Room
  2. Name it room_win
  3. Set the background color to a celebratory color (light green or gold)
  4. Place one obj_win_text instance anywhere in the room (its drawing is at fixed coordinates)

The Win Check

Now the important part: every step, the basket checks if any fruit is left. When the count reaches zero, we go to the win room.

  1. Open obj_player
  2. Click the Blockly tab
  3. Add this Every step event:
Every step
If count of obj_fruit == 0 then
Go to room room_win
What this does: The If Count Of block looks at the room and counts how many obj_fruit instances are still alive. When you've caught them all, the count is zero, the comparison == 0 is true, and the Go to room action runs.

Test Your Full Game!

Press F5 to play!

  • Catch every fruit → YOU WIN! screen appears
  • Touch a bomb → the room starts over, nothing is lost for good
  • Press SPACE on the win screen to play again

You Built a Complete Game!

Congratulations — that's a full game loop with:

  • Player input (keyboard movement)
  • Two kinds of collision (good and bad)
  • A score the player can see grow
  • A clear win state and a forgiving way to try again
  • No variables anywhere — every block was a single, ready-made action
Try this next: add more fruit, move the bombs closer together for a harder challenge, or change the colors in the Sprite Editor. Every change is just something you draw or place — no code to edit.
