Fruit Basket!

🍇

Collect every fruit — watch out for the bombs!

Move the basket left and right, pick up all the fruit to win, and stay away from the bombs or you'll have to start the room over.

What We'll Build

A complete little game: move, collect, avoid, and win. The game will be playable at the end of every phase, so you can stop and try it whenever you want.

How This Tutorial Works

Phase 1 — A Moving Basket
Create a basket that moves left and right. Test it right away!
Phase 2 — Fruit and Bombs
Add fruit to collect and bombs to avoid. Place them in the room.
Phase 3 — Catching and Avoiding
Catch fruit for points; touch a bomb and the room starts over.
Phase 4 — Winning the Game
Add a win screen that appears once every fruit has been collected.

What You'll Learn

  • Creating sprites, objects, and rooms
  • Using keyboard events for player control
  • Detecting collisions between objects
  • Tracking and displaying a score
  • Restarting a room and using room transitions for a win screen
  • Using the If Count Of block to check how many objects remain
No variables needed! Every block in this game is a simple, one-step action — move, collect, avoid, win. You never have to create, name, or remember a variable to build it.
