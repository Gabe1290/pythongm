Phase 2: Fruit and Bombs

Now we'll add the fruit to collect and the bombs to avoid. Unlike some other games, nothing here falls or moves on its own — the fruit and the bombs just sit in the room, waiting for the basket to reach them.

Create the Fruit Sprite

  1. Right-click Sprites → Create New Sprite
  2. Name it spr_fruit
  3. Open the Sprite Editor and draw a 26×26 green circle. Save with Ctrl+S.

Create the Bomb Sprite

  1. Repeat the steps above for a sprite called spr_bomb
  2. Draw a 26×26 dark circle so the bomb is easy to spot

Create the Fruit Object

  1. Right-click Objects → Create New Object
  2. Name it obj_fruit
  3. Set the sprite to spr_fruit

That's it — no events yet. A fruit that just sits there doesn't need any blocks of its own; all the behavior will live on the basket in the next phase.

Create the Bomb Object

  1. Create another object called obj_bomb
  2. Set its sprite to spr_bomb

Same as the fruit — no events needed here either.

Place Them in the Room

  1. Open room_main
  2. Place 5 fruit in a row along the bottom of the room, leaving a clear gap between each one — but not right on top of where the basket starts
  3. Place 2 bombs, one near the left edge and one near the right edge, well away from any fruit
  4. Make sure obj_player is still near the bottom center, with some empty space around it
Tip: Since nothing falls or respawns, exactly where you place things is exactly where they'll be when you press F5 — keep the bombs far from the fruit so collecting everything never means you have to risk touching one.

Test Your Game!

Press F5 to play!

  • The fruit and bombs should be sitting still in the room
  • The basket can move left and right among them
  • Touching them does nothing yet — that's the next phase!
