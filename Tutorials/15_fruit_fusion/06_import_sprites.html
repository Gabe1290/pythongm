Bonus: Import Ready-Made Art

Your game already works with the shapes you drew yourself — this page is completely optional. PyGameMaker also comes with a set of ready-made pictures for this tutorial, in case you'd rather use those instead of (or alongside) your own drawings.

The Sprites You Can Swap In

SpriteWhat it's for
spr_basket_emptyThe basket before it's holding anything
spr_basket_cherryThe basket holding a cherry
spr_basket_strawberryThe basket holding a strawberry

spr_basket_watermelonThe basket holding the winning watermelon
spr_fruit_cherryThe falling cherry

spr_fruit_orangeThe falling orange

How to Import One

  1. Right-click the sprite you want to replace (e.g. spr_fruit_cherry) in the Asset Tree
  2. Choose Import Image...
  3. Browse to Tutorials/15_fruit_fusion/assets/ and pick the matching file — it has the exact same name as the sprite (e.g. spr_fruit_cherry.png)

Do this for as many of the eight sprites as you like. The game doesn't care whether a sprite was drawn or imported — it works exactly the same either way.

If you don't see the assets folder: some school computers run PyGameMaker as a single ready-made program instead of from its own folder of files, and that program may not include this tutorial's asset images in a place you can browse to. If Import Image... doesn't find the folder, that's why — ask your teacher, or just keep the drawings you made. There's nothing wrong with hand-drawn fruit!
