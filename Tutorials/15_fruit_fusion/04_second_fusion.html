Phase 3: Second Fusion

Notice something: this whole phase is the exact same four steps as Phase 2, just with "cherry" changed to "strawberry" and the numbers changed from 1/2 to 2/3. Once you've built one fruit tier, you already know how to build the next one.

Create the Strawberry Sprite and Object

  1. Create a sprite spr_fruit_strawberry, 26×26, a pink-red circle
  2. Create an object obj_fruit_strawberry with that sprite
When created
Set vertical speed to 3
Outside room
Destroy this instance

Create the Strawberry Spawner

  1. Create an object obj_spawn_strawberry (no sprite)
When created
Set alarm 0 to 120 steps
Alarm 0
Create instance of obj_fruit_strawberry at a random x, y: 0
Set alarm 0 to 120 steps

A slightly longer wait (120 steps, 2 seconds) than the cherry spawner — two fruit types falling at the same pace would be a lot to watch at once.

  1. Open room_main and place one obj_spawn_strawberry anywhere

The Basket Holds a Strawberry

  1. Create a new sprite spr_basket_orange
  2. Set the size to 56×40, draw the same bowl shape as before, and add an orange circle inside it

Catching a Strawberry

  1. Open obj_player's Blockly tab and add one more Collision event:
When colliding with obj_fruit_strawberry
If held_level equals 2 then
Set variable held_level to 3
Add to score 20
Set sprite to spr_basket_orange
Otherwise
Add to score 1
Destroy other instance

This is the same pattern as last phase: a matching catch (holding a strawberry, level 2, catching a strawberry) fuses up to an orange (level 3) and is worth more points, because it took more steps to get there.

Test Your Game!

Press F5 to play!

  • Catch a cherry, then catch a strawberry → the basket ends up an orange, having scored 10 + 20 = 30 points
Click "Next" for the final fusion — this one wins the game.
