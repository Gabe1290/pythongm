Phase 1: Moving Basket

Let's start with a basket that moves left and right with the arrow keys.

Create a New Project

  1. Go to File > New Project
  2. Name it FruitFusion

Create the Basket Sprite

  1. Right-click Sprites in the Asset Tree → Create New Sprite
  2. Name it spr_basket_empty
  3. Double-click it to open the Sprite Editor and set the size to 56×40
  4. Draw a simple brown bowl shape, wider at the top
  5. Press Ctrl+S to save
Want to use ready-made pictures instead of drawing your own? There's a bonus page about that at the very end of this tutorial — for now, just draw something simple and move on.

Create the Basket Object

  1. Right-click Objects → Create New Object
  2. Name it obj_player
  3. Set the sprite to spr_basket_empty

Place the Basket in the Room

  1. Every new project already has a room called room0. Right-click it under Rooms and select Rename
  2. Rename it to room_main
  3. Open the room and place obj_player near the bottom center

Add Basket Movement

  1. Double-click obj_player to open the Object Editor
  2. Click the Blockly tab

Move Left

Keyboard: Left Arrow (held)
Set horizontal speed to -5

Move Right

Keyboard: Right Arrow (held)
Set horizontal speed to 5

Stop When No Key Pressed

Keyboard: No key
Stop movement

You should have 3 event blocks.

Test Your Game!

Press F5 to play!

  • Use Left and Right arrow keys to move the basket
  • It can drift off screen for now — fruit is coming next!
Click "Next" to make the first fruit fall from the sky.
