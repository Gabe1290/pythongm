Phase 2: First Fusion

Now let's make cherries fall from the sky, and teach the basket what to do when one lands in it.

Create the Cherry Sprite

  1. Create a new sprite named spr_fruit_cherry
  2. Set the size to 20×20 and draw a small red circle

Create the Cherry Object

  1. Create a new object named obj_fruit_cherry
  2. Set the sprite to spr_fruit_cherry
  3. Click the Blockly tab and add these two events:
When created
Set vertical speed to 3
Outside room
Destroy this instance

The first event makes it fall. The second removes it quietly if it ever reaches the bottom of the room without being caught — nothing piles up, and a new one is always on the way.

Create the Cherry Spawner

  1. Create a new object named obj_spawn_cherry — it needs no sprite, it's invisible, it just makes cherries appear
  2. Click the Blockly tab and add these two events:
When created
Set alarm 0 to 90 steps
Alarm 0
Create instance of obj_fruit_cherry at a random x, y: 0
Set alarm 0 to 90 steps

The alarm resets itself every time it fires, so a new cherry keeps coming about every 1.5 seconds.

  1. Open room_main and place one obj_spawn_cherry anywhere — it won't be visible when you play.

The Basket Starts Holding a Cherry

  1. Open obj_player, double-click its sprite field and change it from spr_basket_empty to a new sprite spr_basket_cherry
  2. Set the size to 56×40, draw the same bowl shape as before, and add a small red circle inside it for the cherry

From now on, the basket's picture always shows what it's currently holding. It starts holding a cherry, which is why there is no "empty basket" to worry about.

Remember the Score and What's Held

  1. Still in obj_player's Blockly tab, add this event:
When created
Set score to 0
Set variable held_level to 1

held_level is a number we invent ourselves: 1 means "holding a cherry", 2 will mean "holding a strawberry", and so on. It's how the basket remembers what it's holding.

When drawing
Draw score at x: 10 y: 10

Catching a Cherry

  1. Add a Collision event for obj_fruit_cherry:
When colliding with obj_fruit_cherry
If held_level equals 1 then
Set variable held_level to 2
Add to score 10
Set sprite to spr_basket_strawberry
Otherwise
Add to score 1
Destroy other instance
What this does: held_level starts at 1 (a cherry), and a falling cherry is also "level 1" — they match, so the If branch runs: the basket becomes level 2 (a strawberry), you get 10 points, and the basket's picture changes. If you ever catch a cherry while already holding something bigger, the match fails, so the Otherwise branch runs instead: just 1 point, nothing else changes. Either way, the caught cherry (the other instance in the collision — not the basket itself) disappears.

Test Your Game!

Press F5 to play!

  • Catch a falling cherry → the basket turns into a strawberry and the score jumps by 10
