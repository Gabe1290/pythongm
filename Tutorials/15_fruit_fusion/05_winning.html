Phase 4: Winning

One more fruit, one more fusion — and this time, fusing it all the way up wins the game.

Create the Orange Sprite and Object

  1. Create a sprite spr_fruit_orange, 32×32, an orange circle
  2. Create an object obj_fruit_orange with that sprite
When created
Set vertical speed to 3
Outside room
Destroy this instance

Create the Orange Spawner

  1. Create an object obj_spawn_orange (no sprite)
When created
Set alarm 0 to 150 steps
Alarm 0
Create instance of obj_fruit_orange at a random x, y: 0
Set alarm 0 to 150 steps
  1. Open room_main and place one obj_spawn_orange anywhere

There is no "falling watermelon" sprite or spawner — a watermelon is only ever something your basket becomes, never something that falls from the sky. It's the goal, not an ingredient.

Build the Win Room

  1. Create an object obj_win_text — no sprite needed
  2. Open its Blockly tab and add these two events:
When drawing
Draw text YOU WIN! You made a watermelon! at x: 120 y: 220
Draw text Press SPACE to play again at x: 190 y: 260
Key press: space
Restart Game
  1. Create a new room named room_win
  2. Set its background color to a bright, celebratory color (light green or gold)
  3. Place one obj_win_text instance anywhere in it

The Basket Holds a Watermelon

  1. Create a new sprite spr_basket_watermelon
  2. Set the size to 56×40, draw the same bowl shape as before, and add a green, watermelon-striped circle inside it

Catching an Orange

  1. Open obj_player's Blockly tab and add the last Collision event:
When colliding with obj_fruit_orange
If held_level equals 3 then
Set variable held_level to 4
Add to score 50
Set sprite to spr_basket_watermelon
Go to room room_win
Otherwise
Add to score 1
Destroy other instance
What this does: same pattern as the first two fusions, with one new line: the moment the fusion succeeds (an orange catching an orange), Go to room room_win runs right there, inside the If branch. There's no separate "check if I've won" step anywhere else — winning happens exactly when the fourth fusion does.

Test Your Full Game!

Press F5 to play!

  • Catch a cherry → strawberry (+10)
  • Catch a strawberry → orange (+20)
  • Catch an orange → watermelon — YOU WIN! (+50)
  • Press SPACE on the win screen to play again

You Built a Complete Game!

Congratulations — that's a full merge game with:

  • Player input (keyboard movement)
  • Three kinds of collision, each handled the same way
  • A variable that remembers what's being held
  • An If / Else block that decides between two outcomes
  • An object's sprite changing while the game runs
  • A score that grows, and a clear win screen
