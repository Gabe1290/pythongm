Fruit Fusion!

🍇🍕🍔🍉

Catch matching fruit to make it bigger — grow a watermelon to win!

Move your basket left and right. Catch a fruit that matches what you're already holding and it fuses into something bigger. Catch the wrong one and you just get a tiny point — nothing is ever lost!

What We'll Build

A basket that always holds one fruit, starting with a cherry. Cherries, strawberries and oranges fall from the sky. Catch a matching fruit and it fuses into the next, bigger fruit. Fuse all the way up to a watermelon and you win! The game is playable at the end of every phase, so stop and try it whenever you like.

How This Tutorial Works

Phase 1 — Moving Basket
Create the basket and move it left and right. Test it right away!
Phase 2 — First Fusion
Add falling cherries. Catch a matching one and your basket turns into a strawberry.
Phase 3 — Second Fusion
Add falling strawberries, using the exact same recipe, to fuse up to an orange.
Phase 4 — Winning
Add falling oranges. Fuse one into a watermelon and the YOU WIN! screen appears.
Bonus (optional): once your game works, the last page shows how to swap your own drawings for ready-made pixel art that comes with this tutorial.

What You'll Learn

  • Creating sprites, objects, and rooms
  • Using keyboard events for player control
  • Detecting collisions between objects
  • Using a variable to remember what you're holding
  • An If / Else block that does one thing when something matches, and another thing when it doesn't
  • Changing an object's sprite while the game is running
  • Tracking a score and ending the game with a win screen
Before you start: this tutorial does not need anything from an earlier one — it's a good first project. Keep this tutorial open on one side of your screen and the PyGameMaker window on the other.
