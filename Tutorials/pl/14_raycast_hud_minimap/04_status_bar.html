Etap 3: Pasek stanu

Tekst w rogu jest w porządku, ale klasyczne strzelanki trzymają solidny pasek wzdłuż dołu. Są dwa kroki: zrób miejsce, potem narysuj pasek.

Krok 1: Zrób miejsce

Nasza sala ma 320 pikseli wysokości, a chcemy pasek o wysokości 64 pikseli. Więc widok 3D dostaje 320 − 64 = 256 pikseli. W zdarzeniu Gdy utworzony obiektu obj_player ustaw Viewport Height w bloku Włącz widok Raycast:

Gdy utworzony
Włącz widok Raycast — … Viewport Height 256

Pozostawiony na 0, widok 3D wypełnia całe okno, a pasek zasłaniałby jego część.

Krok 2: Nadaj graczowi zdrowie

W Start gry dodaj Ustaw zdrowie = 100 po wyniku i życiach. Pasek pokazuje tę liczbę.

Krok 3: Narysuj pasek

W zdarzeniu Gdy rysowanie zastąp wynik i życia jedną akcją:

Gdy rysowanie
Narysuj pasek DOOM — X 0 Y -1 Width 0 Height 64 Health Label HEALTH Score Label SCORE
Narysuj minimapę — X 230 Y 10 Size 80
  • Y = -1 oznacza „umieść pasek na dole okna”
  • Width = 0 oznacza „pełna szerokość”
  • Height musi pasować do zarezerwowanego pasma (64)

Przetestuj to!

Naciśnij F5!

  • Widok 3D siedzi teraz nad ciemnym paskiem pokazującym zielony pasek zdrowia z liczbą, twój wynik i życia
  • Minimapa wciąż jest w rogu widoku 3D

Wyzwania

  • Spraw, by potwór zabierał 25 zdrowia (Ustaw zdrowie −25 względnie) zamiast życia, i uzupełniaj zdrowie przy utracie życia — tak jak raycast_3
  • Narysuj twarz na pasku: pasek sprite'a z czterema twarzami, najzdrowszą pierwszą, ustaw jako Face Sprite z Face Frames = 4. Twarz zmienia się wraz ze spadkiem zdrowia
  • Pasek ma licznik opisany Objective Label („Keys: ”): zlicz swoje klejnoty w zmiennej instancji i podaj jej nazwę w Objective Value

Ukończyłeś serię!

  • Zdarzenia Gdy rysowanie umieszczają HUD nad widokiem 3D
  • Narysuj minimapę i Narysuj pasek DOOM wykonują ciężką pracę
  • Viewport Height rezerwuje miejsce na pasek
