Etap 3: Wyjście

Cel, który sprawdza klejnoty

  1. Narysuj niebieski sprite drzwi lub portalu 16×16, spr_goal, i utwórz niesolidny obj_goal
  2. Dodaj zdarzenie Gdy kolizja z obj_player. Potrzebuje dwóch sprawdzeń, po jednym dla każdego przypadku:
Gdy kolizja z obj_player
Sprawdź liczbę instancji obj_gem: równe 0
Początek bloku
Wyświetl wiadomość You win!
Uruchom grę ponownie
Koniec bloku
Sprawdź liczbę instancji obj_gem: większe niż 0
Początek bloku
Wyświetl wiadomość Collect all the gems first!
Koniec bloku

Akcja Sprawdź liczbę instancji pyta „ile instancji obj_gem istnieje w tej chwili?”. Każdy zebrany klejnot jest niszczony, więc gdy liczba osiągnie 0, masz je wszystkie.
Jej opcje: Object = obj_gem, Number = 0, Operation = equal / greater.

Umieszczaj tekst wiadomości w cudzysłowie. Tekst w wiadomości jest ujęty w cudzysłów, aby myślnik albo znak plus nie zostały wzięte za działanie arytmetyczne.

Przetestuj to!

Naciśnij F5!

  • Wejdź do celu z pozostałymi klejnotami: dostajesz komunikat „Collect all the gems first!”, a gra trwa dalej
  • Zbierz każdy klejnot, potem wejdź do celu: „You win!”

Wyzwania

  • Dodaj drugiego, szybszego potwora (prędkość 4) patrolującego inny korytarz
  • Stwórz drugą salę i użyj Następna sala zamiast Uruchom grę ponownie przy wyjściu. Nadaj drugiej sali jej własny obiekt kamery — na przykład z innymi teksturami — i ustaw jego Camera Object na obj_player. Tak robi raycast_2.
  • Nadaj klejnotowi 50 punktów zamiast 10, aby zrobić „skarb”

Stworzyłeś grę!

  • Niesolidne obiekty ze sprite'em to billboardy, ukryte za ścianami
  • Wynik i życia mieszkają w Start gry
  • Sprawdź liczbę instancji warunkuje wyjście klejnotami
Następna lekcja: HUD i minimapa — pokaż wynik, życia, pasek zdrowia i mapę bezpośrednio na ekranie.
