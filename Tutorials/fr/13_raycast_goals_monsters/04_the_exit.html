Phase 3 : La sortie

Un but qui vérifie les gemmes

  1. Dessinez une porte ou un portail bleu de 16×16, spr_goal, et créez un obj_goal non solide
  2. Ajoutez un événement Quand collision avec obj_player. Il faut deux vérifications, une pour chaque cas :
Quand collision avec obj_player
Tester le nombre d'instances de obj_gem : égal à 0
Début de bloc
Afficher un message You win!
Redémarrer le jeu
Fin de bloc
Tester le nombre d'instances de obj_gem : supérieur à 0
Début de bloc
Afficher un message Collect all the gems first!
Fin de bloc

L'action Tester le nombre d'instances demande « combien d'instances de obj_gem existent en ce moment ? ». Chaque gemme ramassée est détruite : quand le compte atteint 0, vous les avez toutes.
Ses options : Object = obj_gem, Number = 0, Operation = equal / greater.

Les messages sont entre guillemets. Le texte d'un message est mis entre guillemets pour qu'un tiret ou un signe plus ne soit pas pris pour un calcul. Vous pouvez écrire votre message en français : il s'affichera tel quel.

Testez !

Appuyez sur F5 !

  • Entrez dans le but alors qu'il reste des gemmes : vous obtenez le message d'avertissement et le jeu continue
  • Ramassez toutes les gemmes, puis entrez dans le but : victoire !

Défis

  • Ajoutez un second monstre, plus rapide (vitesse 4), qui patrouille dans un autre couloir
  • Créez une seconde salle et utilisez Salle suivante au lieu de Redémarrer le jeu à la sortie. Donnez à la seconde salle son propre objet caméra — par exemple avec d'autres textures — et réglez son Camera Object sur obj_player. C'est ce que fait raycast_2.
  • Faites valoir une gemme 50 points au lieu de 10 pour créer un « trésor »

Vous avez fait un jeu !

  • Les objets non solides avec sprite sont des panneaux, cachés derrière les murs
  • Le score et les vies se règlent dans Game Start
  • Tester le nombre d'instances conditionne la sortie aux gemmes
Prochaine leçon : HUD et minicarte — affichez le score, les vies, une barre de santé et une carte directement à l'écran.
