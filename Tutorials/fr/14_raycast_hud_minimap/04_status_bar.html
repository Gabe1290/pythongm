Phase 3 : La barre d'état

Le texte dans les coins est bien, mais les jeux de tir classiques gardent une barre pleine en bas de l'écran. Deux étapes : faire de la place, puis dessiner la barre.

Étape 1 : Faire de la place

Notre salle fait 320 pixels de haut et nous voulons une barre de 64 pixels. La vue 3D reçoit donc 320 − 64 = 256 pixels. Dans l'événement Quand créé de obj_player, réglez Viewport Height sur Activer la vue Raycast :

Quand créé
Activer la vue Raycast — … Viewport Height 256

À 0, la vue 3D occupe toute la fenêtre et la barre en cacherait une partie.

Étape 2 : Donner de la santé au joueur

Dans Game Start, ajoutez Définir la santé = 100 après le score et les vies. La barre affiche ce nombre.

Étape 3 : Dessiner la barre

Dans l'événement Quand dessiner, remplacez le score et les vies par une seule action :

Quand dessiner
Dessiner l'ATH DOOM — X 0 Y -1 Width 0 Height 64 Health Label SANTÉ Score Label SCORE
Dessiner la mini-carte — X 230 Y 10 Size 80
  • Y = -1 signifie « place la barre en bas de la fenêtre »
  • Width = 0 signifie « pleine largeur »
  • Height doit correspondre à la bande réservée (64)

Testez !

Appuyez sur F5 !

  • La vue 3D est maintenant posée sur une barre sombre montrant une barre de santé verte avec son nombre, votre score et vos vies
  • La minicarte reste dans le coin de la vue 3D

Défis

  • Faites que le monstre retire 25 de santé (Définir la santé −25 relatif) au lieu d'une vie, et remettez la santé au maximum quand une vie est perdue — comme raycast_3
  • Dessinez un visage dans la barre : une bande de quatre visages, du plus en forme au plus abîmé, réglée comme Face Sprite avec Face Frames = 4. Le visage change quand la santé baisse
  • La barre a un compteur nommé Objective Label (« Keys : ») : comptez vos gemmes dans une variable d'instance et donnez son nom à Objective Value

Vous avez terminé la série !

  • Les événements Quand dessiner placent l'ATH par-dessus la vue 3D
  • Dessiner la mini-carte et Dessiner l'ATH DOOM font le gros du travail
  • Viewport Height réserve de la place pour une barre
