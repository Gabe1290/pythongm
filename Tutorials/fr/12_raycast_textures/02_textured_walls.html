Phase 1 : Des murs texturés

Une texture n'a rien de spécial : c'est un sprite ordinaire. La vue 2.5D le découpe en fines bandes verticales et étire chaque bande sur le mur qui se trouve devant elle — plus haute quand le mur est proche, plus courte quand il est loin.

Dessiner le sprite de briques

  1. Créez un sprite nommé spr_wall_texture
  2. Dans l'éditeur de sprites, donnez-lui 64×64 pixels. Remplissez-le de rouge brique, puis tracez des joints clairs : une ligne horizontale tous les 16 pixels, et de courtes lignes verticales entre les briques, décalées d'une demi-brique une rangée sur deux.
  3. Enregistrez avec Ctrl+S

Vous préférez une photo ou une image d'internet ? Utilisez plutôt Importer une image.... N'importe quelle image convient — les images carrées (comme 64×64) rendent le mieux car la texture est répétée de la même façon sur chaque mur.

La donner aux murs

  1. Ouvrez obj_player → onglet Blockly → son événement Quand créé
  2. Sur Activer la vue Raycast, réglez Wall Texture sur spr_wall_texture
Quand créé
Activer la vue Raycast — Field of View 66 Cell Size 32 Render Distance 20 Wall Texture spr_wall_texture

Testez !

Appuyez sur F5 !

  • Chaque mur est maintenant couvert de briques
  • Les murs tournés à l'opposé de la lumière paraissent plus sombres — le jeu ombre différemment les deux directions, une astuce peu coûteuse qui donne du volume aux coins
  • Approchez-vous : les briques grossissent ; reculez : elles rétrécissent
