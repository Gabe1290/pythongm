Phase 3 : Jouer chacun son tour

Pour l'instant, cliquer sur une case ne change que votre écran. Cette phase fait voyager un clic à travers le dossier partagé pour que les deux ordinateurs soient d'accord sur la grille — et s'assure que seul le joueur dont c'est le tour peut cliquer.

À qui le tour ?

  1. Ajoutez à l'événement Création de obj_game (de la Phase 1) : définissez last_round_acted à 0 et my_turn à 0
  2. Ajoutez un événement Step :
Si (global.round_number mod 2 == 1 and my_mark == "X") or (global.round_number mod 2 == 0 and my_mark == "O") alors
Définir la variable my_turn à 1
Sinon
Définir la variable my_turn à 0

Le premier tour publié est le tour 1, pas 0 — donc X (l'hôte) joue aux tours impairs, O aux tours pairs.

Toujours dans le même événement Step, juste après : le joueur dont ce n'est pas le tour doit quand même soumettre quelque chose, sinon le tour resterait bloqué en attendant tout le délai à chaque fois :

Si my_turn == 0 and last_round_acted != global.round_number alors
Terminer le tour (échange de fichiers)
Définir la variable last_round_acted à global.round_number
Ce que ça fait : un « passe » — soumis sans rien préparer, une seule fois par tour (last_round_acted empêche que ça se redéclenche à chaque image). Le joueur actif soumettra quelque chose de réel à la place, depuis le gestionnaire de clic ci-dessous.

Réécrire le gestionnaire de clic

Ajoutez my_turn == 1 comme condition à chacun des neuf clics de la Phase 1, et remplacez le Définir la variable local par une vraie écriture réseau + soumission. Case (0,0), entièrement détaillée :

Souris : Bouton gauche pressé
Si cell_0_0 == "" and my_turn == 1 and mouse_x >= 170 and mouse_x < 270 and mouse_y >= 90 and mouse_y < 190 alors
Définir une variable partagée (échange de fichiers) nom :cell_0_0 valeur :my_mark
Terminer le tour (échange de fichiers)

Même forme pour les huit autres — les mêmes rectangles que le tableau de la Phase 1, chacune écrivant son propre nom de case littéral.

Ce que ça fait : le joueur actif écrit son propre symbole dans la variable partagée de cette case, en utilisant son nom littéral (le paramètre Nom est toujours un nom simplement tapé ici, jamais une expression calculée), puis Terminer le tour (échange de fichiers) le soumet.

Dessiner depuis la grille publiée, pas la supposition locale

Remplacez la vérification de dessin de la Phase 1 pour chaque case — lisez la version partagée au lieu de la locale. Une variable partagée jamais définie se lit comme le nombre 0, pas comme une chaîne vide. Case (0,0) :

Au dessin
Si global.cell_0_0 != 0 alors
Dessiner le texte global.cell_0_0 à x:205 y:115

Même forme pour les huit autres, mêmes positions que la Phase 1.

Ce que ça fait : une variable définie avec Définir une variable partagée (échange de fichiers) est lisible partout, sur toutes les machines, en tant que global.<nom> — aucune action supplémentaire n'est nécessaire pour la récupérer, tant que le nom est littéral comme cell_0_0 ici (un nom construit à l'exécution, comme un nom dérivé d'une position, aurait besoin de Lire une variable partagée (échange de fichiers) à la place, puisque le champ Nom de cette action accepte bien une expression). Cela ne prend effet qu'une fois que l'hôte a réellement publié un tour, pas instantanément au moment du clic.

Testez de vrais tours !

Appuyez sur F5 sur les deux ordinateurs, hébergez et rejoignez comme en Phase 2 !

  • Seul le joueur dont c'est le tour peut cliquer sur une case
  • Le symbole apparaît sur les deux écrans une fois le tour résolu — pas instantanément sur votre propre écran non plus
  • Les tours alternent automatiquement : X, puis O, puis X…
Cliquez sur « Suivant » pour vérifier un gagnant et laisser les deux joueurs rejouer.
