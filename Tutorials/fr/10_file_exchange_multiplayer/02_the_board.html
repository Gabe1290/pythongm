Phase 1 : La grille

Avant tout réseau, construisons une grille de morpion cliquable — entièrement locale, testable seul dès maintenant.

Créer un nouveau projet

  1. Allez dans Fichier > Nouveau projet
  2. Nommez-le TicTacToeFiles
  3. Pour le Modèle, choisissez « Projet vide »

Créer le sprite de case

  1. Clic droit sur Sprites dans l'Arbre des ressources → Créer un nouveau sprite
  2. Nommez-le spr_cell
  3. Double-cliquez dessus pour ouvrir l'éditeur de sprite et dessinez un carré de 120×120 avec une bordure (un remplissage clair avec un contour plus foncé fonctionne bien). Appuyez sur Ctrl+S pour enregistrer.

Créer l'objet case

  1. Clic droit sur Objets → Créer un nouvel objet
  2. Nommez-le obj_cell
  3. Réglez le sprite sur spr_cell

Créer la salle de la grille

  1. Clic droit sur Rooms → Créer une nouvelle salle
  2. Nommez-la room_board
  3. Placez 9 instances de obj_cell exactement à ces positions (faites glisser chacune, puis ajustez son x/y dans le panneau des propriétés si ce n'est pas exact) :
x:100 y:100 x:300 y:100 x:500 y:100
x:100 y:300 x:300 y:300 x:500 y:300
x:100 y:500 x:300 y:500 x:500 y:500

Les positions exactes comptent ici — la Phase 3 construit le nom de la variable partagée de chaque case directement à partir de son x/y, et la vérification de victoire de la Phase 4 utilise ces neuf mêmes positions. Respecter ce tableau fait que chaque étape suivante fonctionne directement.

Suivre si une case est marquée

  1. Double-cliquez sur obj_cell pour ouvrir l'éditeur d'objets
  2. Cliquez sur l'onglet Blockly
  3. Ajoutez un événement Création :
À la création
Définir la variable mark à
Ce que ça fait : chaque case démarre avec sa propre variable mark, vide. Nous la définirons à "X" quand la case est cliquée, et dessinerons ce qu'elle contient.

Marquer une case au clic

Souris : Bouton gauche pressé
Si mark == "" alors
Définir la variable mark à X

Seulement X pour l'instant — alterner entre X et O pour deux vrais joueurs, c'est ce que la Phase 3 ajoute.

Dessiner le marquage

Au dessin
Dessiner le texte mark à x:x y:y

Utiliser les propres x et y de la case fait que chaque case dessine son marquage à sa propre place, avec exactement le même événement sur chaque instance.

Testez la grille !

Appuyez sur F5 pour jouer !

  • Cliquez sur une case → un X apparaît
  • Cliquez à nouveau → rien ne se passe (elle est déjà marquée)
  • Pas encore de tours, pas encore d'adversaire — c'est pour la suite
