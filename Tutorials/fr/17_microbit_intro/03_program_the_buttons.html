Phase 2 : programmer les boutons

Ouvrez microbit_1, cliquez sur l'onglet Blockly, et ajoutez ces événements. Tous les blocs micro:bit se trouvent dans la catégorie d'actions micro:bit, et tous ses événements se choisissent dans le même bloc générique « Événement d'extension » — ce seul bloc couvre les événements de toute extension installée.

Bouton A : un visage content

Événement d'extension : Button A Pressed
Afficher une image — Image HAPPY Durée d'affichage (ms) 0
  1. Ajouter un événement → depuis Événements, emboîtez Événement d'extension
  2. Dans son menu déroulant, choisissez Button A Pressed
  3. Depuis la catégorie micro:bit, emboîtez Afficher une image et tapez HAPPY dans son champ Image
Pas de guillemets ici. Le champ Image d'Afficher une image est un simple nom, pas une expression — contrairement à un texte dessiné avec Dessiner du texte ou Faire défiler un texte, vous ne mettez pas de guillemets autour de HAPPY.
Pourquoi « Button A Pressed » reste en anglais : le menu déroulant des événements d'extension n'est pas encore traduit — c'est ce que vous verrez vraiment à l'écran, même en français.

Bouton B : un visage triste

Événement d'extension : Button B Pressed
Afficher une image — Image SAD Durée d'affichage (ms) 0

Comme pour le bouton A, mais choisissez Button B Pressed et tapez SAD.

Commencer par un cœur

Quand créé
Afficher une image — Image HEART Durée d'affichage (ms) 0

Pour que la carte affiche quelque chose dès le début de la partie, au lieu d'un écran vide.

64 images intégrées. HEART, HAPPY et SAD sont trois des 64 noms que comprend Afficher une image (YES, NO, SKULL, ARROW_N…) — survolez l'action dans Blockly pour voir la liste complète, ou allumez vous-même chaque LED avec cinq lignes de chiffres de luminosité comme 09090:99999:99999:09990:00900.
Cliquez sur « Suivant » pour tester votre carte.
