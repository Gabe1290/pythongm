Phase 2 : La caméra et les commandes

Dans un jeu 2.5D, l'objet joueur est la caméra : la vue est dessinée depuis l'endroit où il se trouve, dans la direction où il regarde. Ouvrez obj_player, cliquez sur l'onglet Blockly et ajoutez ces événements.

Activer la vue 2.5D

Quand créé
Activer la vue Raycast — Field of View 66 Cell Size 32 Render Distance 20
Ce que ça fait : dès maintenant, cette salle est dessinée à la première personne. Les noms des paramètres restent en anglais dans l'IDE : Cell Size (taille de case) doit correspondre à votre grille de murs (32) ; Render Distance (distance de rendu) est le nombre de cases que la caméra peut voir. Laissez Camera Object (objet caméra) vide — cela veut dire « l'objet qui exécute cette action », donc le joueur.

Tourner à gauche et à droite

Clavier : Flèche gauche (maintenue)
Définir l'angle de vue — Angle 3  Relatif : oui
Clavier : Flèche droite (maintenue)
Définir l'angle de vue — Angle -3  Relatif : oui

L'angle de vue est la direction du regard, en degrés (0 = droite, 90 = haut, 180 = gauche, 270 = bas). Relatif signifie « ajouter à l'angle actuel » — en maintenant la touche, vous continuez de tourner, 3 degrés à la fois.

Avancer et reculer

Clavier : Flèche haut (maintenue)
Définir direction et vitesse — Direction facing_angle Speed 3
Clavier : Flèche bas (maintenue)
Définir direction et vitesse — Direction facing_angle+180 Speed 3
Clavier : Aucune touche
Définir direction et vitesse — Direction 0 Speed 0

La marche utilise le même angle de vue que la caméra : « devant » est donc toujours la direction où vous regardez.

Rendre les murs solides pour le joueur

Quand collision avec obj_wall
(aucune action — laissez-le vide)
Ne sautez pas cette étape ! Un événement de collision vide semble inutile, mais sans lui le joueur traverse tous les murs. Un objet solide n'arrête qu'un autre objet qui possède un événement de collision avec lui — l'événement peut être vide.
Cliquez sur « Suivant » pour jouer dans votre salle.
