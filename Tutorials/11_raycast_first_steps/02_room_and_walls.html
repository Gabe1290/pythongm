Phase 1: The Room and the Walls

Everything in a 2.5D room sits on a grid of 32×32 pixel cells. We will build a room 10 cells wide and 10 cells tall (320×320 pixels) and put a wall block in every border cell.

Create a New Project

  1. Go to File > New Project
  2. Name it FirstPerson and choose the "Empty Project" template

Create the Sprites

  1. Create a sprite named spr_wall. Draw a 32×32 square filled with a light grey or a brick pattern.
  2. Create a sprite named spr_player. Draw a 16×16 square (any colour) — you will never actually see it, because the player is the camera, but every object needs a sprite.

The wall sprite must be exactly the size of a cell (32×32). A wall sprite that is roughly square blocks all four sides of its cell.

Create the Wall Object

  1. Create an object named obj_wall and give it the sprite spr_wall
  2. Tick the Solid property — this is what tells the 2.5D view "this is a wall"

Create the Player Object

  1. Create an object named obj_player with the sprite spr_player. Leave it not solid. We add its behaviour in Phase 2.

Build the Room

  1. Create a room named room_main. In its properties set the width and height to 320.
  2. Click the Grid button in the Room Editor's toolbar to show the grid. It is 32 pixels by default, so blocks snap to exactly the right cells.
  3. Place obj_wall at these positions:
    Position (x, y)Blocks
    (0, 0) … (288, 0)the top row: 10 blocks, one every 32 pixels
    (0, 288) … (288, 288)the bottom row: 10 blocks
    (0, 32) … (0, 256)the left column, between the corners: 8 blocks
    (288, 32) … (288, 256)the right column: 8 blocks
    (128, 128), (160, 128), (128, 160)three blocks inside, so there is something to look at
  4. Place one obj_player at (48, 48) — inside the room, away from the walls.
Why the room is small: the game window takes the size of the room, so a 320×320 room gives a 320×320 view. Later you can build bigger rooms — just keep every wall on the 32-pixel grid.
