Phase 2: The Camera and the Controls

In a 2.5D game the player object is the camera: the view is drawn from wherever it stands, looking wherever it faces. Open obj_player, click the Blockly tab, and add these events.

Turn On the 2.5D View

When created
Enable Raycast View — Field of View 66 Cell Size 32 Render Distance 20
What this does: from now on this room is drawn in first person. Cell Size must match your wall grid (32). Render Distance is how many cells far the camera can see. Leave Camera Object empty — that means "the object running this action", i.e. the player.

Turn Left and Right

Keyboard: Left Arrow (held)
Set Facing Angle 3  Relative: on
Keyboard: Right Arrow (held)
Set Facing Angle -3  Relative: on

The facing angle is the direction you look, in degrees (0 = right, 90 = up, 180 = left, 270 = down). Relative means "add to the current angle" — so holding the key keeps turning, 3 degrees at a time.

Walk Forward and Backward

Keyboard: Up Arrow (held)
Set Direction & Speed — direction facing_angle speed 3
Keyboard: Down Arrow (held)
Set Direction & Speed — direction facing_angle+180 speed 3
Keyboard: No key
Set Direction & Speed — direction 0 speed 0

Walking uses the same facing angle as the camera, so "forward" is always the way you are looking.

Make the Walls Solid to the Player

Collision with obj_wall
(no actions — leave it empty)
Don't skip this! An empty collision event looks pointless, but without it the player walks straight through every wall. A solid object only stops another object that has a collision event for it — the event can be empty.
