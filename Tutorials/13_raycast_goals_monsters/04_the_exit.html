Phase 3: The Exit

A Goal That Checks the Gems

  1. Draw a 16×16 blue door or portal sprite spr_goal and create a non-solid obj_goal
  2. Add a Collision with obj_player event. It needs two checks, one for each case:
Collision with obj_player
If count of obj_gem is equal to 0
Start block
Show message You win!
Restart Game
End block
If count of obj_gem is greater than 0
Start block
Show message Collect all the gems first!
End block

The If count of action asks «how many obj_gem instances exist right now?». Every collected gem is destroyed, so when the count reaches 0 you have them all.
Set its options: Object = obj_gem, Number = 0, Operation = equal / greater.

Put quoted text in messages. Text in a message is quoted so that a dash or a plus sign in it isn't mistaken for arithmetic.

Test It!

Press F5!

  • Walk into the goal with gems left: you get the "Collect all the gems first!" message and the game continues
  • Collect every gem, then walk into the goal: "You win!"

Challenges

  • Add a second, faster monster (speed 4) patrolling a different corridor
  • Make a second room, and use Next room instead of Restart Game at the exit. Give the second room its own camera object — for example one with different textures — and set its Camera Object to obj_player. This is what raycast_2 does.
  • Give a gem 50 points instead of 10 to make a "treasure"
