Phase 2: The Monster and Lives

A Patrolling Monster

  1. Draw a 16×16 red monster sprite, spr_monster, and create a non-solid obj_monster
  2. Make it patrol left and right:
When created
Start moving in direction: left, right — Speed 2
  1. Make it turn around when it reaches a wall:
Collision with obj_wall
Reverse horizontal direction

Place the monster in a long straight row (say, along the bottom corridor) so it has room to patrol. Solid blocks stop it just like the player.

Lose a Life

Back in obj_player, add two events:

Collision with obj_monster
Set lives to -1 (Relative)
Restart room
No More Lives
Restart Game

Restarting the room puts you back at the start and puts the gems back — but the lives you have left, and your score, are remembered because they were set in Game Start.

Test It!

Press F5!

  • The monster slides along its corridor and turns at each end
  • You can see it approach; it hides behind walls like the gems do
  • Touching it costs one life; after the third, the game starts over
Good to know: a collision event fires when two objects start touching. If you stand still on the monster you lose one life, not one per frame.
