Phase 1: Gems and Score

The good news: you don't have to do anything special to make objects appear in 2.5D. Every visible, non-solid object that has a sprite is drawn automatically as a billboard. (Walls are solid, so they become walls; your player is the camera, so it is never drawn.)

Create the Gem

  1. Draw a 16×16 yellow diamond sprite named spr_gem
  2. Create an object obj_gem with that sprite. Leave Solid unchecked.
  3. Add a Collision with obj_player event:
Collision with obj_player
Destroy this instance
  1. Add a Destroy event to obj_gem. It runs whenever the gem disappears:
Destroy
Add to score 10

Set Up Score and Lives

  1. Open obj_player and add a Game Start event:
Game Start
Set score to 0
Set lives to 3
Why Game Start and not Create? Create runs again every time a room restarts — and we will restart the room whenever you lose a life. If lives were set to 3 in Create, you would get all three lives back on every death. Game Start runs only once, when the game begins.

Place the Gems

Open the room and place a few gems in the open corridors. Keep them off the wall blocks. In this lesson the player starts at the top-left, facing right, so put the first gem in a straight line ahead of it.

Test It!

Press F5!

  • The gems float in front of you and grow as you approach
  • Walk into one: it vanishes and you score 10
  • Turn so a wall is between you and a gem: the gem is hidden until the wall no longer blocks it
