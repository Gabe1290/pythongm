2.5D: Goals, Gems and Monsters

💎

Turn your empty maze into a real game!

Collect gems, dodge a patrolling monster, and find the exit — but it only opens when every gem is yours.

What We'll Build

We continue with the room from 2.5D: First Steps (Lesson 11). Textures are optional — use them if you did Lesson 12.

Phase 1 — Gems and Score
Things that float in the 3D view, and 10 points for each one.
Phase 2 — The Monster and Lives
A monster that patrols back and forth; touch it and you lose a life.
Phase 3 — The Exit
A goal that only works once all the gems are collected.

What You'll Learn

  • Any non-solid object with a sprite is drawn in the 3D view as a billboard — a picture that always faces you
  • Billboards get smaller with distance and are hidden behind walls
  • Score, lives, and a condition that counts instances
  • Why score and lives are set up in Game Start, not in Create
Time Required: About 30 minutes.
