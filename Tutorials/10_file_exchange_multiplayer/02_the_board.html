Phase 1: The Board

Before any networking, let's build a Tic-Tac-Toe board you can click on — entirely local, testable by yourself right away.

Create a New Project

  1. Go to File > New Project
  2. Name it TicTacToeFiles
  3. For the Template, choose "Empty Project"

Create the Cell Sprite

  1. Right-click Sprites in the Asset Tree → Create New Sprite
  2. Name it spr_cell
  3. Double-click it to open the Sprite Editor and draw a 120×120 square with a border (a light fill with a darker outline works well). Press Ctrl+S to save.

Create the Cell Object

  1. Right-click Objects → Create New Object
  2. Name it obj_cell
  3. Set the sprite to spr_cell

Create the Board Room

  1. Right-click Rooms → Create New Room
  2. Name it room_board
  3. Place 9 instances of obj_cell at exactly these positions (drag each one, then use the Properties panel to fine-tune its x/y if it isn't exact):
x:100 y:100 x:300 y:100 x:500 y:100
x:100 y:300 x:300 y:300 x:500 y:300
x:100 y:500 x:300 y:500 x:500 y:500

The exact positions matter here — Phase 3 builds each cell's shared-variable name straight from its x/y, and Phase 4's win check spells out these same nine positions. Matching this table means every step after this one just works.

Track Whether a Cell Is Marked

  1. Double-click obj_cell to open the Object Editor
  2. Click the Blockly tab
  3. Add a Create event:
When created
Set variable mark to
What this does: every cell starts with its own mark variable, empty. We'll set it to "X" when the cell is clicked, and draw whatever it holds.

Mark a Cell on Click

Mouse: Left Button Pressed
If mark == "" then
Set variable mark to X

Only X for now — alternating between X and O for two real players is what Phase 3 adds.

Draw the Mark

When drawing
Draw text mark at x:x y:y

Using the cell's own x and y means every cell draws its own mark in its own place, with the exact same event on every instance.

Test the Board!

Press F5 to play!

  • Click any cell → an X appears
  • Click it again → nothing happens (it's already marked)
  • No turns, no opponent yet — that's next
