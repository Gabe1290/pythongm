Phase 1: The Board

Before any networking, let's build a Tic-Tac-Toe board you can click on — entirely local, testable by yourself right away. Everything in this game lives on one object, obj_game — it draws the whole board, and (from Phase 2 on) hosts or joins too, so there's nothing else that needs to know about the board's state.

Create a New Project

  1. Go to File > New Project
  2. Name it TicTacToeFiles
  3. For the Template, choose "Empty Project"

Create the Game Object and Room

  1. Right-click Objects → Create New Object
  2. Name it obj_game, no sprite needed (leave it invisible)
  3. Right-click Rooms → Create New Room, name it room_board
  4. Place one instance of obj_game anywhere in room_board

Track Nine Cells

  1. Double-click obj_game to open the Object Editor
  2. Click the Blockly tab
  3. Add a Create event that sets nine variables empty — cell_0_0, cell_1_0, cell_2_0, cell_0_1, cell_1_1, cell_2_1, cell_0_2, cell_1_2, cell_2_2 (column, then row) — one Set Variable block each:
When created
Set variable cell_0_0 to
Set variable cell_1_0 to
... (all nine)
Why nine plain variables instead of nine objects? There's no way in this engine for two different instances to hand each other a computed name to read or write — only self, global, and (in a collision) other. Nine variables on one object, each with its own fixed name, sidesteps that entirely: every action below just names the exact cell it means.

Draw the Grid

A 300×300 board starting at (170, 90) — three 100-pixel columns, three 100-pixel rows:

When drawing
Draw line from x:270 y:90 to x:270 y:390
Draw line from x:370 y:90 to x:370 y:390
Draw line from x:170 y:190 to x:470 y:190
Draw line from x:170 y:290 to x:470 y:290

Mark a Cell on Click

One If per cell, checking the mouse position against that cell's own pixel rectangle. Cell (0,0), fully worked out:

Mouse: Left Button Pressed
If cell_0_0 == "" and mouse_x >= 170 and mouse_x < 270 and mouse_y >= 90 and mouse_y < 190 then
Set variable cell_0_0 to X

Repeat the exact same shape for the other eight, each checking its own variable and its own rectangle:

Only X for now — alternating between X and O for two real players is what Phase 3 adds.

Draw Each Mark

Cell (0,0) again, fully worked out — text centred roughly in its cell:

When drawing
If cell_0_0 != "" then
Draw text cell_0_0 at x:205 y:115

Same shape for the other eight (add 100 to x per column, 100 to y per row, matching the table above).

Test the Board!

Press F5 to play!

  • Click any cell → an X appears
  • Click it again → nothing happens (it's already marked)
  • No turns, no opponent yet — that's next
