Phase 2: Host a Game / Join a Game

Now let's connect two computers through a shared folder. One will host (the referee), and the other will join.

Before you start: pick a folder both computers can reach and write to — a shared network drive, or (to build and test the wiring alone first) just a folder on your own computer. We'll write it into both actions below as Z:\games\tictactoe — replace it with your own path.

Create the Game Controller

  1. Right-click Objects → Create New Object
  2. Name it obj_controller, no sprite needed (leave it invisible)
  3. Place one instance of it anywhere in room_board

Host on Key H, Join on Key J

One object, two ways to start it — run the exact same project on both computers, and press a different key on each:

Key press: H
Host Game (Files) folder:Z:\games\tictactoe max players:2 player name:Player 1
Key press: J
Join Game (Files) folder:Z:\games\tictactoe player name:Player 2
Why keys, not a menu? It's the simplest way to test both roles from the very same project — press H on one computer, J on the other. A real classroom game might instead ask "Host or Join?" on a title screen, but that's UI polish, not something this tutorial needs to teach.

Show Connection Status

  1. Add a When drawing event to obj_controller:
When drawing
If global.player_count < 2 then
Draw text Waiting for opponent... at x:20 y:20
Else if global.player_id == 0 then
Draw text You are X at x:20 y:20
Else
Draw text You are O at x:20 y:20
What this does: global.player_id is assigned automatically — the host is always 0 (so it's X, going first), and each joining player counts up from there. global.player_count tells you how many players have connected so far.

Test the Connection!

Press F5 on two computers!

  • Press H on one, J on the other
  • Both should stop showing "Waiting for opponent..." and show "You are X" / "You are O"
  • If the host can't be reached, the game keeps running single-player — it never freezes or crashes
