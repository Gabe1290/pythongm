Phase 2: Host a Game / Join a Game

Now let's connect two computers through a shared folder. One will host (the referee), and the other will join. Everything below still goes on obj_game, the same object from Phase 1.

Before you start: pick a folder both computers can reach and write to — a shared network drive, or (to build and test the wiring alone first) just a plain folder name, created next to wherever the game runs from. We'll write it into both actions below as tictactoe_files — for real two-computer play, change it to a path both machines can reach (a mapped drive letter, or a UNC path like \\server\share\tictactoe).

Host on Key H, Join on Key J

Run the exact same project on both computers, and press a different key on each. Each branch also fixes this machine's mark once, in my_mark:

Key press: H
Host a Game (File Exchange) folder:tictactoe_files max players:2 player name:Player 1
Set variable my_mark to X
Key press: J
Join a Game (File Exchange) folder:tictactoe_files player name:Player 2
Set variable my_mark to O
Why keys, not a menu? It's the simplest way to test both roles from the very same project — press H on one computer, J on the other (or both, in two Test Game windows on one computer, the way the bundled fichier_1 sample supports a quick solo check). A real classroom game might instead ask "Host or Join?" on a title screen, but that's UI polish, not something this tutorial needs to teach.

Show Connection Status

  1. Add to obj_game's When drawing event, before the grid-drawing from Phase 1:
When drawing
If global.waiting_for_players == 1 then
Draw text Waiting for opponent... at x:170 y:40
Exit Event
Draw text "You are " + my_mark at x:170 y:40
What this does: global.waiting_for_players is 1 until the game has as many players as its Max Players setting (here, 2), then 0 — no need to count players yourself. Exit Event stops the grid from drawing at all while still waiting, the same way the bundled sample keeps its "press H / press J" screen up until someone connects. global.player_id is assigned automatically: the host is always 0, and each joining player counts up from there — not used directly here since my_mark already captures the same information.

Test the Connection!

Press F5 on two computers!

  • Press H on one, J on the other
  • Both should stop showing "Waiting for opponent..." and show "You are X" / "You are O", followed by the board
  • If the host can't be reached, the game keeps running single-player — it never freezes or crashes
