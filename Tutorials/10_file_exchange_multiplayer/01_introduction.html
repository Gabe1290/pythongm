Turn-Based Multiplayer: Tic-Tac-Toe by File Exchange

📄

Two players, one shared folder, no live connection.

Play Tic-Tac-Toe against a friend on another computer — your moves travel as small files on a shared drive instead of over a direct network connection.

What We'll Build

A two-player Tic-Tac-Toe game. One computer hosts, the other joins, and every move is written to (and read from) a shared folder both computers can reach — no direct connection between the two machines at all. The game is playable at the end of every phase, so you can stop and try it whenever you want.

This isn't a new idea. Before everyone had an always-on internet connection, whole genres of multiplayer games worked exactly this way: a player's turn was written to a file, handed to (or shared with) the next player, and the game read whichever file was current. Classic strategy games like VGA Planets (1992) and Stars! (1995) worked this way, and the idea itself goes back further still — to play-by-mail games, where a human "judge" collected every player's mailed-in move and mailed back the result. We're building a small, modern version of the same idea.

How This Tutorial Works

Phase 1 — The Board
Build a 3×3 grid you can click to place an X. No networking yet — test it entirely on your own first.
Phase 2 — Host a Game / Join a Game
Connect two computers through a shared folder and find out whether you're playing X or O.
Phase 3 — Taking Real Turns
Only let the player whose turn it is click, submit the move, and redraw the board once both computers agree what happened.
Phase 4 — Winning and Playing Again
Check for three in a row, announce the winner, and let both players start a fresh game.

What You'll Learn

  • The Host a Game (File Exchange) / Join a Game (File Exchange) actions, and why this extension uses a shared folder instead of a live connection
  • Reading identity globals like global.player_id and global.round_number
  • Staging a move with Set a Shared Variable (File Exchange) and submitting it with End Turn (File Exchange)
  • Reacting to the Round Resolved event to redraw the board once a turn is confirmed
  • Using an If action to gate whose turn it is
Time Required: About 25–30 minutes. Note: Phases 1 and most of Phase 2 can be built and tested alone; fully testing Phases 2–4 needs a second computer (or a friend) and a shared folder both computers can reach. You can also try both roles on ONE computer by pressing both keys yourself in two runs, the same way the bundled fichier_1 sample (its own finished version of this game) supports testing solo.
