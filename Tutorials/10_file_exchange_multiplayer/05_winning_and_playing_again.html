Phase 4: Winning and Playing Again

Last piece: check for three marks in a row, announce the winner on both screens, and let both players start over.

Check One Line

  1. Open obj_controller's Round Resolved event (add one if it doesn't have it yet) and add this, checking the top row:
Round Resolved
If global.cell_100_100 == global.cell_300_100 and global.cell_300_100 == global.cell_500_100 and global.cell_100_100 != "" then
Set variable winner to global.cell_100_100
What this does: if all three cells in the line hold the same mark, and that mark isn't blank, someone just won on this line — winner becomes whichever mark it was.

Eight If blocks total in the Round Resolved event — tedious to type, but each one is identical in shape to the first.

Show the Winner

  1. Add a Create event to obj_controller that sets winner to "" (so there's no leftover winner from a previous game)
  2. Add a When drawing event:
When drawing
If winner != "" then
Draw text winner + " wins! Press SPACE to play again." at x:80 y:650

Play Again

Either player can restart once there's a winner:

Key press: Space
If winner != "" then
Leave Game (Files)
What this does: Leave Game (Files) stops this session cleanly without touching the other player's files. Press H or J again (from Phase 2) on both computers to start a fresh game.

Test the Full Game!

Press F5 on both computers!

  • Host and join as in Phase 2
  • Take turns as in Phase 3, X then O
  • Get three in a row → both screens announce the winner
  • Press SPACE, then H/J again, to play a fresh game
