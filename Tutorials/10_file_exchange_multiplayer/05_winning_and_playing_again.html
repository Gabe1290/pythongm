Phase 4: Winning and Playing Again

Last piece: check for three marks in a row, announce the winner on both screens, and let both players start over.

Check One Line

  1. Add a Round Resolved event to obj_game and add this, checking the top row (cell_0_0, cell_1_0, cell_2_0):
Round Resolved
If global.cell_0_0 == global.cell_1_0 and global.cell_1_0 == global.cell_2_0 and global.cell_0_0 != 0 then
Set variable winner to global.cell_0_0
What this does: if all three cells in the line hold the same mark, and that shared variable has actually been set (remember, an untouched one reads as the number 0, not blank), someone just won on this line — winner becomes whichever mark it was.

Check the Other Seven Lines

Repeat the exact same pattern for each of these lines — three cell names, all equal, not 0:

Eight If blocks total in the Round Resolved event — tedious to type, but each one is identical in shape to the first (and matches the bundled fichier_1 sample's own board layout exactly, if you want to compare).

Show the Winner

  1. Add to obj_game's Create event: set winner to "" (so there's no leftover winner from a previous game)
  2. Add to the When drawing event, after everything from Phases 1–3:
If winner != "" then
Draw text winner + " wins! Press SPACE to play again." at x:80 y:650

Play Again

Either player can restart once there's a winner:

Key press: Space
If winner != "" then
Leave the Game (File Exchange)
What this does: Leave the Game (File Exchange) stops this session cleanly without touching the other player's files. Press H or J again (from Phase 2) on both computers to start a fresh game — the nine cell_* variables and winner all need resetting too if you want a truly clean rematch without restarting the whole project (left as a "Try this next," below).

Test the Full Game!

Press F5 on both computers!

  • Get three in a row → both screens announce the winner
  • Press SPACE, then H/J again, to play a fresh game

You Built a File-Exchange Multiplayer Game!

That's a complete turn-based multiplayer loop, using the same idea games like VGA Planets used decades ago — no live connection, no firewall problem, just files on a shared folder:

  • Hosting and joining through a shared folder instead of a direct connection
  • Staging a move and submitting it with End Turn (File Exchange)
  • Gating whose turn it is, and passing when it isn't
  • Reacting to Round Resolved to stay in sync across machines
  • A complete win check and a way to play again
