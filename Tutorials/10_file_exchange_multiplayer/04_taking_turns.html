Phase 3: Taking Real Turns

Right now, clicking a cell only changes it on your screen. This phase makes a click travel through the shared folder so both computers agree on the board — and makes sure only the player whose turn it is can click at all.

Give Every Cell a Unique Name

Since every cell shares the same x/y-based position, we can build a name for its shared variable straight from that position — no per-cell setup needed, every cell runs the exact same code. We'll write that name as "cell_" + string(x) + "_" + string(y) wherever we need it below.

Whose Turn Is It?

Two players alternate, and global.round_number counts up by one every time a move is confirmed. The player whose turn it is right now is whichever global.player_id matches the round number's remainder after dividing by 2:

If global.turn_ready == 1 and global.round_number mod 2 == global.player_id then

Player 0 (the host, X) goes on round 0, 2, 4… Player 1 (O) goes on round 1, 3, 5… global.turn_ready makes sure this doesn't fire again mid-round, before the last move has actually resolved.

Rewrite the Click Handler

  1. Open obj_cell's Mouse: Left Button Pressed event and replace it with this:
Mouse: Left Button Pressed
If mark == "" and global.turn_ready == 1 and global.round_number mod 2 == global.player_id then

Then, still inside that If, one branch per player — each writes its own symbol to this cell's shared variable:

If global.player_id == 0 then
Set Shared Variable "cell_" + string(x) + "_" + string(y) = X
Else
Set Shared Variable "cell_" + string(x) + "_" + string(y) = O
End Turn
What this does: the active player writes their own symbol into this cell's own shared variable, then End Turn submits it. Nobody else can write to this cell this round — only the player whose turn it is gets past the outer If at all.

Redraw the Board When a Round Resolves

Right now mark only ever changes locally. Let's make it follow the published state instead:

Round Resolved
Get Shared Variable "cell_" + string(x) + "_" + string(y) into mark
What this does: Round Resolved fires on every machine once the host has published the new state for a round. Each cell asks "what does the shared variable with my name say now?" and updates its own mark — the same When drawing event from Phase 1 draws whatever that turns out to be, with no changes needed there at all.

  • The mark appears on both screens once the round resolves — not instantly on your own screen either
  • Turns alternate automatically: X, then O, then X…
