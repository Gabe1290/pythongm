Phase 3: Taking Real Turns

Right now, clicking a cell only changes it on your screen. This phase makes a click travel through the shared folder so both computers agree on the board — and makes sure only the player whose turn it is can click at all.

Track Whose Turn It Is

  1. Add to obj_game's Create event (from Phase 1): set last_round_acted to 0 and my_turn to 0
  2. Add a Step event:
If (global.round_number mod 2 == 1 and my_mark == "X") or (global.round_number mod 2 == 0 and my_mark == "O") then
Set variable my_turn to 1
Else
Set variable my_turn to 0

The first published round is round 1, not 0 — so X (the host) goes on the odd rounds, O on the even ones.

Still in the same Step event, right after: the player who is not on turn still needs to submit something, or the round would sit waiting out the full deadline every time:

If my_turn == 0 and last_round_acted != global.round_number then
End Turn (File Exchange)
Set variable last_round_acted to global.round_number
What this does: a "pass" — submitted with nothing staged, once per round (last_round_acted stops it firing every single frame). The active player will submit something real instead, from the click handler below.

Rewrite the Click Handler

Guard every one of Phase 1's nine click checks with my_turn == 1, and replace the local Set Variable with a real network write + submit. Cell (0,0), fully worked out:

Mouse: Left Button Pressed
If cell_0_0 == "" and my_turn == 1 and mouse_x >= 170 and mouse_x < 270 and mouse_y >= 90 and mouse_y < 190 then
Set a Shared Variable (File Exchange) name:cell_0_0 value:my_mark
End Turn (File Exchange)

Same shape for the other eight — same rectangles as Phase 1's table, each writing its own literal cell name.

What this does: the active player writes their own mark into that cell's shared variable by its literal name (the Name parameter is always a plain typed name here, never a computed expression), then End Turn (File Exchange) submits it.

Draw From the Published Board, Not the Local Guess

Replace Phase 1's drawing check for each cell — read the shared version instead of the local one. A shared variable nobody has set yet reads as the number 0, not an empty string. Cell (0,0):

When drawing
If global.cell_0_0 != 0 then
Draw text global.cell_0_0 at x:205 y:115

Same shape for the other eight, same positions as Phase 1.

What this does: a variable set with Set a Shared Variable (File Exchange) is readable everywhere, on every machine, as global.<name> — no extra action needed to fetch it, as long as the name is a literal like cell_0_0 here (a name built at runtime, like a position-derived one, would need Read a Shared Variable (File Exchange) instead, since that action's own Name field does accept an expression). This only takes effect once the host has actually published a round, though — not the instant you click.

  • The mark appears on both screens once the round resolves — not instantly on your own screen either
  • Turns alternate automatically: X, then O, then X…
