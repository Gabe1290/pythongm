Fase 1: Jugador y paredes

¡Vamos a crear un jugador que camina por una cuadrícula dentro de una sala con paredes!

Crear los sprites

  1. Haz clic derecho en Sprites en el árbol de recursos → Crear sprite
  2. Llámalo spr_player (32×32 píxeles)
  3. Dibuja un personaje sencillo o impórtalo de Tutorials/05_sokoban/assets/
  4. Pulsa Ctrl+S para guardar
  1. Crea otro sprite: spr_wall (32×32 píxeles)
  2. Dibuja un motivo oscuro de ladrillo o piedra, o impórtalo de Tutorials/05_sokoban/assets/
  3. Pulsa Ctrl+S para guardar

Crear los objetos

  1. Haz clic derecho en Objetos → Crear objeto
  2. Llámalo obj_wall y asígnale el sprite spr_wall
  3. Marca la casilla Sólido
  1. Crea otro objeto: obj_player
  2. Asígnale el sprite spr_player

Programar al jugador (Blockly)

  1. Haz doble clic en obj_player para abrir el editor de objetos
  2. Haz clic en la pestaña Blockly

Mover a la derecha

Key press: Right Arrow
Move grid right size 32

Busca Key press en la categoría Events y elige Right Arrow. Luego busca Move grid en la categoría Movement, pon la dirección en right y el tamaño en 32.

Mover a la izquierda, arriba y abajo

Repite para las otras tres direcciones:

Key press: Left Arrow
Move grid left size 32
Key press: Up Arrow
Move grid up size 32
Key press: Down Arrow
Move grid down size 32

Cada evento Key press se activa una vez por pulsación — ¡perfecto para moverse en cuadrícula!

Detenerse en las paredes

When colliding with obj_wall
Stop movement

Busca Collision en Events y escribe obj_wall. Encaja dentro un bloque Stop Movement. Así el jugador no atraviesa las paredes.

Deberías tener 5 bloques de evento (4 de teclado + 1 de colisión).

Crear la sala

  1. Haz clic derecho en Salas → Crear sala
  2. Llámala room_sokoban
  3. Pon el tamaño en 320×320 píxeles (una cuadrícula de 10×10)
  4. Activa el ajuste a la cuadrícula: 32×32
  1. Coloca obj_wall por todo el borde para formar una sala cerrada
  2. Añade algunas paredes dentro para crear pasillos y esquinas
  3. Coloca obj_player en algún sitio dentro de la sala
Cómo funciona: al pulsar una flecha, el jugador se mueve exactamente 32 píxeles (una casilla de la cuadrícula). Si choca con una pared, se activa el evento de colisión y el movimiento se detiene.
