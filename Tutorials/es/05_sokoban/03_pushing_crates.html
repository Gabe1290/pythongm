Fase 2: Empujar cajas

¡Ahora añadimos cajas que el jugador puede empujar — la mecánica central de Sokoban!

Crear el sprite de la caja

  1. Haz clic derecho en Sprites → Crear sprite
  2. Llámalo spr_crate (32×32 píxeles)
  3. Dibuja una caja marrón o impórtala de Tutorials/05_sokoban/assets/
  4. Pulsa Ctrl+S para guardar

Crear el objeto de la caja

  1. Haz clic derecho en Objetos → Crear objeto
  2. Llámalo obj_crate y asígnale el sprite spr_crate
  3. Marca la casilla Sólido

Cambiar al jugador: empujar cajas

  1. Haz doble clic en obj_player para abrir el editor de objetos
  2. Haz clic en la pestaña Blockly
  3. Añade un nuevo evento de colisión con obj_crate:
When colliding with obj_crate
If Can Push box in direction facing then push and move else stop movement

Busca Collision en Events y escribe obj_crate. Luego busca If Can Push en Control — es un solo bloque que comprueba si la caja se puede empujar en la dirección en que se mueve el jugador, y hace el empujón él mismo: Object Type box, Direction facing, Then Action push and move, Else Action stop movement.

Cómo funciona el empujón: cuando el jugador choca con una caja, el motor comprueba si el espacio detrás de la caja (en la dirección en que se mueve el jugador) está libre. Si lo está, la caja avanza una casilla. Si detrás hay una pared u otra caja, el empujón queda bloqueado.

Programar la caja: detenerse en las paredes

  1. Haz doble clic en obj_crate para abrir el editor de objetos
  2. Haz clic en la pestaña Blockly
  3. Añade un evento de colisión con obj_wall:
When colliding with obj_wall
Stop movement

Así las cajas se detienen al chocar con una pared.

Cambiar la sala

  1. Abre room_sokoban
  2. Coloca 2–3 instancias de obj_crate dentro de la sala
  3. Asegúrate de que cada caja tenga espacio para empujarla
Consejo: no pongas una caja pegada a una esquina — ¡quedaría atascada desde el principio!

¡Prueba tu juego!

¡Pulsa F5 para jugar!

  • Acércate a una caja y empújala con las flechas
  • Las cajas avanzan una casilla al empujarlas
  • Las cajas se detienen al chocar con una pared
  • No puedes empujar una caja si detrás hay otra caja o una pared
¡Haz clic en «Siguiente» para añadir destinos y terminar el juego!
