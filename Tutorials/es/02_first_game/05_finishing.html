Fase 4: Los últimos detalles

¡Vamos a pulir tu juego para que se sienta terminado!

Mantener al jugador en la pantalla

Abre obj_player en el editor Blockly y añade un evento Every step con comprobaciones de los bordes:

  • If my position: x position < 0 then Set variable x to 0
  • If my position: x position > 608 then Set variable x to 608 (608 = ancho de la sala 640 − ancho del sprite 32)

Así el jugador no puede salir de la pantalla.

Poner un color de fondo

Abre room_game en el editor de salas y pon como color de fondo un bonito azul cielo o un color oscuro de espacio.

¡Enhorabuena!

¡Tu primer juego está terminado!

Pulsa F5 para jugar al juego terminado. ¡Atrapa todas las estrellas que puedas!

Ideas de retos

Want to go further? Try these:
  • Añade vidas — pierde una vida cuando una estrella llega abajo
  • Haz que las estrellas caigan más rápido a medida que sube la puntuación
  • Añade estrellas de distintos colores que valgan puntos distintos
  • Añade un objeto «malo» (una bomba) que termine el juego si lo atrapas
  • Añade efectos de sonido al atrapar estrellas
