Fase 1: Un jugador que se mueve

¡Vamos a crear un jugador, ponerlo en una sala y hacer que se mueva enseguida!

Crear un proyecto nuevo

Ve a Archivo > Nuevo proyecto y llámalo CatchTheStar.

Crear el sprite del jugador

  1. Haz clic derecho en Sprites en el árbol de recursos → Crear sprite
  2. Llámalo spr_player
  3. Haz doble clic en él para abrir el editor de sprites y dibuja un personaje sencillo de 32×32 (una nave, una persona o una cesta). Pulsa Ctrl+S para guardar.

Crear el objeto del jugador

  1. Haz clic derecho en Objetos → Crear objeto
  2. Llámalo obj_player
  3. Asígnale el sprite spr_player

Crear la sala

  1. Haz clic derecho en Salas → Crear sala
  2. Llámala room_game
  3. Abre la sala y coloca obj_player cerca del centro de la parte inferior

Añadir el movimiento del jugador

  1. Haz doble clic en obj_player para abrir el editor de objetos
  2. Haz clic en la pestaña Blockly

Mover a la izquierda

Keyboard: Left Arrow (held)
Set horizontal speed to -5

Mover a la derecha

Keyboard: Right Arrow (held)
Set horizontal speed to 5

Detenerse cuando no se pulsa ninguna tecla

Keyboard: No key
Stop movement

Deberías tener 3 bloques de evento.

¡Prueba tu juego!

¡Pulsa F5 para jugar!

  • Usa las flechas izquierda y derecha para mover al jugador
  • El jugador puede salirse de la pantalla — ¡lo arreglaremos más adelante!
Haz clic en «Siguiente» para añadir estrellas que caen.
