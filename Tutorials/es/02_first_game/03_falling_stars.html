Fase 2: Estrellas que caen

¡Ahora haremos que aparezcan estrellas en la parte superior de la pantalla y que caigan!

Crear el sprite de la estrella

  1. Crea un sprite nuevo llamado spr_star
  2. Dibuja una estrella o una moneda (32×32 píxeles) y guarda

Crear el objeto de la estrella

  1. Crea un objeto nuevo llamado obj_star
  2. Asígnale el sprite spr_star

Hacer que caigan las estrellas

  1. Doble clic en obj_star → pestaña Blockly
  2. Añade este bloque:
When created
Set vertical speed to 3

Cada estrella cae a velocidad 3 en cuanto aparece.

Crear un generador

Necesitamos un objeto invisible que cree estrellas en posiciones aleatorias.

  1. Crea un objeto nuevo llamado obj_spawner
  2. No necesita sprite (será invisible)

Programar el generador

  1. Doble clic en obj_spawner → pestaña Blockly
  2. Añade estos bloques:
When created
Set Alarm 0 to 60 steps
When alarm 0 triggers
Create instance of obj_star at x: random y: 0
Set Alarm 0 to 60 steps

El evento When created pone en marcha un temporizador. Cuando suena la alarma (cada segundo), crea una estrella en una posición x aleatoria en la parte superior de la pantalla y vuelve a poner el temporizador.

Colocar el generador en la sala

  1. Abre room_game
  2. Coloca obj_spawner en cualquier sitio (es invisible, la posición no importa)

¡Prueba tu juego!

¡Pulsa F5 para jugar!

  • Las estrellas deberían caer desde posiciones aleatorias de arriba
  • Mueve al jugador para esquivarlas o alcanzarlas
  • De momento las estrellas atraviesan al jugador — ¡enseguida añadimos la captura!
