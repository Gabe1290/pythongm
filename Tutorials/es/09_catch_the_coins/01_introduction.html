¡Atrapa las monedas!

💰

Atrapa cada moneda — ¡sin chocar con el enemigo!

Muévete a izquierda y derecha, recoge todas las monedas que caen para ganar, y evita al enemigo o se acaba el juego.

Lo que vamos a construir

Crearás un juego completo con un estado claro de victoria y de derrota. El juego será jugable al final de cada fase, así que puedes detenerte y probarlo cuando quieras.

Cómo funciona este tutorial

Fase 1 — Un jugador en movimiento
Crea un jugador que se mueva a izquierda y derecha. ¡Pruébalo enseguida!
Fase 2 — Monedas y un enemigo
Añade monedas que caen del cielo, más un enemigo. Colócalos en la sala.
Fase 3 — Atrapar y chocar
Atrapa monedas para sumar puntos, choca con el enemigo y el juego termina.
Fase 4 — Ganar el juego
Añade una pantalla de victoria que aparece cuando se han atrapado todas las monedas.

Lo que aprenderás

  • Crear sprites, objetos y salas
  • Usar eventos de teclado para controlar al jugador
  • Detectar colisiones entre objetos
  • Registrar y mostrar una puntuación
  • Usar transiciones de sala para las pantallas de fin de juego y de victoria
  • Usar el bloque If Condition para comprobar cuántos objetos quedan
Tiempo necesario: Unos 15–20 minutos
