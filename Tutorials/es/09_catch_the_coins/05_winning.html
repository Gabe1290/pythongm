Fase 4: Ganar el juego

Ahora mismo el jugador puede perder, pero no hay forma de ganar. Lo arreglaremos comprobando después de cada paso: "¿Quedan monedas?" — si no quedan, vamos a una sala de victoria completamente nueva.

Construye la sala de victoria

Crea el sprite de victoria (opcional)

Si quieres un aspecto festivo, crea un sprite llamado spr_win_text. Este paso es opcional — el texto dibujado en el siguiente paso funciona sin sprite.

Crea el objeto de texto de victoria

  1. Clic derecho en Objetos → Crear nuevo objeto
  2. Llámalo obj_win_text
  3. Abre la pestaña Blockly y añade estos dos eventos:

Muestra el mensaje de victoria:

When drawing
Draw text ¡GANASTE! at x:412 y:320
Draw text Pulsa ESPACIO para jugar de nuevo at x:340 y:400

Reinicia con espacio:

Key press: space
Restart Game

Crea la sala de victoria

  1. Clic derecho en Salas → Crear nueva sala
  2. Llámala room_win
  3. Pon el color de fondo en un color festivo (verde claro o dorado)
  4. Coloca una instancia de obj_win_text en cualquier lugar de la sala (su dibujo está en coordenadas fijas)

La comprobación de victoria

Ahora la parte importante: en cada paso, el jugador comprueba si quedan monedas. Cuando el conteo llega a cero, vamos a la sala de victoria.

  1. Abre obj_player
  2. Haz clic en la pestaña Blockly
  3. Añade este evento Step:
Every step
If count of obj_coin == 0 then
Go to room room_win
Qué hace esto: El bloque If Count Of mira la sala y cuenta cuántas instancias de obj_coin siguen vivas. Cuando las has atrapado todas, el conteo es cero, la comparación == 0 es verdadera, y la acción Go to room se ejecuta.

¡Prueba tu juego completo!

¡Pulsa F5 para jugar!

  • Atrapa cada moneda → aparece la pantalla ¡GANASTE!
  • Toca al enemigo → aparece la pantalla GAME OVER
  • Pulsa ESPACIO desde cualquiera de los dos finales para volver a jugar

¡Has construido un juego completo!

Felicidades — eso es un bucle de juego completo con:

  • Entrada del jugador (movimiento por teclado)
  • Dos tipos de colisión (buena y mala)
  • Una puntuación que el jugador puede ver crecer
  • Un estado claro de victoria y de derrota
  • Una forma de reiniciar y volver a intentarlo
Prueba esto a continuación: añade más monedas, coloca un segundo enemigo, o cambia las velocidades de la moneda y el enemigo en sus eventos When created. Cada cambio es solo un número que puedes editar y probar.
