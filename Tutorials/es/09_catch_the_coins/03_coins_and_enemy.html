Fase 2: Monedas y un enemigo

Ahora añadiremos las monedas para recoger y un enemigo para evitar. Ambos caen en línea recta.

Crea el sprite de la moneda

  1. Clic derecho en Sprites → Crear nuevo sprite
  2. Llámalo spr_coin
  3. Abre el Editor de sprites y dibuja un círculo amarillo de 24×24. Guarda con Ctrl+S.

Crea el sprite del enemigo

  1. Repite los pasos anteriores para un sprite llamado spr_enemy
  2. Dibuja un cuadrado rojo de 32×32 para que el enemigo sea fácil de detectar

Crea el objeto de la moneda

  1. Clic derecho en Objetos → Crear nuevo objeto
  2. Llámalo obj_coin
  3. Asigna el sprite spr_coin
  4. Abre la pestaña Blockly y añade esto:
When created
Set vertical speed to 3

Crea el objeto del enemigo

  1. Crea otro objeto llamado obj_enemy
  2. Asigna su sprite a spr_enemy
  3. Añade el mismo evento When created para que también caiga:
When created
Set vertical speed to 3

Colócalos en la sala

  1. Abre room_main
  2. Coloca de 5 a 8 monedas repartidas horizontalmente por la parte superior de la sala
  3. Coloca 1 enemigo en algún lugar de la parte superior, entre las monedas
  4. Asegúrate de que obj_player sigue en el centro inferior
Consejo: El número de monedas es la puntuación que el jugador necesita alcanzar para ganar. Empieza con 5 para una demostración rápida — siempre puedes añadir más después.

¡Prueba tu juego!

¡Pulsa F5 para jugar!

  • Las monedas y el enemigo deberían caer desde la parte superior de la sala
  • El jugador puede moverse a izquierda y derecha debajo de ellos
