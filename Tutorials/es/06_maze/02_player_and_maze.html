Fase 1: Jugador y laberinto

En esta fase crearás los sprites del jugador y de la pared, construirás los objetos, programarás el movimiento con Blockly, harás que el jugador mire en la dirección en la que camina y diseñarás un laberinto sencillo. ¡Al final podrás caminar por tu laberinto!

Paso 1: Crear los sprites

spr_player (32x32)

  1. En el árbol de recursos, haz clic derecho en Sprites y elige Crear sprite
  2. Llámalo spr_player

Opción A — Dibújalo tú mismo

  1. Haz doble clic en spr_player para abrir el editor de sprites
  2. Pon el tamaño en 32x32 píxeles
  3. Dibuja un personaje pequeño (un círculo con ojos o una persona sencilla)
  4. Usa un color vivo, como azul
  5. Guarda con Ctrl+S

Opción B — Carga el sprite de ejemplo

  1. Haz clic derecho en spr_player en el árbol de recursos
  2. Elige Importar imagen...
  3. Busca Tutorials/06_maze/assets/
  4. Elige spr_player.png y haz clic en Abrir

spr_wall (32x32)

  1. Crea un sprite nuevo llamado spr_wall

Opción A — Dibújalo tú mismo

  1. Abre el editor de sprites y pon el tamaño en 32x32 píxeles
  2. Dibuja un motivo de ladrillo o de piedra
  3. Usa colores grises o marrones

Opción B — Carga el sprite de ejemplo

  1. Clic derecho en spr_wall → Importar imagen...
  2. Elige Tutorials/06_maze/assets/spr_wall.png

Paso 2: Crear los objetos

obj_wall (sólido)

  1. Haz clic derecho en Objetos → Crear objeto
  2. Llámalo obj_wall
  3. Asígnale el sprite spr_wall
  4. Marca «Sólido» — es imprescindible para que el jugador no atraviese las paredes
  5. La pared no necesita eventos

obj_player

  1. Crea un objeto nuevo llamado obj_player
  2. Asígnale el sprite spr_player
  3. Deja «Sólido» sin marcar

Paso 3: Programar al jugador (Blockly)

Cómo funciona Blockly: arrastra bloques desde la caja de herramientas de la izquierda al área de trabajo. Encaja bloques de acción dentro de bloques de evento para indicar qué ocurre. Tus bloques se guardan automáticamente en el panel de eventos mientras editas.
  1. Haz doble clic en obj_player en el árbol de recursos para abrir el editor de objetos
  2. Haz clic en la pestaña Blockly de la parte de arriba del editor

Mover a la derecha

Keyboard: Right Arrow (held)
Set horizontal speed to 4

Busca Keyboard (held) en la categoría Events y elige Right Arrow en la lista desplegable. Luego busca Set Horizontal Speed en la categoría Movement y encájalo dentro. Escribe 4 en el campo del número.

Mover a la izquierda

Keyboard: Left Arrow (held)
Set horizontal speed to -4

Igual que arriba, pero elige Left Arrow y escribe -4 (negativo = hacia la izquierda).

Mover hacia abajo

Keyboard: Down Arrow (held)
Set vertical speed to 4

Usa Set Vertical Speed de Movement. Positivo = hacia abajo.

Mover hacia arriba

Keyboard: Up Arrow (held)
Set vertical speed to -4

Escribe -4 para moverte hacia arriba.

Detenerse cuando no se pulsa ninguna tecla

Keyboard: No key
Stop movement

Busca Keyboard: No key en Events y Stop Movement en Movement. ¡Así el jugador no sigue deslizándose sin fin!

Detenerse en las paredes

When colliding with obj_wall
Stop movement

Busca Collision en Events. Escribe obj_wall en el campo de texto. Encaja dentro un bloque Stop Movement.

Deberías tener 6 bloques de evento en el área de trabajo.

Cómo funciona: cada flecha pone la velocidad en su dirección. Cuando sueltas todas las teclas, el jugador se detiene. Si choca con una pared, también se detiene.

Paso 3B: Haz que tu jugador mire hacia donde va

Ahora mismo tu jugador se ve siempre igual, vaya en la dirección que vaya. Muchos juegos muestran una imagen distinta para cada dirección — un sprite distinto según hacia dónde mira el personaje. Ya construiste los 4 eventos de las flechas; en este paso solo se añade un bloque más a cada uno.

spr_player_up / _down / _left / _right (24x24)

  1. Crea 4 sprites nuevos: spr_player_up, spr_player_down, spr_player_left, spr_player_right

Opción A — Dibújalos tú mismo

  1. Dale a cada uno el mismo tamaño que spr_player
  2. Dibuja el mismo personaje pequeño, pero mueve los ojos (o una flecha) para mostrar hacia dónde mira: los dos ojos para _down, sin cara para _up (la parte de atrás de la cabeza), un ojo en ese lado para _left / _right

Opción B — Carga los sprites de ejemplo

  1. Clic derecho en cada sprite nuevo → Importar imagen...
  2. Busca Tutorials/06_maze/assets/
  3. Elige el archivo correspondiente (spr_player_up.png, spr_player_down.png, spr_player_left.png, spr_player_right.png)

Añadir un bloque Set Sprite a cada flecha

  1. Haz doble clic en obj_player para abrir el editor de objetos (si no está ya abierto) y haz clic en la pestaña Blockly
  2. Busca cada uno de tus 4 eventos de flechas del Paso 3 y encaja un bloque más dentro — Set Sprite (de la categoría Instance)
Keyboard: Right Arrow (held)
Set horizontal speed to 4
Set sprite to spr_player_right
Keyboard: Left Arrow (held)
Set horizontal speed to -4
Set sprite to spr_player_left
Keyboard: Up Arrow (held)
Set vertical speed to -4
Set sprite to spr_player_up
Keyboard: Down Arrow (held)
Set vertical speed to 4
Set sprite to spr_player_down

Deja Keyboard: No key y When colliding with obj_wall tal como estaban — el jugador simplemente sigue mostrando la última dirección en la que se movió.

Cómo funciona: ahora cada flecha hace dos cosas: pone la velocidad y elige la imagen correspondiente. El sprite del jugador muestra siempre la última dirección que pulsaste, aunque te detengas.

Paso 4: Crear la sala

  1. Haz clic derecho en Salas → Crear sala
  2. Llámala room_maze
  3. Pon el tamaño en 640x480
  4. Activa el ajuste a la cuadrícula: 32x32

Construir un laberinto sencillo

  1. Elige obj_wall y haz clic para poner paredes alrededor del borde
  2. Añade paredes interiores para crear pasillos y caminos
  3. Coloca obj_player cerca de la esquina superior izquierda del laberinto
  4. Deja algo de espacio libre para poder caminar
