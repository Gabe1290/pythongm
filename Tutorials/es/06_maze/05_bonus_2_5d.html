Extra: hazlo en 2.5D

Esta página es opcional. Tu juego de laberinto ya está terminado — esto es un extra para quien quiera probar algo nuevo. Ni laberinto nuevo ni dibujos nuevos para el laberinto: verás exactamente el mismo laberinto desde dentro, al estilo de Doom o Wolfenstein.

¿Recuerdas la Fase 1, en la que tu jugador mostraba una imagen distinta para cada dirección en la que se movía? Eso era la dirección en la que mira. Una cámara en primera persona necesita exactamente la misma idea — hacia dónde apunta — solo que, en lugar de elegir una imagen, usa esa dirección para decidir qué dibujar. Ya conoces este patrón; vas a volver a usarlo.

Activar la vista 2.5D

When created
Enable Raycast View — Field of View 66 Cell Size 32 Render Distance 20
  1. Haz doble clic en obj_player para abrir el editor de objetos y haz clic en la pestaña Blockly
  2. Añade un nuevo evento When created (de Events)
  3. Busca Enable Raycast View en la categoría 3D View y encájalo dentro
  4. Pon Cell Size en 32 — tiene que coincidir con la cuadrícula de tu laberinto
  5. Deja Camera Object vacío — eso significa «quien ejecute esta acción», es decir, el jugador
¿No ves 3D View en la caja de herramientas? Abre Archivo → Configuración del proyecto... → Extensiones y marca 2.5D Raycast View.

Hacer que la cámara mire hacia donde mira tu sprite

Vuelve a los mismos 4 eventos de las flechas de la Fase 1 y añade un bloque más a cada uno — Set Facing Angle (de 3D View), con los ángulos de una brújula: 0 = derecha, 90 = arriba, 180 = izquierda, 270 = abajo.

Keyboard: Right Arrow (held)
Set horizontal speed to 4
Set sprite to spr_player_right
Set Facing Angle 0
Keyboard: Left Arrow (held)
Set horizontal speed to -4
Set sprite to spr_player_left
Set Facing Angle 180
Keyboard: Up Arrow (held)
Set vertical speed to -4
Set sprite to spr_player_up
Set Facing Angle 90
Keyboard: Down Arrow (held)
Set vertical speed to 4
Set sprite to spr_player_down
Set Facing Angle 270
¿Por qué no reutilizar el sprite? Set Sprite elige una imagen; Set Facing Angle elige un número (el ángulo). La cámara necesita el número para calcular lo que de verdad verías — paredes, pasillos, todo — desde esa dirección.

Las paredes ya bloquean al jugador

¡Aquí no hay nada que añadir! Tu evento When colliding with obj_wall → Stop movement de la Fase 1 ya hace que las paredes detengan al jugador — funciona exactamente igual tanto si la sala se dibuja desde arriba como en primera persona.

¡Prueba tu laberinto 2.5D!

¡Pulsa F5 para jugar!

  • Ahora la sala aparece en primera persona en lugar de desde arriba
  • Las paredes llevan como textura tu propia imagen spr_wall — nunca pusiste una textura de pared: cada pared usa su propio sprite automáticamente
  • Al girar miras enseguida hacia la flecha que mantienes pulsada, igual que hacía tu sprite en la Fase 1
  • Chocas con las paredes en lugar de atravesarlas
  • Las monedas y la salida siguen funcionando — aparecen flotando en el aire, mirándote, sin ningún cambio

¿Quieres más?

Hay dos acciones más de 3D View si quieres seguir explorando por tu cuenta: Draw Minimap (un pequeño mapa visto desde arriba en una esquina de la pantalla) y Draw DOOM HUD (una barra de estado clásica con salud y puntuación). Ninguna se explica aquí — ¡prueba a encajar una en el evento When drawing de tu obj_game_controller y mira qué pasa!
