Fase 1: Un módulo que vuela

En esta fase creamos los sprites, los objetos y los controles para volar un módulo con la gravedad lunar. ¡Al final tendrás un módulo jugable con el que volar por la pantalla!

Crear los sprites

spr_lander (32x32) — La nave

  1. Haz clic derecho en Sprites > Crear sprite
  2. Llámalo spr_lander (32x32 píxeles)
  3. Dibuja una nave pequeña (un triángulo o la forma clásica de un módulo lunar), o impórtala de Tutorials/08_lunar_lander/assets/

spr_ground (32x32) — Terreno rocoso

  1. Crea un sprite nuevo llamado spr_ground (32x32 píxeles)
  2. Dibuja terreno rocoso en grises o marrones, o impórtalo de los recursos

Crear los objetos

obj_ground

  1. Haz clic derecho en Objetos > Crear objeto
  2. Llámalo obj_ground y asígnale spr_ground
  3. Marca la casilla Sólido

obj_lander

  1. Crea un objeto nuevo llamado obj_lander
  2. Asígnale spr_lander

Programar el módulo (Blockly)

Haz doble clic en obj_lander y abre la pestaña Blockly.

1. Activar la gravedad (When created)

When created
Set Gravity: direction 270, strength 0.05

Busca When created en la categoría Events. Luego busca Set Gravity en la categoría Movement. Pon la dirección en 270 (abajo) y la fuerza en 0.05.

¿Por qué 0.05? La gravedad de la Luna es más o menos 1/6 de la de la Tierra. Un valor muy bajo como 0.05 hace que el módulo flote despacio — ¡como en un alunizaje de verdad!

2. Propulsión hacia arriba (flecha arriba mantenida)

Keyboard: Up Arrow (held)
Set vertical speed to -2

Busca Keyboard (held) en Events y elige Up Arrow. Añade Set vertical speed to (de Movement) con el valor -2. Una velocidad vertical negativa mueve el módulo hacia arriba (propulsión contra la gravedad).

3. Girar a la izquierda (flecha izquierda mantenida)

Keyboard: Left Arrow (held)
Set horizontal speed to -2

Busca Keyboard (held) en Events y elige Left Arrow. Añade Set horizontal speed to (de Movement) con el valor -2.

4. Girar a la derecha (flecha derecha mantenida)

Keyboard: Right Arrow (held)
Set horizontal speed to 2

Busca Keyboard (held) en Events y elige Right Arrow. Añade Set horizontal speed to (de Movement) con el valor 2.

5. Detener el movimiento horizontal cuando no se pulsa ninguna tecla

Keyboard: No key
Set horizontal speed to 0

Busca Keyboard: No key en Events. Añade Set horizontal speed to con el valor 0. Así se detiene el movimiento horizontal cuando no se pulsa ninguna flecha, ¡pero la gravedad sigue tirando del módulo hacia abajo!

Importante: solo ponemos hspeed a 0, no vspeed. Así la gravedad sigue actuando sobre el módulo cuando no se pulsa ninguna tecla — ¡el módulo sigue cayendo!

Deberías tener 5 bloques de evento (Create + 3 de teclado + No key).

Crear la sala

  1. Haz clic derecho en Salas > Crear sala
  2. Llámala room_game
  3. Pon el tamaño: 640 x 480
  4. Pon el color de fondo en negro (¡el espacio!)
  5. Activa el ajuste a la cuadrícula (32x32)
  6. Coloca bloques obj_ground a lo largo de toda la fila de abajo
  7. Coloca obj_lander cerca de la parte de arriba de la sala

¡Prueba tu juego!

¡Pulsa F5 para jugar!

  • El módulo cae despacio hacia el suelo (¡gravedad lunar!)
  • Flecha arriba: propulsión hacia arriba contra la gravedad
  • Flechas izquierda/derecha: dirigir en horizontal
  • Suelta todas las teclas y mira cómo el módulo baja despacio
