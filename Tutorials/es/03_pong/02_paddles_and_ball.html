Fase 1: Palas y pelota que rebota

¡Vamos a crear todo lo que necesitamos para un Pong jugable!

Crear los sprites

Crea estos 3 sprites (dibújalos o importa imágenes):

SpriteTamañoDescripción
spr_ball16×16Círculo blanco pequeño
spr_paddle16×64Rectángulo alto y estrecho
spr_wall32×32Bloque gris

Crear los objetos

  1. Crea obj_wall — sprite: spr_wall, marca Sólido
  2. Crea obj_paddle_left — sprite: spr_paddle, marca Sólido
  3. Crea obj_paddle_right — sprite: spr_paddle, marca Sólido
  4. Crea obj_ball — sprite: spr_ball, deja Sólido sin marcar

Programar la pala izquierda (Jugador 1: W/S)

Doble clic en obj_paddle_left → pestaña Blockly.

Keyboard: W (held)
Set vertical speed to -8
Keyboard: S (held)
Set vertical speed to 8
Keyboard: No key
Stop movement
When colliding with obj_wall
Stop movement

Programar la pala derecha (Jugador 2: flechas)

Doble clic en obj_paddle_right → pestaña Blockly. La misma estructura, pero con otras teclas:

Keyboard: Up Arrow (held)
Set vertical speed to -8
Keyboard: Down Arrow (held)
Set vertical speed to 8
Keyboard: No key
Stop movement
When colliding with obj_wall
Stop movement

Programar la pelota

Doble clic en obj_ball → pestaña Blockly.

When created
Move or angle 45 at speed 6
When colliding with obj_wall
Bounce
When colliding with obj_paddle_left
Bounce
When colliding with obj_paddle_right
Bounce

Crear la sala

  1. Crea una sala nueva llamada room_pong (640×480)
  2. Coloca obj_wall a lo largo de los bordes superior e inferior
  3. Coloca obj_paddle_left cerca del borde izquierdo, centrada en vertical
  4. Coloca obj_paddle_right cerca del borde derecho, centrada en vertical
  5. Coloca obj_ball en el centro de la sala
+--[WALL WALL WALL WALL WALL WALL]--+
|                                     |
|  [P1]                        [P2]  |
|  [  ]         (o)            [  ]  |
|  [  ]                        [  ]  |
|                                     |
+--[WALL WALL WALL WALL WALL WALL]--+

¡Prueba tu juego!

¡Pulsa F5 para jugar!

  • Jugador 1: W (arriba) y S (abajo)
  • Jugador 2: flecha arriba y flecha abajo
  • La pelota rebota en las paredes y en las palas
  • La pelota se escapa por los lados — ¡enseguida añadimos las porterías!
Haz clic en «Siguiente» para añadir porterías y puntuación.
