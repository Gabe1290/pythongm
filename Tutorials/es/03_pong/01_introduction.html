PONG

¡El clásico juego arcade para dos jugadores!

Lo que vamos a crear

En este tutorial construirás paso a paso un Pong clásico para dos jugadores. ¡Tendrás algo jugable al final de cada fase!

Fase 1 — Palas y pelota
¡Crea las palas, las paredes y una pelota que rebota, y juega enseguida!
Fase 2 — Porterías y puntuación
Añade una portería detrás de cada pala y lleva la cuenta de los puntos.
Fase 3 — Mostrar la puntuación
Muestra los puntos en pantalla con un controlador del juego.

Lo que aprenderás

  • Controles de teclado para dos jugadores (W/S y Arriba/Abajo)
  • Rebotes con detección de colisiones
  • Usar variables globales para llevar la puntuación
  • Mostrar texto en pantalla
Tiempo necesario: unos 20–25 minutos
