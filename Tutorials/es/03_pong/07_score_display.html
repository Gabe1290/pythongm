Paso 6: Mostrar las Puntuaciones

Necesitamos un objeto controlador para inicializar las puntuaciones y mostrarlas.

Crear Objeto Controlador de Puntuación

  1. Crea un nuevo objeto llamado obj_score
  2. No se necesita sprite (déjalo vacío)

Inicializar Puntuaciones (Evento Crear)

  1. Agrega Evento: Crear
  2. Agrega Acción: Control > Establecer variable
  3. Variable: global.p1score, Valor: 0
  4. Agrega otra acción Establecer Variable
  5. Variable: global.p2score, Valor: 0

Dibujar Puntuaciones (Evento Dibujar)

  1. Agrega Evento: Dibujar
  2. Agrega Acción: Juego > Dibujar texto
  3. Texto: Jugador 1:
  4. X: 10, Y: 10
  1. Agrega Acción: Dibujo > Dibujar variable
  2. Variable: global.p1score
  3. X: 100, Y: 10
  1. Agrega Acción: Juego > Dibujar texto
  2. Texto: Jugador 2:
  3. X: 10, Y: 30
  1. Agrega Acción: Dibujo > Dibujar variable
  2. Variable: global.p2score
  3. X: 100, Y: 30
Recuerda: No olvides colocar obj_score en tu habitación!
