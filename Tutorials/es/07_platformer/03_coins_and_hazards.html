Fase 2: Monedas y peligros

Ahora añadimos monedas que recoger, pinchos peligrosos y una bandera a la que llegar. Todo lo programamos como nuevos eventos de colisión de obj_player.

Crear los sprites

  1. Crea el sprite spr_coin, tamaño 32x32 — dibuja un círculo amarillo o dorado (o impórtalo de Tutorials/07_platformer/assets/)
  2. Crea el sprite spr_spike, tamaño 32x32 — dibuja pinchos triangulares hacia arriba
  3. Crea el sprite spr_flag, tamaño 32x32 — dibuja una bandera en un mástil

Crear los objetos

  1. Crea obj_coin y asígnale el sprite spr_coin
  2. Crea obj_spike y asígnale el sprite spr_spike
  3. Crea obj_flag y asígnale el sprite spr_flag
¡Estos objetos no necesitan Blockly! Programaremos todas las interacciones como eventos de colisión de obj_player, ya que es el jugador quien toca las monedas, los pinchos y la bandera.

Programar obj_player — añadir eventos de colisión

Abre el editor Blockly de obj_player (los bloques de la Fase 1 siguen ahí). Añade estos nuevos bloques de evento:

Recoger monedas

When colliding with obj_coin
Add to score 10
Destroy other instance

Busca Collision en Events y escribe obj_coin. Encaja Add to Score (de Score/Lives/Health) con el valor 10. Luego encaja Destroy Instance (de Instance) en Other, para que la moneda desaparezca al recogerla.

Tocar un pincho

When colliding with obj_spike
Restart room

Busca Collision en Events y escribe obj_spike. Encaja Restart Room (de Room) dentro. ¡Cuando el jugador toca un pincho, el nivel vuelve a empezar!

Llegar a la bandera

When colliding with obj_flag
Show message "You Win!"

Busca Collision en Events y escribe obj_flag. Encaja Show Message (de Output) y escribe You Win!. ¡Aparece una ventana cuando el jugador llega a la bandera!

Aplicar tus bloques

  1. Ahora deberías tener 9 bloques de evento en total en obj_player (6 de la Fase 1 + 3 nuevos eventos de colisión)

Cambiar tu sala

  1. Abre room_level1
  2. Coloca obj_coin en las plataformas y en sitios difíciles de alcanzar
  3. Coloca obj_spike cerca de los fosos o en plataformas peligrosas
  4. Coloca obj_flag al final del nivel (a la derecha)
                                        F
                                      ====
                  C           C
                ====        ====
    C                               C
  ====  X     X         X     ====
    P               C
  ====  ====  ====  ====  ====  ====  ====
  GGGGGG      GGGG  GGGG       GGGGGGGGGG

G = Ground    P = Player    F = Flag    C = Coin    X = Spike
Consejo de diseño: pon pinchos cerca de los huecos para crear tensión. Pon monedas en plataformas altas para premiar los buenos saltos. ¡Pon la bandera al fondo para que el jugador tenga que recorrer todo el nivel!
