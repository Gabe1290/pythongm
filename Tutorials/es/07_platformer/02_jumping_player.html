Fase 1: Un jugador que salta

En esta fase creamos el jugador y el suelo, preparamos la gravedad y el movimiento, y construimos una sala con plataformas. ¡Al final podrás correr y saltar!

Crear los sprites

  1. Haz clic derecho en Sprites > Crear sprite
  2. Llámalo spr_player, tamaño 32x32
  3. Dibuja un personaje (o impórtalo de Tutorials/07_platformer/assets/)
  4. Crea otro sprite: spr_ground, tamaño 32x32
  5. Dibuja una baldosa de suelo (arriba verde, abajo marrón) o impórtala

Crear los objetos

  1. Haz clic derecho en Objetos > Crear objeto
  2. Crea obj_ground y asígnale el sprite spr_ground
  3. Marca la casilla Sólido de obj_ground
  4. Crea obj_player y asígnale el sprite spr_player
¿Por qué sólido? Marcar obj_ground como sólido le dice al motor que los demás objetos no deben atravesarlo. ¡Es imprescindible para las plataformas!

Programar obj_player con Blockly

  1. Haz doble clic en obj_player para abrir el editor de objetos
  2. Haz clic en la pestaña Blockly

Activar la gravedad (When created)

When created
Set Gravity: direction 270, strength 0.5

Busca When created en la categoría Events. Luego busca Set Gravity en la categoría Movement. Pon la dirección en 270 (abajo) y la fuerza en 0.5.

Dirección 270 = abajo. Los ángulos empiezan en 0 (derecha) y giran en sentido contrario a las agujas del reloj: 90 = arriba, 180 = izquierda, 270 = abajo.

Mover a la izquierda

Keyboard: Left Arrow (held)
Set horizontal speed to -4

Busca Keyboard (held) en Events y elige Left Arrow. Luego encaja Set Horizontal Speed de Movement con el valor -4 (negativo = izquierda).

Mover a la derecha

Keyboard: Right Arrow (held)
Set horizontal speed to 4

Detenerse cuando no se pulsa ninguna tecla

Keyboard: No key
Set horizontal speed to 0

Así se detiene el movimiento horizontal cuando no se pulsa ninguna tecla. Usamos Set horizontal speed to 0 (NO «Stop Movement») ¡para que la gravedad siga funcionando!

Importante: si aquí usas «Stop Movement», también se anularía la velocidad vertical y la gravedad dejaría de actuar. Poniendo solo la velocidad horizontal a 0, el jugador sigue cayendo con normalidad.

Saltar

Key press: Up Arrow
Set vertical speed to -10

Busca Key press en Events y elige Up Arrow. Pon la velocidad vertical en -10 (negativo = hacia arriba). El evento Press se activa una sola vez y da un único impulso de salto.

Chocar con el suelo

When colliding with obj_ground
Stop movement

Busca Collision en Events y escribe obj_ground. Encaja Stop Movement dentro. Así el jugador no atraviesa el suelo y se detiene al chocar con las paredes.

Deberías tener 6 bloques de evento en el área de trabajo (Create + Left + Right + No key + Press Up + Collision).

Crear la sala

  1. Haz clic derecho en Salas > Crear sala
  2. Llámala room_level1
  3. Pon el tamaño: 800 x 480
  4. Pon como color de fondo un azul claro (el cielo)
  5. Activa el ajuste a la cuadrícula y pon la cuadrícula en 32x32
  6. Coloca obj_ground a lo largo de la fila de abajo
  7. Crea plataformas a distintas alturas colocando más bloques obj_ground en el aire
  8. Coloca un obj_player a la izquierda, encima del suelo

            ====                  ====
    P                 ====
  ====  ====  ====          ====  ====  ====
  GGGGGGGGGGGGGGGG    GGGGGGGGGGGGGGGGGGGGGG

G = Ground (obj_ground)     P = Player (obj_player)
==== = Platforms at different heights
