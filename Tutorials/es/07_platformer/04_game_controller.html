Fase 3: Controlador del juego

El controlador del juego es un objeto invisible que gestiona la puntuación y las vidas en pantalla. Además, cambiamos la colisión con los pinchos para que use un sistema de vidas.

Crear el objeto controlador

  1. Haz clic derecho en Objetos > Crear objeto
  2. Llámalo obj_game_controller
  3. NO le asignes sprite — se queda invisible
¿Qué es un controlador del juego? Es un objeto invisible que funciona en segundo plano para gestionar cosas como la puntuación y las vidas en pantalla. Como no tiene sprite, no aparece en el juego — solo dibuja información en la pantalla.

Programar obj_game_controller con Blockly

  1. Haz doble clic en obj_game_controller para abrir el editor de objetos
  2. Haz clic en la pestaña Blockly

Inicializar la puntuación y las vidas (Other event: Game Start)

Other event: Game Start
Set score to 0
Set lives to 3

Busca Other Events en Events y elige Game Start. Desde Score/Lives/Health, encaja Set Score to con el valor 0 y Set Lives con el valor 3.

¿Por qué Game Start y no When created? Un evento When created se vuelve a ejecutar cada vez que la sala vuelve a empezar — y un pincho reinicia la sala. Si las vidas se pusieran a 3 en When created, cada pincho te devolvería las vidas y nunca se acabarían. Game Start se ejecuta una sola vez, al empezar el juego.

Dibujar la puntuación y las vidas (When drawing)

When drawing
Draw score at x: 10 y: 10
Draw lives at x: 200 y: 10

Busca When drawing en Events. Desde Score/Lives/Health, encaja Draw Score en la posición (10, 10) y Draw Lives en la posición (200, 10). La puntuación y las vidas aparecerán en la parte superior izquierda de la pantalla.

Aplicar tus bloques

  1. Deberías tener 2 bloques de evento (Game Start + Draw)

Cambiar obj_player — colisión con los pinchos y vidas

Ahora abre el editor Blockly de obj_player y cambia la colisión con los pinchos. Busca el bloque de colisión con obj_spike y añade un bloque antes del reinicio:

When colliding with obj_spike
Add to lives -1
Restart room

Añade Add to Lives (de Score/Lives/Health) con el valor -1 antes del bloque Restart Room. ¡Ahora cada pincho cuesta una vida!

Cómo funciona: cuando el jugador toca un pincho, pierde una vida y la sala vuelve a empezar. El controlador del juego muestra en cada fotograma la puntuación actual y las vidas que quedan.

Colocar el controlador en tu sala

  1. Abre room_level1
  2. Coloca un obj_game_controller en cualquier sitio de la sala
  3. Como no tiene sprite, será invisible — la posición no importa

¡Prueba tu juego!

¡Pulsa F5 para jugar!

  • La puntuación y las vidas aparecen en la esquina superior izquierda
  • Recoger monedas aumenta la puntuación
  • Tocar un pincho cuesta una vida y reinicia la sala
  • Al llegar a la bandera aparece «You Win!»

¡Enhorabuena! Has construido un juego de plataformas completo ¡con gravedad, saltos, monedas, peligros, puntuación y vidas!

Ideas de retos

¿Quieres ir más allá? Prueba estas ideas:

  • Plataformas móviles: crea un objeto que se mueva solo a izquierda y derecha
  • Enemigos: añade objetos que patrullen las plataformas y hagan daño al jugador
  • Doble salto: usa una variable para permitir un salto más en el aire
  • Varios niveles: crea más salas y usa «Next Room» en la bandera
  • Fin de la partida: comprueba si las vidas llegan a 0 y muestra un mensaje «Game Over»
