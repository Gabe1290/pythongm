Próximos pasos

Ahora que conoces lo básico, aquí hay algunos temas para explorar:

Agregar movimiento

Abre tu objeto y agrega un evento de Teclado. Usa acciones como "Mover en dirección" o "Establecer velocidad" para hacer que tu objeto responda a las pulsaciones de teclas.

Detección de colisiones

Crea otro objeto (como una pared) y agrega un evento de Colisión a tu jugador. Usa acciones para detener el movimiento o cambiar de dirección cuando los objetos colisionen.

Programación visual con Blockly

PyGameMaker soporta programación visual con Blockly. En el Editor de Objetos, cambia al Modo Blockly para crear comportamientos conectando bloques en lugar de escribir código.

Múltiples habitaciones

Crea más habitaciones para diferentes niveles. Usa la acción "Ir a habitación" para cambiar entre ellas cuando el jugador alcance una meta o puerta.

Exportar tu juego

Cuando tu juego este listo, ve a Archivo > Exportar como HTML5 para crear una versión web que se pueda jugar en cualquier navegador.
