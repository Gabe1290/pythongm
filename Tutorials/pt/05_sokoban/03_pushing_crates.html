Fase 2: Empurrando caixas

Agora vamos adicionar caixas que o jogador pode empurrar — a mecânica central do Sokoban!

Crie o sprite da caixa

  1. Clique com o botão direito em Sprites → Criar Novo Sprite
  2. Nomeie-o spr_crate (32×32 pixels)
  3. Desenhe uma caixa marrom ou importe de Tutorials/05_sokoban/assets/
  4. Pressione Ctrl+S para salvar

Crie o objeto da caixa

  1. Clique com o botão direito em Objetos → Criar Novo Objeto
  2. Nomeie-o obj_crate, atribua o sprite spr_crate
  3. Marque a caixa de seleção Solid

Atualize o jogador: empurrar caixas

  1. Dê um duplo clique em obj_player para abrir o Editor de Objetos
  2. Clique na aba Blockly
  3. Adicione um novo evento de colisão para obj_crate:
When colliding with obj_crate
If Can Push facing
Push Other Instance 32

Encontre Collision em Events e digite obj_crate. Depois encontre If Can Push em Control — ele verifica se a caixa pode ser empurrada na direção em que o jogador está se movendo. Dentro da seção "then", encaixe um bloco Push Other Instance com distância 32.

Como o empurrão funciona: Quando o jogador colide com uma caixa, o motor verifica se o espaço atrás da caixa (na direção em que o jogador está se movendo) está livre. Se estiver, a caixa é empurrada uma célula. Se houver uma parede ou outra caixa atrás dela, o empurrão é bloqueado.

Programe a caixa: parar nas paredes

  1. Dê um duplo clique em obj_crate para abrir o Editor de Objetos
  2. Clique na aba Blockly
  3. Adicione um evento de colisão para obj_wall:
When colliding with obj_wall
Stop movement

Isso garante que as caixas parem ao atingir uma parede.

Atualize a sala

  1. Abra room_sokoban
  2. Posicione 2–3 instâncias de obj_crate dentro da sala
  3. Certifique-se de que cada caixa tenha espaço para ser empurrada
Dica: Não posicione uma caixa diretamente contra um canto — ela ficaria presa imediatamente!

Teste seu jogo!

Pressione F5 para jogar!

  • Caminhe até uma caixa e empurre-a com as teclas de seta
  • As caixas se movem uma célula quando empurradas
  • As caixas param ao atingir uma parede
  • Você não pode empurrar uma caixa se houver outra caixa ou parede atrás dela
Clique em "Próximo" para adicionar alvos e finalizar o jogo!
