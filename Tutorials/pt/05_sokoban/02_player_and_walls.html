Fase 1: Jogador e paredes

Vamos criar um jogador que caminha em uma grade dentro de uma sala com paredes!

Crie os sprites

  1. Clique com o botão direito em Sprites na Árvore de Recursos → Criar Novo Sprite
  2. Nomeie-o spr_player (32×32 pixels)
  3. Desenhe um personagem simples ou importe de Tutorials/05_sokoban/assets/
  4. Pressione Ctrl+S para salvar
  1. Crie outro sprite: spr_wall (32×32 pixels)
  2. Desenhe um padrão de tijolo ou pedra escura, ou importe de Tutorials/05_sokoban/assets/
  3. Pressione Ctrl+S para salvar

Crie os objetos

  1. Clique com o botão direito em Objetos → Criar Novo Objeto
  2. Nomeie-o obj_wall, atribua o sprite spr_wall
  3. Marque a caixa de seleção Solid
  1. Crie outro objeto: obj_player
  2. Atribua o sprite spr_player

Programe o jogador (Blockly)

  1. Dê um duplo clique em obj_player para abrir o Editor de Objetos
  2. Clique na aba Blockly

Mover para a direita

Key press: Right Arrow
Move grid right size 32

Encontre Key press na categoria Events e selecione Right Arrow. Depois encontre Move grid na categoria Movement, defina a direção como right e o tamanho como 32.

Mover para esquerda, cima, baixo

Repita para as outras três direções:

Key press: Left Arrow
Move grid left size 32
Key press: Up Arrow
Move grid up size 32
Key press: Down Arrow
Move grid down size 32

Cada evento Key press dispara uma vez por pressionamento de tecla — perfeito para movimento em grade!

Parar nas paredes

When colliding with obj_wall
Stop movement

Encontre Collision em Events e digite obj_wall. Encaixe um bloco Stop Movement dentro. Isso impede que o jogador atravesse as paredes.

Você deve ter 5 blocos de evento (4 de teclado + 1 de colisão).

Crie a sala

  1. Clique com o botão direito em Salas → Criar Nova Sala
  2. Nomeie-a room_sokoban
  3. Defina o tamanho como 320×320 pixels (uma grade de 10×10)
  4. Ative o ajuste à grade: 32×32
  1. Posicione obj_wall ao redor de todas as bordas para formar uma sala fechada
  2. Adicione algumas paredes internas para criar corredores e cantos
  3. Posicione obj_player em algum lugar dentro da sala
Como funciona: Pressionar uma tecla de seta move o jogador exatamente 32 pixels (uma célula da grade). Se o jogador atinge uma parede, o evento de colisão dispara e para o movimento.

Teste seu jogo!

Pressione F5 para jogar!

  • Use as teclas de seta para caminhar
  • O jogador se move exatamente uma célula por pressionamento de tecla
  • Paredes bloqueiam seu movimento — você não pode atravessá-las
Clique em "Próximo" para adicionar caixas que você pode empurrar!
