Fase 2: Moedas e saída

Seu labirinto já é percorrível! Agora vamos adicionar um objetivo: colete moedas para pontos e alcance a saída para vencer.

Passo 1: Crie os sprites

spr_coin (32x32)

  1. Clique com o botão direito em Sprites → Criar Novo Sprite
  2. Nomeie-o spr_coin

Opção A — Desenhe você mesmo

  1. Abra o Editor de Sprites e defina o tamanho como 32x32 pixels
  2. Desenhe um pequeno círculo amarelo ou dourado

Opção B — Carregue o sprite de exemplo

  1. Clique com o botão direito em spr_coin → Importar Imagem...
  2. Navegue até Tutorials/06_maze/assets/
  3. Selecione spr_coin.png

spr_exit (32x32)

  1. Crie um novo sprite chamado spr_exit

Opção A — Desenhe você mesmo

  1. Defina o tamanho como 32x32 pixels
  2. Desenhe uma porta, bandeira, ou marcador brilhante
  3. Use cores verde ou dourado para que se destaque

Opção B — Carregue o sprite de exemplo

  1. Clique com o botão direito em spr_exit → Importar Imagem...
  2. Selecione Tutorials/06_maze/assets/spr_exit.png

Passo 2: Crie os objetos

obj_coin

  1. Clique com o botão direito em Objetos → Criar Novo Objeto
  2. Nomeie-o obj_coin
  3. Atribua o sprite spr_coin
  4. Deixe "Solid" desmarcado

obj_exit

  1. Crie um novo objeto chamado obj_exit
  2. Atribua o sprite spr_exit
  3. Deixe "Solid" desmarcado

Passo 3: Programe a moeda (Blockly)

  1. Dê um duplo clique em obj_coin na Árvore de Recursos para abrir o Editor de Objetos
  2. Clique na aba Blockly
  3. Construa estes blocos:
When colliding with obj_player
Add to score 10
Destroy this instance

De Events, arraste um bloco Collision e digite obj_player. De Score/Lives/Health, encaixe Add to Score dentro e digite 10. De Instance, encaixe Destroy Instance abaixo dele.

Como funciona: Quando o jogador toca uma moeda, 10 pontos são adicionados à pontuação e a moeda desaparece.

Passo 4: Programe a saída (Blockly)

  1. Dê um duplo clique em obj_exit na Árvore de Recursos para abrir o Editor de Objetos
  2. Clique na aba Blockly
  3. Construa estes blocos:
When colliding with obj_player
Show message "Você Venceu!"
Restart room

De Events, arraste um bloco Collision e digite obj_player. De Output, encaixe Show Message dentro e digite Você Venceu!. De Room, encaixe Restart Room abaixo dele.

Dica: Se você criar vários níveis mais tarde, use Go to next room (da categoria Room) em vez de Restart room para avançar para o próximo labirinto!

Passo 5: Atualize sua sala

  1. Abra room_maze dando um duplo clique nela
  2. Selecione obj_coin e espalhe várias moedas pelos corredores do seu labirinto
  3. Selecione obj_exit e posicione-o no final do labirinto (longe do início do jogador)
Dica de design: Posicione moedas ao longo de caminhos diferentes para recompensar a exploração. Coloque a saída no canto mais distante da posição inicial do jogador para tornar o labirinto mais interessante.

Teste seu jogo!

Pressione F5 para jogar!

  • Navegue pelo labirinto e toque as moedas — elas devem desaparecer
  • Cada moeda adiciona 10 pontos à sua pontuação (você verá na tela na Fase 3)
  • Alcance a saída — uma mensagem "Você Venceu!" deve aparecer
  • Após a mensagem, a sala reinicia para que você possa jogar novamente
