Fase 1: Jogador e labirinto

Nesta fase você vai criar os sprites do jogador e da parede, construir objetos, programar o movimento com Blockly, e projetar um labirinto simples. Ao final, você poderá caminhar dentro do seu labirinto!

Passo 1: Crie os sprites

spr_player (32x32)

  1. Na Árvore de Recursos, clique com o botão direito em Sprites e selecione Criar Novo Sprite
  2. Nomeie-o spr_player

Opção A — Desenhe você mesmo

  1. Dê um duplo clique em spr_player para abrir o Editor de Sprites
  2. Defina o tamanho como 32x32 pixels
  3. Desenhe um pequeno personagem (um círculo com olhos, ou uma pessoa simples)
  4. Use uma cor viva como azul
  5. Salve com Ctrl+S

Opção B — Carregue o sprite de exemplo

  1. Clique com o botão direito em spr_player na Árvore de Recursos
  2. Selecione Importar Imagem...
  3. Navegue até Tutorials/06_maze/assets/
  4. Selecione spr_player.png e clique em Abrir

spr_wall (32x32)

  1. Crie um novo sprite chamado spr_wall

Opção A — Desenhe você mesmo

  1. Abra o Editor de Sprites e defina o tamanho como 32x32 pixels
  2. Desenhe um padrão de tijolo ou pedra
  3. Use cores cinza ou marrom

Opção B — Carregue o sprite de exemplo

  1. Clique com o botão direito em spr_wall → Importar Imagem...
  2. Selecione Tutorials/06_maze/assets/spr_wall.png

Passo 2: Crie os objetos

obj_wall (Solid)

  1. Clique com o botão direito em Objetos → Criar Novo Objeto
  2. Nomeie-o obj_wall
  3. Atribua o sprite spr_wall
  4. Marque "Solid" — isso é essencial para que o jogador não possa atravessar as paredes
  5. Nenhum evento é necessário para a parede

obj_player

  1. Crie um novo objeto chamado obj_player
  2. Atribua o sprite spr_player
  3. Deixe "Solid" desmarcado

Passo 3: Programe o jogador (Blockly)

Como o Blockly funciona: Arraste blocos da caixa de ferramentas à esquerda para a área de trabalho. Encaixe blocos de ação dentro de blocos de evento para definir o que acontece. Seus blocos são salvos no painel de eventos automaticamente enquanto você edita.
  1. Dê um duplo clique em obj_player na Árvore de Recursos para abrir o Editor de Objetos
  2. Clique na aba Blockly no topo do editor

Mover para a direita

Keyboard: Right Arrow (held)
Set horizontal speed to 4

Encontre Keyboard (held) na categoria Events e selecione Right Arrow no menu suspenso. Depois encontre Set Horizontal Speed na categoria Movement e encaixe dentro. Digite 4 no campo numérico.

Mover para a esquerda

Keyboard: Left Arrow (held)
Set horizontal speed to -4

Igual ao anterior, mas escolha Left Arrow e digite -4 (negativo = direção esquerda).

Mover para baixo

Keyboard: Down Arrow (held)
Set vertical speed to 4

Use Set Vertical Speed de Movement. Positivo = para baixo.

Mover para cima

Keyboard: Up Arrow (held)
Set vertical speed to -4

Digite -4 para movimento para cima.

Parar quando nenhuma tecla for pressionada

Keyboard: No key
Stop movement

Encontre Keyboard: No key em Events e Stop Movement em Movement. Isso impede que o jogador deslize para sempre!

Parar nas paredes

When colliding with obj_wall
Stop movement

Encontre Collision em Events. Digite obj_wall no campo de texto. Encaixe um bloco Stop Movement dentro.

Você deve ter 6 blocos de evento na sua área de trabalho.

Como funciona: Cada tecla de seta define a velocidade naquela direção. Quando você solta todas as teclas, o jogador para. Se o jogador atinge uma parede, também para.

Passo 4: Crie a sala

  1. Clique com o botão direito em Salas → Criar Nova Sala
  2. Nomeie-a room_maze
  3. Defina o tamanho como 640x480
  4. Ative Snap to Grid: 32x32

Construa um labirinto simples

  1. Selecione obj_wall e clique para posicionar paredes ao redor da borda
  2. Adicione paredes internas para criar corredores e caminhos
  3. Posicione obj_player perto do canto superior esquerdo do labirinto
  4. Deixe algum espaço aberto para que você possa caminhar
