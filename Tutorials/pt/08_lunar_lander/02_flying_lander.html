Fase 1: Um módulo voador

Nesta fase, criamos os sprites, objetos e controles para voar um módulo com gravidade lunar. No final, você terá um módulo jogável que pode pilotar pela tela!

Crie os sprites

spr_lander (32x32) — A nave espacial

  1. Clique com o botão direito em Sprites > Criar Novo Sprite
  2. Nomeie-o spr_lander (32x32 pixels)
  3. Desenhe uma pequena nave espacial (triângulo ou formato clássico de módulo lunar), ou importe de Tutorials/08_lunar_lander/assets/

spr_ground (32x32) — Terreno rochoso

  1. Crie um novo sprite chamado spr_ground (32x32 pixels)
  2. Desenhe um terreno rochoso usando cores cinza ou marrom, ou importe dos recursos

Crie os objetos

obj_ground

  1. Clique com o botão direito em Objetos > Criar Novo Objeto
  2. Nomeie-o obj_ground, atribua spr_ground
  3. Marque a caixa Solid

obj_lander

  1. Crie um novo objeto chamado obj_lander
  2. Atribua spr_lander

Programe o módulo (Blockly)

Dê um duplo clique em obj_lander e abra a aba Blockly.

1. Ative a gravidade (Create Event)

Create
Set Gravity: direction 270, strength 0.05

Encontre Create na categoria Events. Depois encontre Set Gravity na categoria Movement. Defina a direção como 270 (para baixo) e a força como 0.05.

Por que 0.05? A gravidade da Lua é cerca de 1/6 da da Terra. Um valor muito baixo como 0.05 dá ao módulo uma sensação lenta e flutuante — exatamente como um pouso lunar real!

2. Impulso para cima (Up Arrow segurada)

Keyboard: Up Arrow (held)
Set vspeed -2

Encontre Keyboard (held) em Events, escolha Up Arrow. Adicione Set vspeed (de Movement) com valor -2. Um vspeed negativo move o módulo para cima (impulso contra a gravidade).

3. Guie para a esquerda (Left Arrow segurada)

Keyboard: Left Arrow (held)
Set hspeed -2

Encontre Keyboard (held) em Events, escolha Left Arrow. Adicione Set hspeed (de Movement) com valor -2.

4. Guie para a direita (Right Arrow segurada)

Keyboard: Right Arrow (held)
Set hspeed 2

Encontre Keyboard (held) em Events, escolha Right Arrow. Adicione Set hspeed (de Movement) com valor 2.

5. Pare o horizontal quando nenhuma tecla for pressionada

Keyboard: No key
Set hspeed 0

Encontre Keyboard: No key em Events. Adicione Set hspeed com valor 0. Isso para o movimento horizontal quando nenhuma seta é pressionada, mas a gravidade continua puxando o módulo para baixo!

Importante: Redefinimos apenas hspeed para 0, não vspeed. Isso permite que a gravidade continue agindo sobre o módulo quando nenhuma tecla é pressionada — o módulo continua caindo!

Você deve ter 5 blocos de evento (Create + 3 teclado + No key).

Crie a sala

  1. Clique com o botão direito em Rooms > Criar Nova Sala
  2. Nomeie-a room_game
  3. Defina o tamanho: 640 x 480
  4. Defina a cor de fundo como preto (espaço!)
  5. Ative "Snap to Grid" (32x32)
  6. Posicione blocos obj_ground ao longo de toda a linha inferior
  7. Posicione obj_lander perto do topo da sala

Teste seu jogo!

Pressione F5 para jogar!

  • O módulo cai lentamente em direção ao solo (gravidade lunar!)
  • Seta para cima: Dá impulso para cima contra a gravidade
  • Setas esquerda/direita: Guiam horizontalmente
  • Solte todas as teclas e observe o módulo descer lentamente à deriva
Clique em "Próximo" para adicionar pouso e colisão!
