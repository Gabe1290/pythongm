Fase 3: Controlador de jogo

Vamos adicionar um objeto controlador de jogo para exibir um título, instruções, e inicializar a pontuação.

Crie o objeto controlador

  1. Clique com o botão direito em Objetos > Criar Novo Objeto
  2. Nomeie-o obj_game_controller
  3. Nenhum sprite necessário — este é um controlador invisível

Programe o controlador (Blockly)

Dê um duplo clique em obj_game_controller e abra a aba Blockly.

1. Inicialize a pontuação (Create Event)

Create
Set Score 0

Encontre Create em Events. Adicione Set Score (de Score) com valor 0. Isso redefine a pontuação toda vez que a sala inicia.

2. Desenhe o texto do HUD (Draw Event)

Draw
Draw Text "Lunar Lander" at 10, 10
Draw Text "Pouse na plataforma verde!" at 10, 30

Encontre Draw em Events. Adicione dois blocos Draw Text (de Drawing) — um para o título do jogo na posição (10, 10) e um para as instruções na posição (10, 30).

Aplique seus blocos

  1. Você deve ter 2 blocos de evento (Create + Draw)

Posicione o controlador na sala

  1. Abra room_game
  2. Posicione uma instância de obj_game_controller em qualquer lugar da sala (não tem sprite, então sua posição não importa)

Teste seu jogo!

Pressione F5 para jogar!

  • O título "Lunar Lander" aparece no canto superior esquerdo
  • As instruções "Pouse na plataforma verde!" são exibidas abaixo
  • Pilote seu módulo, pouse na plataforma para vencer, colida para reiniciar
  • O jogo completo agora está pronto!

Parabéns! Você construiu um jogo Lunar Lander!

Seu jogo tem gravidade lunar, controles de impulso, uma plataforma de pouso, detecção de colisão e um display de HUD. Muito bem!

Ideias de desafio

Quer tornar seu jogo ainda melhor? Tente estas melhorias:

  • Sistema de combustível: Adicione uma variável de combustível que diminui ao dar impulso. Se o combustível chegar a 0, o impulso para de funcionar!
  • Detecção de colisão baseada em velocidade: Use o vspeed do módulo para verificar a velocidade de pouso. Se o módulo estiver se movendo rápido demais ao tocar a plataforma, ele colide em vez de pousar com segurança!
  • Plataforma de pouso menor: Torne a plataforma menor (menos blocos) para aumentar a dificuldade
  • Múltiplos níveis: Crie salas adicionais com diferentes layouts de terreno e pontos de pouso mais difíceis
  • Pontuação baseada no combustível restante: Conceda mais pontos por pousar com mais combustível restante — incentiva o voo eficiente!
