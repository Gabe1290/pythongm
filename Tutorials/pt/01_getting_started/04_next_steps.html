Próximos Passos

Agora que você conhece o básico, aqui estão alguns tópicos para explorar:

Adicionando Movimento

Abra seu objeto e adicione um evento de Teclado. Use ações como "Mover em Direção" ou "Definir Velocidade" para fazer seu objeto responder a pressionamentos de teclas.

Detecção de Colisão

Crie outro objeto (como uma parede) e adicione um evento de Colisão ao seu jogador. Use ações para parar o movimento ou mudar de direção quando os objetos colidirem.

Programação Visual com Blockly

O PyGameMaker suporta programação visual com Blockly. No Editor de Objetos, mude para o Modo Blockly para criar comportamentos conectando blocos em vez de escrever código.

Múltiplas Salas

Crie mais salas para diferentes níveis. Use a ação "Ir para Sala" para alternar entre elas quando o jogador alcançar um objetivo ou porta.

Exportando Seu Jogo

Quando seu jogo estiver pronto, vá em Arquivo > Exportar como HTML5 para criar uma versão web que pode ser jogada em qualquer navegador!
