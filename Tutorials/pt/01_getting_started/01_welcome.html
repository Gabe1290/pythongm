Bem-vindo ao PyGameMaker!

O PyGameMaker é um ambiente de desenvolvimento visual de jogos inspirado no GameMaker Studio. Ele permite criar jogos 2D usando programação visual (blocos Blockly) ou programação tradicional baseada em eventos.

O que você vai aprender

Nesta série de tutoriais, você vai aprender a:

  • Navegar pela interface do PyGameMaker
  • Criar e gerenciar recursos do jogo (sprites, objetos, salas)
  • Adicionar comportamentos a objetos do jogo usando eventos e ações
  • Testar e exportar seus jogos
Dica: Você pode fechar este painel de tutorial a qualquer momento clicando no botão "Fechar" no topo. Para voltar aos tutoriais, selecione Ajuda > Tutoriais no menu.

Pré-requisitos

Nenhuma experiência em programação é necessária! O sistema de programação visual do PyGameMaker facilita para iniciantes começarem no desenvolvimento de jogos.
