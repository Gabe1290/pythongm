Fase 1: Um jogador que pula

Nesta fase, criamos o jogador e o chão, configuramos a gravidade e o movimento, e construímos uma sala com plataformas. No final, você poderá correr e pular!

Crie os sprites

  1. Clique com o botão direito em Sprites > Criar Novo Sprite
  2. Nomeie-o spr_player, tamanho 32x32
  3. Desenhe um personagem (ou importe de Tutorials/07_platformer/assets/)
  4. Crie outro sprite: spr_ground, tamanho 32x32
  5. Desenhe um bloco de chão (verde no topo, marrom embaixo) ou importe-o

Crie os objetos

  1. Clique com o botão direito em Objetos > Criar Novo Objeto
  2. Crie obj_ground, atribua o sprite spr_ground
  3. Marque a caixa Solid para obj_ground
  4. Crie obj_player, atribua o sprite spr_player
Por que Solid? Marcar obj_ground como Solid diz ao motor do jogo que outros objetos não devem atravessá-lo. Isso é essencial para plataformas!

Programe obj_player com Blockly

  1. Dê um duplo clique em obj_player para abrir o Editor de Objetos
  2. Clique na aba Blockly

Ative a gravidade (Create Event)

Create
Set Gravity: direction 270, strength 0.5

Encontre Create na categoria Events. Depois encontre Set Gravity na categoria Movement. Defina a direção como 270 (para baixo) e a força como 0.5.

Direção 270 = para baixo. Os ângulos começam em 0 (direita) e vão sentido anti-horário: 90 = cima, 180 = esquerda, 270 = baixo.

Mova para a esquerda

Keyboard: Left Arrow (held)
Set horizontal speed to -4

Encontre Keyboard (held) em Events, selecione Left Arrow. Depois encaixe Set Horizontal Speed de Movement com valor -4 (negativo = esquerda).

Mova para a direita

Keyboard: Right Arrow (held)
Set horizontal speed to 4

Pare quando nenhuma tecla for pressionada

Keyboard: No key
Set horizontal speed to 0

Isso para o movimento horizontal quando nenhuma tecla é pressionada. Usamos Set horizontal speed to 0 (NÃO "Stop Movement") para que a gravidade continue funcionando!

Importante: Se você usar "Stop Movement" aqui, isso também cancelaria a velocidade vertical e a gravidade pararia. Ao definir apenas a velocidade horizontal como 0, o jogador continua caindo normalmente.

Pule

Key press: Up Arrow
Set vertical speed to -10

Encontre Key press em Events, selecione Up Arrow. Defina a velocidade vertical como -10 (negativo = para cima). O evento Press dispara apenas uma vez, dando um único impulso de pulo.

Colida com o chão

When colliding with obj_ground
Stop movement

Encontre Collision em Events, digite obj_ground. Encaixe Stop Movement dentro. Isso impede que o jogador caia através do chão e o para ao atingir paredes.

Você deve ter 6 blocos de evento em seu espaço de trabalho (Create + Left + Right + No key + Press Up + Collision).

Crie a sala

  1. Clique com o botão direito em Rooms > Criar Nova Sala
  2. Nomeie-a room_level1
  3. Defina o tamanho: 800 x 480
  4. Defina a cor de fundo como azul claro (céu)
  5. Ative "Snap to Grid" e defina a grade como 32x32
  6. Posicione obj_ground ao longo da linha inferior
  7. Crie plataformas em diferentes alturas posicionando mais blocos obj_ground no ar
  8. Posicione um único obj_player no lado esquerdo, sobre o chão
                        ====
            ====                  ====
    P                 ====
  ====  ====  ====          ====  ====  ====
  GGGGGGGGGGGGGGGG    GGGGGGGGGGGGGGGGGGGGGG

G = Chão (obj_ground)     P = Jogador (obj_player)
==== = Plataformas em diferentes alturas

Teste seu jogo!

Pressione F5 para jogar!

  • O jogador cai com a gravidade
  • As setas esquerda/direita movem o jogador
  • A seta para cima faz o jogador pular
  • O jogador pousa em plataformas e no chão
Clique em "Próximo" para adicionar moedas, espinhos e uma bandeira!
