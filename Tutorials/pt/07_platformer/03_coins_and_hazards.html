Fase 2: Moedas e perigos

Agora adicionamos moedas colecionáveis, espinhos perigosos e uma bandeira para alcançar. Programamos tudo como novos eventos de colisão em obj_player.

Crie os sprites

  1. Crie o sprite spr_coin, tamanho 32x32 — desenhe um círculo amarelo/dourado (ou importe de Tutorials/07_platformer/assets/)
  2. Crie o sprite spr_spike, tamanho 32x32 — desenhe espinhos triangulares apontando para cima
  3. Crie o sprite spr_flag, tamanho 32x32 — desenhe uma bandeira em um mastro

Crie os objetos

  1. Crie obj_coin, atribua o sprite spr_coin
  2. Crie obj_spike, atribua o sprite spr_spike
  3. Crie obj_flag, atribua o sprite spr_flag
Nenhum Blockly necessário nesses objetos! Vamos programar todas as interações como eventos de colisão em obj_player, já que é o jogador quem toca as moedas, os espinhos e a bandeira.

Programe obj_player — Adicione eventos de colisão

Abra o editor Blockly de obj_player (os blocos da Fase 1 ainda estão lá). Adicione estes novos blocos de evento:

Colete moedas

When colliding with obj_coin
Add to score 10
Destroy other instance

Encontre Collision em Events, digite obj_coin. Encaixe Add to Score (de Score/Lives/Health) com valor 10. Depois encaixe Destroy Instance (de Instance) definido como Other, para que a moeda desapareça ao ser coletada.

Toque em um espinho

When colliding with obj_spike
Restart room

Encontre Collision em Events, digite obj_spike. Encaixe Restart Room (de Room) dentro. Quando o jogador toca um espinho, a fase reinicia!

Alcance a bandeira

When colliding with obj_flag
Show message "Você Venceu!"

Encontre Collision em Events, digite obj_flag. Encaixe Show Message (de Output) e digite Você Venceu!. Uma janela aparece quando o jogador alcança a bandeira!

Aplique seus blocos

  1. Você deve agora ter 9 blocos de evento no total para obj_player (6 da Fase 1 + 3 novos eventos de colisão)

Atualize sua sala

  1. Abra room_level1
  2. Posicione obj_coin em plataformas e locais de difícil acesso
  3. Posicione obj_spike perto de buracos ou em plataformas perigosas
  4. Posicione obj_flag no final da fase (lado direito)

                ====        ====
    C                               C
  ====  X     X         X     ====
    P               C
  ====  ====  ====  ====  ====  ====  ====
  GGGGGG      GGGG  GGGG       GGGGGGGGGG

G = Chão    P = Jogador    F = Bandeira    C = Moeda    X = Espinho
Dica de design de fase: Posicione espinhos perto de buracos para criar tensão. Coloque moedas em plataformas altas para recompensar saltos habilidosos. Posicione a bandeira na extremidade mais distante para que o jogador tenha que atravessar toda a fase!

Teste seu jogo!

Pressione F5 para jogar!

  • Toque um espinho — a sala reinicia!
  • Alcance a bandeira — uma mensagem "Você Venceu!" aparece
