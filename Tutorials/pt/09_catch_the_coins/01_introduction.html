Pegue as Moedas!

💰

Pegue cada moeda — sem esbarrar no inimigo!

Mova-se para a esquerda e direita, colete todas as moedas que caem para vencer, e evite o inimigo ou é fim de jogo.

O que vamos construir

Você vai criar um jogo completo com um estado claro de vitória e derrota. O jogo será jogável ao final de cada fase, então você pode parar e testá-lo quando quiser.

Como este tutorial funciona

Fase 1 — Um jogador em movimento
Crie um jogador que se move para a esquerda e direita. Teste-o imediatamente!
Fase 2 — Moedas e um inimigo
Adicione moedas que caem do céu, mais um inimigo. Posicione-os na sala.
Fase 3 — Pegando e colidindo
Pegue moedas para ganhar pontos, atinja o inimigo e o jogo termina.
Fase 4 — Vencendo o jogo
Adicione uma tela de vitória que aparece quando todas as moedas forem pegas.

O que você vai aprender

  • Criar sprites, objetos e salas
  • Usar eventos de teclado para controlar o jogador
  • Detectar colisões entre objetos
  • Rastrear e exibir uma pontuação
  • Usar transições de sala para telas de fim de jogo e vitória
  • Usar o bloco If Condition para verificar quantos objetos restam
Tempo necessário: Cerca de 15–20 minutos
Pronto? Clique em "Próximo" para começar a construir.
