Fase 4: Vencendo o jogo

Agora o jogador pode perder, mas não há como vencer. Vamos corrigir isso verificando a cada passo: "Ainda há moedas restantes?" — se não, vamos para uma sala de vitória totalmente nova.

Construa a sala de vitória

Crie o sprite de vitória (opcional)

Se você quiser um visual de comemoração, crie um sprite chamado spr_win_text. Este passo é opcional — o texto desenhado no próximo passo funciona sem um sprite.

Crie o objeto de texto de vitória

  1. Clique com o botão direito em Objetos → Criar Novo Objeto
  2. Nomeie-o obj_win_text
  3. Abra a aba Blockly e adicione estes dois eventos:

Exiba a mensagem de vitória:

When drawing
Draw text VOCÊ VENCEU! at x:412 y:320
Draw text Pressione ESPAÇO para jogar novamente at x:340 y:400

Reinicie ao pressionar espaço:

Key press: space
Restart Game

Crie a sala de vitória

  1. Clique com o botão direito em Rooms → Criar Nova Sala
  2. Nomeie-a room_win
  3. Defina a cor de fundo como uma cor de comemoração (verde claro ou dourado)
  4. Posicione uma instância de obj_win_text em qualquer lugar da sala (seu desenho está em coordenadas fixas)

A verificação de vitória

Agora a parte importante: a cada passo, o jogador verifica se ainda restam moedas. Quando a contagem chega a zero, vamos para a sala de vitória.

  1. Abra obj_player
  2. Clique na aba Blockly
  3. Adicione este evento Step:
Every step
If count of obj_coin == 0 then
Go to room room_win
O que isso faz: O bloco If Count Of observa a sala e conta quantas instâncias de obj_coin ainda estão vivas. Quando você pegou todas, a contagem é zero, a comparação == 0 é verdadeira, e a ação Go to room é executada.

Teste seu jogo completo!

Pressione F5 para jogar!

  • Pegue todas as moedas → a tela VOCÊ VENCEU! aparece
  • Toque o inimigo → a tela GAME OVER aparece
  • Pressione ESPAÇO em qualquer uma das telas finais para jogar novamente

Você construiu um jogo completo!

Parabéns — isso é um ciclo de jogo completo com:

  • Entrada do jogador (movimento por teclado)
  • Dois tipos de colisão (boa e ruim)
  • Uma pontuação que o jogador pode ver crescer
  • Um estado claro de vitória e de derrota
  • Uma maneira de reiniciar e tentar novamente
Tente isto a seguir: adicione mais moedas, posicione um segundo inimigo, ou mude as velocidades da moeda e do inimigo em seus eventos When created. Cada mudança é apenas um número que você pode editar e testar.
