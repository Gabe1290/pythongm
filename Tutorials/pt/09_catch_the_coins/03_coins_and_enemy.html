Fase 2: Moedas e um inimigo

Agora vamos adicionar as moedas para coletar e um inimigo para evitar. Ambos caem em linha reta.

Crie o sprite da moeda

  1. Clique com o botão direito em Sprites → Criar Novo Sprite
  2. Nomeie-o spr_coin
  3. Abra o Editor de Sprites e desenhe um círculo amarelo 24×24. Salve com Ctrl+S.

Crie o sprite do inimigo

  1. Repita os passos acima para um sprite chamado spr_enemy
  2. Desenhe um quadrado vermelho 32×32 para que o inimigo seja fácil de identificar

Crie o objeto da moeda

  1. Clique com o botão direito em Objetos → Criar Novo Objeto
  2. Nomeie-o obj_coin
  3. Defina o sprite como spr_coin
  4. Abra a aba Blockly e adicione isto:
When created
Set vertical speed to 3

Crie o objeto do inimigo

  1. Crie outro objeto chamado obj_enemy
  2. Defina seu sprite como spr_enemy
  3. Adicione o mesmo evento When created para que ele também caia:
When created
Set vertical speed to 3

Posicione-os na sala

  1. Abra room_main
  2. Posicione de 5 a 8 moedas pelo topo da sala, espalhadas horizontalmente
  3. Posicione 1 inimigo em algum lugar do topo, entre as moedas
  4. Certifique-se de que obj_player ainda está no centro inferior
Dica: O número de moedas é a pontuação que o jogador precisa alcançar para vencer. Comece com 5 para uma demonstração rápida — você sempre pode adicionar mais depois.

Teste seu jogo!

Pressione F5 para jogar!

  • Moedas e o inimigo devem cair do topo da sala
  • O jogador pode se mover para a esquerda e direita embaixo deles
  • Tocá-los ainda não faz nada — essa é a próxima fase!
Clique em "Próximo" para conectar a pontuação e a colisão de fim de jogo.
