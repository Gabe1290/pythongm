Fase 3: Pegando e colidindo

É hora de fazer as moedas e o inimigo realmente fazerem algo. Vamos adicionar três regras:

  • Tocar uma moeda: +1 pontuação, a moeda desaparece
  • Tocar o inimigo: fim de jogo
  • A pontuação é exibida na tela

Abra o objeto do jogador

  1. Dê um duplo clique em obj_player para abrir o Editor de Objetos
  2. Clique na aba Blockly

Redefina a pontuação quando o jogo começar

Adicione este evento para que a pontuação comece em zero toda vez:

When created
Set score to 0

Pegue uma moeda (pontue e a destrua)

Adicione um evento de Collision com obj_coin:

Collision with obj_coin
Add to score 1
Destroy other instance

Destroy other instance significa “destruir a moeda que acabamos de tocar” — não o jogador.

Colida com o inimigo (fim de jogo)

Adicione outro evento de Collision, desta vez com obj_enemy:

Collision with obj_enemy
Go to room room_gameover

A sala room_gameover veio do modelo "With Game Over Screen" — ela já exibe "GAME OVER" e reinicia quando o jogador pressiona ESPAÇO.

Exiba a pontuação na tela

Adicione um evento Draw para que a pontuação fique visível enquanto você joga:

When drawing
Draw Score at x:10 y:10

Seu obj_player agora tem: When created, When drawing, duas colisões, e os três eventos de teclado da Fase 1 — sete blocos de evento no total.

Teste seu jogo!

Pressione F5 para jogar!

  • Pegue moedas → a pontuação aumenta, as moedas desaparecem
  • Toque o inimigo → a tela de Game Over aparece
  • Pressione ESPAÇO na tela de Game Over para reiniciar
Clique em "Próximo" para adicionar a tela de vitória.
