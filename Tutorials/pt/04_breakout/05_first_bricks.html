Fase 2: Primeira fileira de blocos

Agora vamos adicionar blocos para a bola quebrar! Vamos usar um truque inteligente chamado objeto pai para que, mais tarde, quando adicionarmos mais cores de blocos, não precisemos reescrever o código de colisão.

Crie o sprite do bloco

  1. Crie um novo sprite chamado spr_brick_red

Opção A — Desenhe você mesmo

  1. Abra o Editor de Sprites e desenhe um retângulo sólido vermelho
  2. Tamanho: 32×16 pixels

Opção B — Carregue o sprite de exemplo

  1. Clique com o botão direito em spr_brick_red → Importar Imagem...
  2. Selecione Tutorials/04_breakout/assets/spr_brick_red.png

Crie o objeto pai do bloco

Um objeto pai é um modelo. Qualquer objeto que o use como pai vai herdar automaticamente seu comportamento de colisão. Assim, escrevemos o código de "bola atinge bloco" apenas uma vez.

  1. Crie um novo objeto chamado obj_brick_parent
  2. Nenhum sprite necessário — é apenas um modelo, não vai aparecer no jogo
  3. Marque Solid

Crie o objeto do bloco vermelho

  1. Crie um novo objeto chamado obj_brick_red
  2. Atribua o sprite spr_brick_red
  3. Defina Parent como obj_brick_parent
  4. Marque Solid
O que definir um pai faz? Quando a bola verifica uma colisão com obj_brick_parent, ela também detectará colisões com obj_brick_red e qualquer outro bloco filho que adicionarmos depois. Um único evento de colisão cobre todas as cores de blocos!

Adicione colisão com blocos à bola

Precisamos dizer à bola o que fazer quando atinge um bloco.

  1. Dê um duplo clique em obj_ball para abrir o Editor de Objetos
  2. Clique na aba Blockly — você deve ver seus 5 blocos existentes
  3. Adicione este novo bloco de evento:
When colliding with obj_brick_parent
Reverse vertical movement
Destroy other instance
Add to score 10

Encaixe três blocos dentro:

  • Reverse vertical movement (de Movement) — a bola quica de volta
  • Destroy other instance (de Instance) — destrói o bloco, não a bola!
  • Add to score 10 (de Score/Lives/Health) — ganha pontos

Você deve ter agora 6 blocos de evento para a bola.

Ponto-chave: A colisão é com obj_brick_parent, não com obj_brick_red. Isso significa que vai funcionar automaticamente com toda cor de bloco que adicionarmos depois!

Adicione blocos à sala

  1. Abra room_breakout
  2. Posicione uma fileira de obj_brick_red perto do topo, entre as paredes laterais
  3. Ative Snap to Grid (32×16) para alinhamento fácil
  4. Preencha uma fileira completa com blocos vermelhos

Teste seu jogo!

Pressione F5 para jogar!

  • A bola deve quicar nos blocos e destruí-los
  • Cada bloco adiciona 10 pontos à pontuação
  • Tente quebrar todos os blocos!
