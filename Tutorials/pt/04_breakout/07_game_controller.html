Fase 4: Controlador de jogo

O passo final! Vamos adicionar um controlador de jogo invisível que gerencia vidas, exibe a pontuação na tela, e faz a bola tirar uma vida quando cai.

Crie o objeto controlador de jogo

  1. Crie um novo objeto chamado obj_game_controller
  2. Nenhum sprite necessário (deixe vazio)
  3. Deixe Solid desmarcado
O que é um controlador de jogo? É um objeto invisível que gerencia coisas como pontuação e vidas. Como não tem sprite, ele não aparece no jogo — apenas funciona em segundo plano.

Inicialize vidas e pontuação

  1. Dê um duplo clique em obj_game_controller para abrir o Editor de Objetos
  2. Clique na aba Blockly
  3. Construa estes blocos:
Create Event
Set lives to 3
Set score to 0

O Create Event roda uma vez quando o jogo começa. Ele dá ao jogador 3 vidas e zera a pontuação.

Exiba pontuação e vidas

Adicione um segundo bloco de evento para mostrar a pontuação e as vidas na tela:

Draw Event
Draw score at x: 10 y: 10
Draw lives at x: 200 y: 10

O Draw Event roda a cada quadro. Ele desenha o texto da pontuação e das vidas na tela.

Você deve ter 2 blocos de evento.

Atualize a bola: perder uma vida

Atualmente, a bola apenas reaparece quando cai. Vamos fazer com que ela também subtraia uma vida.

  1. Dê um duplo clique em obj_ball para abrir o Editor de Objetos
  2. Clique na aba Blockly
  3. Encontre o bloco de evento collision with obj_death_zone
  4. Adicione um novo bloco antes do bloco de salto:
When colliding with obj_death_zone
Add to lives -1
Jump to x: 320 y: 100

Add to lives -1 (de Score/Lives/Health) subtrai uma vida toda vez que a bola cai além da raquete.

Posicione o controlador de jogo na sala

  1. Abra room_breakout
  2. Posicione obj_game_controller em qualquer lugar da sala (ele não tem sprite, então a posição não importa)
Não esqueça! O controlador de jogo precisa estar na sala para que vidas e pontuação funcionem. Mesmo sendo invisível, ele precisa existir na sala.

Fim de jogo e recorde

No momento, quando o jogador fica sem vidas, a bola simplesmente continua reaparecendo para sempre. Vamos fazer o jogo mostrar uma mensagem de Game Over, exibir a tabela de recordes, e então fechar.

O evento No More Lives roda automaticamente no momento em que as vidas do jogador chegam a zero. Você não precisa verificar isso você mesmo — basta adicionar o evento e o motor vai disparar.
  1. Abra obj_game_controller no Editor de Objetos
  2. Clique na aba Blockly
  3. Adicione um terceiro bloco de evento. Em Events, escolha Other Events e selecione No More Lives
  4. Encaixe estes três blocos dentro, em ordem:
When No More Lives
Show message "Fim de Jogo!"
Show Highscore
End Game
  • Show message (de Output) — exibe um diálogo "Fim de Jogo!"
  • Show Highscore (de Game) — exibe a tabela de recordes e, se o jogador entrou na lista dos melhores, pede o nome dele
  • End Game (de Game) — fecha a janela do jogo
A ordem importa! Coloque Show Highscore antes de End Game. Se você encerrar o jogo primeiro, o diálogo de recorde nunca tem chance de aparecer.

Agora você deve ter 3 blocos de evento no controlador de jogo (Create, Draw, No More Lives).

Parabéns! Teste seu jogo final!

Pressione F5 para jogar!

  • Use as teclas de seta Esquerda e Direita para mover a raquete
  • Quebre todos os blocos para vencer!
  • Não deixe a bola cair além da raquete — você só tem 3 vidas!
  • Observe sua pontuação e vidas no canto superior esquerdo
Ideias de desafios:
  • Dê valores de pontos diferentes para cada cor de bloco (vermelho = 40, laranja = 30, amarelo = 20, verde = 10)
  • Faça a bola acelerar conforme os blocos são destruídos
  • Adicione um segundo nível com um layout de blocos diferente
  • Toque um som quando o jogo terminar (adicione-o ao evento No More Lives)
