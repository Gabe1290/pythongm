Fase 1: Crie os sprites

Vamos começar apenas com o necessário para um jogo de bola quicante — ainda sem blocos! Para cada sprite você pode desenhá-lo você mesmo ou carregar uma imagem de exemplo.

SpriteTamanhoDescrição
spr_ball16×16Pequeno círculo amarelo
spr_paddle64×16Retângulo azul largo
spr_wall32×32Padrão de tijolo cinza
spr_death_zone32×32Retângulo escuro (invisível no jogo)

spr_ball (16×16)

  1. Na Árvore de Recursos, clique com o botão direito em Sprites e selecione Criar Novo Sprite
  2. Nomeie-o spr_ball

Opção A — Desenhe você mesmo

  1. Dê um duplo clique em spr_ball para abrir o Editor de Sprites
  2. Desenhe um pequeno círculo em uma cor viva como amarelo ou branco
  3. Mantenha o tamanho em 16×16 pixels
  4. Salve seu trabalho com Ctrl+S

Opção B — Carregue o sprite de exemplo

  1. Clique com o botão direito em spr_ball na Árvore de Recursos
  2. Selecione Importar Imagem...
  3. Navegue até Tutorials/04_breakout/assets/ dentro da pasta do PyGameMaker
  4. Selecione spr_ball.png e clique em Abrir

spr_paddle (64×16)

  1. Crie um novo sprite chamado spr_paddle

Opção A — Desenhe você mesmo

  1. Abra o Editor de Sprites e desenhe um retângulo largo e achatado
  2. Use uma cor viva como azul
  3. Tamanho: 64×16 pixels

Opção B — Carregue o sprite de exemplo

  1. Clique com o botão direito em spr_paddle → Importar Imagem...
  2. Selecione Tutorials/04_breakout/assets/spr_paddle.png

spr_wall (32×32)

  1. Crie um novo sprite chamado spr_wall

Opção A — Desenhe você mesmo

  1. Desenhe um padrão de tijolo ou pedra usando cores cinza
  2. Tamanho: 32×32 pixels

Opção B — Carregue o sprite de exemplo

  1. Clique com o botão direito em spr_wall → Importar Imagem...
  2. Selecione Tutorials/04_breakout/assets/spr_wall.png

spr_death_zone (32×32)

  1. Crie um novo sprite chamado spr_death_zone

Opção A — Desenhe você mesmo

  1. Desenhe um retângulo sólido de qualquer cor (por exemplo, vermelho escuro)
  2. Tamanho: 32×32 pixels

Opção B — Carregue o sprite de exemplo

  1. Clique com o botão direito em spr_death_zone → Importar Imagem...
  2. Selecione Tutorials/04_breakout/assets/spr_death_zone.png
Ponto de aprendizado: O recurso Importar Imagem permite carregar qualquer arquivo PNG, GIF ou BMP como sprite. Isso é útil quando você tem arte criada em um programa externo ou recursos de exemplo fornecidos com um tutorial.
É isso por enquanto! Só precisamos de 4 sprites para começar. Vamos adicionar os sprites de blocos mais tarde, quando precisarmos deles.
