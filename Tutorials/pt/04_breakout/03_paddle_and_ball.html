Fase 1: Objetos, raquete e bola

Vamos criar os objetos do jogo e programá-los para que possamos testar o jogo rapidamente!

Crie os objetos

Precisamos de dois tipos diferentes de parede para que a bola saiba em qual direção quicar.

  1. Clique com o botão direito em Objetos → Criar Novo Objeto
  2. Crie obj_wall_side — sprite: spr_wall, marque Solid
  3. Crie obj_wall_top — sprite: spr_wall, marque Solid
  4. Crie obj_paddle — sprite: spr_paddle, marque Solid
  5. Crie obj_ball — sprite: spr_ball, deixe Solid desmarcado
  6. Crie obj_death_zone — sprite: spr_death_zone, desmarque Visible
Por que dois tipos de parede? Quando a bola atinge uma parede lateral, ela inverte sua direção horizontal. Quando atinge a parede do topo, inverte sua direção vertical. Usar dois objetos permite programar comportamentos de quique diferentes!

Programe a raquete

  1. Dê um duplo clique em obj_paddle para abrir o Editor de Objetos
  2. Clique na aba Blockly
Como o Blockly funciona: Arraste blocos da caixa de ferramentas à esquerda para a área de trabalho. Encaixe blocos de ação dentro de blocos de evento para definir o que acontece. Seus blocos são salvos no painel de eventos automaticamente enquanto você edita.

Mover para a esquerda

Keyboard: Left Arrow (held)
Set horizontal speed to -8

Encontre Keyboard (held) em Events, selecione Left Arrow. Depois encaixe Set Horizontal Speed de Movement dentro. Digite -8 (negativo = esquerda).

Mover para a direita

Keyboard: Right Arrow (held)
Set horizontal speed to 8

Igual ao anterior, mas escolha Right Arrow e digite 8 (positivo = direita).

Parar quando nenhuma tecla for pressionada

Keyboard: No key
Stop movement

Isso impede que a raquete deslize para sempre quando você solta a tecla.

Parar nas paredes laterais

When colliding with obj_wall_side
Stop movement

Isso mantém a raquete dentro da área de jogo.

Você deve ter 4 blocos de evento.

Programe a bola

  1. Dê um duplo clique em obj_ball para abrir o Editor de Objetos
  2. Clique na aba Blockly

Inicie o movimento da bola

Create Event
Set horizontal speed to 3
Set vertical speed to -3

O Create Event roda uma vez quando o jogo começa. Definir ambas as velocidades faz a bola se mover na diagonal para cima.

Por que duas velocidades? A velocidade horizontal (3) move a bola para os lados. A velocidade vertical (-3) a move para cima (negativo = cima). Juntas, a bola se move na diagonal!

Quicar nas paredes laterais

When colliding with obj_wall_side
Reverse horizontal movement

A bola inverte sua direção esquerda/direita ao atingir uma parede lateral.

Quicar na parede do topo

When colliding with obj_wall_top
Reverse vertical movement

A bola quica para baixo ao atingir a parede do topo.

Quicar na raquete

When colliding with obj_paddle
Reverse vertical movement

Igual à parede do topo — a bola quica de volta para cima.

A bola cai da tela

When colliding with obj_death_zone
Jump to x: 320 y: 100

Quando a bola atinge a zona de morte no fundo, ela reaparece acima da raquete. Vamos adicionar vidas mais tarde — por enquanto, a bola simplesmente volta!

Você deve ter 5 blocos de evento.

Como o quique funciona: A bola sempre se move na diagonal. Quando atinge uma superfície vertical (parede lateral), invertemos o movimento horizontal. Quando atinge uma superfície horizontal (parede do topo, raquete), invertemos o movimento vertical. Isso cria um quique realista!
