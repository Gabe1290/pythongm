Fase 4: Retoques finais

Vamos adicionar alguns retoques para fazer seu jogo parecer completo!

Mantenha o jogador na tela

Abra obj_player no editor Blockly e adicione um evento Step com verificações de limite:

  • Se x < 0, defina x = 0
  • Se x > room_width − sprite_width, defina x = room_width − sprite_width

Isso impede que o jogador saia da tela.

Defina uma cor de fundo

Abra room_game no Editor de Salas e defina a cor de fundo para um azul-céu ou uma cor escura espacial.

Parabéns!

Seu primeiro jogo está completo!

Pressione F5 para jogar o jogo finalizado. Pegue quantas estrelas puder!

Ideias de desafios

Quer ir além? Experimente estas:
  • Adicione vidas — perca uma vida quando uma estrela chegar ao fundo
  • Faça as estrelas caírem mais rápido conforme a pontuação aumenta
  • Adicione estrelas de cores diferentes valendo pontuações diferentes
  • Adicione um objeto "ruim" (bomba) que encerra o jogo se for pego
  • Adicione efeitos sonoros ao pegar estrelas
