Fase 1: Um jogador em movimento

Vamos criar um jogador, colocá-lo em uma sala, e fazê-lo se mover imediatamente!

Crie um novo projeto

Vá em Arquivo > Novo Projeto e nomeie-o CatchTheStar.

Crie o sprite do jogador

  1. Clique com o botão direito em Sprites na Árvore de Recursos → Criar Novo Sprite
  2. Nomeie-o spr_player
  3. Dê um duplo clique para abrir o Editor de Sprites e desenhe um personagem simples de 32×32 (uma nave espacial, pessoa ou cesta). Pressione Ctrl+S para salvar.

Crie o objeto do jogador

  1. Clique com o botão direito em Objetos → Criar Novo Objeto
  2. Nomeie-o obj_player
  3. Atribua o sprite spr_player

Crie a sala

  1. Clique com o botão direito em Salas → Criar Nova Sala
  2. Nomeie-a room_game
  3. Abra a sala e posicione obj_player perto do centro inferior

Adicione movimento ao jogador

  1. Dê um duplo clique em obj_player para abrir o Editor de Objetos
  2. Clique na aba Blockly

Mover para a esquerda

Keyboard: Left Arrow (held)
Set horizontal speed to -5

Mover para a direita

Keyboard: Right Arrow (held)
Set horizontal speed to 5

Parar quando nenhuma tecla for pressionada

Keyboard: No key
Stop movement

Você deve ter 3 blocos de evento.

Teste seu jogo!

Pressione F5 para jogar!

  • Use as teclas Esquerda e Direita para mover o jogador
  • O jogador pode sair da tela — vamos corrigir isso depois!
Clique em "Próximo" para adicionar estrelas caindo.
