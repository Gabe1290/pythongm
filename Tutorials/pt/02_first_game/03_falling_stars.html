Fase 2: Estrelas caindo

Agora vamos fazer estrelas aparecerem no topo da tela e caírem!

Crie o sprite da estrela

  1. Crie um novo sprite chamado spr_star
  2. Desenhe uma estrela ou moeda (32×32 pixels) e salve

Crie o objeto da estrela

  1. Crie um novo objeto chamado obj_star
  2. Atribua o sprite spr_star

Faça as estrelas caírem

  1. Dê um duplo clique em obj_star → aba Blockly
  2. Adicione este bloco:
Create Event
Set vertical speed to 3

Cada estrela cai para baixo na velocidade 3 assim que aparece.

Crie um gerador

Precisamos de um objeto invisível que cria estrelas em posições aleatórias.

  1. Crie um novo objeto chamado obj_spawner
  2. Nenhum sprite necessário (ele será invisível)

Programe o gerador

  1. Dê um duplo clique em obj_spawner → aba Blockly
  2. Adicione estes blocos:
Create Event
Set Alarm 0 to 60
Alarm 0
Create instance of obj_star at x: random y: 0
Set Alarm 0 to 60

O evento Create inicia um temporizador. Quando o alarme dispara (a cada 2 segundos), ele cria uma estrela em uma posição x aleatória no topo da tela, e então reinicia o temporizador.

Posicione o gerador na sala

  1. Abra room_game
  2. Posicione obj_spawner em qualquer lugar (ele é invisível, a posição não importa)

Teste seu jogo!

Pressione F5 para jogar!

  • Estrelas devem cair de posições aleatórias no topo
  • Mova o jogador para desviar ou alcançá-las
  • Por enquanto, as estrelas atravessam o jogador — vamos adicionar a captura a seguir!
Clique em "Próximo" para adicionar colisão e pontuação.
