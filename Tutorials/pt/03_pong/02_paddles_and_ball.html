Fase 1: Raquetes e bola quicante

Vamos criar tudo o que precisamos para um jogo de Pong jogável!

Crie os sprites

Crie estes 3 sprites (desenhe-os ou importe imagens):

SpriteTamanhoDescrição
spr_ball16×16Pequeno círculo branco
spr_paddle16×64Retângulo alto e estreito
spr_wall32×32Bloco cinza

Crie os objetos

  1. Crie obj_wall — sprite: spr_wall, marque Solid
  2. Crie obj_paddle_left — sprite: spr_paddle, marque Solid
  3. Crie obj_paddle_right — sprite: spr_paddle, marque Solid
  4. Crie obj_ball — sprite: spr_ball, deixe Solid desmarcado

Programe a raquete esquerda (Jogador 1: W/S)

Dê um duplo clique em obj_paddle_left → aba Blockly.

Keyboard: W (held)
Set vertical speed to -8
Keyboard: S (held)
Set vertical speed to 8
Keyboard: No key
Stop movement
When colliding with obj_wall
Stop movement

Programe a raquete direita (Jogador 2: setas)

Dê um duplo clique em obj_paddle_right → aba Blockly. Mesma estrutura, mas teclas diferentes:

Keyboard: Up Arrow (held)
Set vertical speed to -8
Keyboard: Down Arrow (held)
Set vertical speed to 8
Keyboard: No key
Stop movement
When colliding with obj_wall
Stop movement

Programe a bola

Dê um duplo clique em obj_ball → aba Blockly.

Create Event
Start moving in direction 45 at speed 6
When colliding with obj_wall
Bounce against solid objects
When colliding with obj_paddle_left
Bounce against solid objects
When colliding with obj_paddle_right
Bounce against solid objects

Crie a sala

  1. Crie uma nova sala chamada room_pong (640×480)
  2. Posicione obj_wall ao longo das bordas superior e inferior
  3. Posicione obj_paddle_left perto da borda esquerda, centralizado verticalmente
  4. Posicione obj_paddle_right perto da borda direita, centralizado verticalmente
  5. Posicione obj_ball no centro da sala
+--[WALL WALL WALL WALL WALL WALL]--+
|                                     |
|  [P1]                        [P2]  |
|  [  ]         (o)            [  ]  |
|  [  ]                        [  ]  |
|                                     |
+--[WALL WALL WALL WALL WALL WALL]--+

Teste seu jogo!

Pressione F5 para jogar!

  • Jogador 1: W (cima) e S (baixo)
  • Jogador 2: Seta cima e Seta baixo
  • A bola quica nas paredes e raquetes
  • A bola sai voando pelas laterais — vamos adicionar os gols a seguir!
