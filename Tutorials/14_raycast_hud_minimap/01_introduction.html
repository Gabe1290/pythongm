2.5D: HUD and Minimap

🗺

Give the player a dashboard!

Score and lives on screen, a map in the corner, and a DOOM-style status bar with a health meter.

What We'll Build

We add a HUD (heads-up display) to the game from 2.5D: Goals, Gems and Monsters (Lesson 13). Nothing about the gameplay changes.

Phase 1 — Score and Lives
Text drawn on top of the 3D view.
Phase 2 — The Minimap
A top-down map of the walls with an arrow showing where you look.
Phase 3 — The Status Bar
Shrink the 3D view and put a full DOOM-style bar underneath.

What You'll Learn

  • The Draw event puts things on the screen over the 3D view
  • Why the object that draws the HUD must be visible
  • How Draw Minimap and Draw DOOM HUD save you from drawing every line yourself
  • How Viewport Height makes room for a bar
Time Required: About 25 minutes.
