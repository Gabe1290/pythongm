Phase 1: Score and Lives

In Lesson 13 the score changed, but you couldn't see it. The 3D view only draws the world; anything on top of it comes from a Draw event.

Add a Draw Event

  1. Open obj_player and add a Draw event
  2. Add these actions:
Draw
Set draw color #ffffff
Draw score at x: 8 y: 8 caption Score:
Draw lives at x: 230 y: 6 sprite spr_player
Set the colour first. Text is drawn in black unless you say otherwise — invisible against a dark wall.
The HUD object must be visible. Its Draw event only runs while the object is visible. Your player is the camera, and a camera is never drawn in the 3D view — but the object itself is still visible, so its Draw event works. If you put the HUD on a separate object, keep Visible checked or nothing will appear.

Test It!

Press F5!

  • The score shows at the top left, and one small icon per life at the top right
  • Pick up a gem: the score goes up. Touch the monster: an icon disappears
