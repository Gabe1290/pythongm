Phase 2: The Minimap

One action draws the whole map for you.

  1. In the same Draw event, add Draw Minimap after the other actions:

… (score and lives as before)
Draw Minimap — X 230 Y 10 Size 80
SettingWhat it does
X, YWhere the map's top-left corner goes, in screen pixels
SizeThe map is a square this many pixels wide
Background / Wall / Player ColorThe three colours; the defaults already look good
What the map shows: the walls and an arrow for you. North is always at the top — the map does not spin when you turn, the arrow does. It does not show gems or monsters, on purpose: a map that reveals every gem would make a collect-them-all game too easy.

Test It!

Press F5!

  • A small map appears in the top-right corner with your room's border and blocks
  • The arrow moves as you walk and turns as you turn
Challenge: make a map you can switch on and off. Use Set variable map_on = 0 in Create, a Key Press M event that flips it, and wrap Draw Minimap in an If variable map_on = 1. raycast_4 does exactly this.
