Phase 2: Kisten schieben

Jetzt fügen wir Kisten hinzu, die der Spieler schieben kann — das Herzstück von Sokoban!

Das Kisten-Sprite erstellen

  1. Rechtsklicke auf Sprites → Sprite erstellen
  2. Nenne es spr_crate (32×32 Pixel)
  3. Zeichne eine braune Kiste oder importiere sie aus Tutorials/05_sokoban/assets/
  4. Drücke Strg+S zum Speichern

Das Kisten-Objekt erstellen

  1. Rechtsklicke auf Objekte → Objekt erstellen
  2. Nenne es obj_crate und setze sein Sprite auf spr_crate
  3. Setze ein Häkchen bei Fest

Den Spieler ändern: Kisten schieben

  1. Doppelklicke auf obj_player, um den Objekt-Editor zu öffnen
  2. Klicke auf den Reiter Blockly
  3. Füge ein neues Kollisionsereignis für obj_crate hinzu:
Wenn Kollision mit obj_crate
Wenn schiebbar box in Richtung facing dann push and move sonst stop movement

Suche Kollision in Ereignisse und gib obj_crate ein. Suche dann Wenn schiebbar in Steuerung — ein einzelner Block, der prüft, ob die Kiste in die Laufrichtung des Spielers geschoben werden kann, und das Schieben selbst erledigt: Objekttyp box, Richtung facing, Dann-Aktion push and move, Sonst-Aktion stop movement.

So funktioniert das Schieben: Stößt der Spieler gegen eine Kiste, prüft die Engine, ob der Platz hinter der Kiste (in Laufrichtung des Spielers) frei ist. Ist er frei, wird die Kiste eine Zelle weitergeschoben. Steht dahinter eine Wand oder eine andere Kiste, ist das Schieben blockiert.

Die Kiste programmieren: an Wänden anhalten

  1. Doppelklicke auf obj_crate, um den Objekt-Editor zu öffnen
  2. Klicke auf den Reiter Blockly
  3. Füge ein Kollisionsereignis für obj_wall hinzu:
Wenn Kollision mit obj_wall
Bewegung stoppen

So halten Kisten an, wenn sie gegen eine Wand stoßen.

Den Raum ändern

  1. Öffne room_sokoban
  2. Setze 2–3 Instanzen von obj_crate in den Raum
  3. Achte darauf, dass jede Kiste Platz zum Schieben hat
Tipp: Stell keine Kiste direkt in eine Ecke — sie säße sofort fest!

Teste dein Spiel!

Drücke F5 zum Spielen!

  • Geh zu einer Kiste und schiebe sie mit den Pfeiltasten
  • Kisten bewegen sich beim Schieben eine Zelle weiter
  • Kisten halten an, wenn sie gegen eine Wand stoßen
  • Du kannst keine Kiste schieben, hinter der eine andere Kiste oder eine Wand steht
Klicke auf „Weiter“, um Ziele hinzuzufügen und das Spiel fertigzustellen!
