Schritt 5: Füge das Leben-System hinzu

Der Spieler verliert ein Leben, wenn der Ball vom unteren Bildschirmrand fällt.

Erstelle eine Todeszone

  1. Erstelle ein Sprite spr_death_zone (32x32, beliebige Farbe)
  2. Erstelle Objekt obj_death_zone
  3. Deaktiviere "Sichtbar" - es soll unsichtbar sein
  4. Aktiviere "Solide"

Ball fällt in die Todeszone

In obj_ball:

  1. Füge Ereignis hinzu: Kollision > obj_death_zone
  2. Füge Aktion hinzu: Punkte > Leben setzen
  3. Leben: -1, Relativ angehakt
  4. Füge Aktion hinzu: Bewegung > Zur Startposition springen

Erstelle einen Spiel-Controller

  1. Erstelle Objekt obj_game_controller
  2. Kein Sprite benötigt

Leben initialisieren (Erstellen-Ereignis)

In obj_game_controller:

  1. Füge Ereignis hinzu: Erstellen
  2. Füge Aktion hinzu: Punkte > Leben setzen
  3. Wert: 3
  4. Füge Aktion hinzu: Punkte > Punkte setzen
  5. Wert: 0

Auf Spielende prüfen (Schritt-Ereignis)

  1. Füge Ereignis hinzu: Schritt
  2. Füge Aktion hinzu: Punkte/Leben/Gesundheit > Leben testen
  3. Prüfe, ob Leben kleiner oder gleich 0 sind
  4. Füge Aktion hinzu: Spiel > Nachricht anzeigen
  5. Nachricht: Spiel vorbei!
  6. Füge Aktion hinzu: Raum > Raum neu starten
Denke daran: Platziere obj_game_controller in deinem Raum!
Klicke auf "Weiter", um die Punkteanzeige hinzuzufügen.
