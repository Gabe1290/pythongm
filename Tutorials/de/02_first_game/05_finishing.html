Phase 4: Der letzte Schliff

Jetzt polieren wir dein Spiel, damit es sich fertig anfühlt!

Den Spieler auf dem Bildschirm halten

Öffne obj_player im Blockly-Editor und füge ein Ereignis Jeden Schritt mit Randprüfungen hinzu:

  • Wenn meine Position: x-Position < 0 dann Variable setzen x auf 0
  • Wenn meine Position: x-Position > 608 dann Variable setzen x auf 608 (608 = Raumbreite 640 − Sprite-Breite 32)

So kann der Spieler den Bildschirm nicht verlassen.

Eine Hintergrundfarbe festlegen

Öffne room_game im Raum-Editor und setze die Hintergrundfarbe auf ein schönes Himmelblau oder eine dunkle Weltraumfarbe.

Glückwunsch!

Dein erstes Spiel ist fertig!

Drücke F5, um das fertige Spiel zu spielen. Fange so viele Sterne wie möglich!

Ideen für Herausforderungen

Want to go further? Try these:
  • Füge Leben hinzu — verliere ein Leben, wenn ein Stern unten ankommt
  • Lass die Sterne schneller fallen, wenn der Punktestand steigt
  • Füge verschiedenfarbige Sterne mit unterschiedlichen Punktwerten hinzu
  • Füge ein „böses“ Objekt (eine Bombe) hinzu, das das Spiel beendet, wenn man es fängt
  • Füge Soundeffekte beim Fangen von Sternen hinzu
