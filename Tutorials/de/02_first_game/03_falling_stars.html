Phase 2: Fallende Sterne

Jetzt lassen wir oben am Bildschirm Sterne erscheinen und herunterfallen!

Das Stern-Sprite erstellen

  1. Erstelle ein neues Sprite namens spr_star
  2. Zeichne einen Stern oder eine Münze (32×32 Pixel) und speichere

Das Stern-Objekt erstellen

  1. Erstelle ein neues Objekt namens obj_star
  2. Setze das Sprite auf spr_star

Sterne fallen lassen

  1. Doppelklicke auf obj_star → Reiter Blockly
  2. Füge diesen Block hinzu:
Wenn erstellt
setze vertikale Geschwindigkeit auf 3

Jeder Stern fällt mit Geschwindigkeit 3 nach unten, sobald er erscheint.

Einen Spawner erstellen

Wir brauchen ein unsichtbares Objekt, das Sterne an zufälligen Positionen erzeugt.

  1. Erstelle ein neues Objekt namens obj_spawner
  2. Kein Sprite nötig (es ist unsichtbar)

Den Spawner programmieren

  1. Doppelklicke auf obj_spawner → Reiter Blockly
  2. Füge diese Blöcke hinzu:
Wenn erstellt
Setze Alarm 0 auf 60 Schritte
Wenn Alarm 0 auslöst
Erstelle obj_star bei x: random y: 0
Setze Alarm 0 auf 60 Schritte

Das Ereignis „Wenn erstellt“ startet einen Zeitgeber. Wenn der Alarm auslöst (jede Sekunde), erzeugt er oben am Bildschirm einen Stern an einer zufälligen x-Position und startet den Zeitgeber neu.

Den Spawner in den Raum setzen

  1. Öffne room_game
  2. Setze obj_spawner irgendwohin (er ist unsichtbar, die Position spielt keine Rolle)

Teste dein Spiel!

Drücke F5 zum Spielen!

  • Sterne sollten oben an zufälligen Positionen herunterfallen
  • Bewege den Spieler, um ihnen auszuweichen oder sie zu erreichen
  • Die Sterne fliegen vorerst durch den Spieler hindurch — das Fangen kommt als Nächstes!
Klicke auf „Weiter“, um Kollisionen und Punkte hinzuzufügen.
