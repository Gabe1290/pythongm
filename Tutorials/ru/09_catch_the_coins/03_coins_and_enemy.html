Фаза 2: Монеты и враг

Теперь добавим монеты для сбора и одного врага, которого нужно избегать. Оба падают прямо вниз.

Создай спрайт монеты

  1. Щёлкни правой кнопкой на Спрайты → Создать новый спрайт
  2. Назови его spr_coin
  3. Открой Редактор спрайтов и нарисуй жёлтый круг 24×24. Сохрани через Ctrl+S.

Создай спрайт врага

  1. Повтори шаги выше для спрайта под названием spr_enemy
  2. Нарисуй красный квадрат 32×32, чтобы врага было легко заметить

Создай объект монеты

  1. Щёлкни правой кнопкой на Объекты → Создать новый объект
  2. Назови его obj_coin
  3. Установи спрайт spr_coin
  4. Открой вкладку Blockly и добавь это:
When created
Set vertical speed to 3

Создай объект врага

  1. Создай ещё один объект под названием obj_enemy
  2. Установи его спрайт spr_enemy
  3. Добавь такое же событие When created, чтобы он тоже падал:
When created
Set vertical speed to 3

Размести их в комнате

  1. Открой room_main
  2. Размести от 5 до 8 монет в верхней части комнаты, распределив их по горизонтали
  3. Размести 1 врага где-нибудь сверху, между монетами
  4. Убедись, что obj_player всё ещё внизу по центру
Совет: Количество монет — это счёт, которого игроку нужно достичь для победы. Начни с 5 для быстрой демонстрации — позже ты всегда сможешь добавить ещё.

Проверь свою игру!

Нажми F5, чтобы играть!

  • Монеты и враг должны падать сверху комнаты
  • Игрок может двигаться влево и вправо под ними
  • Пока прикосновение к ним ничего не делает — это следующая фаза!
Нажми «Далее», чтобы настроить очки и столкновение, ведущее к проигрышу.
