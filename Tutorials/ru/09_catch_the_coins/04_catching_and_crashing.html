Фаза 3: Сбор и столкновение

Пора заставить монеты и врага по-настоящему что-то делать. Добавим три правила:

  • Касание монеты: +1 очко, монета исчезает
  • Касание врага: игра окончена
  • Счёт отображается на экране

Открой объект игрока

  1. Дважды щёлкни по obj_player, чтобы открыть Редактор объектов
  2. Нажми на вкладку Blockly

Сбрось счёт при старте игры

Добавь это событие, чтобы счёт каждый раз начинался с нуля:

When created
Set score to 0

Собери монету (начисли очки и уничтожь её)

Добавь событие Collision с obj_coin:

Collision with obj_coin
Add to score 1
Destroy other instance

Destroy other instance означает «уничтожить монету, которую мы только что коснулись» — а не игрока.

Столкновение с врагом (игра окончена)

Добавь ещё одно событие Collision, на этот раз с obj_enemy:

Collision with obj_enemy
Go to room room_gameover

Комната room_gameover взята из шаблона «С экраном проигрыша» — она уже показывает «GAME OVER» и перезапускается, когда игрок нажимает ПРОБЕЛ.

Покажи счёт на экране

Добавь событие Draw, чтобы счёт был виден во время игры:

When drawing
Draw Score at x:10 y:10

Теперь у твоего obj_player есть: When created, When drawing, два столкновения, и три события клавиатуры из Фазы 1 — всего семь блоков событий.

Проверь свою игру!

Нажми F5, чтобы играть!

  • Собирай монеты → счёт растёт, монеты исчезают
  • Коснись врага → появляется экран проигрыша
  • Нажми ПРОБЕЛ на экране проигрыша, чтобы начать заново
Нажми «Далее», чтобы добавить экран победы.
