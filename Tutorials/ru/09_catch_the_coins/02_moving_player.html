Фаза 1: Движущийся игрок

Начнём с создания игрока и его движения влево и вправо с помощью клавиш со стрелками.

Создай новый проект

  1. Перейди в Файл > Новый проект
  2. Назови его CatchTheCoins
  3. Для Шаблона выбери «С экраном проигрыша»

Этот шаблон даёт тебе готовый экран проигрыша, который мы подключим позже, так что тебе не придётся создавать его самому.

Создай спрайт игрока

  1. Щёлкни правой кнопкой на Спрайты в дереве ресурсов → Создать новый спрайт
  2. Назови его spr_player
  3. Дважды щёлкни по нему, чтобы открыть Редактор спрайтов, и нарисуй персонажа 32×32 (ракетка, корзина или просто зелёный квадрат подойдут). Нажми Ctrl+S, чтобы сохранить.

Создай объект игрока

  1. Щёлкни правой кнопкой на Объекты → Создать новый объект
  2. Назови его obj_player
  3. Установи спрайт spr_player

Создай игровую комнату

  1. Щёлкни правой кнопкой на Комнаты → Создать новую комнату
  2. Назови её room_main
  3. Открой комнату и размести obj_player внизу по центру

Добавь движение игрока

  1. Дважды щёлкни по obj_player, чтобы открыть Редактор объектов
  2. Нажми на вкладку Blockly

Движение влево

Keyboard: Left Arrow (held)
Set horizontal speed to -5

Движение вправо

Keyboard: Right Arrow (held)
Set horizontal speed to 5

Остановка, когда клавиша не нажата

Keyboard: No key
Stop movement

У тебя должно получиться 3 блока событий.

Проверь свою игру!

Нажми F5, чтобы играть!

  • Используй клавиши Влево и Вправо, чтобы двигать игрока
  • Пока игрок может уходить за пределы экрана — монеты появятся дальше!
Нажми «Далее», чтобы добавить монеты и врага.
