## Вступ

У цьому посібнику ви створите **Гру-Лабіринт**, де гравець проходить через коридори до виходу, уникаючи перешкод та збираючи монети. Цей класичний тип гри ідеально підходить для вивчення плавного руху, виявлення зіткнень та дизайну рівнів.

**Що ви навчитесь:**
- Плавний рух гравця з введенням з клавіатури
- Обробка зіткнень зі стінами
- Виявлення цілі (досягнення виходу)
- Предмети для збирання
- Проста система таймера

**Складність:** Початківець
**Пресет:** Середній пресет (дія Execute Code, використана для
таймера, не входить до пресету для початківців)

## Крок 1: Зрозуміти Гру

### Правила Гри
1. Гравець рухається лабіринтом за допомогою клавіш зі стрілками
2. Стіни блокують рух гравця
3. Збирайте монети для очок
4. Досягніть виходу, щоб завершити рівень
5. Пройдіть лабіринт якомога швидше!

### Що Нам Потрібно

| Елемент | Призначення |
|---------|-------------|
| **Гравець** | Персонаж, яким ви керуєте |
| **Стіна** | Тверді перешкоди, що блокують рух |
| **Вихід** | Ціль, що завершує рівень |
| **Монета** | Предмети для збирання та очок |
| **Підлога** | Візуальний фон (необов'язково) |

## Крок 2: Створити Спрайти

Всі спрайти стін та підлоги повинні бути 32x32 пікселі для створення правильної сітки.

### 2.1 Спрайт Гравця

1. У **Дереві Ресурсів** клацніть правою кнопкою на **Sprites** та виберіть **Create Sprite**
2. Назвіть його `spr_player`
3. Натисніть **Edit Sprite**, щоб відкрити редактор
4. Намалюйте маленького персонажа (коло, людину або форму стрілки)
5. Використовуйте яскравий колір, як синій або зелений
6. Розмір: 24x24 пікселі (менше за стіни для легшої навігації)
7. Натисніть **OK** для збереження

### 2.2 Спрайт Стіни

1. Створіть новий спрайт з назвою `spr_wall`
2. Намалюйте твердий візерунок цегли або каменю
3. Використовуйте сірі або темні кольори
4. Розмір: 32x32 пікселі

### 2.3 Спрайт Виходу

1. Створіть новий спрайт з назвою `spr_exit`
2. Намалюйте двері, прапор або яскравий маркер цілі
3. Використовуйте зелені або золоті кольори
4. Розмір: 32x32 пікселі

### 2.4 Спрайт Монети

1. Створіть новий спрайт з назвою `spr_coin`
2. Намалюйте маленьке жовте/золоте коло
3. Розмір: 16x16 пікселів

### 2.5 Спрайт Підлоги (Необов'язково)

1. Створіть новий спрайт з назвою `spr_floor`
2. Намалюйте простий візерунок плитки підлоги
3. Використовуйте світлий нейтральний колір
4. Розмір: 32x32 пікселі

## Крок 3: Створити Об'єкт Стіни

Стіна блокує рух гравця.

1. Клацніть правою кнопкою на **Objects** та виберіть **Create Object**
2. Назвіть його `obj_wall`
3. Встановіть спрайт на `spr_wall`
4. **Позначте прапорець "Solid"**
5. Події не потрібні

---

## Крок 4: Створити Об'єкт Виходу

Вихід завершує рівень, коли гравець його досягає.

1. Створіть новий об'єкт з назвою `obj_exit`
2. Встановіть спрайт на `spr_exit`

**Подія: Collision with obj_player**
1. Add Event → Collision → obj_player
2. Add Action: **Output** → **Show Message**
   - Message: `You Win!`
3. Add Action: **Room** → **Next Room** (або **Restart Room** для одного рівня)

Текст Show Message — фіксований рядок, він не може містити живе
значення, як-от витрачений час. Таймер лишається видимим у HUD (Крок
7) аж до перемоги, тож гравець уже бачив свій час.

---

## Крок 5: Створити Об'єкт Монети

Монети додають до рахунку при зборі.

1. Створіть новий об'єкт з назвою `obj_coin`
2. Встановіть спрайт на `spr_coin`

**Подія: Collision with obj_player**
1. Add Event → Collision → obj_player
2. Add Action: **Score** → **Set Score**
   - New Score: `10`
   - Позначте "Relative" для додавання 10 очок
3. Add Action: **Instance** → **Destroy Instance**
   - Applies to: Self

---

## Крок 6: Створити Об'єкт Гравця

Гравець плавно рухається за допомогою клавіш зі стрілками.

1. Створіть новий об'єкт з назвою `obj_player`
2. Встановіть спрайт на `spr_player`

### 6.1 Рух

Додайте чотири події **Keyboard (held)** та одну подію **No Key**,
кожна з дією **Move** → **Set Horizontal/Vertical Speed**:

| Подія | Дія |
|---|---|
| Keyboard (held) → Right Arrow | Set Horizontal Speed на `4` |
| Keyboard (held) → Left Arrow | Set Horizontal Speed на `-4` |
| Keyboard (held) → Down Arrow | Set Vertical Speed на `4` |
| Keyboard (held) → Up Arrow | Set Vertical Speed на `-4` |
| Keyboard: No Key | Set Horizontal Speed на `0` **і** Set Vertical Speed на `0` |

### 6.2 Зупинка Біля Стін

**Подія: Collision with obj_wall**
1. Add Event → Collision → `obj_wall`
2. Add Action: **Move** → **Stop Movement**

Тут не потрібен ручний код для перевірки позиції. Цикл руху цього
рушія вже не дозволяє екземпляру зайти в твердий об'єкт до того, як
кадр буде намальовано (`obj_wall` — Solid), тому гравець насправді
ніколи не перекривається зі стіною — подія зіткнення вище лише
скидає залишкову швидкість, щоб гравець не "тиснув" далі в неї.

## Крок 7: Створити Контролер Гри

Контролер гри керує таймером та відображає інформацію.

1. Створіть новий об'єкт з назвою `obj_game_controller`
2. Спрайт не потрібен

**Подія: Create** — запускає таймер за допомогою **Control** →
**Execute Code** (дія Execute Code в цьому проєкті виконує справжній
Python, а не GameMaker Language):

```python
self.timer = 0.0
```

**Подія: Step** — збільшує його щокадру:

```python
self.timer += 1.0 / game.fps
```

**Подія: Draw** — будує HUD за допомогою справжніх команд черги
малювання. Додайте три дії **Draw** → **Draw Text**:

| Дія Draw Text | Текст | Позиція |
|---|---|---|
| 1. | `Score:` | X `10`, Y `10` |
| 2. | `Time:` | X `10`, Y `30` |
| 3. | `Coins:` | X `10`, Y `50` |

а потім одразу за ними три дії **Draw** → **Draw Variable**, щоб
показати живі значення поруч із кожним підписом:

| Дія Draw Variable | Змінна | Позиція |
|---|---|---|
| 1. | `score` | X `70`, Y `10` |
| 2. | `self.timer` | X `70`, Y `30` |
| 3. | *(див. нижче)* | X `70`, Y `50` |

Немає вбудованого лічильника "монет, що залишилися", на який могла б
вказувати Draw Variable — прямо перед діями Draw Variable додайте ще
одну дію **Control** → **Execute Code**, щоб обчислити його в змінну
екземпляра, яку Draw Variable потім зможе прочитати:

```python
self.coins_left = sum(
    1 for inst in game.current_room.instances
    if inst.object_name == 'obj_coin'
)
```

(потім встановіть поле Variable 3-ї дії Draw Variable на `self.coins_left`).

## Крок 8: Спроектуйте Свій Лабіринт

1. Клацніть правою кнопкою на **Rooms** та виберіть **Create Room**
2. Назвіть її `room_maze`
3. Встановіть розмір кімнати (наприклад, 640x480)
4. Увімкніть "Snap to Grid" та встановіть сітку на 32x32

### Розміщення Об'єктів

Побудуйте свій лабіринт за цими рекомендаціями:

1. **Створіть межу** — Оточіть кімнату стінами
2. **Побудуйте коридори** — Створіть шляхи через лабіринт
3. **Розмістіть вихід** — Поставте його в кінці лабіринту
4. **Розкидайте монети** — Розмістіть їх уздовж шляхів
5. **Розмістіть гравця** — Біля входу
6. **Додайте контролер гри** — Де завгодно (він невидимий)

## Покращення (Необов'язково)

### Додати Ворогів

Створіть простого патрулюючого ворога:

1. Створіть `spr_enemy` (червоний колір, 24x24)
2. Створіть `obj_enemy` зі спрайтом `spr_enemy`

**Подія: Create** — Add Action: **Move** → **Start Moving Direction**
(Directions: `right`, Speed: `2`)

**Подія: Collision with obj_wall** — Add Action: **Move** → **Reverse
Horizontal** (розвертає ворога, коли той зачіпає стіну — код не
потрібен; разом із вбудованим твердим зіткненням з Кроку 6.2 ворог
ніколи не зможе пройти крізь стіну)

**Подія: Collision with obj_player** — Add Action: **Room** →
**Restart Room**

### Додати Систему Життів

У події **Create** для `obj_game_controller` додайте **Score** →
**Set Lives** (Value: `3`).

У події **Collision with obj_player** для `obj_enemy` замініть
**Restart Room** на дві дії: **Score** → **Set Lives** (Value: `-1`,
позначено **Relative**), потім **Move** → **Jump to Start Position**
(застосована до гравця через **Applies to: Other**), щоб гравець
відроджувався, а не перезапускав увесь лабіринт.

Додайте `obj_game_controller` ще одну подію: **Other Events** → **No
More Lives** — вона спрацьовує автоматично, щойно життя досягають 0,
тож перевіряти це вручну не потрібно. Додайте **Output** → **Show
Message** (`Game Over!`), потім **Room** → **Restart Game**.

### Додати Ключі та Замкнені Двері

1. Створіть `obj_key` — при зіткненні з `obj_player`: **Set Variable**
   (Variable: `global.has_key`, Value: `true`, Scope: `global`), потім
   **Destroy Instance** (self).
2. Створіть `obj_locked_door` з позначеним Solid. Додайте йому подію
   **Step** з **Control** → **Test Variable** (Variable:
   `global.has_key`, Value: `true`, Scope: `global`) → **Instance** →
   **Destroy Instance** (self) — двері зникають (і перестають
   блокувати) щойно ключ підібрано.

### Додати Кілька Рівнів

1. Створіть додаткові кімнати (`room_maze2`, `room_maze3`)
2. У `obj_exit` використовуйте дію **Next Room** замість **Restart Room**

### Додати Звукові Ефекти

Додайте звуки для:
- Збирання монет
- Досягнення виходу
- Торкання ворогів (якщо додані)
- Фонова музика

## Усунення Неполадок

| Проблема | Рішення |
|----------|---------|
| Гравець проходить крізь стіни | Перевірте, що `obj_wall` позначено "Solid" |
| Гравець застрягає в стінах | Переконайтеся, що спрайт гравця менший за проміжки між стінами |
| Монети не зникають | Перевірте, що подія зіткнення знищує Self, а не Other |
| Таймер не працює | Переконайтеся, що контролер гри розміщений у кімнаті |
| Рух відчувається ривками | Налаштуйте значення швидкості в діях Set Horizontal/Vertical Speed (спробуйте 3-5) |
