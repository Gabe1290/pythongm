# Scorciatoie da Tastiera

> [English](Keyboard-Shortcuts) | [Français](Keyboard-Shortcuts_fr) | [Deutsch](Keyboard-Shortcuts_de) | [Italiano](Keyboard-Shortcuts_it)

---

> [Torna alla Home](Home_it)

Un riferimento delle scorciatoie di modifica proprie di PyGameMaker. Si
tratta di **costruire il tuo gioco nell'IDE** — per i tasti che il tuo
*gioco finito* legge durante l'esecuzione (`keyboard_check`, eventi di
pressione tasto, ecc.), vedi invece [[Eventi_e_Azioni_it|Eventi e Azioni]].

---

## Globali (Finestra Principale)

| Scorciatoia | Azione |
|----------|--------|
| Ctrl+N | Nuovo Progetto |
| Ctrl+O | Apri Progetto |
| Ctrl+S | Salva Progetto |
| Ctrl+Maiusc+S | Salva Progetto Come |
| Ctrl+E | Esporta Progetto |
| Ctrl+Q | Esci |
| Ctrl+Z | Annulla |
| Ctrl+Y | Ripeti |
| Ctrl+X | Taglia |
| Ctrl+C | Copia |
| Ctrl+V | Incolla |
| Ctrl+D | Duplica |
| Ctrl+F | Trova |
| Ctrl+H | Trova e Sostituisci |
| F1 | Documentazione |
| F5 | Testa Gioco |
| F6 | Debug Gioco |
| F7 | Compila Gioco |
| F8 | Compila ed Esegui |

## Editor Sprite

| Scorciatoia | Strumento |
|----------|------|
| P | Matita |
| E | Gomma |
| I | Contagocce |
| G | Riempimento (secchiello) |
| L | Linea |
| R | Rettangolo |
| O | Ellisse |
| S | Selezione |
| Ctrl+C / Ctrl+X / Ctrl+V | Copia / Taglia / Incolla (una selezione) |
| Canc | Elimina (una selezione) |
| Esc | Deseleziona |

Vedi [[Sprite-Editor_it|Editor Sprite]] per cosa fa esattamente ogni strumento.

---

## Editor Oggetti

| Scorciatoia | Azione |
|----------|--------|
| Ctrl+S | Salva questo oggetto (funziona anche quando la scheda dell'editor oggetti ha il focus, senza attivare il Salva della finestra principale) |
| Ctrl+Su / Ctrl+Giù | Sposta l'evento selezionato su/giù nella lista |
| Ctrl+C / Ctrl+V | Copia / incolla un'azione |

---

## Editor Stanze

| Scorciatoia | Azione |
|----------|--------|
| Canc | Elimina l'istanza/le istanze selezionata/e |

La barra degli strumenti dell'Editor Stanze espone anche **Griglia**,
**Snap**, **Cancella Tutto** e **Sposta Tutto** — vedi
[[Editor_Stanze_it|Editor Stanze]].
