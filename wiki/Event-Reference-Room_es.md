# Eventos de Sala

*[Inicio](Home_es) | [Referencia de Eventos](Event-Reference_es) | [Referencia completa de acciones](Full-Action-Reference_es)*

### Room Start
| Propiedad | Valor |
|-----------|-------|
| **Nombre** | `room_start` |
| **Icono** | 🚪 |
| **Categoría** | Sala |
| **Preset** | Principiante |

**Descripción:** Se dispara al entrar en una sala, después de todos los eventos Create.

**Usos comunes:**
- Inicialización de sala
- Reproducir música de sala
- Establecer variables específicas de sala

---

### Room End
| Propiedad | Valor |
|-----------|-------|
| **Nombre** | `room_end` |
| **Icono** | 🚪 |
| **Categoría** | Sala |
| **Preset** | Principiante |

**Descripción:** Se dispara al salir de una sala.

**Usos comunes:**
- Guardar progreso
- Detener música
- Limpieza
