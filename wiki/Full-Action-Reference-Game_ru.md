### Нарисовать круг

| Свойство | Значение |
|----------|-------|
| **Имя** | `draw_circle` |
| **Значок** | ⭕ |
| **Категория** | Игра |

Нарисовать заполненный или контурный круг

| Параметр | Тип | По умолч. | Примечания |
|-----------|------|---------|-------|
| `x` | Число | `0` | Центр X |
| `y` | Число | `0` | Центр Y |
| `radius` | Число | `50` | Радиус круга |
| `filled` | Да/Нет | Да | Заполненный или только контур; необязательно |

### Нарисовать текст

| Свойство | Значение |
|----------|-------|
| **Имя** | `draw_text` |
| **Значок** | 🖍️ |
| **Категория** | Игра |

Нарисовать текстовую строку в позиции

| Параметр | Тип | По умолч. | Примечания |
|-----------|------|---------|-------|
| `text` | Текст | — | Текст для рисования (поддерживает выражения) |
| `x` | Число | `0` | Позиция X |
| `y` | Число | `0` | Позиция Y |
| `relative` | Да/Нет | Нет | Рисовать относительно позиции этого экземпляра вместо абсолютных экранных координат; необязательно |
| `color` | Цвет | — | Цвет текста (например, #ffffff). Пусто — активный цвет рисования, иначе чёрный.; необязательно |

### Задать прозрачность

| Свойство | Значение |
|----------|-------|
| **Имя** | `set_alpha` |
| **Значок** | 🌫️ |
| **Категория** | Игра |

Задать прозрачность рисования для последующих рисований

| Параметр | Тип | По умолч. | Примечания |
|-----------|------|---------|-------|
| `alpha` | Число | `1.0` | Непрозрачность от 0.0 (прозрачно) до 1.0 (непрозрачно) |

### Задать заголовок окна

| Свойство | Значение |
|----------|-------|
| **Имя** | `set_window_caption` |
| **Значок** | 🪟 |
| **Категория** | Игра |

Настроить отображение счёта/жизней/здоровья в заголовке окна

| Параметр | Тип | По умолч. | Примечания |
|-----------|------|---------|-------|
| `show_score` | Да/Нет | Да | Добавить текущий счёт в заголовок окна |
| `show_lives` | Да/Нет | Да | Добавить текущее количество жизней в заголовок окна |
| `show_health` | Да/Нет | Нет | Добавить текущее значение здоровья в заголовок окна |
| `caption` | Текст | — | Необязательный префикс заголовка, показываемый перед счётчиками; необязательно |
