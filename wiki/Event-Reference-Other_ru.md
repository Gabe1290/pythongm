### Outside Room
| Свойство | Значение |
|----------|----------|
| **Имя** | `outside_room` |
| **Иконка** | 🚫 |
| **Категория** | Другое |
| **Пресет** | Начинающий |

**Описание:** Срабатывает, когда экземпляр полностью за пределами комнаты.

**Типичные использования:**
- Уничтожение снарядов за экраном
- Перенос на другую сторону
- Запуск конца игры

### Animation End
| Свойство | Значение |
|----------|----------|
| **Имя** | `animation_end` |
| **Иконка** | 🎞️ |
| **Категория** | Другое |
| **Пресет** | Начинающий |

**Описание:** Срабатывает, когда анимация спрайта экземпляра завершает полный цикл (возвращается с последнего кадра к первому).

**Типичные использования:**
- Уничтожить одноразовый эффект (взрыв) после одного воспроизведения
- Перейти к другой анимации, когда текущая завершается
- Продвинуть конечный автомат по завершении анимации
