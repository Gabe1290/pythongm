## Вступ

У цьому посібнику ви створите **Гру-Платформер** — екшн-гру з боковою прокруткою, де гравець бігає, стрибає та переміщується платформами, уникаючи небезпек та збираючи монети. Цей класичний жанр ідеально підходить для вивчення гравітації, механіки стрибків та зіткнень з платформами.

**Що ви навчитесь:**
- Гравітація та фізика падіння
- Механіка стрибків з виявленням землі
- Зіткнення з платформами (приземлення зверху)
- Рух вліво/вправо
- Предмети для збирання та небезпеки

**Складність:** Початківець
**Пресет:** Пресет для Початківців

---

## Крок 1: Зрозуміти Гру

### Механіки Гри
1. На гравця діє гравітація, він падає вниз
2. Гравець може рухатися вліво та вправо
3. Гравець може стрибати, коли стоїть на землі
4. Платформи не дають гравцю провалитися
5. Збирайте монети для очок
6. Досягніть прапора, щоб завершити рівень

### Що Нам Потрібно

| Елемент | Призначення |
|---------|-------------|
| **Гравець** | Персонаж, яким ви керуєте |
| **Земля/Платформа** | Тверді поверхні для стояння |
| **Монета** | Предмети для збирання та очок |
| **Шип** | Небезпека, що шкодить гравцю |
| **Прапор** | Ціль, що завершує рівень |

## Крок 2: Створити Спрайти

### Спрайти
- `spr_player` (32x48 пікселів) — простий персонаж
- `spr_ground` (32x32 пікселі) — плитка трави/землі
- `spr_platform` (64x16 пікселів) — плаваюча платформа
- `spr_coin` (16x16 пікселів) — золоте коло
- `spr_spike` (32x32 пікселі) — трикутні шипи
- `spr_flag` (32x64 пікселі) — прапор на палиці

---

## Крок 3: Створити Об'єкт Землі

Земля — тверда платформа, що не дає гравцю впасти.

1. Клацніть правою кнопкою на **Objects** та виберіть **Create Object**
2. Назвіть його `obj_ground`
3. Встановіть спрайт на `spr_ground`
4. **Позначте прапорець "Solid"**
5. Події не потрібні

---

## Крок 4: Створити Об'єкт Платформи

Платформи діють так само, як земля, але їх можна розмістити в повітрі.

1. Створіть новий об'єкт з назвою `obj_platform`
2. Встановіть спрайт на `spr_platform`
3. **Позначте прапорець "Solid"**

---

## Крок 5: Створити Об'єкт Гравця

Гравець — найскладніший об'єкт, з гравітацією, стрибками та рухом.

1. Створіть новий об'єкт з назвою `obj_player`
2. Встановіть спрайт на `spr_player`

### 5.1 Гравітація

**Подія: Create** — Add Action: **Move** → **Set Gravity**
(Direction: `270`, Gravity: `0.5`) — 270° означає прямо вниз;
значення додається до вертикальної швидкості гравця щокадру, тож
відтепер гравець сам пришвидшується вниз.

### 5.2 Рух, Стрибки Та Зіткнення Із Землею

Додайте ці події за тим самим шаблоном, який уже використовують попередні посібники цієї вікі:

| Подія | Дія |
|---|---|
| Keyboard (held) → Left Arrow | Set Horizontal Speed на `-4` |
| Keyboard (held) → Right Arrow | Set Horizontal Speed на `4` |
| Keyboard: No Key | Set Horizontal Speed на `0` |
| Key Press → Up Arrow | Set Vertical Speed на `-10` |
| Collision with obj_ground | Stop Movement |

Дві деталі, через які це працює правильно:

- **No Key встановлює ЛИШЕ горизонтальну швидкість на 0** — ніколи не
  використовуйте тут Stop Movement, бо Stop Movement скидає й
  вертикальну швидкість теж, що щоразу скасовувало б гравітацію,
  коли гравець відпускає клавішу напрямку.
- **Key Press (не held)** — саме це робить Up одним стрибковим
  імпульсом, а не постійним підштовхуванням гравця вгору щокадру,
  поки клавіша утримується. **Stop Movement** при приземленні скасовує
  цей імпульс, тож гравець не продовжує підійматися після приземлення
  — вбудоване тверде зіткнення рушія (Крок 3 уже зробив `obj_ground`
  Solid) уже не дає гравцю провалитися в землю; подія тут лише очищає
  залишкову швидкість падіння.

## Крок 6-8: Предмети Для Збирання Та Небезпеки

**obj_coin** — Зіткнення з obj_player: Рахунок +10, знищити Self

**obj_spike** — Зіткнення з obj_player: Показати повідомлення, перезапустити кімнату

**obj_flag** — Зіткнення з obj_player: Показати повідомлення, наступна кімната

---

## Крок 9: Спроектуйте Свій Рівень

1. Створіть `room_level1` (800x480)
2. Увімкніть прив'язку до сітки (32x32)
3. Розмістіть землю внизу, платформи в повітрі
4. Додайте монети, шипи
5. Поставте прапор в кінці, гравця на початку

---

## Що Ви Навчились

- **Фізика гравітації** — Set Gravity щокадру застосовує постійну силу вниз
- **Механіка стрибків** — Подія Key Press (не held) дає один-єдиний імпульс швидкості вгору
- **Вбудоване тверде зіткнення** — Земля автоматично блокує гравця, коли позначена як Solid, без ручного коду для перевірки позиції
