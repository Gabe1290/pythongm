## Вступ

У цьому посібнику ви створите **Гру-Платформер** — екшн-гру з боковою прокруткою, де гравець бігає, стрибає та переміщується платформами, уникаючи небезпек та збираючи монети. Цей класичний жанр ідеально підходить для вивчення гравітації, механіки стрибків та зіткнень з платформами.

**Що ви навчитесь:**
- Гравітація та фізика падіння
- Механіка стрибків з виявленням землі
- Зіткнення з платформами (приземлення зверху)
- Рух вліво/вправо
- Предмети для збирання та небезпеки

**Складність:** Початківець
**Пресет:** Середній Пресет (дії Execute Code з розділу «Покращення» відсутні в Пресеті для Початківців; для базового посібника аж до Кроку 10 потрібні лише дії Пресета для Початківців)

## Крок 1: Зрозуміти Гру

### Механіки Гри
1. На гравця діє гравітація, він падає вниз
2. Гравець може рухатися вліво та вправо
3. Гравець може стрибати, коли стоїть на землі
4. Платформи не дають гравцю провалитися
5. Збирайте монети для очок
6. Досягніть прапора, щоб завершити рівень

### Що Нам Потрібно

| Елемент | Призначення |
|---------|-------------|
| **Гравець** | Персонаж, яким ви керуєте |
| **Земля/Платформа** | Тверді поверхні для стояння |
| **Монета** | Предмети для збирання за очки |
| **Шип** | Небезпека, що ранить гравця |
| **Прапор** | Ціль, що завершує рівень |

## Крок 2: Створити Спрайти

### 2.1 Спрайт Гравця

1. У **Дереві Ресурсів** клацніть правою кнопкою на **Sprites** та виберіть **Create Sprite**
2. Назвіть його `spr_player`
3. Натисніть **Edit Sprite**, щоб відкрити редактор спрайтів
4. Намалюйте простого персонажа (прямокутник з обличчям або чоловічка з паличок)
5. Використайте яскравий колір, як-от синій або червоний
6. Розмір: 32x48 пікселів (вищий, ніж ширший, для персонажа)
7. Натисніть **OK**, щоб зберегти

### 2.2 Спрайт Землі

1. Створіть новий спрайт з назвою `spr_ground`
2. Намалюйте плитку платформи з трави/землі
3. Використайте коричневий та зелений кольори
4. Розмір: 32x32 пікселі

### 2.3 Спрайт Платформи

1. Створіть новий спрайт з назвою `spr_platform`
2. Намалюйте плаваючу платформу (дерево або камінь)
3. Розмір: 64x16 пікселів (широка й тонка)

### 2.4 Спрайт Монети

1. Створіть новий спрайт з назвою `spr_coin`
2. Намалюйте маленьке жовте/золоте коло
3. Розмір: 16x16 пікселів

### 2.5 Спрайт Шипа

1. Створіть новий спрайт з назвою `spr_spike`
2. Намалюйте трикутні шипи, спрямовані вгору
3. Використайте сірий або червоний колір
4. Розмір: 32x32 пікселі

### 2.6 Спрайт Прапора

1. Створіть новий спрайт з назвою `spr_flag`
2. Намалюйте прапор на держаку
3. Використайте яскраві кольори (зелений прапор, коричневий держак)
4. Розмір: 32x64 пікселі

## Крок 5: Створити Об'єкт Гравця

Гравець — найскладніший об'єкт: гравітація, стрибок і рух.

1. Створіть новий об'єкт з назвою `obj_player`
2. Встановіть спрайт `spr_player`

### 5.1 Гравітація

**Подія: Create** — Додайте дію **Move** → **Set Gravity**
(Direction: `270`, Gravity: `0.5`) — 270° це прямо вниз; значення
додається до вертикальної швидкості гравця на кожному кроці, тож гравець
сам прискорюється вниз з цього моменту.

### 5.2 Рух, Стрибок і Зіткнення із Землею

Додайте ці події за тим самим шаблоном, який уже використовують попередні
посібники цього вікі:

| Подія | Дія |
|---|---|
| Keyboard (held) → Left Arrow | Set Horizontal Speed на `-4` |
| Keyboard (held) → Right Arrow | Set Horizontal Speed на `4` |
| Keyboard: No Key | Set Horizontal Speed на `0` |
| Key Press → Up Arrow | Set Vertical Speed на `-10` |
| Collision with obj_ground | Stop Movement |

Дві деталі, завдяки яким усе відчувається правильно:

- **No Key обнуляє ЛИШЕ горизонтальну швидкість** — ніколи не
  використовуйте тут Stop Movement, бо Stop Movement обнуляє й
  вертикальну швидкість, що скасовувало б гравітацію щоразу, коли гравець
  відпускає клавішу напрямку.
- **Key Press (не held)** — це те, що робить Up одним імпульсом стрибка,
  замість підкидання гравця вгору на кожному кадрі, поки клавіша
  утримується. **Stop Movement** при приземленні потім скасовує цей
  імпульс, щоб гравець не продовжував підніматися після приземлення —
  вбудоване зіткнення з твердими об'єктами рушія (Крок 3 уже зробив
  `obj_ground` Solid) уже не дає гравцю провалитися в землю; подія тут
  лише очищує залишкову швидкість падіння.

## Покращення (Необов'язково)

### Додати Змінну Висоту Стрибка

Додайте подію **Step** до `obj_player` з **Control** → **Execute Code**
(справжній Python — `self` це поточний екземпляр, `keyboard` дозволяє
перевірити утримувану клавішу за іменем):

```python
# Обриває стрибок, якщо Up відпущено під час підйому
if self.vspeed < 0 and not keyboard.check('up'):
    self.vspeed = max(self.vspeed, -5)  # половина імпульсу стрибка -10
```

### Додати Подвійний Стрибок

Це можна зробити повністю структурованими діями — код не потрібен.

**Подія: Create** — Додайте дію **Control** → **Set Variable**
(Variable: `jumps_left`, Value: `2`)

**Подія: Collision with obj_ground** — після **Stop Movement** додайте
**Control** → **Set Variable** (Variable: `jumps_left`, Value: `2`), щоб
поповнювати обидва стрибки при приземленні.

Замініть єдину дію наявної події **Key Press → Up Arrow** на три, по
порядку:
1. **Control** → **Test Variable** (Variable: `jumps_left`, Value: `0`,
   Operation: `greater`)
2. **Control** → **Start Block**
3. **Move** → **Set Vertical Speed** (`-10`)
4. **Control** → **Set Variable** (Variable: `jumps_left`, Value: `-1`,
   позначено **Relative**)
5. **Control** → **End Block**

Пара Start/End Block означає, що обидві дії всередині виконуються лише
тоді, коли Test Variable над ними істинний — той самий шаблон захищеного
блоку, який посібники Sokoban та Лабіринт використовують для своїх умов.

### Додати Рухомі Платформи

1. Створіть `obj_moving_platform` як нащадка `obj_platform`

**Подія: Create** — Додайте дію **Control** → **Execute Code**:

```python
self.start_x = self.x
self.hspeed = 2
```

**Подія: Step** — Додайте дію **Control** → **Execute Code**:

```python
if self.x > self.start_x + 100:
    self.hspeed = -2
elif self.x < self.start_x:
    self.hspeed = 2
```

### Додати Ворога

1. Створіть `obj_enemy` з простим ШІ

**Подія: Create** — Додайте дію **Move** → **Start Moving Direction**
(Directions: `right`, Speed: `2`)

**Подія: Collision with obj_ground** — Додайте дію **Move** → **Reverse
Horizontal** (розвертається біля стін; у поєднанні з тим, що `obj_ground`
є Solid, ворог ніколи не зійде з краю платформи в землю нижче й не пройде
крізь стіну)

**Подія: Collision with obj_player** — ця подія спрацьовує на `obj_enemy`,
тож `self` це ворог, а `other` це гравець. Додайте дію **Control** →
**Test Expression** із вкладеними діями Then/Else (той самий шаблон, який
вбудований приклад `plateforme_3` використовує саме для цієї перевірки
«стрибка на голову», лише дзеркально, бо перевірка тут живе на ворозі, а
не на гравці):
   - Expression: `other.vspeed > 0 and other.y - other.vspeed < y - 16`
   - Then Actions: **Control** → **Execute Code** з `other.vspeed = -5`
     (невеликий відскок для гравця — у `set_vspeed` немає опції "applies
     to other", тож це єдине місце, де потрібен рядок справжнього Python
     замість структурованої дії), потім **Instance** → **Destroy
     Instance** (self)
   - Else Actions: **Room** → **Restart Room** (гравець помирає)

`other.vspeed > 0 and other.y - other.vspeed < y - 16` перевіряє позицію
*гравця* з моменту до руху падіння в цьому кадрі (використовуючи власний
`vspeed` гравця, адже падає саме він), тож швидке падіння не може
проскочити 16-піксельне вікно стрибка за один крок — див. README
`plateforme_3` для повної історії про те, чому наївна версія
`other.y < y - 16` ненадійна.

### Додати Систему Життів

У події **Create** об'єкта `obj_game_controller` додайте **Score** → **Set
Lives** (Value: `3`).

Коли гравець помирає (зіткнення з шипом і гілка Else ворога вище),
замініть **Restart Room** на **Score** → **Set Lives** (Value: `-1`,
позначено **Relative**) — room перезапускається автоматично, бо подія
**No More Lives** спрацьовує лише тоді, коли життя справді досягають 0.
Додайте цю подію до `obj_game_controller`: **Other Events** → **No More
Lives** → **Output** → **Show Message** (`Game Over!`) → **Room** →
**Restart Game**.

## Усунення Несправностей

| Проблема | Рішення |
|----------|---------|
| Гравець провалюється крізь землю | Перевірте, що в `obj_ground` позначено "Solid" |
| Гравець не може стрибнути | Переконайтеся, що подія Key Press → Up Arrow існує й Set Vertical Speed від'ємне |
| Гравець продовжує підніматися після приземлення | Переконайтеся, що Collision with obj_ground має дію Stop Movement |
| Стрибок відчувається «плаваючим» | Збільште значення Gravity в Set Gravity або зробіть значення стрибка Set Vertical Speed більш від'ємним |
| Стрибок надто слабкий | Зменште значення Gravity в Set Gravity або зробіть значення стрибка Set Vertical Speed більш від'ємним |

## Що Ви Навчились

Вітаємо! Ви створили гру-платформер! Ви навчились:

- **Фізика гравітації** — Set Gravity застосовує сталу силу вниз на кожному кроці
- **Механіка стрибків** — Подія Key Press (не held) дає один імпульс швидкості вгору
- **Вбудоване зіткнення з твердими об'єктами** — Земля блокує гравця автоматично, щойно позначена як Solid, без ручного коду перевірки позиції
- **Небезпеки** — Створення об'єктів, які перезапускають рівень
- **Дизайн рівнів** — Побудова платформенних випробувань
