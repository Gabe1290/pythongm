### Применить гравитацию

| Свойство | Значение |
|----------|-------|
| **Имя** | `apply_gravity` |
| **Значок** | ⬇️ |
| **Категория** | 3D-вид |

Непрерывная физика падения и приземления для камеры Block World: разместите её в событии Шаг (а не в событии удерживаемой клавиши), чтобы она выполнялась каждый кадр независимо от ввода движения. Ничего не делает, пока параметр «Гравитация» действия «Включить вид Block World» не больше 0

*Параметры:* нет

### Разрушить блок

| Свойство | Значение |
|----------|-------|
| **Имя** | `break_block` |
| **Значок** | ⛏️ |
| **Категория** | 3D-вид |

Убирает блок, на который смотрит камера; кроме того, кладёт его в инвентарь вызвавшего экземпляра, если инвентарь в «Включить вид Block World» включён, и отказывается убирать блок, если он защищён («Задать защиту блоков»), а нужного ключа нет в инвентаре

| Параметр | Тип | По умолч. | Примечания |
|-----------|------|---------|-------|
| `reach` | Число | `5` | Дальность действия вперёд, в ячейках сетки; необязательно |

### Включить вид Block World

| Свойство | Значение |
|----------|-------|
| **Имя** | `enable_block_world_view` |
| **Значок** | 🧱 |
| **Категория** | 3D-вид |

Показывает комнату как воксельный вид от первого лица (один слой) вместо вида сверху

| Параметр | Тип | По умолч. | Примечания |
|-----------|------|---------|-------|
| `enable` | Да/Нет | Да | Вкл. — вид блоков от первого лица; выкл. — обычный вид сверху |
| `camera_object` | Объект | — | Объект, чья позиция + угол взгляда является камерой (пусто = объект, выполняющий это действие); необязательно |
| `z_layer` | Число | `0` | Какой слой мира отрисовывается (на этапе 2a рисуется ровно один слой — взгляда вверх и вниз пока нет); необязательно |
| `fov` | Число | `66` | Горизонтальное поле зрения в градусах; необязательно |
| `render_distance` | Число | `20` | Макс. длина луча в клетках сетки; необязательно |
| `cell_size` | Число | `32` | Размер ячейки сетки в пикселях (в соответствии с сеткой размещения блоков); необязательно |
| `columns` | Число | `320` | Столбцы экрана для raycast (меньше = быстрее/грубее); необязательно |
| `wall_color` | Цвет | `#8a8a8a` | Сплошной цвет, используется только если текстурные блоки выключены; необязательно |
| `floor_color` | Цвет | `#3a2f1c` | Сплошной цвет пола (на этапе 2a пол ещё не текстурируется); необязательно |
| `ceiling_color` | Цвет | `#87CEEB` | Сплошной цвет потолка или неба (на этапе 2a неба ещё нет); необязательно |
| `pitch` | Число | `0` | Градусы для взгляда вверх (+) или вниз (−); 0 — горизонт; необязательно |
| `wall_textured` | Да/Нет | Да | Выкл. принудительно даёт сплошные цвета блоков, даже когда доступны настоящие текстуры; необязательно |
| `top_cast_res` | Число | `4` | Детализация текстуры верхних и нижних граней: сколько строк выбирается на каждые N строк экрана (больше — быстрее и грубее, 0 — сплошной средний цвет вместо текстуры); необязательно |
| `eye_height` | Число | `1.5` | Высота камеры над слоем, на котором она стоит, в ячейках (1,5 — тело высотой в два блока; нужно, чтобы видеть верх блока на своём слое и забираться на него); необязательно |
| `gravity` | Число | `0` | Ускорение вниз в ячейках/шаг² для действия «Прыжок», а также для гравитации и падения (уровень 7a). 0 (по умолчанию) сохраняет исходное мгновенное вставание «Двигаться со столкновением» без прыжков; типичное значение — около 0,04; необязательно |
| `inventory` | Да/Нет | Нет | Вкл. — «Разрушить блок» подбирает разрушенное, а «Поставить блок» расходует из этого инвентаря (уровень 7c); выкл. (по умолчанию) — неограниченная постройка как в творческом режиме, как и до уровня 7c; необязательно |
| `generate` | Да/Нет | Нет | Вкл. — процедурно создавать холмистый ландшафт вокруг камеры по мере исследования (уровень 7e), используя зерно ниже; выкл. (по умолчанию) — существуют только расставленные вручную или загруженные блоки, как и до уровня 7e; необязательно |
| `seed` | Число | `0` | Зерно мира для «Создать ландшафт» — одно и то же зерно всегда даёт один и тот же ландшафт на этой платформе. Игнорируется, если создание ландшафта выключено; необязательно |

### Включить вид Raycast

| Свойство | Значение |
|----------|-------|
| **Имя** | `enable_raycast_view` |
| **Значок** | 🕹️ |
| **Категория** | 3D-вид |

Отображать комнату как 3D-вид от первого лица в стиле Doom/Wolfenstein (стены, небо, пол) вместо вида сверху

| Параметр | Тип | По умолч. | Примечания |
|-----------|------|---------|-------|
| `enable` | Да/Нет | Да | Вкл. = вид raycast от первого лица; выкл. = обычный вид сверху |
| `camera_object` | Объект | — | Объект, чья позиция + угол взгляда является камерой (пусто = объект, выполняющий это действие); необязательно |
| `fov` | Число | `66` | Горизонтальное поле зрения в градусах; необязательно |
| `render_distance` | Число | `20` | Макс. длина луча в клетках сетки; необязательно |
| `cell_size` | Число | `32` | Размер клетки сетки в пикселях (соответствует сетке размещения стен); необязательно |
| `columns` | Число | `320` | Столбцы экрана для raycast (меньше = быстрее/грубее); необязательно |
| `wall_color` | Цвет | `#993333` | Сплошной цвет стен, когда текстура стены не задана; необязательно |
| `floor_color` | Цвет | `#464632` | Сплошной цвет пола, когда текстура пола не задана; необязательно |
| `ceiling_color` | Цвет | `#87CEEB` | Сплошной цвет потолка, когда текстура неба/потолка не задана; необязательно |
| `wall_texture` | Спрайт | — | Спрайт для текстурирования каждой стены (пусто = сплошной цвет); необязательно |
| `sky_texture` | Спрайт | — | Спрайт для панорамного неба над потолком (пусто = сплошной); необязательно |
| `floor_texture` | Спрайт | — | Спрайт, проецируемый на пол (пусто = сплошной цвет); необязательно |
| `ceiling_texture` | Спрайт | — | Спрайт, проецируемый на потолок, когда небо не задано; необязательно |
| `wall_textured` | Да/Нет | Да | Выкл. принудительно задаёт сплошные цвета стен, даже когда задана текстура; необязательно |
| `floor_cast_res` | Число | `4` | Уменьшение дискретизации пола (больше = быстрее + грубее); необязательно |
| `viewport_height` | Число | `0` | Ограничить 3D-вид до этой высоты в пикселях (леттербокс), зарезервировав полосу ниже для полосы состояния в стиле DOOM (0 = полная высота окна, без изменений); необязательно |

### Прыжок

| Свойство | Значение |
|----------|-------|
| **Имя** | `jump` |
| **Значок** | ⬆️ |
| **Категория** | 3D-вид |

Придаёт камере Block World скорость вверх — только когда она стоит на твёрдой поверхности (без двойных прыжков и прыжков в воздухе). Требует настроенной гравитации («Включить вид Block World») и действия «Применить гравитацию» в событии Шаг, иначе камера уже не опустится

| Параметр | Тип | По умолч. | Примечания |
|-----------|------|---------|-------|
| `speed` | Число | `0.35` | Начальная скорость вверх, в ячейках за шаг; необязательно |

### Двигаться со столкновением

|----------|-------|
| **Имя** | `move_and_collide` |
| **Значок** | 🚶 |
| **Категория** | 3D-вид |

Выполняет шаг движения с проверкой по сетке блоков и автоматической опорой (подъём на один блок, спуск на любую высоту): слой z_layer камеры следует за ним, если это камера Block World

### Поставить блок

|----------|-------|
| **Имя** | `place_block` |

### Задать защиту блоков

| Свойство | Значение |
|----------|-------|
| **Имя** | `set_block_protection` |
| **Значок** | 🔒 |
| **Категория** | 3D-вид |

Требует наличия определённого типа блока в инвентаре, прежде чем «Разрушить блок» сможет убрать выбранный тип блока: вызывайте по одному разу на каждый защищённый тип; требует включённого инвентаря в «Включить вид Block World», иначе условие невозможно выполнить

| Параметр | Тип | По умолч. | Примечания |

### Задать награду за блок

| Свойство | Значение |
|----------|-------|
| **Имя** | `set_block_reward` |
| **Значок** | 💎 |
| **Категория** | 3D-вид |

Начисляет очки, когда «Разрушить блок» успешно убирает выбранный тип блока: вызывайте по одному разу на каждый награждаемый тип (например, в событии Создание комнаты, сразу после «Включить вид Block World»). Добываемая руда или самоцвет: разместите блок в ландшафте, зарегистрируйте награду — и разрушение начислит очки автоматически

### Задать угол взгляда

| **Категория** | 3D-вид |
