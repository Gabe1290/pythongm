Кімнати — це рівні, екрани або сцени вашої гри. Редактор Кімнат
дозволяє проєктувати ці простори, розміщуючи об'єкти та налаштовуючи фони.

---

## Відкриття Редактора Кімнат

1. Двічі клацніть на наявній кімнаті в дереві ресурсів, або
2. Клацніть правою кнопкою на **Rooms** > **Create Room**

![Редактор Кімнат: палітра об'єктів зліва для вибору того, що

## Властивості Кімнати

| Властивість | Опис |
|-----------|-------------|
| **Name** | Унікальний ідентифікатор (напр. `room_level1`) |
| **Width** | Ширина кімнати в пікселях |
| **Height** | Висота кімнати в пікселях |
| **Speed** | Швидкість гри в кадрах на секунду (за замовчуванням: 60) |
| **Persistent** | Зберігає стан кімнати при виході/повторному вході |

### Угода Про Іменування

Використовуйте префікс `room_` для кімнат:
- `room_menu`
- `room_level1`
- `room_game_over`

## Розміщення Об'єктів

### Додавання Екземплярів

1. Виберіть об'єкт у панелі **Objects**
2. Клацніть у вигляді кімнати, щоб розмістити екземпляр
3. Клацніть і перетягуйте, щоб розмістити кілька екземплярів

### Вибір Екземплярів

- Клацніть на екземплярі, щоб вибрати його
- Утримуйте **Ctrl** і клацайте, щоб вибрати кілька
- Намалюйте прямокутник, щоб вибрати всі екземпляри всередині нього

### Переміщення Екземплярів

- Перетягуйте вибрані екземпляри мишею
- Використовуйте клавіші зі стрілками для точного переміщення

### Видалення Екземплярів

- Виберіть екземпляри та натисніть **Delete**, або
- Клацніть правою кнопкою і виберіть "Видалити"

## Налаштування Сітки

Увімкніть сітку для точного розміщення:

1. Перейдіть до **View > Show Grid**
2. Встановіть розмір сітки (напр. 32x32)
3. Увімкніть "Snap to Grid"

Поширені розміри сітки:
- **16x16** — Малі плитки
- **32x32** — Стандартні плитки
- **64x64** — Великі плитки

---

## Фони

### Налаштування Фону

1. Клацніть на вкладку **Backgrounds**
2. Виберіть ресурс фону
3. Налаштуйте параметри відображення

### Параметри Фону

| Параметр | Опис |
|--------|-------------|
| **Visible** | Показує/приховує фон |
| **Foreground** | Малює перед об'єктами |
| **Tile Horizontal** | Повторює горизонтально |
| **Tile Vertical** | Повторює вертикально |
| **Stretch** | Розтягує, щоб заповнити кімнату |
| **Horizontal Speed** | Швидкість прокручування (паралакс) |
| **Vertical Speed** | Швидкість прокручування (паралакс) |

### Шари Фону

Кімната підтримує до **8 шарів фону**, кожен зі своєю швидкістю
прокручування для ефектів паралаксу. Приклад розташування:
- Шар 0: Небо (найдальше на фоні)
- Шар 1: Гори (повільніше прокручування)
- Шар 2: Дерева (середнє прокручування)
- Шар 3: Земля (без прокручування)

## Views (Камера)

Views контролюють, яка частина кімнати видима на екрані. Для кімнати
можна налаштувати до **8 views** (View 0 до View 7) — View 0 видимий
за замовчуванням; додаткові views вмикайте для розділеного екрана або
"картинки в картинці".

### Увімкнення Views

1. Виберіть "Enable Views" у властивостях кімнати
2. Налаштуйте View 0 (головний view)

### Властивості Views

| Властивість | Опис |
|-----------|-------------|
| **View X/Y** | Верхній лівий кут view в кімнаті |
| **View Width/Height** | Розмір видимої області |
| **Port X/Y** | Позиція на екрані |
| **Port Width/Height** | Розмір на екрані (може розтягуватися) |
| **Object Following** | Об'єкт, за яким слідкує view |
| **Border H/V** | Мертва зона, перш ніж камера почне рухатися |

### Слідкування За Об'єктом

Щоб камера слідкувала за гравцем:
1. Встановіть "Object Following" на `obj_player`
2. Налаштуйте "Border H" та "Border V" для плавного прокручування

## Порядок Кімнат

Порядок кімнат у дереві ресурсів визначає:
1. Яка кімната завантажується першою (кімната зверху = початкова кімната)
2. Порядок для дій "Next Room" та "Previous Room"

### Зміна Порядку Кімнат

- Перетягуйте кімнати в дереві ресурсів, щоб змінити їх порядок
- Або клацніть правою кнопкою і використовуйте "Перемістити Вгору" / "Перемістити Вниз"

---

## Поради Та Найкращі Практики

### Організація
- Давайте кімнатам зрозумілі назви відповідно до їх призначення
- Тримайте головне меню як першу кімнату
- Використовуйте узгоджені розміри кімнат у грі

### Продуктивність
- Не розміщуйте забагато екземплярів в одній кімнаті
- Для статичної геометрії рівнів використовуйте плитки
- Коли можливо, знищуйте екземпляри поза екраном
