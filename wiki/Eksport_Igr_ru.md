PyGameMaker может экспортировать вашу игру на несколько платформ. Это руководство охватывает каждую опцию экспорта и её использование.

---

## Обзор экспорта

| Платформа | Формат | Требования |
|-----------|--------|------------|
| **Windows** | .exe | PyInstaller |
| **macOS** | .app | PyInstaller (на Mac) |
| **HTML5** | .html | Современный браузер |
| **Linux** | Двоичный файл | PyInstaller, Python 3.10+ |
| **Kivy / Android** | Исходный код / .apk | Buildozer |
| **Проект (.zip)** | .zip | — (поделиться редактируемым проектом) |

> **Ничто не отбрасывается молча.** Если ваша игра использует действие, которое цель
> не может воспроизвести (например, некоторые действия не поддерживаются экспортом
> Kivy/Android), экспорт всё равно удаётся, но сообщает вам, какие именно действия
> были **пропущены**, чтобы вы могли скорректировать. Если ваш проект использует
> отключённое [расширение](Extensions_ru) (например, 3D-вид), IDE предупреждает вас
> при загрузке.

## Экспорт Windows EXE

Создайте автономный исполняемый файл Windows, работающий без установленного Python.

### Как экспортировать

1. Откройте **Файл → Экспортировать проект…** (Ctrl+E) и выберите **Windows**
2. Выберите папку вывода
3. Дождитесь завершения процесса сборки
4. Найдите файл .exe в папке вывода

### Что создаётся

```
папка_вывода/
├── МояИгра.exe       # Основной исполняемый файл
├── _internal/        # Необходимые библиотеки
└── assets/           # Ресурсы игры
```

### Требования

- PyInstaller (устанавливается через `pip install pyinstaller`)
- Система Windows для сборки (кросс-компиляция не поддерживается)

### Распространение

Чтобы поделиться игрой:
1. Сожмите всю папку вывода в zip
2. Распространяйте zip-файл
3. Пользователи распаковывают и запускают .exe

### Устранение неполадок

**Отсутствующие DLL:** Убедитесь, что все зависимости включены. Проверьте вывод PyInstaller на предупреждения.

**Предупреждения антивируса:** Некоторые антивирусы помечают исполняемые файлы PyInstaller. Это ложное срабатывание. Возможно, придётся подписать ваш исполняемый файл.

## Экспорт приложения macOS

Создайте нативный пакет `.app` для macOS с помощью PyInstaller.

### Как экспортировать

1. Откройте **Файл → Экспортировать проект…** (Ctrl+E) и выберите **macOS**
2. Выберите папку вывода
3. Дождитесь завершения сборки
4. Найдите `МояИгра.app` в папке вывода

### Требования

- **Mac** для сборки (кросс-компиляция из Windows/Linux не поддерживается)
- PyInstaller и Kivy, установленные в Python сборки

### Распространение

Сожмите пакет `.app` в zip, чтобы поделиться им. Неподписанные приложения вызывают
Gatekeeper на других Mac — пользователи при первом запуске делают правый клик →
**Открыть**, или вы подписываете/нотаризуете приложение с помощью учётной записи
Apple Developer.

## Экспорт HTML5

Создайте один HTML-файл, работающий в веб-браузерах.

### Как экспортировать

1. Перейдите в **Файл → Экспортировать как HTML5…**
2. Выберите место вывода
3. Выберите опции (сжатие и т. д.)
4. Нажмите Экспорт

### Что создаётся

```
папка_вывода/
└── МояИгра.html      # Игра в одном файле
```

### Особенности

- Работает в любом современном браузере (Chrome, Firefox, Edge, Safari)
- Не требует установки
- Сжато gzip для быстрой загрузки
- Подходит для мобильных с сенсорным управлением

### Хостинг вашей игры

Загрузите HTML-файл на:
- Ваш собственный веб-сервер
- GitHub Pages (бесплатно)
- itch.io (хостинг, ориентированный на игры)
- Любой хостинг статических файлов

### Совместимость браузеров

| Браузер | Поддержка |
|---------|-----------|
| Chrome 80+ | Полная |
| Firefox 75+ | Полная |
| Edge 80+ | Полная |
| Safari 13+ | Полная |
| Мобильный Chrome | Полная |
| Мобильный Safari | Полная |

### Ограничения

- Некоторые функции могут не работать (доступ к файловой системе и т. д.)
- Аудио может требовать взаимодействия пользователя для запуска
- Производительность зависит от устройства/браузера

## Экспорт Linux

Создайте нативный исполняемый файл Linux.

### Как экспортировать

1. Откройте **Файл → Экспортировать проект…** (Ctrl+E) и выберите **Linux**
2. Выберите папку вывода
3. Дождитесь процесса сборки

### Требования

- Система Linux для сборки
- Python 3.10+
- PyInstaller

### Распространение

```bash
# Сделать файл исполняемым
chmod +x МояИгра

# Запустить игру
./МояИгра
```

Распространяйте как архив .tar.gz:
```bash
tar -czvf МояИгра-linux.tar.gz МояИгра/
```

## Экспорт Kivy (мобильный)

Создавайте мобильные приложения для iOS и Android с помощью фреймворка Kivy.

### Как экспортировать

1. Перейдите в **Файл → Экспортировать в Kivy…**
2. Выберите папку вывода
3. Настройте мобильные параметры
4. Экспортируйте проект Kivy

### Сборка для Android

Экспортированный проект Kivy использует Buildozer для создания APK:

```bash
cd экспортированный_проект
pip install buildozer
buildozer init
buildozer android debug
```

### Сборка для iOS

Требует Mac с Xcode:

```bash
cd экспортированный_проект
pip install kivy-ios
toolchain build python3 kivy
toolchain create МояИгра ~/ios_проект
```

### Мобильные соображения

- Сенсорное управление сопоставляется автоматически
- Масштабирование экрана обрабатывается автоматически
- Тестируйте на нескольких размерах экрана
- Оптимизируйте размеры ресурсов для мобильных

## Экспорт проекта (.zip)

Поделитесь самим **редактируемым проектом** (не скомпилированной игрой):
воспользуйтесь **Файл → Экспортировать проект…** (Ctrl+E), чтобы создать архив
`.zip`, который кто-то другой может снова открыть в PyGameMaker. Идеально для
совместной работы, резервных копий или сдачи школьных работ.

## Параметры экспорта

### Общие параметры

| Параметр | Описание |
|----------|----------|
| **Название игры** | Название, показываемое в заголовке/приложении |
| **Иконка** | Иконка приложения (Windows/мобильный) |
| **Версия** | Номер версии (1.0.0) |
| **Автор** | Имя разработчика |

### Параметры Windows

| Параметр | Описание |
|----------|----------|
| **Консоль** | Показывать окно консоли (для отладки) |
| **Один файл** | Один .exe против папки с _internal |
| **UPX** | Сжать с помощью UPX (меньший размер) |

### Параметры HTML5

| Параметр | Описание |
|----------|----------|
| **Сжатие** | Включить сжатие gzip |
| **Полный экран** | Запускать в полноэкранном режиме |
| **Сенсорное управление** | Показывать экранное управление |

## Контрольный список перед экспортом

Перед экспортом проверьте:

- [ ] Все ресурсы включены в проект
- [ ] Игра корректно работает в IDE
- [ ] Нет отладочных сообщений или тестового кода
- [ ] Порядок комнат правильный (стартовая комната первой)
- [ ] Аудиофайлы в поддерживаемых форматах
- [ ] Спрайты оптимизированы по размеру файла

---

## Оптимизация размера файла

### Спрайты
- Используйте подходящие размеры (не слишком большие)
- Сожмите файлы PNG
- Рассмотрите JPEG для изображений без прозрачности

### Аудио
- Используйте OGG/MP3 для музыки (не WAV)
- Держите звуковые эффекты короткими
- Более низкие частоты дискретизации для простых звуков

### Общее
- Удалите неиспользуемые ресурсы
- Минимизируйте размеры комнат
- Тестируйте на целевых платформах

## Тестирование экспортов

Всегда тестируйте вашу экспортированную игру:

1. **Windows:** Тестируйте на чистом ПК без Python
2. **HTML5:** Тестируйте в нескольких браузерах
3. **Linux:** По возможности тестируйте на разных дистрибутивах
4. **Мобильный:** Тестируйте на реальных устройствах, а не только на эмуляторах

## Платформы распространения

### itch.io
- Бесплатный хостинг для инди-игр
- Поддерживает HTML5, Windows, Linux, Mac
- Встроенная платёжная система

### Steam
- Требует интеграции Steamworks SDK
- Используйте PyInstaller с Steam API
- Платный взнос за публикацию

### Google Play (Android)
- Требует учётной записи разработчика (25 $)
- Соберите подписанный APK с помощью Buildozer
- Следуйте правилам в отношении контента

### App Store (iOS)
- Требует учётной записи Apple Developer (99 $/год)
- Соберите с помощью kivy-ios
- Отправьте через App Store Connect
