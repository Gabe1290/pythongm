## Введение

В этом учебнике вы создадите игру-головоломку **Sokoban** — классическую головоломку с передвижением ящиков, в которой игрок должен толкать все ящики на целевые места. Sokoban (означает "хранитель склада" на японском) идеально подходит для обучения движению по сетке и логике игры-головоломки.

**Что вы научитесь:**
- Движению по сетке (движение фиксированными шагами)
- Механике толкания объектов
- Обнаружению столкновений с различными типами объектов
- Определению условия победы
- Проектированию уровней для игр-головоломок

**Сложность:** Начинающий
**Пресет:** Средний пресет (механика толкания и движение по сетке,
использованные здесь, не входят в пресет для начинающих)

## Шаг 1: Поймите игру

### Правила игры
1. Игрок может двигаться вверх, вниз, влево или вправо
2. Игрок может толкать ящики (но не тянуть их)
3. За раз можно толкать только один ящик
4. Ящики нельзя толкать сквозь стены или другие ящики
5. Уровень завершён, когда все ящики находятся на целевых местах

### Что нам нужно

| Элемент | Назначение |
|---------|-----------|
| **Игрок** | Хранитель склада, которым вы управляете |
| **Ящик** | Коробки, которые игрок толкает |
| **Стена** | Твёрдые препятствия, блокирующие движение |
| **Цель** | Целевые места, где должны находиться ящики |
| **Пол** | Проходимая поверхность (опционально, только для вида) |

---

## Шаг 2: Создание спрайтов

Все спрайты должны быть одного размера (32x32 пикселя работают хорошо), чтобы создать правильную сетку.

### 2.1 Спрайт игрока

1. В **Дереве ресурсов** кликните правой кнопкой мыши на **Sprites** и выберите **Create Sprite**
2. Назовите его `spr_player`
3. Нажмите **Edit Sprite**, чтобы открыть редактор спрайтов
4. Нарисуйте простого персонажа (фигуру человека или робота)
5. Используйте отличительный цвет, например синий или зелёный
6. Размер: 32x32 пикселя
7. Нажмите **OK** для сохранения

### 2.2 Спрайт ящика

1. Создайте новый спрайт с именем `spr_crate`
2. Нарисуйте деревянный ящик
3. Используйте коричневый или оранжевый цвет
4. Размер: 32x32 пикселя

### 2.3 Спрайт ящика на цели

1. Создайте новый спрайт с именем `spr_crate_ok`
2. Нарисуйте тот же ящик, но с другим цветом (зелёным), чтобы показать, что он правильно размещён
3. Размер: 32x32 пикселя

### 2.4 Спрайт стены

1. Создайте новый спрайт с именем `spr_wall`
2. Нарисуйте сплошной кирпичный или каменный узор
3. Используйте серый или тёмный цвет
4. Размер: 32x32 пикселя

### 2.5 Спрайт цели

1. Создайте новый спрайт с именем `spr_target`
2. Нарисуйте отметку X или индикатор цели
3. Используйте яркий цвет, например красный или жёлтый
4. Размер: 32x32 пикселя

### 2.6 Спрайт пола (опционально)

1. Создайте новый спрайт с именем `spr_floor`
2. Нарисуйте простой узор напольной плитки
3. Используйте нейтральный цвет
4. Размер: 32x32 пикселя

## Шаг 3: Создание объекта стены

Стена — самый простой объект, он просто блокирует движение.

1. Кликните правой кнопкой мыши на **Objects** и выберите **Create Object**
2. Назовите его `obj_wall`
3. Установите спрайт на `spr_wall`
4. **Отметьте флажок "Solid"**
5. События не требуются

---

## Шаг 4: Создание объекта цели

Цели отмечают места, куда должны быть поставлены ящики.

1. Создайте новый объект с именем `obj_target`
2. Установите спрайт на `spr_target`
3. События не требуются — это просто метка
4. Оставьте "Solid" неотмеченным (игрок и ящики могут находиться на ней)

---

## Шаг 5: Создание объекта ящика

Ящик толкается игроком и меняет внешний вид, когда стоит на цели.

1. Создайте новый объект с именем `obj_crate`
2. Установите спрайт на `spr_crate`
3. **Отметьте флажок "Solid"**

**Событие: Step**
1. Add Event → Step → Step
2. Add Action: **Control** → **If Collision**
   - X Offset: `0`
   - Y Offset: `0`
   - Against: `obj_target`
3. Add Action: **Instance** → **Set Sprite**
   - Sprite: `spr_crate_ok`
4. Add Action: **Control** → **Else**
5. Add Action: **Instance** → **Set Sprite**
   - Sprite: `spr_crate`

Так ящик становится зелёным, как только оказывается на целевом месте
— **If Collision** с обоими смещениями `0` проверяет, перекрывается
ли *текущая* позиция ящика с `obj_target`.

---

## Шаг 6: Создание объекта игрока

Игрок всегда двигается ровно на одну клетку сетки и толкает ящики, в которые упирается.

1. Создайте новый объект с именем `obj_player`
2. Установите спрайт на `spr_player`

### 6.1 Движение по сетке

Добавьте по одному событию **Key Press** для каждого направления, каждое с действием **Move** → **Move Grid**:

| Событие | Действие Move Grid |
|---|---|
| Key Press → Right Arrow | Direction: `right`, Grid Size: `32` |
| Key Press → Left Arrow | Direction: `left`, Grid Size: `32` |
| Key Press → Up Arrow | Direction: `up`, Grid Size: `32` |
| Key Press → Down Arrow | Direction: `down`, Grid Size: `32` |

**Move Grid** перемещает экземпляр ровно на одну клетку сетки и
самостоятельно определяет столкновения — она не переместит игрока в
твёрдую `obj_wall`, поэтому дополнительная проверка стены здесь не нужна.

### 6.2 Остановка у стен

**Событие: Collision with obj_wall**
1. Add Event → Collision → `obj_wall`
2. Add Action: **Move** → **Stop Movement**

### 6.3 Толкание ящиков

**Событие: Collision with obj_crate**
1. Add Event → Collision → `obj_crate`
2. Add Action: **Control** → **If Can Push**
   - Direction: `facing`
   - Object Type: `obj_crate`
   - Then Action: `push_and_move`

**If Can Push** проверяет, свободно ли место за ящиком (в
направлении, в котором движется игрок), и если да, толкает ящик на
одну клетку и перемещает игрока на его прежнее место — всё это одним
действием. Если место за ящиком заблокировано стеной или другим
ящиком, ничего не двигается.

## Шаг 7: Создание проверки условия победы

Нам нужен невидимый контроллер, который следит, стоит ли каждый ящик на цели.

1. Создайте новый объект с именем `obj_game_controller`
2. Спрайт не требуется

**Событие: Create** — единожды определяет количество целей с помощью
**Control** → **Execute Code** (действие Execute Code в этом проекте
выполняет настоящий Python, а не GameMaker Language — `self` — это
текущий экземпляр, `game` — исполнитель игры):

```python
# Считает, сколько целей находится в комнате
self.total_targets = sum(
    1 for inst in game.current_room.instances
    if inst.object_name == 'obj_target'
)
```

**Событие: Step** — каждый кадр проверяет, все ли ящики стоят на цели:

```python
# Считает ящики, которые сейчас перекрываются с целью
crates_on_targets = sum(
    1 for inst in game.current_room.instances
    if inst.object_name == 'obj_crate'
    and game.check_collision_at_position(inst, inst.x, inst.y, 'obj_target')
)

if self.total_targets > 0 and crates_on_targets >= self.total_targets:
    self.restart_room_flag = True
```

`self.restart_room_flag = True` запускает тот же перезапуск комнаты,
что и действие **Restart Room** — главный цикл проверяет этот флаг
каждый кадр. Если хотите показать всплывающее окно перед перезапуском,
добавьте сразу после блока Execute Code действие **Show Message** (из
категории **Output**, сообщение `Level Complete!`).

**Событие: Draw**
1. Add Event → Draw
2. Add Action: **Draw** → **Draw Text**
   - Text: `Sokoban - Push all crates to targets!`
   - X: `10`
   - Y: `10`

## Шаг 9: Проектирование вашего уровня

1. Кликните правой кнопкой мыши на **Rooms** и выберите **Create Room**
2. Назовите её `room_level1`
3. Установите размер комнаты кратным 32 (например, 640x480)
4. Включите "Snap to Grid" и установите сетку на 32x32

### Размещение объектов

Постройте ваш уровень, следуя этим рекомендациям:

1. **Окружите уровень стенами** — создайте границу
2. **Добавьте внутренние стены** — создайте структуру головоломки
3. **Разместите цели** — куда должны попасть ящики
4. **Разместите ящики** — столько же, сколько и целей!
5. **Разместите игрока** — начальная позиция
6. **Разместите контроллер игры** — где угодно (он невидим)

### Пример раскладки уровня

```
W W W W W W W W W W
W . . . . . . . . W
W . P . . . C . . W
W . . W W . . . . W
W . . W T . . C . W
W . . . . . W W . W
W . T . . . . . . W
W . . . . . . . . W
W W W W W W W W W W

W = Стена
P = Игрок
C = Ящик
T = Цель
. = Пустой пол
```

**Важно:** Всегда имейте одинаковое количество ящиков и целей!

## Шаг 10: Протестируйте вашу игру!

1. Нажмите **Run** или **F5** для теста
2. Используйте клавиши со стрелками для движения
3. Толкайте ящики на красные X-цели
4. Когда все ящики на целях, вы выигрываете!

## Улучшения (опционально)

### Добавьте счётчик ходов

В событии **Create** для `obj_game_controller` добавьте **Control** →
**Set Variable** (Variable: `global.moves`, Value: `0`, Scope: `global`).

В каждом из четырёх событий Key Press для `obj_player` добавьте второе
действие сразу после Move Grid: **Control** → **Set Variable**
(Variable: `global.moves`, Value: `1`, Scope: `global`, отмечено
**Relative**) — это добавляет 1 к счётчику при каждом нажатии клавиши,
независимо от того, была ли движение действительно заблокировано стеной.

В событии **Draw** для `obj_game_controller` добавьте **Draw** →
**Draw Variable** (Variable: `global.moves`, X: `10`, Y: `30`).

### Добавьте функцию отмены

Сохраняйте предыдущие позиции и разрешайте нажатие Z для отмены последнего хода.

### Добавьте несколько уровней

Создайте больше комнат (`room_level2`, `room_level3` и т. д.) и в
блоке Execute Code для проверки победы используйте действие **Next
Room** (категория Room) вместо **Restart Room**
(`self.next_room_flag = True` вместо `self.restart_room_flag = True`)
при завершении уровня.

### Добавьте звуковые эффекты

Добавьте звуки для:
- Движения игрока
- Толкания ящика
- Приземления ящика на цель
- Завершения уровня

## Устранение неполадок

| Проблема | Решение |
|----------|---------|
| Игрок проходит сквозь стены | Проверьте, что у `obj_wall` отмечен "Solid" |
| Ящик не меняет цвет | Проверьте, что действие **If Collision** в событии Step нацелено на `obj_target` |
| Ящик можно толкнуть сквозь стену | Проверьте обнаружение столкновений перед перемещением ящика |
| Сообщение о победе появляется сразу | Убедитесь, что цели размещены отдельно от ящиков |
| Игрок движется на несколько клеток | Используйте событие Keyboard Press, а не событие Keyboard |
