Uma referência dos atalhos de edição próprios do PyGameMaker. Trata-se
de **construir o seu jogo no IDE** — para as teclas que o seu *jogo
terminado* lê em tempo de execução (`keyboard_check`, eventos de tecla
pressionada, etc.), veja antes [[Eventos_e_Acoes_pt|Eventos e Ações]].

---

## Global (Janela Principal)

| Atalho | Ação |
|----------|--------|
| Ctrl+N | Novo Projeto |
| Ctrl+O | Abrir Projeto |
| Ctrl+S | Guardar Projeto |
| Ctrl+Shift+S | Guardar Projeto Como |
| Ctrl+E | Exportar Projeto |
| Ctrl+Q | Sair |
| Ctrl+Z | Desfazer |
| Ctrl+Y | Refazer |
| Ctrl+X | Cortar |
| Ctrl+C | Copiar |
| Ctrl+V | Colar |
| Ctrl+D | Duplicar |
| Ctrl+F | Localizar |
| Ctrl+H | Localizar e Substituir |
| F1 | Documentação |
| F5 | Testar Jogo |
| F6 | Depurar Jogo |
| F7 | Compilar Jogo |
| F8 | Compilar e Executar |

## Editor de Sprites

| Atalho | Ferramenta |
|----------|------|
| P | Lápis |
| E | Borracha |
| I | Conta-gotas |
| G | Preenchimento (balde de tinta) |
| L | Linha |
| R | Retângulo |
| O | Elipse |
| S | Seleção |
| Ctrl+C / Ctrl+X / Ctrl+V | Copiar / Cortar / Colar (uma seleção) |
| Del | Eliminar (uma seleção) |
| Esc | Desselecionar |

Veja [[Sprite-Editor_pt|Editor de Sprites]] para saber o que cada ferramenta faz exatamente.

---

## Editor de Objetos

| Atalho | Ação |
|----------|--------|
| Ctrl+S | Guarda este objeto (funciona mesmo com o separador do editor de objetos em foco, sem acionar o Guardar da janela principal) |
| Ctrl+Cima / Ctrl+Baixo | Move o evento selecionado para cima/baixo na lista |
| Ctrl+C / Ctrl+V | Copiar / colar uma ação |

---

## Editor de Salas

| Atalho | Ação |
|----------|--------|
| Del | Elimina a(s) instância(s) selecionada(s) |

A barra de ferramentas do Editor de Salas também disponibiliza
**Grelha**, **Encaixe**, **Limpar Tudo** e **Deslocar Tudo** — veja
[[Editor_Salas_pt|Editor de Salas]].
