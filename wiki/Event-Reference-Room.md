# Room Events

*[Home](Home) | [Event Reference](Event-Reference) | [Full Action Reference](Full-Action-Reference)*

### Room Start
| Property | Value |
|----------|-------|
| **Name** | `room_start` |
| **Icon** | 🚪 |
| **Category** | Room |
| **Preset** | Beginner |

**Description:** Fires when entering a room, after all Create events.

**Common uses:**
- Room initialization
- Play room music
- Set room-specific variables

---

### Room End
| Property | Value |
|----------|-------|
| **Name** | `room_end` |
| **Icon** | 🚪 |
| **Category** | Room |
| **Preset** | Beginner |

**Description:** Fires when leaving a room.

**Common uses:**
- Save progress
- Stop music
- Cleanup
