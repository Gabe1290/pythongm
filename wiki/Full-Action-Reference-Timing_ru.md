# Время

*[Главная](Home_ru) | [Руководство по пресетам](Preset-Guide_ru) | [Справочник событий](Event-Reference_ru)*

> **Сгенерировано автоматически** из реестра действий IDE с помощью `tools/gen_action_reference.py` — не редактируйте вручную; повторно запустите генератор после изменения действий. Переводы взяты из `tools/action_ref_i18n.py`.

### Приостановить шкалу

| Свойство | Значение |
|----------|-------|
| **Имя** | `pause_timeline` |
| **Значок** | ⏸️ |
| **Категория** | Время |

Приостанавливает воспроизведение временной шкалы на текущей позиции

*Параметры:* нет

### Установить будильник

| Свойство | Значение |
|----------|-------|
| **Имя** | `set_alarm` |
| **Значок** | ⏰ |
| **Категория** | Время |

Установить будильник

| Параметр | Тип | По умолч. | Примечания |
|-----------|------|---------|-------|
| `alarm_number` | Число | `0` | Какой будильник (0-11) |
| `steps` | Число | `30` | Количество шагов до срабатывания будильника (30 = 0,5 с при 60 FPS) |

### Задать временную шкалу

| Свойство | Значение |
|----------|-------|
| **Имя** | `set_timeline` |
| **Значок** | ⏱️ |
| **Категория** | Время |

Задаёт метку временной шкалы этого экземпляра и сбрасывает его позицию в 0 (только учёт — см. примечание к категории)

| Параметр | Тип | По умолч. | Примечания |
|-----------|------|---------|-------|
| `timeline` | Текст | — | Метка для вашего собственного использования; это не поиск ресурса |

### Задать позицию на шкале

| Свойство | Значение |
|----------|-------|
| **Имя** | `set_timeline_position` |
| **Значок** | ⏱️ |
| **Категория** | Время |

Задаёт (или сдвигает) позицию этого экземпляра на временной шкале

| Параметр | Тип | По умолч. | Примечания |
|-----------|------|---------|-------|
| `position` | Число | `0` | Позиция в шагах |
| `relative` | Да/Нет | Нет | Прибавить к текущей позиции, а не задать её абсолютно |

### Задать скорость шкалы

| Свойство | Значение |
|----------|-------|
| **Имя** | `set_timeline_speed` |
| **Значок** | ⏱️ |
| **Категория** | Время |

Задаёт множитель скорости воспроизведения временной шкалы

| Параметр | Тип | По умолч. | Примечания |
|-----------|------|---------|-------|
| `speed` | Число | `1.0` | 1.0 — обычная, 0.5 — вдвое медленнее, 2.0 — вдвое быстрее |

### Пауза

| Свойство | Значение |
|----------|-------|
| **Имя** | `sleep` |
| **Значок** | 💤 |
| **Категория** | Время |

Приостановить игру на определённое количество миллисекунд, затем продолжить. Звуки продолжают воспроизводиться во время паузы (например, чтобы звук завершился перед сменой комнаты). Примечание: рендеринг и ввод заморожены во время паузы, поэтому держите длительность короткой

| Параметр | Тип | По умолч. | Примечания |
|-----------|------|---------|-------|
| `milliseconds` | Число | `1000` | Длительность паузы в миллисекундах (1000 = 1 секунда) |

### Запустить шкалу

| Свойство | Значение |
|----------|-------|
| **Имя** | `start_timeline` |
| **Значок** | ▶️ |
| **Категория** | Время |

Запускает или продолжает воспроизведение временной шкалы с текущей позиции

*Параметры:* нет

### Остановить шкалу

| Свойство | Значение |
|----------|-------|
| **Имя** | `stop_timeline` |
| **Значок** | ⏹️ |
| **Категория** | Время |

Останавливает воспроизведение временной шкалы и сбрасывает позицию в 0

*Параметры:* нет
