# Средний Пресет

*[Главная](Home_ru) | [Руководство по Пресетам](Preset-Guide_ru) | [Пресет для Начинающих](Beginner-Preset_ru)*

**Средний** пресет основывается на [Пресете для Начинающих](Beginner-Preset_ru), добавляя более продвинутые события и действия. Он предназначен для пользователей, которые освоили основы и хотят создавать более сложные игры с такими функциями, как таймированные события, звук, жизни и системы здоровья.

## Обзор

Средний пресет включает все из Начального, плюс:
- **4 Дополнительных Типа Событий** - Рисование, Уничтожение, Мышь, Будильник
- **12 Дополнительных Типов Действий** - Жизни, Здоровье, Звук, Таймер и больше опций движения
- **3 Дополнительных Категории** - Таймер, Звук, Рисование

## Дополнительные События (Сверх Начального)

### Событие Рисования
| Свойство | Значение |
|----------|----------|
| **Имя Блока** | `event_draw` |
| **Категория** | Рисование |
| **Иконка** | 🎨 |
| **Описание** | Срабатывает, когда объект нужно отрендерить |

**Когда срабатывает:** Каждый кадр во время фазы рисования, после всех step событий.

**Важно:** Когда вы добавляете событие Рисования, стандартное рисование спрайта отключается. Вы должны вручную рисовать спрайт, если хотите, чтобы он был видимым.

**Распространенные использования:**
- Пользовательский рендеринг
- Рисование полос здоровья
- Отображение текста
- Рисование фигур и эффектов
- Элементы интерфейса

---

### Событие Уничтожения
| Свойство | Значение |
|----------|----------|
| **Имя Блока** | `event_destroy` |
| **Категория** | Объект |
| **Иконка** | 💥 |
| **Описание** | Срабатывает, когда экземпляр уничтожается |

**Когда срабатывает:** Непосредственно перед удалением экземпляра из игры.

**Распространенные использования:**
- Создание эффектов взрыва
- Выпадение предметов
- Воспроизведение звука смерти
- Обновление счета
- Генерация частиц

---

### Событие Мыши
| Свойство | Значение |
|----------|----------|
| **Имя Блока** | `event_mouse` |
| **Категория** | Ввод |
| **Иконка** | 🖱️ |
| **Описание** | Срабатывает при взаимодействии с мышью |

**Типы событий мыши:**
- Левая кнопка (нажатие, отпускание, удержание)
- Правая кнопка (нажатие, отпускание, удержание)
- Средняя кнопка (нажатие, отпускание, удержание)
- Мышь входит (курсор входит в экземпляр)
- Мышь выходит (курсор покидает экземпляр)
- Глобальные события мыши (где угодно на экране)

**Распространенные использования:**
- Нажимаемые кнопки
- Перетаскивание
- Эффекты наведения
- Взаимодействие с меню

---

### Событие Будильника
| Свойство | Значение |
|----------|----------|
| **Имя Блока** | `event_alarm` |
| **Категория** | Таймер |
| **Иконка** | ⏰ |
| **Описание** | Срабатывает, когда таймер будильника достигает нуля |

**Когда срабатывает:** Когда соответствующий отсчет будильника достигает 0.

**Доступные будильники:** 12 независимых будильников (0-11)

**Распространенные использования:**
- Таймированное создание
- Отложенные действия
- Перезарядка
- Тайминг анимации
- Периодические события

## Дополнительные Действия (Сверх Начального)

### Действия Движения

#### Движение в Направлении
| Свойство | Значение |
|----------|----------|
| **Имя Действия** | `move_direction` |
| **Имя Блока** | `move_direction` |
| **Категория** | Движение |

**Описание:** Установить движение, используя направление (0-360 градусов) и скорость.

**Параметры:**
| Параметр | Тип | Описание |
|----------|-----|----------|
| `direction` | Число | Направление в градусах (0=вправо, 90=вверх, 180=влево, 270=вниз) |
| `speed` | Число | Скорость движения |

---

#### Движение К Точке
| Свойство | Значение |
|----------|----------|
| **Имя Действия** | `move_towards_point` |
| **Имя Блока** | `move_towards_point` |
| **Категория** | Движение |

**Описание:** Двигаться к определенной позиции.

**Параметры:**
| Параметр | Тип | Описание |
|----------|-----|----------|
| `x` | Число/Выражение | Целевая координата X |
| `y` | Число/Выражение | Целевая координата Y |
| `speed` | Число | Скорость движения |

---

### Действия Таймера

#### Установить Будильник
| Свойство | Значение |
|----------|----------|
| **Имя Действия** | `set_alarm` |
| **Имя Блока** | `set_alarm` |
| **Категория** | Таймер |
| **Иконка** | ⏰ |

**Описание:** Установить будильник для срабатывания через определенное количество шагов.

**Параметры:**
| Параметр | Тип | Описание |
|----------|-----|----------|
| `alarm` | Число | Номер будильника (0-11) |
| `steps` | Число | Шаги до срабатывания будильника (при 60 FPS, 60 шагов = 1 секунда) |

**Пример:** Установите будильник 0 на 180 шагов для 3-секундной задержки.

## Пример: Игра-Стрелялка с Жизнями

### Объект Игрока

**Create:**
- Set Lives: 3

**Keyboard Press (Пробел):**
- Create Instance: obj_bullet в (x, y-20)
- Set Alarm: 0 до 15 (перезарядка)

**Столкновение с obj_enemy:**
- Add Lives: -1
- Play Sound: snd_hurt
- Jump to Position: (320, 400)

**No More Lives:**
- Show Message: "Game Over!"
- Restart Room

### Объект Врага

**Create:**
- Set Alarm: 0 до 60

**Alarm 0:**
- Create Instance: obj_enemy_bullet в (x, y+20)
- Set Alarm: 0 до 60 (повторить)

**Столкновение с obj_bullet:**
- Add Score: 100
- Play Sound: snd_explosion
- Destroy Instance: self
