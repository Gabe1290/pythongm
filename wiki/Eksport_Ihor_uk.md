PyGameMaker може експортувати вашу гру на кілька платформ. Цей посібник охоплює кожну опцію експорту та її використання.

---

## Огляд експорту

| Платформа | Формат | Вимоги |
|-----------|--------|--------|
| **Windows** | .exe | PyInstaller |
| **macOS** | .app | PyInstaller (на Mac) |
| **HTML5** | .html | Сучасний браузер |
| **Linux** | Двійковий файл | PyInstaller, Python 3.10+ |
| **Kivy / Android** | Вихідний код / .apk | Buildozer |
| **Проєкт (.zip)** | .zip | — (поділитися редагованим проєктом) |

> **Ніщо не відкидається мовчки.** Якщо ваша гра використовує дію, яку ціль не може
> відтворити (наприклад, деякі дії не підтримуються експортом Kivy/Android), експорт
> усе одно вдається, але повідомляє вам, які саме дії було **пропущено**, щоб ви
> могли скоригувати. Якщо ваш проєкт використовує вимкнене
> [розширення](Extensions_uk) (наприклад, 3D-вигляд), IDE попереджає вас під час
> завантаження.

## Експорт Windows EXE

Створіть автономний виконуваний файл Windows, що працює без встановленого Python.

### Як експортувати

1. Відкрийте **Файл → Експортувати проєкт…** (Ctrl+E) і виберіть **Windows**
2. Виберіть теку виводу
3. Дочекайтеся завершення процесу збірки
4. Знайдіть файл .exe у теці виводу

### Що створюється

```
тека_виводу/
├── МояГра.exe        # Основний виконуваний файл
├── _internal/        # Необхідні бібліотеки
└── assets/           # Ресурси гри
```

### Вимоги

- PyInstaller (встановлюється через `pip install pyinstaller`)
- Система Windows для збірки (крос-компіляція не підтримується)

### Розповсюдження

Щоб поділитися грою:
1. Стисніть усю теку виводу в zip
2. Розповсюджуйте zip-файл
3. Користувачі розпаковують і запускають .exe

### Усунення несправностей

**Відсутні DLL:** Переконайтеся, що всі залежності включено. Перевірте вивід PyInstaller на попередження.

**Попередження антивірусу:** Деякі антивіруси позначають виконувані файли PyInstaller. Це хибне спрацювання. Можливо, доведеться підписати ваш виконуваний файл.

## Експорт додатка macOS

Створіть нативний пакет `.app` для macOS за допомогою PyInstaller.

### Як експортувати

1. Відкрийте **Файл → Експортувати проєкт…** (Ctrl+E) і виберіть **macOS**
2. Виберіть теку виводу
3. Дочекайтеся завершення збірки
4. Знайдіть `МояГра.app` у теці виводу

### Вимоги

- **Mac** для збірки (крос-компіляція з Windows/Linux не підтримується)
- PyInstaller і Kivy, встановлені у Python збірки

### Розповсюдження

Стисніть пакет `.app` у zip, щоб поділитися ним. Непідписані додатки викликають
Gatekeeper на інших Mac — користувачі при першому запуску роблять правий клік →
**Відкрити**, або ви підписуєте/нотаризуєте додаток за допомогою облікового запису
Apple Developer.

## Експорт HTML5

Створіть один HTML-файл, що працює у веб-браузерах.

### Як експортувати

1. Перейдіть до **Файл → Експортувати як HTML5…**
2. Виберіть місце виводу
3. Виберіть опції (стиснення тощо)
4. Натисніть Експорт

### Що створюється

```
тека_виводу/
└── МояГра.html       # Гра в одному файлі
```

### Особливості

- Працює в будь-якому сучасному браузері (Chrome, Firefox, Edge, Safari)
- Не потребує встановлення
- Стиснуто gzip для швидкого завантаження
- Придатне для мобільних із сенсорним керуванням

### Хостинг вашої гри

Завантажте HTML-файл на:
- Ваш власний веб-сервер
- GitHub Pages (безкоштовно)
- itch.io (хостинг, орієнтований на ігри)
- Будь-який хостинг статичних файлів

### Сумісність браузерів

| Браузер | Підтримка |
|---------|-----------|
| Chrome 80+ | Повна |
| Firefox 75+ | Повна |
| Edge 80+ | Повна |
| Safari 13+ | Повна |
| Мобільний Chrome | Повна |
| Мобільний Safari | Повна |

### Обмеження

- Деякі функції можуть не працювати (доступ до файлової системи тощо)
- Аудіо може потребувати взаємодії користувача для запуску
- Продуктивність залежить від пристрою/браузера

## Експорт Linux

Створіть нативний виконуваний файл Linux.

### Як експортувати

1. Відкрийте **Файл → Експортувати проєкт…** (Ctrl+E) і виберіть **Linux**
2. Виберіть теку виводу
3. Дочекайтеся процесу збірки

### Вимоги

- Система Linux для збірки
- Python 3.10+
- PyInstaller

### Розповсюдження

```bash
# Зробити файл виконуваним
chmod +x МояГра

# Запустити гру
./МояГра
```

Розповсюджуйте як архів .tar.gz:
```bash
tar -czvf МояГра-linux.tar.gz МояГра/
```

## Експорт Kivy (мобільний)

Створюйте мобільні додатки для iOS та Android за допомогою фреймворку Kivy.

### Як експортувати

1. Перейдіть до **Файл → Експортувати в Kivy…**
2. Виберіть теку виводу
3. Налаштуйте мобільні параметри
4. Експортуйте проєкт Kivy

### Збірка для Android

Експортований проєкт Kivy використовує Buildozer для створення APK:

```bash
cd експортований_проєкт
pip install buildozer
buildozer init
buildozer android debug
```

### Збірка для iOS

Потребує Mac з Xcode:

```bash
cd експортований_проєкт
pip install kivy-ios
toolchain build python3 kivy
toolchain create МояГра ~/ios_проєкт
```

### Мобільні міркування

- Сенсорне керування зіставляється автоматично
- Масштабування екрана обробляється автоматично
- Тестуйте на кількох розмірах екрана
- Оптимізуйте розміри ресурсів для мобільних

## Експорт проєкту (.zip)

Поділіться самим **редагованим проєктом** (не скомпільованою грою): скористайтеся
**Файл → Експортувати проєкт…** (Ctrl+E), щоб створити архів `.zip`, який хтось
інший може знову відкрити в PyGameMaker. Ідеально для співпраці, резервних копій
або здавання шкільних робіт.

## Параметри експорту

### Загальні параметри

| Параметр | Опис |
|----------|------|
| **Назва гри** | Назва, що показується в заголовку/додатку |
| **Іконка** | Іконка додатка (Windows/мобільний) |
| **Версія** | Номер версії (1.0.0) |
| **Автор** | Ім'я розробника |

### Параметри Windows

| Параметр | Опис |
|----------|------|
| **Консоль** | Показувати вікно консолі (для налагодження) |
| **Один файл** | Один .exe проти теки з _internal |
| **UPX** | Стиснути за допомогою UPX (менший розмір) |

### Параметри HTML5

| Параметр | Опис |
|----------|------|
| **Стиснення** | Увімкнути стиснення gzip |
| **Повний екран** | Запускати в повноекранному режимі |
| **Сенсорне керування** | Показувати екранне керування |

## Контрольний список перед експортом

Перед експортом перевірте:

- [ ] Усі ресурси включено в проєкт
- [ ] Гра коректно працює в IDE
- [ ] Немає повідомлень налагодження або тестового коду
- [ ] Порядок кімнат правильний (стартова кімната першою)
- [ ] Аудіофайли в підтримуваних форматах
- [ ] Спрайти оптимізовано за розміром файлу

## Оптимізація розміру файлу

### Спрайти
- Використовуйте відповідні розміри (не завеликі)
- Стисніть файли PNG
- Розгляньте JPEG для зображень без прозорості

### Аудіо
- Використовуйте OGG/MP3 для музики (не WAV)
- Тримайте звукові ефекти короткими
- Нижчі частоти дискретизації для простих звуків

### Загальне
- Видаліть невикористані ресурси
- Мінімізуйте розміри кімнат
- Тестуйте на цільових платформах

## Тестування експортів

Завжди тестуйте вашу експортовану гру:

1. **Windows:** Тестуйте на чистому ПК без Python
2. **HTML5:** Тестуйте в кількох браузерах
3. **Linux:** За можливості тестуйте на різних дистрибутивах
4. **Мобільний:** Тестуйте на реальних пристроях, а не лише на емуляторах

## Платформи розповсюдження

### itch.io
- Безкоштовний хостинг для інді-ігор
- Підтримує HTML5, Windows, Linux, Mac
- Вбудована платіжна система

### Steam
- Потребує інтеграції Steamworks SDK
- Використовуйте PyInstaller із Steam API
- Платний внесок за публікацію

### Google Play (Android)
- Потребує облікового запису розробника (25 $)
- Зберіть підписаний APK за допомогою Buildozer
- Дотримуйтесь правил щодо вмісту

### App Store (iOS)
- Потребує облікового запису Apple Developer (99 $/рік)
- Зберіть за допомогою kivy-ios
- Подайте через App Store Connect
