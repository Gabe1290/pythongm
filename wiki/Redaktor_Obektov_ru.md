Объекты — это фундаментальные строительные блоки вашей игры. Они
представляют всё, от игроков и врагов до собираемых предметов и
элементов интерфейса.

---

## Открытие Редактора Объектов

1. Дважды кликните на существующем объекте в дереве ресурсов, или
2. Кликните правой кнопкой на **Objects** > **Create Object**

---

## Свойства Объекта

| Свойство | Описание |
|-----------|-------------|
| **Name** | Уникальный идентификатор объекта (напр. `obj_player`) |
| **Sprite** | Визуальное представление объекта |
| **Visible** | Отображается ли объект (по умолчанию: да) |
| **Solid** | Используется для обнаружения столкновений с твёрдыми объектами |
| **Depth** | Порядок рисования (меньше = рисуется сверху) |
| **Persistent** | Объект переживает смены комнат |
| **Parent Object** | Наследует общие свойства/события от другого объекта |

### Соглашение об Именовании

Используйте префикс `obj_` для объектов:
- `obj_player`
- `obj_enemy`
- `obj_coin`
- `obj_wall`

## События

События — это триггеры, вызывающие выполнение действий. Нажмите "Add
Event", чтобы добавить одно.

### Распространённые События

| Событие | Когда Срабатывает |
|-------|------------------|
| **Create** | Один раз, когда экземпляр создан |
| **Destroy** | Когда экземпляр уничтожен |
| **Step** | Каждый кадр игры (60 раз в секунду) |
| **Draw** | Во время фазы рисования |
| **Alarm [0-11]** | Когда таймер будильника достигает нуля |

### События Клавиатуры

| Событие | Когда Срабатывает |
|-------|------------------|
| **Key Press** | Один раз, когда клавиша нажата |
| **Key Release** | Один раз, когда клавиша отпущена |
| **Keyboard** | Каждый кадр, пока клавиша нажата |
| **No Key** | Когда не нажата ни одна клавиша |

### События Мыши

| Событие | Когда Срабатывает |
|-------|------------------|
| **Mouse Button** | При клике на экземпляре |
| **Global Mouse** | При клике в любом месте |
| **Mouse Enter** | Когда курсор входит в экземпляр |
| **Mouse Leave** | Когда курсор покидает экземпляр |

### События Столкновений

| Событие | Когда Срабатывает |
|-------|------------------|
| **Collision with [объект]** | При касании с другим типом объекта |

### Другие События

| Событие | Когда Срабатывает |
|-------|------------------|
| **Outside Room** | Когда экземпляр покидает комнату |
| **Intersect Boundary** | Когда экземпляр касается границы комнаты |
| **Game Start** | Один раз, при запуске игры |
| **Game End** | Один раз, при закрытии игры |
| **Room Start** | При входе в комнату |
| **Room End** | При выходе из комнаты |

## Действия

Действия — это операции, которые выполняются при срабатывании
события. Каждое событие может иметь несколько действий, выполняемых по порядку.

### Действия Движения
- **Set Speed** — Устанавливает скорость движения
- **Set Direction** — Устанавливает направление движения (0-360 градусов)
- **Set Horizontal Speed** — Устанавливает hspeed
- **Set Vertical Speed** — Устанавливает vspeed
- **Move Towards Point** — Движение к координатам
- **Jump to Position** — Мгновенный телепорт на координаты
- **Jump to Start Position** — Вернуться на позицию создания
- **Jump to Random Position** — Телепортироваться на случайную позицию

### Действия Instance
- **Create Instance** — Создаёт новый объект
- **Destroy Instance** — Удаляет текущий экземпляр
- **Change Instance** — Превращает в другой тип объекта

### Действия Таймера
- **Set Alarm** — Запускает обратный отсчёт
- **Sleep** — Приостанавливает выполнение на короткое время

### Действия Рисования
- **Draw Sprite** — Рисует спрайт
- **Draw Text** — Показывает текст на экране
- **Draw Rectangle** — Рисует заполненный или контурный прямоугольник
- **Draw Score** — Показывает текущий счёт
- **Draw Lives** — Показывает остаток жизней
- **Draw Health Bar** — Показывает полосу здоровья

### Score/Lives/Health
- **Set Score** — Меняет значение счёта
- **Set Lives** — Меняет количество жизней
- **Set Health** — Меняет значение здоровья
- **Test Score** — Проверяет условие счёта
- **Test Lives** — Проверяет условие жизней
- **Test Health** — Проверяет условие здоровья

### Действия Комнаты
- **Next Room** — Перейти к следующей комнате
- **Previous Room** — Перейти к предыдущей комнате
- **Restart Room** — Перезапустить текущую комнату
- **Go to Room** — Перейти к конкретной комнате

### Действия Звука
- **Play Sound** — Воспроизводит звуковой эффект
- **Stop Sound** — Останавливает воспроизводимый звук
- **Play Music** — Воспроизводит фоновую музыку
- **Stop Music** — Останавливает фоновую музыку

### Действия Переменных
- **Set Variable** — Присваивает значение переменной
- **Test Variable** — Проверяет условие переменной

## Визуальное Программирование с Blockly

Вместо использования списка действий вы можете переключиться на
вкладку **Blockly** для визуального программирования:

1. Откройте объект
2. Кликните на вкладку **Blockly**
3. Перетаскивайте блоки из панели инструментов, чтобы построить логику
4. Блоки соединяются, образуя полные программы

Подробнее см. [[Vizualnoe_Programmirovanie_ru]].

## Советы И Лучшие Практики

### Организация
- Давайте объектам описательные названия
- Группируйте связанные объекты похожими префиксами
- Используйте событие Create только для инициализации

### Производительность
- Избегайте требовательных вычислений в событии Step
- Используйте будильники вместо ручного подсчёта кадров
- Уничтожайте экземпляры, покинувшие комнату

### Устранение Неполадок
- Используйте действие **Show Message** для показа значений
- Проверяйте вывод консоли на ошибки
- Тестируйте часто во время разработки

## Пример: Простой Искусственный Интеллект Врага

```
Create Event:
  - Set Alarm[0] = 60 (1 секунда при 60 FPS)
  - Set direction = random(360)
  - Set speed = 2

Alarm[0] Event:
  - Set direction = random(360)
  - Set Alarm[0] = 60

Collision with obj_player:
  - Set Lives relative = -1
  - Destroy Instance
```
