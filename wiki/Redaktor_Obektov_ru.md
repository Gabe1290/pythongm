Объекты — это фундаментальные строительные блоки вашей игры. Они
представляют всё, от игроков и врагов до собираемых предметов и
элементов интерфейса.

---

## Открытие Редактора Объектов

1. Дважды кликните на существующем объекте в дереве ресурсов, или
2. Кликните правой кнопкой на **Objects** > **Create Object**

## Свойства Объекта

| Свойство | Описание |
|-----------|-------------|
| **Name** | Уникальный идентификатор объекта (напр. `obj_player`) |
| **Sprite** | Визуальное представление объекта |
| **Visible** | Отображается ли объект (по умолчанию: да) |
| **Solid** | Используется для обнаружения столкновений с твёрдыми объектами |
| **Depth** | Порядок рисования (меньше = рисуется сверху) |
| **Persistent** | Объект переживает смены комнат |
| **Parent Object** | Наследует общие свойства/события от другого объекта |

### Соглашение об Именовании

Используйте префикс `obj_` для объектов:
- `obj_player`
- `obj_enemy`
- `obj_coin`
- `obj_wall`

## События

События — это триггеры, вызывающие выполнение действий. Нажмите "Add
Event", чтобы добавить одно.

### Распространённые События

| Событие | Когда Срабатывает |
|-------|------------------|
| **Создание** | Один раз, когда экземпляр создан |
| **Уничтожение** | Когда экземпляр уничтожен |
| **Шаг** | Каждый кадр игры (60 раз в секунду) |
| **Рисование** | Во время фазы рисования |
| **Alarm [0-11]** | Когда таймер будильника достигает нуля |

### События Клавиатуры

| Событие | Когда Срабатывает |
|-------|------------------|
| **Key Press** | Один раз, когда клавиша нажата |
| **Key Release** | Один раз, когда клавиша отпущена |
| **Keyboard** | Каждый кадр, пока клавиша нажата |
| **No Key** | Когда не нажата ни одна клавиша |

### События Мыши

| Событие | Когда Срабатывает |
|-------|------------------|
| **Mouse Button** | При клике на экземпляре |
| **Global Mouse** | При клике в любом месте |
| **Mouse Enter** | Когда курсор входит в экземпляр |
| **Mouse Leave** | Когда курсор покидает экземпляр |

### События Столкновений

| Событие | Когда Срабатывает |
|-------|------------------|
| **Collision with [объект]** | При касании с другим типом объекта |

### Другие События

| Событие | Когда Срабатывает |
|-------|------------------|
| **Вне комнаты** | Когда экземпляр покидает комнату |
| **Касание границы комнаты** | Когда экземпляр касается границы комнаты |
| **Начало игры** | Один раз, при запуске игры |
| **Конец игры** | Один раз, при закрытии игры |
| **Начало комнаты** | При входе в комнату |
| **Конец комнаты** | При выходе из комнаты |

## Действия

Действия — это операции, которые выполняются при срабатывании
события. Каждое событие может иметь несколько действий, выполняемых по порядку.

### Действия Движения
- **Задать скорость** — Устанавливает скорость движения
- **Задать направление** — Устанавливает направление движения (0-360 градусов)
- **Задать горизонтальную скорость** — Устанавливает hspeed
- **Задать вертикальную скорость** — Устанавливает vspeed
- **Движение к точке** — Движение к координатам
- **Jump to Position** — Мгновенный телепорт на координаты
- **Перейти к стартовой позиции** — Вернуться на позицию создания
- **Перейти в случайную позицию** — Телепортироваться на случайную позицию

### Действия Instance
- **Создать экземпляр** — Создаёт новый объект
- **Уничтожить экземпляр** — Удаляет текущий экземпляр
- **Изменить экземпляр** — Превращает в другой тип объекта

### Действия Таймера
- **Установить будильник** — Запускает обратный отсчёт
- **Пауза** — Приостанавливает выполнение на короткое время

### Действия Рисования
- **Нарисовать спрайт** — Рисует спрайт
- **Нарисовать текст** — Показывает текст на экране
- **Нарисовать прямоугольник** — Рисует заполненный или контурный прямоугольник
- **Нарисовать счёт** — Показывает текущий счёт
- **Нарисовать жизни** — Показывает остаток жизней
- **Нарисовать полосу здоровья** — Показывает полосу здоровья

### Score/Lives/Health
- **Задать счёт** — Меняет значение счёта
- **Задать жизни** — Меняет количество жизней
- **Задать здоровье** — Меняет значение здоровья
- **Проверить счёт** — Проверяет условие счёта
- **Проверить жизни** — Проверяет условие жизней
- **Проверить здоровье** — Проверяет условие здоровья

### Действия Комнаты
- **Следующая комната** — Перейти к следующей комнате
- **Предыдущая комната** — Перейти к предыдущей комнате
- **Перезапустить комнату** — Перезапустить текущую комнату
- **Перейти в комнату** — Перейти к конкретной комнате

### Действия Звука
- **Воспроизвести звук** — Воспроизводит звуковой эффект
- **Остановить звук** — Останавливает воспроизводимый звук
- **Воспроизвести музыку** — Воспроизводит фоновую музыку
- **Остановить музыку** — Останавливает фоновую музыку

### Действия Переменных
- **Задать переменную** — Присваивает значение переменной
- **Проверить переменную** — Проверяет условие переменной

## Визуальное Программирование с Blockly

Вместо использования списка действий вы можете переключиться на
вкладку **Blockly** для визуального программирования:

1. Откройте объект
2. Кликните на вкладку **Blockly**
3. Перетаскивайте блоки из панели инструментов, чтобы построить логику
4. Блоки соединяются, образуя полные программы

Подробнее см. [[Vizualnoe_Programmirovanie_ru]].

## Советы И Лучшие Практики

### Организация
- Давайте объектам описательные названия
- Группируйте связанные объекты похожими префиксами
- Используйте событие Create только для инициализации

### Производительность
- Избегайте требовательных вычислений в событии Step
- Используйте будильники вместо ручного подсчёта кадров
- Уничтожайте экземпляры, покинувшие комнату

### Устранение Неполадок
- Используйте действие **Показать сообщение** для показа значений
- Проверяйте вывод консоли на ошибки
- Тестируйте часто во время разработки

## Пример: Простой Искусственный Интеллект Врага

```
Create Event:
  - Set Alarm[0] = 60 (1 секунда при 60 FPS)
  - Set direction = random(360)
  - Set speed = 2

Alarm[0] Event:
  - Set direction = random(360)
  - Set Alarm[0] = 60

Collision with obj_player:
  - Set Lives relative = -1
  - Destroy Instance
```
