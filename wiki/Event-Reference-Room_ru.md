*[Главная](Home_ru) | [Справочник Событий](Event-Reference_ru) | [Полный справочник действий](Full-Action-Reference_ru)*

### Room Start
| Свойство | Значение |
|----------|----------|
| **Имя** | `room_start` |
| **Иконка** | 🚪 |
| **Категория** | Комната |
| **Пресет** | Начинающий |

**Описание:** Срабатывает при входе в комнату, после всех событий Create.

**Типичные использования:**
- Инициализация комнаты
- Воспроизведение музыки комнаты
- Установка переменных, специфичных для комнаты

---

### Room End
| Свойство | Значение |
|----------|----------|
| **Имя** | `room_end` |
| **Иконка** | 🚪 |
| **Категория** | Комната |
| **Пресет** | Начинающий |

**Описание:** Срабатывает при выходе из комнаты.

**Типичные использования:**
- Сохранение прогресса
- Остановка музыки
- Очистка
