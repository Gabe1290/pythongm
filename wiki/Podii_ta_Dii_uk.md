## Довідник Подій

### Подія Create
**Коли:** Один раз, коли екземпляр створено
**Використання:** Ініціалізація, встановлення змінних, запуск таймерів

### Подія Destroy
**Коли:** Коли екземпляр знищено
**Використання:** Очищення, створення ефектів, нарахування очок

### Події Step

| Подія | Коли |
|-----------|-------|
| **Step** | Щокадру (60 разів на секунду) |
| **Begin Step** | Перед перевірками зіткнень |
| **End Step** | Після всіх інших подій |

### Події Alarm

| Подія | Коли |
|-----------|-------|
| **Alarm[0-11]** | Коли лічильник досягає 0 |

Використовуйте дію `Set Alarm`, щоб запустити відлік. Значення будильника вимірюються в кадрах (60 = 1 секунда при 60 FPS).

### Події Клавіатури

| Подія | Коли |
|-----------|-------|
| **Keyboard [Клавіша]** | Поки клавіша утримується (повторюється) |
| **Key Press [Клавіша]** | Один раз, коли клавішу натиснуто |
| **Key Release [Клавіша]** | Один раз, коли клавішу відпущено |
| **No Key** | Коли не натиснуто жодної клавіші |

Доступні клавіші: літери (A-Z), цифри (0-9), клавіші зі стрілками, пробіл, Enter, Shift, Ctrl, Alt, функціональні клавіші (F1-F12)

### Події Миші

| Подія | Коли |
|-----------|-------|
| **Left Button** | Клацання лівою кнопкою на екземплярі |
| **Right Button** | Клацання правою кнопкою на екземплярі |
| **Middle Button** | Клацання середньою кнопкою на екземплярі |
| **Left Press** | Натиснуто ліву кнопку (один раз) |
| **Left Release** | Відпущено ліву кнопку (один раз) |
| **Mouse Enter** | Курсор входить в екземпляр |
| **Mouse Leave** | Курсор залишає екземпляр |
| **Global Left Button** | Клацання лівою кнопкою будь-де |
| **Global Right Button** | Клацання правою кнопкою будь-де |

### Події Зіткнень

| Подія | Коли |
|-----------|-------|
| **Collision with [Об'єкт]** | При контакті із зазначеним об'єктом |

Перевірки зіткнень відбуваються між подіями Step та Draw.

### Інші Події

| Подія | Коли |
|-----------|-------|
| **Outside Room** | Екземпляр повністю поза кімнатою |
| **Intersect Boundary** | Екземпляр торкається межі кімнати |
| **Game Start** | Гра запускається (завантажена перша кімната) |
| **Game End** | Гра завершується |
| **Room Start** | При вході в кімнату |
| **Room End** | При виході з кімнати |
| **No More Lives** | Життя досягають 0 |
| **No More Health** | Здоров'я досягає 0 |
| **Animation End** | Анімацію спрайта завершено |

### Події Draw

| Подія | Коли |
|-----------|-------|
| **Draw** | Під час фази малювання |
| **Draw GUI** | Після малювання кімнати (в просторі екрана) |

## Довідник Дій

### Дії Руху

| Дія | Опис | Параметри |
|--------|-------------|------------|
| **Set Speed** | Встановлює швидкість руху | speed, relative |
| **Set Direction** | Встановлює напрямок | direction (0-360), relative |
| **Set Horizontal Speed** | Встановлює hspeed | hspeed, relative |
| **Set Vertical Speed** | Встановлює vspeed | vspeed, relative |
| **Set Gravity** | Встановлює гравітацію | gravity, direction |
| **Set Friction** | Встановлює тертя | friction |
| **Move Towards Point** | Рух до координат | x, y, speed |
| **Start Moving Direction** | Рух у напрямку | direction, speed |
| **Jump To Position** | Телепорт на координати | x, y, relative |
| **Jump to Start Position** | Повернутися на позицію створення | - |
| **Jump to Random Position** | Телепорт на цілком випадкову позицію (обидві осі; можливість прив'язки до сітки) | snap_h, snap_v |
| **Bounce** | Відскочити від твердих об'єктів | precise |

### Дії Instance

| Дія | Опис | Параметри |
|--------|-------------|------------|
| **Create Instance** | Створює новий об'єкт | object, x, y, relative |
| **Create Moving Instance** | Створює зі швидкістю | object, x, y, speed, direction |
| **Destroy Instance** | Видаляє екземпляр | - |
| **Change Instance** | Перетворює на інший об'єкт | object, perform_events |

### Дії Таймера

| Дія | Опис | Параметри |
|--------|-------------|------------|
| **Set Alarm** | Запускає відлік | alarm_number, steps |
| **Sleep** | Призупиняє виконання | milliseconds |

### Дії Score/Lives/Health

| Дія | Опис | Параметри |
|--------|-------------|------------|
| **Set Score** | Змінює рахунок | value, relative |
| **Set Lives** | Змінює життя | value, relative |
| **Set Health** | Змінює здоров'я | value, relative |
| **Draw Score** | Показує рахунок | x, y, caption |
| **Draw Lives** | Показує життя як повторювані зображення спрайта | x, y, sprite, scale, tiled |
| **Draw Health Bar** | Показує здоров'я як двоколірну смугу | x1, y1, x2, y2, back_color, bar_color |

### Дії Малювання

| Дія | Опис | Параметри |
|--------|-------------|------------|
| **Draw Sprite** | Малює спрайт | sprite, x, y, subimage |
| **Draw Text** | Показує текст | x, y, text |
| **Draw Rectangle** | Малює прямокутник | x1, y1, x2, y2, filled |
| **Draw Circle** | Малює коло | x, y, radius, filled |
| **Draw Line** | Малює лінію | x1, y1, x2, y2 |
| **Set Draw Color** | Встановлює колір для наступних Draw Text/Draw Rectangle/тощо | color |
| **Set Color** | Встановлює тон і прозорість спрайта (не колір малювання вище) | color, alpha |
| **Set Draw Font** | Встановлює шрифт і вирівнювання для наступного малювання тексту | font, halign, valign |

### Дії Кімнати

| Дія | Опис | Параметри |
|--------|-------------|------------|
| **Next Room** | Перейти до наступної кімнати | transition |
| **Previous Room** | Перейти до попередньої кімнати | transition |
| **Restart Room** | Перезапустити кімнату | - |
| **Go to Room** | Перейти до конкретної кімнати | room, transition |
| **If Next Room Exists** | Перевіряє, чи існує наступна кімната | - |
| **If Previous Room Exists** | Перевіряє, чи існує попередня кімната | - |

### Дії Звуку

| Дія | Опис | Параметри |
|--------|-------------|------------|
| **Play Sound** | Відтворює звуковий ефект | sound, loop |
| **Stop Sound** | Зупиняє звук | sound |
| **Check Sound Playing** | Перевіряє, чи відтворюється звук | sound |
| **Play Music** | Відтворює фонову музику | music, loop |
| **Stop Music** | Зупиняє всю музику | - |

### Дії Змінних

| Дія | Опис | Параметри |
|--------|-------------|------------|
| **Set Variable** | Задає значення | variable, value, relative |
| **Test Variable** | Перевіряє значення | variable, value, operation |
| **Draw Variable** | Показує змінну | x, y, variable |

### Дії Керування Потоком

| Дія | Опис | Параметри |
|--------|-------------|------------|
| **Test Expression** | Умовна перевірка (логічний вираз Python) | expression |
| **Else** | Альтернативна гілка | - |
| **Start Block** | Починає групу дій | - |
| **End Block** | Завершує групу дій | - |
| **Repeat** | Повторює N разів | count |
| **Exit Event** | Зупиняє поточну подію | - |

### Інші Дії

| Дія | Опис | Параметри |
|--------|-------------|------------|
| **Show Message** | Показує спливаюче повідомлення | message |
| **Restart Game** | Перезапускає гру | - |
| **End Game** | Закриває гру | - |

## Вбудовані Змінні

Ці змінні доступні для всіх екземплярів:

| Змінна | Опис |
|----------|-------------|
| `x` | Горизонтальна позиція |
| `y` | Вертикальна позиція |
| `xstart` | Початкова позиція x |
| `ystart` | Початкова позиція y |
| `hspeed` | Горизонтальна швидкість |
| `vspeed` | Вертикальна швидкість |
| `speed` | Швидкість анімації спрайта (кадрів на секунду) — **не** швидкість руху. Вбудованої змінної для "сумарної швидкості" немає; обчисліть її самі з `hspeed`/`vspeed`, наприклад `(hspeed**2 + vspeed**2)**0.5` |
| `direction` | Напрямок руху (0-360) |
| `gravity` | Гравітація |
| `gravity_direction` | Напрямок гравітації |
| `friction` | Тертя руху |
| `image_index` | Поточний кадр анімації |
| `image_speed` | Швидкість анімації |
| `image_xscale` | Горизонтальний масштаб |
| `image_yscale` | Вертикальний масштаб |
| `image_angle` | Кут повороту |
| `visible` | Чи малюється |
| `solid` | Чи твердий для зіткнень |
| `depth` | Глибина малювання |
| `sprite_index` | Поточний спрайт |
| `alarm[0-11]` | Таймери будильників |

### Глобальні Змінні

| Змінна | Опис |
|----------|-------------|
| `score` | Рахунок гри |
| `lives` | Життя гравця |
| `health` | Здоров'я гравця (0-100) |
| `room` | Поточна кімната |
| `room_width` | Ширина поточної кімнати |
| `room_height` | Висота поточної кімнати |
| `mouse_x` | Позиція X миші |
| `mouse_y` | Позиція Y миші |
