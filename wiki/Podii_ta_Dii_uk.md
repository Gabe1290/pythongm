## Довідник Подій

### Подія Create
**Коли:** Один раз, коли екземпляр створено
**Використання:** Ініціалізація, встановлення змінних, запуск таймерів

### Подія Destroy
**Коли:** Коли екземпляр знищено
**Використання:** Очищення, створення ефектів, нарахування очок

### Події Step

| Подія | Коли |
|-----------|-------|
| **Крок** | Щокадру (60 разів на секунду) |
| **Початок кроку** | Перед перевірками зіткнень |
| **Кінець кроку** | Після всіх інших подій |

### Події Alarm

| Подія | Коли |
|-----------|-------|
| **Alarm[0-11]** | Коли лічильник досягає 0 |

Використовуйте дію `Set Alarm`, щоб запустити відлік. Значення будильника вимірюються в кадрах (60 = 1 секунда при 60 FPS).

### Події Клавіатури

| Подія | Коли |
|-----------|-------|
| **Keyboard [Клавіша]** | Поки клавіша утримується (повторюється) |
| **Key Press [Клавіша]** | Один раз, коли клавішу натиснуто |
| **Key Release [Клавіша]** | Один раз, коли клавішу відпущено |
| **No Key** | Коли не натиснуто жодної клавіші |

Доступні клавіші: літери (A-Z), цифри (0-9), клавіші зі стрілками, пробіл, Enter, Shift, Ctrl, Alt, функціональні клавіші (F1-F12)

### Події Миші

| Подія | Коли |
|-----------|-------|
| **Left Button** | Клацання лівою кнопкою на екземплярі |
| **Right Button** | Клацання правою кнопкою на екземплярі |
| **Middle Button** | Клацання середньою кнопкою на екземплярі |
| **Left Press** | Натиснуто ліву кнопку (один раз) |
| **Left Release** | Відпущено ліву кнопку (один раз) |
| **Mouse Enter** | Курсор входить в екземпляр |
| **Mouse Leave** | Курсор залишає екземпляр |
| **Global Left Button** | Клацання лівою кнопкою будь-де |
| **Global Right Button** | Клацання правою кнопкою будь-де |

### Події Зіткнень

| Подія | Коли |
|-----------|-------|
| **Collision with [Об'єкт]** | При контакті із зазначеним об'єктом |

Перевірки зіткнень відбуваються між подіями Step та Draw.

### Інші Події

| Подія | Коли |
|-----------|-------|
| **Поза кімнатою** | Екземпляр повністю поза кімнатою |
| **Дотик до межі кімнати** | Екземпляр торкається межі кімнати |
| **Початок гри** | Гра запускається (завантажена перша кімната) |
| **Кінець гри** | Гра завершується |
| **Початок кімнати** | При вході в кімнату |
| **Кінець кімнати** | При виході з кімнати |
| **Життя скінчилися** | Життя досягають 0 |
| **Здоров'я скінчилося** | Здоров'я досягає 0 |
| **Кінець анімації** | Анімацію спрайта завершено |

### Події Draw

| Подія | Коли |
|-----------|-------|
| **Малювання** | Під час фази малювання |
| **Малювання інтерфейсу** | Після малювання кімнати (в просторі екрана) |

## Довідник Дій

### Дії Руху

| Дія | Опис | Параметри |
|--------|-------------|------------|
| **Задати швидкість** | Встановлює швидкість руху | speed, relative |
| **Задати напрямок** | Встановлює напрямок | direction (0-360), relative |
| **Задати горизонтальну швидкість** | Встановлює hspeed | hspeed, relative |
| **Задати вертикальну швидкість** | Встановлює vspeed | vspeed, relative |
| **Задати гравітацію** | Встановлює гравітацію | gravity, direction |
| **Задати тертя** | Встановлює тертя | friction |
| **Рух до точки** | Рух до координат | x, y, speed |
| **Start Moving Direction** | Рух у напрямку | direction, speed |
| **Перейти до позиції** | Телепорт на координати | x, y, relative |
| **Перейти до стартової позиції** | Повернутися на позицію створення | - |
| **Перейти до випадкової позиції** | Телепорт на цілком випадкову позицію (обидві осі; можливість прив'язки до сітки) | snap_h, snap_v |
| **Відскок** | Відскочити від твердих об'єктів | precise |

### Дії Instance

| Дія | Опис | Параметри |
|--------|-------------|------------|
| **Створити екземпляр** | Створює новий об'єкт | object, x, y, relative |
| **Створити рухомий екземпляр** | Створює зі швидкістю | object, x, y, speed, direction |
| **Знищити екземпляр** | Видаляє екземпляр | - |
| **Змінити екземпляр** | Перетворює на інший об'єкт | object, perform_events |

### Дії Таймера

| Дія | Опис | Параметри |
|--------|-------------|------------|
| **Встановити будильник** | Запускає відлік | alarm_number, steps |
| **Пауза** | Призупиняє виконання | milliseconds |

### Дії Score/Lives/Health

| Дія | Опис | Параметри |
|--------|-------------|------------|
| **Задати рахунок** | Змінює рахунок | value, relative |
| **Задати життя** | Змінює життя | value, relative |
| **Задати здоров'я** | Змінює здоров'я | value, relative |
| **Намалювати рахунок** | Показує рахунок | x, y, caption |
| **Намалювати життя** | Показує життя як повторювані зображення спрайта | x, y, sprite, scale, tiled |
| **Намалювати смугу здоров'я** | Показує здоров'я як двоколірну смугу | x1, y1, x2, y2, back_color, bar_color |

### Дії Малювання

| Дія | Опис | Параметри |
|--------|-------------|------------|
| **Намалювати спрайт** | Малює спрайт | sprite, x, y, subimage |
| **Намалювати текст** | Показує текст | x, y, text |
| **Намалювати прямокутник** | Малює прямокутник | x1, y1, x2, y2, filled |
| **Намалювати коло** | Малює коло | x, y, radius, filled |
| **Намалювати лінію** | Малює лінію | x1, y1, x2, y2 |

| **Задати шрифт малювання** | Встановлює шрифт і вирівнювання для наступного малювання тексту | font, halign, valign |

## Вбудовані Змінні

Ці змінні доступні для всіх екземплярів:

| Змінна | Опис |
|----------|-------------|
| `x` | Горизонтальна позиція |
| `y` | Вертикальна позиція |
| `xstart` | Початкова позиція x |
| `ystart` | Початкова позиція y |
| `hspeed` | Горизонтальна швидкість |
| `vspeed` | Вертикальна швидкість |
| `speed` | Швидкість анімації спрайта (кадрів на секунду) — **не** швидкість руху. Вбудованої змінної для "сумарної швидкості" немає; обчисліть її самі з `hspeed`/`vspeed`, наприклад `(hspeed**2 + vspeed**2)**0.5` |
| `direction` | Напрямок руху (0-360) |
| `gravity` | Гравітація |
| `gravity_direction` | Напрямок гравітації |
| `friction` | Тертя руху |
| `image_index` | Поточний кадр анімації |
| `image_speed` | Швидкість анімації |
| `image_xscale` | Горизонтальний масштаб |
| `image_yscale` | Вертикальний масштаб |
| `image_angle` | Кут повороту |
| `visible` | Чи малюється |
| `solid` | Чи твердий для зіткнень |
| `depth` | Глибина малювання |
| `sprite_index` | Поточний спрайт |
| `alarm[0-11]` | Таймери будильників |

### Глобальні Змінні

| Змінна | Опис |
|----------|-------------|
| `score` | Рахунок гри |
| `lives` | Життя гравця |
| `health` | Здоров'я гравця (0-100) |
| `room` | Поточна кімната |
| `room_width` | Ширина поточної кімнати |
| `room_height` | Висота поточної кімнати |
| `mouse_x` | Позиція X миші |
| `mouse_y` | Позиція Y миші |
