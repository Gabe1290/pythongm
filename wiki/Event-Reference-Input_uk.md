### Keyboard (Безперервна)
| Властивість | Значення |
|-------------|----------|
| **Назва** | `keyboard` |
| **Іконка** | ⌨️ |
| **Категорія** | Введення |
| **Пресет** | Початківець |

**Опис:** Спрацьовує безперервно, поки клавіша утримується.

**Найкраще для:** Плавного, безперервного руху

**Підтримувані Клавіші:**
- Клавіші зі стрілками (вгору, вниз, вліво, вправо)
- Літери (A-Z)
- Цифри (0-9)
- Пробіл, Enter, Escape
- Функціональні клавіші (F1-F12)
- Модифікатори (Shift, Ctrl, Alt)

---

### Key Press
| Властивість | Значення |
|-------------|----------|
| **Назва** | `keyboard_press` |
| **Іконка** | 🔘 |
| **Категорія** | Введення |
| **Пресет** | Середній |

**Опис:** Спрацьовує один раз при першому натисканні клавіші.

**Найкраще для:** Одиничних дій (стрибок, постріл, вибір у меню)

**Відмінність від Keyboard:** Спрацьовує лише раз за натискання, не під час утримання.

---

### Key Release
| Властивість | Значення |
|-------------|----------|
| **Назва** | `keyboard_release` |
| **Іконка** | ⬆️ |
| **Категорія** | Введення |
| **Пресет** | Повний (лише редакція Development) |

**Опис:** Спрацьовує один раз при відпусканні клавіші.

**Типові використання:**
- Зупинка руху при відпусканні клавіші
- Завершення заряджених атак
- Перемикання станів

---

### Keyboard (No Key)
| Властивість | Значення |
|-------------|----------|
| **Назва** | `keyboard_no_key` |
| **Іконка** | ⌨️ |
| **Категорія** | Введення |
| **Пресет** | Початківець |

**Опис:** Спрацьовує кожен кадр, поки **не** утримується жодна клавіша.

**Коли спрацьовує:** Кожен кадр, коли клавіатура неактивна, *перед* подією Step.

**Типові використання:**
- Зупинка руху, коли гравець відпускає всі клавіші (ігри на сітці/лабіринти)
- Анімації спокою

---

### Mouse
| Властивість | Значення |
|-------------|----------|
| **Назва** | `mouse` |
| **Іконка** | 🖱️ |
| **Категорія** | Введення |
| **Пресет** | Повний (лише редакція Development) |

**Опис:** Події кнопок миші та руху.

**Типи Подій:**

| Тип | Опис |
|-----|------|
| Left Button | Клацання лівою кнопкою миші |
| Right Button | Клацання правою кнопкою миші |
| Middle Button | Клацання середньою кнопкою/коліщатком |
| Mouse Enter | Курсор входить у межі екземпляра |
| Mouse Leave | Курсор виходить з меж екземпляра |
| Global Left Button | Лівий клік будь-де |
| Global Right Button | Правий клік будь-де |
