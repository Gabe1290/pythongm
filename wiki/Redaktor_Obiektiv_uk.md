Об'єкти — це фундаментальні будівельні блоки вашої гри. Вони
представляють усе, від гравців і ворогів до предметів для збирання та
елементів інтерфейсу.

---

## Відкриття Редактора Об'єктів

1. Двічі клацніть на наявному об'єкті в дереві ресурсів, або
2. Клацніть правою кнопкою на **Objects** > **Create Object**

![Редактор Об'єктів: список подій зліва (Create, Step, декілька подій

подій / Blockly / Редактор Коду, що перемикають спосіб редагування дій

## Властивості Об'єкта

| Властивість | Опис |
|-----------|-------------|
| **Name** | Унікальний ідентифікатор об'єкта (напр. `obj_player`) |
| **Sprite** | Візуальне представлення об'єкта |
| **Visible** | Чи малюється об'єкт (за замовчуванням: так) |
| **Solid** | Використовується для виявлення зіткнень з твердими об'єктами |
| **Depth** | Порядок малювання (менше = малюється зверху) |
| **Persistent** | Об'єкт переживає зміни кімнат |
| **Parent Object** | Успадковує спільні властивості/події від іншого об'єкта |

### Угода Про Іменування

Використовуйте префікс `obj_` для об'єктів:
- `obj_player`
- `obj_enemy`
- `obj_coin`
- `obj_wall`

## Події

Події — це тригери, які запускають виконання дій. Клацніть "Add
Event", щоб додати одну.

### Поширені Події

| Подія | Коли Спрацьовує |
|-------|------------------|
| **Create** | Один раз, коли екземпляр створено |
| **Destroy** | Коли екземпляр знищено |
| **Step** | Щокадру гри (60 разів на секунду) |
| **Draw** | Під час фази малювання |
| **Alarm [0-11]** | Коли таймер будильника досягає нуля |

### Події Клавіатури

| Подія | Коли Спрацьовує |
|-------|------------------|
| **Key Press** | Один раз, коли клавішу натиснуто |
| **Key Release** | Один раз, коли клавішу відпущено |
| **Keyboard** | Щокадру, поки клавіша натиснута |
| **No Key** | Коли не натиснуто жодної клавіші |

### Події Миші

| Подія | Коли Спрацьовує |
|-------|------------------|
| **Mouse Button** | При клацанні на екземплярі |
| **Global Mouse** | При клацанні будь-де |
| **Mouse Enter** | Коли курсор входить в екземпляр |
| **Mouse Leave** | Коли курсор залишає екземпляр |

### Події Зіткнень

| Подія | Коли Спрацьовує |
|-------|------------------|
| **Collision with [об'єкт]** | При дотику з іншим типом об'єкта |

### Інші Події

| Подія | Коли Спрацьовує |
|-------|------------------|
| **Outside Room** | Коли екземпляр залишає кімнату |
| **Intersect Boundary** | Коли екземпляр торкається межі кімнати |
| **Game Start** | Один раз, при запуску гри |
| **Game End** | Один раз, при закритті гри |
| **Room Start** | При вході в кімнату |
| **Room End** | При виході з кімнати |

## Дії

Дії — це операції, що виконуються при спрацьовуванні події. Кожна
подія може мати кілька дій, що виконуються по черзі.

### Дії Руху
- **Set Speed** — Встановлює швидкість руху
- **Set Direction** — Встановлює напрямок руху (0-360 градусів)
- **Set Horizontal Speed** — Встановлює hspeed
- **Set Vertical Speed** — Встановлює vspeed
- **Move Towards Point** — Рух до координат
- **Jump to Position** — Миттєвий телепорт на координати
- **Jump to Start Position** — Повернутися на позицію створення
- **Jump to Random Position** — Телепортуватися на випадкову позицію

### Дії Instance
- **Create Instance** — Створює новий об'єкт
- **Destroy Instance** — Видаляє поточний екземпляр
- **Change Instance** — Перетворює на інший тип об'єкта

### Дії Таймера
- **Set Alarm** — Запускає зворотний відлік
- **Sleep** — Призупиняє виконання на короткий час

### Дії Малювання
- **Draw Sprite** — Малює спрайт
- **Draw Text** — Показує текст на екрані
- **Draw Rectangle** — Малює заповнений або контурний прямокутник
- **Draw Score** — Показує поточний рахунок
- **Draw Lives** — Показує залишок життів
- **Draw Health Bar** — Показує смугу здоров'я

### Score/Lives/Health
- **Set Score** — Змінює значення рахунку
- **Set Lives** — Змінює кількість життів
- **Set Health** — Змінює значення здоров'я
- **Test Score** — Перевіряє умову рахунку
- **Test Lives** — Перевіряє умову життів
- **Test Health** — Перевіряє умову здоров'я

### Дії Кімнати
- **Next Room** — Перейти до наступної кімнати
- **Previous Room** — Перейти до попередньої кімнати
- **Restart Room** — Перезапустити поточну кімнату
- **Go to Room** — Перейти до конкретної кімнати

### Дії Звуку
- **Play Sound** — Відтворює звуковий ефект
- **Stop Sound** — Зупиняє відтворюваний звук
- **Play Music** — Відтворює фонову музику
- **Stop Music** — Зупиняє фонову музику

### Дії Змінних
- **Set Variable** — Присвоює значення змінній
- **Test Variable** — Перевіряє умову змінної

## Візуальне Програмування з Blockly

Замість використання списку дій ви можете перемкнутися на вкладку
**Blockly** для візуального програмування:

1. Відкрийте об'єкт
2. Клацніть на вкладку **Blockly**
3. Перетягуйте блоки з панелі інструментів, щоб побудувати логіку
4. Блоки з'єднуються, утворюючи повні програми

Детальніше див. [[Vizualne_Prohramuvannya_uk]].

## Поради Та Найкращі Практики

### Організація
- Давайте об'єктам описові назви
- Групуйте пов'язані об'єкти схожими префіксами
- Використовуйте подію Create лише для ініціалізації

### Продуктивність
- Уникайте вимогливих обчислень у події Step
- Використовуйте будильники замість ручного підрахунку кадрів
- Знищуйте екземпляри, що залишили кімнату

### Усунення Неполадок
- Використовуйте дію **Show Message** для показу значень
- Перевіряйте вивід консолі на помилки
- Тестуйте часто під час розробки

## Приклад: Проста Штучний Інтелект Ворога

```
Create Event:
  - Set Alarm[0] = 60 (1 секунда при 60 FPS)
  - Set direction = random(360)
  - Set speed = 2

Alarm[0] Event:
  - Set direction = random(360)
  - Set Alarm[0] = 60

Collision with obj_player:
  - Set Lives relative = -1
  - Destroy Instance
```
