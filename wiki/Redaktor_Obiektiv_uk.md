Об'єкти — це фундаментальні будівельні блоки вашої гри. Вони
представляють усе, від гравців і ворогів до предметів для збирання та
елементів інтерфейсу.

---

## Відкриття Редактора Об'єктів

1. Двічі клацніть на наявному об'єкті в дереві ресурсів, або
2. Клацніть правою кнопкою на **Objects** > **Create Object**

![Редактор Об'єктів: список подій зліва (Create, Step, декілька подій
Collision, Keyboard, Життя скінчилися, Початок гри), властивості об'єкта
(sprite, parent, Visible/Persistent/Solid) справа, і вкладки Список
подій / Blockly / Редактор Коду, що перемикають спосіб редагування дій

## Властивості Об'єкта

| Властивість | Опис |
|-----------|-------------|
| **Name** | Унікальний ідентифікатор об'єкта (напр. `obj_player`) |
| **Sprite** | Візуальне представлення об'єкта |
| **Visible** | Чи малюється об'єкт (за замовчуванням: так) |
| **Solid** | Використовується для виявлення зіткнень з твердими об'єктами |
| **Depth** | Порядок малювання (менше = малюється зверху) |
| **Persistent** | Об'єкт переживає зміни кімнат |
| **Parent Object** | Успадковує спільні властивості/події від іншого об'єкта |

### Угода Про Іменування

Використовуйте префікс `obj_` для об'єктів:
- `obj_player`
- `obj_enemy`
- `obj_coin`
- `obj_wall`

## Події

Події — це тригери, які запускають виконання дій. Клацніть "Add
Event", щоб додати одну.

### Поширені Події

| Подія | Коли Спрацьовує |
|-------|------------------|
| **Створення** | Один раз, коли екземпляр створено |
| **Знищення** | Коли екземпляр знищено |
| **Крок** | Щокадру гри (60 разів на секунду) |
| **Малювання** | Під час фази малювання |
| **Alarm [0-11]** | Коли таймер будильника досягає нуля |

### Події Клавіатури

| Подія | Коли Спрацьовує |
|-------|------------------|
| **Key Press** | Один раз, коли клавішу натиснуто |
| **Key Release** | Один раз, коли клавішу відпущено |
| **Keyboard** | Щокадру, поки клавіша натиснута |
| **No Key** | Коли не натиснуто жодної клавіші |

### Події Миші

| Подія | Коли Спрацьовує |
|-------|------------------|
| **Mouse Button** | При клацанні на екземплярі |
| **Global Mouse** | При клацанні будь-де |
| **Mouse Enter** | Коли курсор входить в екземпляр |
| **Mouse Leave** | Коли курсор залишає екземпляр |

### Події Зіткнень

| Подія | Коли Спрацьовує |
|-------|------------------|
| **Collision with [об'єкт]** | При дотику з іншим типом об'єкта |

### Інші Події

| Подія | Коли Спрацьовує |
|-------|------------------|
| **Поза кімнатою** | Коли екземпляр залишає кімнату |
| **Дотик до межі кімнати** | Коли екземпляр торкається межі кімнати |
| **Початок гри** | Один раз, при запуску гри |
| **Кінець гри** | Один раз, при закритті гри |
| **Початок кімнати** | При вході в кімнату |
| **Кінець кімнати** | При виході з кімнати |

## Дії

Дії — це операції, що виконуються при спрацьовуванні події. Кожна
подія може мати кілька дій, що виконуються по черзі.

### Дії Руху
- **Задати швидкість** — Встановлює швидкість руху
- **Задати напрямок** — Встановлює напрямок руху (0-360 градусів)
- **Задати горизонтальну швидкість** — Встановлює hspeed
- **Задати вертикальну швидкість** — Встановлює vspeed
- **Рух до точки** — Рух до координат
- **Jump to Position** — Миттєвий телепорт на координати
- **Перейти до стартової позиції** — Повернутися на позицію створення
- **Перейти до випадкової позиції** — Телепортуватися на випадкову позицію

### Дії Instance
- **Створити екземпляр** — Створює новий об'єкт
- **Знищити екземпляр** — Видаляє поточний екземпляр
- **Змінити екземпляр** — Перетворює на інший тип об'єкта

### Дії Таймера
- **Встановити будильник** — Запускає зворотний відлік
- **Пауза** — Призупиняє виконання на короткий час

### Дії Малювання
- **Намалювати спрайт** — Малює спрайт
- **Намалювати текст** — Показує текст на екрані
- **Намалювати прямокутник** — Малює заповнений або контурний прямокутник
- **Намалювати рахунок** — Показує поточний рахунок
- **Намалювати життя** — Показує залишок життів
- **Намалювати смугу здоров'я** — Показує смугу здоров'я

### Score/Lives/Health
- **Задати рахунок** — Змінює значення рахунку
- **Задати життя** — Змінює кількість життів
- **Задати здоров'я** — Змінює значення здоров'я
- **Перевірити рахунок** — Перевіряє умову рахунку
- **Перевірити життя** — Перевіряє умову життів
- **Перевірити здоров'я** — Перевіряє умову здоров'я

### Дії Кімнати
- **Наступна кімната** — Перейти до наступної кімнати
- **Попередня кімната** — Перейти до попередньої кімнати
- **Перезапустити кімнату** — Перезапустити поточну кімнату
- **Перейти до кімнати** — Перейти до конкретної кімнати

### Дії Звуку
- **Відтворити звук** — Відтворює звуковий ефект
- **Зупинити звук** — Зупиняє відтворюваний звук
- **Відтворити музику** — Відтворює фонову музику
- **Зупинити музику** — Зупиняє фонову музику

### Дії Змінних
- **Задати змінну** — Присвоює значення змінній
- **Перевірити змінну** — Перевіряє умову змінної

## Візуальне Програмування з Blockly

Замість використання списку дій ви можете перемкнутися на вкладку
**Blockly** для візуального програмування:

1. Відкрийте об'єкт
2. Клацніть на вкладку **Blockly**
3. Перетягуйте блоки з панелі інструментів, щоб побудувати логіку
4. Блоки з'єднуються, утворюючи повні програми

Детальніше див. [[Vizualne_Prohramuvannya_uk]].

## Поради Та Найкращі Практики

### Організація
- Давайте об'єктам описові назви
- Групуйте пов'язані об'єкти схожими префіксами
- Використовуйте подію Create лише для ініціалізації

### Продуктивність
- Уникайте вимогливих обчислень у події Step
- Використовуйте будильники замість ручного підрахунку кадрів
- Знищуйте екземпляри, що залишили кімнату

### Усунення Неполадок
- Використовуйте дію **Показати повідомлення** для показу значень
- Перевіряйте вивід консолі на помилки
- Тестуйте часто під час розробки

## Приклад: Проста Штучний Інтелект Ворога

```
Create Event:
  - Set Alarm[0] = 60 (1 секунда при 60 FPS)
  - Set direction = random(360)
  - Set speed = 2

Alarm[0] Event:
  - Set direction = random(360)
  - Set Alarm[0] = 60

Collision with obj_player:
  - Set Lives relative = -1
  - Destroy Instance
```
