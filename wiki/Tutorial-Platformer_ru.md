## Введение

В этом руководстве вы создадите **Игру-Платформер** — экшн-игру с боковой прокруткой, где игрок бегает, прыгает и перемещается по платформам, избегая опасностей и собирая монеты. Этот классический жанр идеально подходит для изучения гравитации, механики прыжков и столкновений с платформами.

**Что вы узнаете:**
- Гравитация и физика падения
- Механика прыжков с обнаружением земли
- Столкновение с платформами (приземление сверху)
- Движение влево/вправо
- Собираемые предметы и опасности

**Сложность:** Начинающий
**Пресет:** Пресет для Начинающих

---

## Шаг 1: Понять Игру

### Механики Игры
1. На игрока действует гравитация, он падает вниз
2. Игрок может двигаться влево и вправо
3. Игрок может прыгать, когда стоит на земле
4. Платформы не дают игроку провалиться
5. Собирайте монеты для очков
6. Достигните флага, чтобы завершить уровень

### Что Нам Нужно

| Элемент | Назначение |
|---------|------------|
| **Игрок** | Персонаж, которым вы управляете |
| **Земля/Платформа** | Твёрдые поверхности для стояния |
| **Монета** | Собираемые предметы для очков |
| **Шип** | Опасность, которая ранит игрока |
| **Флаг** | Цель, завершающая уровень |

---

## Шаг 2: Создать Спрайты

### Спрайты
- `spr_player` (32x48 пикселей) — простой персонаж
- `spr_ground` (32x32 пикселя) — плитка травы/земли
- `spr_platform` (64x16 пикселей) — плавающая платформа
- `spr_coin` (16x16 пикселей) — золотой круг
- `spr_spike` (32x32 пикселя) — треугольные шипы
- `spr_flag` (32x64 пикселя) — флаг на шесте

---

## Шаг 3: Создать Объект Земли

Земля — твёрдая платформа, не дающая игроку упасть.

1. Щёлкните правой кнопкой на **Objects** и выберите **Create Object**
2. Назовите его `obj_ground`
3. Установите спрайт на `spr_ground`
4. **Поставьте галочку "Solid"**
5. События не нужны

---

## Шаг 4: Создать Объект Платформы

Платформы действуют так же, как земля, но их можно размещать в воздухе.

1. Создайте новый объект с именем `obj_platform`
2. Установите спрайт на `spr_platform`
3. **Поставьте галочку "Solid"**

---

## Шаг 5: Создать Объект Игрока

Игрок — самый сложный объект, с гравитацией, прыжками и движением.

1. Создайте новый объект с именем `obj_player`
2. Установите спрайт на `spr_player`

### 5.1 Гравитация

**Событие: Create** — Add Action: **Move** → **Set Gravity**
(Direction: `270`, Gravity: `0.5`) — 270° означает прямо вниз;
значение добавляется к вертикальной скорости игрока каждый кадр, так
что отныне игрок сам ускоряется вниз.

### 5.2 Движение, Прыжки И Столкновение С Землёй

Добавьте эти события по тому же шаблону, который уже используют предыдущие руководства этой вики:

| Событие | Действие |
|---|---|
| Keyboard (held) → Left Arrow | Set Horizontal Speed на `-4` |
| Keyboard (held) → Right Arrow | Set Horizontal Speed на `4` |
| Keyboard: No Key | Set Horizontal Speed на `0` |
| Key Press → Up Arrow | Set Vertical Speed на `-10` |
| Collision with obj_ground | Stop Movement |

Две детали, из-за которых это работает правильно:

- **No Key устанавливает ТОЛЬКО горизонтальную скорость на 0** —
  никогда не используйте здесь Stop Movement, потому что Stop
  Movement сбрасывает и вертикальную скорость тоже, что каждый раз
  отменяло бы гравитацию, когда игрок отпускает клавишу направления.
- **Key Press (не held)** — именно это делает Up одним прыжковым
  импульсом, а не постоянным подталкиванием игрока вверх каждый кадр,
  пока клавиша удерживается. **Stop Movement** при приземлении
  сбрасывает этот импульс, так что игрок не продолжает подниматься
  после приземления — встроенное твёрдое столкновение движка (Шаг 3
  уже сделал `obj_ground` Solid) уже не даёт игроку провалиться в
  землю; событие здесь лишь очищает оставшуюся скорость падения.

## Шаг 6-8: Собираемые Предметы И Опасности

**obj_coin** — Столкновение с obj_player: Счёт +10, уничтожить Self

**obj_spike** — Столкновение с obj_player: Показать сообщение, перезапустить комнату

**obj_flag** — Столкновение с obj_player: Показать сообщение, следующая комната

---

## Шаг 9: Спроектируйте Свой Уровень

1. Создайте `room_level1` (800x480)
2. Включите привязку к сетке (32x32)
3. Разместите землю внизу, платформы в воздухе
4. Добавьте монеты, шипы
5. Поставьте флаг в конце, игрока в начале

---

## Что Вы Узнали

- **Физика гравитации** — Set Gravity каждый кадр применяет постоянную силу вниз
- **Механика прыжков** — Событие Key Press (не held) даёт единственный импульс скорости вверх
- **Встроенное твёрдое столкновение** — Земля автоматически блокирует игрока, когда отмечена как Solid, без ручного кода для проверки позиции
