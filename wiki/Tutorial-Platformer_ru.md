## Введение

В этом руководстве вы создадите **Игру-Платформер** — экшн-игру с боковой прокруткой, где игрок бегает, прыгает и перемещается по платформам, избегая опасностей и собирая монеты. Этот классический жанр идеально подходит для изучения гравитации, механики прыжков и столкновений с платформами.

**Что вы узнаете:**
- Гравитация и физика падения
- Механика прыжков с обнаружением земли
- Столкновение с платформами (приземление сверху)
- Движение влево/вправо
- Собираемые предметы и опасности

**Сложность:** Начинающий
**Пресет:** Пресет для Среднего Уровня (действия Execute Code из раздела «Улучшения» отсутствуют в Пресете для Начинающих; для базового руководства вплоть до Шага 10 нужны только действия Пресета для Начинающих)

## Шаг 1: Понять Игру

### Механики Игры
1. На игрока действует гравитация, он падает вниз
2. Игрок может двигаться влево и вправо
3. Игрок может прыгать, когда стоит на земле
4. Платформы не дают игроку провалиться
5. Собирайте монеты для очков
6. Достигните флага, чтобы завершить уровень

### Что Нам Нужно

| Элемент | Назначение |
|---------|------------|
| **Игрок** | Персонаж, которым вы управляете |
| **Земля/Платформа** | Твёрдые поверхности для стояния |
| **Монета** | Собираемые предметы для очков |
| **Шип** | Опасность, которая ранит игрока |
| **Флаг** | Цель, завершающая уровень |

## Шаг 2: Создать Спрайты

### 2.1 Спрайт Игрока

1. В **Дереве Ресурсов** щёлкните правой кнопкой на **Sprites** и выберите **Create Sprite**
2. Назовите его `spr_player`
3. Нажмите **Edit Sprite**, чтобы открыть редактор спрайтов
4. Нарисуйте простого персонажа (прямоугольник с лицом или человечка из палочек)
5. Используйте яркий цвет, например синий или красный
6. Размер: 32x48 пикселей (выше, чем шире, для персонажа)
7. Нажмите **OK**, чтобы сохранить

### 2.2 Спрайт Земли

1. Создайте новый спрайт с именем `spr_ground`
2. Нарисуйте плитку платформы из травы/земли
3. Используйте коричневый и зелёный цвета
4. Размер: 32x32 пикселя

### 2.3 Спрайт Платформы

1. Создайте новый спрайт с именем `spr_platform`
2. Нарисуйте плавающую платформу (дерево или камень)
3. Размер: 64x16 пикселей (широкая и тонкая)

### 2.4 Спрайт Монеты

1. Создайте новый спрайт с именем `spr_coin`
2. Нарисуйте маленький жёлтый/золотой круг
3. Размер: 16x16 пикселей

### 2.5 Спрайт Шипа

1. Создайте новый спрайт с именем `spr_spike`
2. Нарисуйте треугольные шипы, направленные вверх
3. Используйте серый или красный цвет
4. Размер: 32x32 пикселя

### 2.6 Спрайт Флага

1. Создайте новый спрайт с именем `spr_flag`
2. Нарисуйте флаг на шесте
3. Используйте яркие цвета (зелёный флаг, коричневый шест)
4. Размер: 32x64 пикселя

## Шаг 3: Создать Объект Земли

Земля — это твёрдая платформа, которая не даёт игроку упасть.

1. Щёлкните правой кнопкой на **Objects** и выберите **Create Object**
2. Назовите его `obj_ground`
3. Установите спрайт `spr_ground`
4. **Поставьте галочку "Solid"**
5. События не нужны

![obj_ground's Object Events panel: empty -- Solid checked is all it needs](images/tutorial-platformer-03-ground-object.png)

---

## Шаг 4: Создать Объект Платформы

Платформы работают так же, как земля, но их можно размещать в воздухе.

1. Создайте новый объект с именем `obj_platform`
2. Установите спрайт `spr_platform`
3. **Поставьте галочку "Solid"**
4. События не нужны

**Совет:** вы можете сделать платформу потомком `obj_ground`, чтобы использовать то же поведение столкновений.

![obj_platform's Object Events panel: empty, with Solid checked -- a wide, thin sprite is the only difference from obj_ground](images/tutorial-platformer-04-platform-object.png)

## Шаг 5: Создать Объект Игрока

Игрок — самый сложный объект: гравитация, прыжок и движение.

1. Создайте новый объект с именем `obj_player`
2. Установите спрайт `spr_player`

### 5.1 Гравитация

**Событие: Create** — Добавьте действие **Move** → **Set Gravity**
(Direction: `270`, Gravity: `0.5`) — 270° это прямо вниз; значение
добавляется к вертикальной скорости игрока на каждом шаге, поэтому игрок
сам ускоряется вниз с этого момента.

### 5.2 Движение, Прыжок и Столкновение с Землёй

Добавьте эти события по тому же шаблону, что уже используют предыдущие
руководства этого вики:

| Событие | Действие |
|---|---|
| Keyboard (held) → Left Arrow | Set Horizontal Speed на `-4` |
| Keyboard (held) → Right Arrow | Set Horizontal Speed на `4` |
| Keyboard: No Key | Set Horizontal Speed на `0` |
| Key Press → Up Arrow | Set Vertical Speed на `-10` |
| Collision with obj_ground | Stop Movement |

Две детали, из-за которых всё ощущается правильно:

- **No Key обнуляет ТОЛЬКО горизонтальную скорость** — никогда не
  используйте здесь Stop Movement, потому что Stop Movement обнуляет и
  вертикальную скорость, что отменяло бы гравитацию каждый раз, когда
  игрок отпускает клавишу направления.
- **Key Press (не held)** — это то, что делает Up одним импульсом
  прыжка вместо подбрасывания игрока вверх на каждом кадре, пока клавиша
  удерживается. **Stop Movement** при приземлении затем обнуляет этот
  импульс, чтобы игрок не продолжал подниматься после приземления —
  встроенное твёрдое столкновение движка (Шаг 3 уже сделал `obj_ground`
  Solid) уже не даёт игроку провалиться в землю; событие здесь лишь
  очищает оставшуюся скорость падения.

## Шаг 6: Создать Объект Монеты

Монеты добавляют очки, когда их собирают.

1. Создайте новый объект с именем `obj_coin`
2. Установите спрайт `spr_coin`

**Событие: Collision with obj_player**
1. Добавить Событие → Collision → obj_player
2. Добавьте действие **Score** → **Set Score**
   - New Score: `10`
   - Поставьте галочку "Relative"
3. Добавьте действие **Main1** → **Destroy Instance**
   - Applies to: Self

![obj_coin's Object Events panel: a Collision with obj_player event holding Set Score (Relative) and Destroy Instance](images/tutorial-platformer-06-coin-object.png)

## Шаг 7: Создать Объект Шипа

Шипы ранят игрока и перезапускают уровень.

1. Создайте новый объект с именем `obj_spike`
2. Установите спрайт `spr_spike`

**Событие: Collision with obj_player**
1. Добавить Событие → Collision → obj_player
2. Добавьте действие **Main2** → **Show Message**
   - Message: `Ouch! You hit a spike!`
3. Добавьте действие **Main1** → **Restart Room**

![obj_spike's Object Events panel: a Collision with obj_player event holding Show Message and Restart Room](images/tutorial-platformer-07-spike-object.png)

## Шаг 8: Создать Объект Флага

Флаг завершает уровень, когда игрок его достигает.

1. Создайте новый объект с именем `obj_flag`
2. Установите спрайт `spr_flag`

**Событие: Collision with obj_player**
1. Добавить Событие → Collision → obj_player
2. Добавьте действие **Output** → **Show Message**
   - Message: `Level Complete!`
3. Добавьте действие **Room** → **Next Room** (или **Restart Room** для одиночного уровня)

Текст Show Message — это фиксированная строка, в неё нельзя встроить живое
значение вроде счёта. HUD игрового контроллера (Шаг 9) уже показывает счёт
на экране в течение всего уровня, так что игрок его уже видел.

![obj_flag's Object Events panel: a Collision with obj_player event holding Show Message and Next Room](images/tutorial-platformer-08-flag-object.png)

## Шаг 9: Создать Игровой Контроллер

Игровой контроллер отображает счёт.

1. Создайте новый объект с именем `obj_game_controller`
2. Спрайт не нужен

**Событие: Draw**
1. Добавить Событие → Draw → Draw
2. Добавьте действие **Draw** → **Draw Text** (Text: `Score:`, X: `10`, Y: `10`)
3. Добавьте действие **Draw** → **Draw Variable** (Variable: `score`, X: `70`, Y: `10`)

Необязательно: добавьте так же пару **Draw Text** (`Lives:`, X `10`, Y
`30`) + **Draw Variable** (`lives`, X `70`, Y `30`), как только будет
добавлено улучшение «Система жизней» ниже.

![obj_game_controller's Object Events panel: a Draw event with one Draw Text and one Draw Variable action, with no sprite set](images/tutorial-platformer-09-controller-object.png)

## Шаг 10: Спроектировать Свой Уровень

1. Щёлкните правой кнопкой на **Rooms** и выберите **Create Room**
2. Назовите её `room_level1`
3. Задайте размер room (например, 800x480)
4. Включите "Snap to Grid" и задайте сетку 32x32

### Размещение Объектов

Стройте уровень по этим рекомендациям:

1. **Создайте землю** — Разместите `obj_ground` вдоль низа
2. **Добавьте платформы** — Разместите `obj_platform` в воздухе для прыжковых испытаний
3. **Добавьте пропасти** — Оставьте промежутки в земле (ямы)
4. **Разместите монеты** — Разбросайте их по платформам и в труднодоступных местах
5. **Добавьте шипы** — Рядом с ямами или на платформах для сложности
6. **Разместите флаг** — В конце уровня
7. **Разместите игрока** — В начале (левая сторона)
8. **Добавьте игровой контроллер** — Где угодно (он невидим)

### Пример Раскладки Уровня

```
                                        F
                                      ===
                          C       C
                        =====   =====
            C                           C
          ===== X     X         X     =====
    P                   C
  ====== === ===   ===   === === ===== ======
  GGGGGG     GGG   GGG   GGG         GGGGGGGG

G = Земля    P = Игрок    F = Флаг    C = Монета
X = Шип    === = Платформа
```

## Улучшения (Необязательно)

### Добавить Переменную Высоту Прыжка

Добавьте событие **Step** к `obj_player` с **Control** → **Execute Code**
(настоящий Python — `self` это текущий экземпляр, `keyboard` позволяет
проверить удерживаемую клавишу по имени):

```python
# Обрывает прыжок, если Up отпущена во время подъёма
if self.vspeed < 0 and not keyboard.check('up'):
    self.vspeed = max(self.vspeed, -5)  # половина импульса прыжка -10
```

### Добавить Двойной Прыжок

Это можно сделать полностью структурированными действиями — код не нужен.

**Событие: Create** — Добавьте действие **Control** → **Set Variable**
(Variable: `jumps_left`, Value: `2`)

**Событие: Collision with obj_ground** — после **Stop Movement** добавьте
**Control** → **Set Variable** (Variable: `jumps_left`, Value: `2`), чтобы
пополнять оба прыжка при приземлении.

Замените единственное действие существующего события **Key Press → Up
Arrow** на три, по порядку:
1. **Control** → **Test Variable** (Variable: `jumps_left`, Value: `0`,
   Operation: `greater`)
2. **Control** → **Start Block**
3. **Move** → **Set Vertical Speed** (`-10`)
4. **Control** → **Set Variable** (Variable: `jumps_left`, Value: `-1`,
   галочка **Relative**)
5. **Control** → **End Block**

Пара Start/End Block означает, что оба действия внутри выполняются, только
когда Test Variable над ними истинно — тот же шаблон защищённого блока,
что руководства Sokoban и Лабиринт используют для своих условий.

### Добавить Движущиеся Платформы

1. Создайте `obj_moving_platform` как потомка `obj_platform`

**Событие: Create** — Добавьте действие **Control** → **Execute Code**:

```python
self.start_x = self.x
self.hspeed = 2
```

**Событие: Step** — Добавьте действие **Control** → **Execute Code**:

```python
if self.x > self.start_x + 100:
    self.hspeed = -2
elif self.x < self.start_x:
    self.hspeed = 2
```

### Добавить Врага

1. Создайте `obj_enemy` с простым ИИ

**Событие: Create** — Добавьте действие **Move** → **Start Moving
Direction** (Directions: `right`, Speed: `2`)

**Событие: Collision with obj_ground** — Добавьте действие **Move** →
**Reverse Horizontal** (разворачивается у стен; в сочетании с тем, что
`obj_ground` Solid, враг никогда не сойдёт с края платформы в землю ниже и
не пройдёт сквозь стену)

**Событие: Collision with obj_player** — это событие срабатывает на
`obj_enemy`, поэтому `self` это враг, а `other` это игрок. Добавьте
действие **Control** → **Test Expression** с вложенными действиями
Then/Else (тот же шаблон, что встроенный пример `plateforme_3` использует
именно для этой проверки «прыжка на голову», только зеркально, потому что
проверка живёт на враге, а не на игроке):
   - Expression: `other.vspeed > 0 and other.y - other.vspeed < y - 16`
   - Then Actions: **Control** → **Execute Code** с `other.vspeed = -5`
     (небольшой отскок для игрока — у `set_vspeed` нет опции «applies to
     other», поэтому это единственное место, где нужна строка настоящего
     Python вместо структурированного действия), затем **Instance** →
     **Destroy Instance** (self)
   - Else Actions: **Room** → **Restart Room** (игрок умирает)

`other.vspeed > 0 and other.y - other.vspeed < y - 16` проверяет позицию
*игрока* до движения падения в этом кадре (используя собственный `vspeed`
игрока, ведь падает именно он), поэтому быстрое падение не может проскочить
16-пиксельное окно прыжка за один шаг — см. README `plateforme_3` для
полной истории о том, почему наивная версия `other.y < y - 16` ненадёжна.

### Добавить Систему Жизней

В событии **Create** объекта `obj_game_controller` добавьте **Score** →
**Set Lives** (Value: `3`).

Когда игрок умирает (столкновение с шипом и ветка Else врага выше),
замените **Restart Room** на **Score** → **Set Lives** (Value: `-1`,
галочка **Relative**) — room перезапустится автоматически, потому что
событие **No More Lives** срабатывает, только когда жизни действительно
достигают 0. Добавьте это событие к `obj_game_controller`: **Other
Events** → **No More Lives** → **Output** → **Show Message** (`Game
Over!`) → **Room** → **Restart Game**.

## Устранение Неполадок

| Проблема | Решение |
|----------|---------|
| Игрок проваливается сквозь землю | Проверьте, что у `obj_ground` отмечено "Solid" |
| Игрок не может прыгнуть | Убедитесь, что событие Key Press → Up Arrow существует и Set Vertical Speed отрицательное |
| Игрок продолжает подниматься после приземления | Убедитесь, что у Collision with obj_ground есть действие Stop Movement |
| Прыжок ощущается «плавающим» | Увеличьте значение Gravity в Set Gravity или сделайте значение прыжка Set Vertical Speed более отрицательным |
| Прыжок слишком слабый | Уменьшите значение Gravity в Set Gravity или сделайте значение прыжка Set Vertical Speed более отрицательным |

## Что Вы Узнали

Поздравляем! Вы создали игру-платформер! Вы узнали:

- **Физика гравитации** — Set Gravity применяет постоянную силу вниз на каждом шаге
- **Механика прыжков** — Событие Key Press (не held) даёт один импульс скорости вверх
- **Встроенное твёрдое столкновение** — Земля блокирует игрока автоматически, как только помечена Solid, без ручного кода проверки позиции
- **Опасности** — Создание объектов, которые перезапускают уровень
- **Дизайн уровней** — Построение платформенных испытаний

## Идеи для Испытаний

1. **Прыжок от Стены** — Разрешить отпрыгивать от стен
2. **Рывок** — Короткий горизонтальный всплеск скорости
3. **Рушащиеся Платформы** — Платформы, которые падают после того, как на них наступили
4. **Контрольные Точки** — Сохранение прогресса посреди уровня
5. **Бой с Боссом** — Добавить финального врага с несколькими попаданиями
