Referenca lastnih urejevalnih bližnjic PyGameMaker. Gre za **gradnjo
vaše igre v IDE** — za tipke, ki jih vaša *dokončana igra* bere med
izvajanjem (`keyboard_check`, dogodki pritiska tipke itd.), glejte
namesto tega [[Dogodki_in_Akcije_sl|Dogodki in Akcije]].

## Globalno (Glavno Okno)

| Bližnjica | Dejanje |
|----------|--------|
| Ctrl+N | Nov Projekt |
| Ctrl+O | Odpri Projekt |
| Ctrl+S | Shrani Projekt |
| Ctrl+Shift+S | Shrani Projekt Kot |
| Ctrl+E | Izvozi Projekt |
| Ctrl+Q | Izhod |
| Ctrl+Z | Razveljavi |
| Ctrl+Y | Uveljavi |
| Ctrl+X | Izreži |
| Ctrl+C | Kopiraj |
| Ctrl+V | Prilepi |
| Ctrl+D | Podvoji |
| Ctrl+F | Najdi |
| Ctrl+H | Najdi in Zamenjaj |
| F1 | Dokumentacija |
| F5 | Testiraj Igro |
| F6 | Razhroščuj Igro |
| F7 | Zgradi Igro |
| F8 | Zgradi in Zaženi |

## Urejevalnik Sprite-ov

| Bližnjica | Orodje |
|----------|------|
| P | Svinčnik |
| E | Radirka |
| I | Kapalka |
| G | Zapolnitev (vedro barve) |
| L | Črta |
| R | Pravokotnik |
| O | Elipsa |
| S | Izbira |
| Ctrl+C / Ctrl+X / Ctrl+V | Kopiraj / Izreži / Prilepi (izbiro) |
| Del | Izbriši (izbiro) |
| Esc | Prekliči izbiro |

Glejte [[Sprite-Editor_sl|Urejevalnik Sprite-ov]], kaj natanko naredi vsako orodje.

---

## Urejevalnik Objektov

| Bližnjica | Dejanje |
|----------|--------|
| Ctrl+S | Shrani ta objekt (deluje tudi, ko je fokusiran zavihek urejevalnika objektov, ne da bi sprožil Shrani glavnega okna) |
| Ctrl+Gor / Ctrl+Dol | Premakne izbrani dogodek gor/dol po seznamu |
| Ctrl+C / Ctrl+V | Kopiraj / prilepi akcijo |

---

## Urejevalnik Sob

| Bližnjica | Dejanje |
|----------|--------|
| Del | Izbriše izbrano(e) instanco(e) |

Orodna vrstica Urejevalnika Sob ponuja tudi **Grid**, **Snap**, **Clear
All** in **Shift All** — glejte [[Urejevalnik_Sob_sl|Urejevalnik Sob]].
