## Общие Вопросы

### Что такое PyGameMaker?

PyGameMaker — это IDE для разработки игр с открытым исходным кодом, вдохновлённый GameMaker 7.0. Он позволяет создавать 2D-игры с помощью визуального программирования (Google Blockly) или системы событий-действий, без написания кода.

### PyGameMaker бесплатный?

Да! PyGameMaker полностью бесплатен и с открытым исходным кодом — исходный код лицензирован под MIT, а документация — под CC BY 4.0.

### Для каких платформ я могу экспортировать?

- Windows (автономный .exe)
- HTML5 (веббраузеры)
- Linux (нативный бинарный файл)
- Мобильные устройства (iOS/Android через Kivy)

### Нужен ли мне опыт программирования?

Нет! PyGameMaker разработан для начинающих. Вы можете создавать игры с помощью:
- Блоков Blockly перетаскиванием
- Системы событий/действий point-and-click
- Без написания кода

### Совместим ли он с файлами GameMaker?

PyGameMaker вдохновлён GameMaker 7.0, но использует собственный формат проекта. Файлы GameMaker нельзя импортировать напрямую, но концепции и рабочий процесс похожи.

## Установка

### Какие системные требования?

- Python 3.10 или новее
- Windows, Linux или macOS
- Минимум 4 ГБ RAM (рекомендуется 8 ГБ)
- ~500 МБ свободного места на диске

### Как установить PyGameMaker?

Подробные инструкции по установке см. в [[Nachalo_ru]]. Краткая версия:

```bash
git clone https://github.com/Gabe1290/pythongm.git
cd pythongm
python -m venv venv
source venv/bin/activate  # или venv\Scripts\activate на Windows
pip install -r requirements.txt
python main.py
```

### Python не распознаётся / не найден

Убедитесь, что Python установлен и добавлен в PATH системы. Проверьте командой:

```bash
python --version
```

Если это не работает, переустановите Python и во время установки включите "Add Python to PATH".

### При запуске возникают ошибки импорта

Попробуйте переустановить зависимости:

```bash
pip install -r requirements.txt --force-reinstall
```

## Проекты

### Где хранятся мои проекты?

Проекты хранятся в папках, которые вы выбираете сами. Каждый проект содержит:
- `project.json` — Основной файл проекта
- Папки для спрайтов, звуков, объектов, комнат и т. д.

### Могу ли я иметь открытыми несколько проектов одновременно?

В настоящее время PyGameMaker открывает один проект за раз. Чтобы переключиться между проектами, используйте **File > Open Project**.

### Как сделать резервную копию проекта?

Просто скопируйте всю папку проекта. Все ресурсы и настройки содержатся в ней. Также рассмотрите использование git для контроля версий:

```bash
cd my_project
git init
git add .
git commit -m "Начальная резервная копия"
```

### Мой проект не открывается / повреждён

Попробуйте следующие шаги:
1. Проверьте, что `project.json` существует и не пуст
2. Откройте `project.json` в текстовом редакторе и проверьте на ошибки JSON
3. Если доступно, восстановите из резервной копии
4. Проверьте вывод консоли на конкретные сообщения об ошибках

## Объекты и События

### В чём разница между объектом и экземпляром?

- **Объект**: Шаблон/модель, определяющая поведение
- **Экземпляр**: Конкретная копия объекта, размещённая в комнате

Например, `obj_enemy` — это объект. Размещение 5 врагов в комнате создаёт 5 экземпляров объекта `obj_enemy`.

### Почему моё событие не срабатывает?

Распространённые причины:
1. **Неправильный тип события**: Убедитесь, что используете правильное событие (напр. "Key Press", а не "Keyboard")
2. **Нет экземпляров**: У объекта должны быть экземпляры в комнате
3. **Объект не виден**: Проверьте свойство visible
4. **Порядок выполнения**: Некоторые события выполняются перед другими

### Как сделать взаимодействие между объектами?

Используйте события столкновений:
1. Откройте объект, который должен обнаруживать столкновения
2. Добавьте событие **Collision with [другой объект]**
3. Добавьте действия для того, что происходит при столкновении

### В чём разница между событиями "Keyboard" и "Key Press"?

- **Keyboard [клавиша]**: Срабатывает каждый кадр, пока клавиша нажата
- **Key Press [клавиша]**: Срабатывает один раз, когда клавиша впервые нажата
- **Key Release [клавиша]**: Срабатывает один раз, когда клавиша отпущена

## Комнаты

### Какая комната загружается первой?

Первая комната в дереве ресурсов (сверху списка) загружается при старте игры. Перетаскивайте комнаты, чтобы изменить их порядок.

### Как сменить комнату?

Используйте действия комнаты:
- **Next Room**: Перейти к следующей комнате по порядку
- **Previous Room**: Перейти к предыдущей комнате
- **Go to Room**: Перейти к конкретной комнате

### Объекты исчезают при смене комнаты

Объекты уничтожаются при выходе из комнаты, если только они не отмечены как **Persistent** в своих свойствах.

### Моя комната слишком большая/маленькая на экране

Размер окна игры соответствует размерам первой комнаты. Вы можете:
- Изменить размер комнаты в соответствии с желаемым размером окна
- Использовать Views, чтобы показывать только часть комнаты

## Графика И Спрайты

### Какие форматы изображений поддерживаются?

- PNG (рекомендуется, поддерживает прозрачность)
- JPEG/JPG
- BMP
- GIF (только первый кадр)

### Мой спрайт отображается в неправильном месте

Проверьте настройку **Origin** в редакторе спрайтов. Точка начала координат — это точка привязки для размещения. Распространённые настройки:
- Верхний левый угол (0, 0): По умолчанию
- Центр: Хорошо для вращающихся объектов
- Центр снизу: Хорошо для персонажей

### Как анимировать спрайт?

1. Создайте спрайт с несколькими кадрами (горизонтальная лента)
2. В свойствах спрайта установите **Number of Frames**
3. Настройте **Animation Speed** (кадров в секунду)

### Спрайты размыты

Это происходит при изменении размера спрайтов. Для пиксель-арта отключите интерполяцию/сглаживание в настройках игры, если доступно.

## Звук И Музыка

### Какие аудиоформаты поддерживаются?

- WAV (несжатый)
- OGG (рекомендуется для музыки)
- MP3

### Звук не воспроизводится

Проверьте:
1. Существует ли звуковой файл в папке sounds
2. Поддерживается ли формат файла
3. Используете ли вы правильное название звука в действиях
4. Браузер может требовать взаимодействия пользователя (для HTML5)

### Как сделать циклическое воспроизведение фоновой музыки?

Используйте действие **Play Music** с включённой опцией цикла, или **Play Sound** с параметром loop, установленным на true.

## Экспорт

### Моя экспортированная игра не работает

Распространённые проблемы:
- **Windows**: Отсутствующие DLL — убедитесь, что включена вся выходная папка
- **HTML5**: Браузер блокирует локальные файлы — разместите на сервере
- **Отсутствующие ресурсы**: Проверьте, что включены все файлы

### Экспортированный файл огромный

Размер игры включает Python и все библиотеки. Чтобы уменьшить:
- Удалите неиспользуемые ресурсы
- Сожмите изображения и звук
- Используйте подходящие форматы (OGG вместо WAV)
- Для сборок Windows включите сжатие UPX

### Могу ли я продавать игры, сделанные с PyGameMaker?

Да! Игры, которые вы создаёте, полностью ваши, и вы можете их продавать. Исходный код PyGameMaker лицензирован под разрешительной лицензией MIT, поэтому вы можете свободно использовать его в коммерческих проектах — и, в отличие от copyleft-лицензий, вам не нужно открывать код собственных изменений.

## Blockly / Визуальное Программирование

### Где найти редактор Blockly?

1. Откройте объект
2. В редакторе объектов кликните на вкладку **Blockly**
3. Появится рабочая область визуального программирования

### Как переключаться между Blockly и событиями?

Обе системы работают с тем же объектом. Вкладки Blockly и Events показывают разные представления той же логики. Изменения в одной отражаются в другой.

### Мои блоки Blockly исчезли

Проверьте:
1. Смотрите ли вы на правильный объект
2. Прокрутите рабочую область (блоки могут быть за пределами экрана)
3. Проверьте уровень масштабирования

## Производительность

### Моя игра медленная

Советы для лучшей производительности:
1. Уменьшите количество экземпляров
2. Избегайте требовательных вычислений в событиях Step
3. Используйте будильники вместо подсчёта кадров
4. Оптимизируйте размеры спрайтов
5. Уничтожайте экземпляры, покинувшие комнату

### Событие Step выполняется слишком часто

Событие Step выполняется каждый кадр (по умолчанию 60 раз в секунду). Используйте:
- Будильники для отложенных действий
- Условия, проверяемые перед требовательными операциями
- Более низкую скорость комнаты, если уместно
