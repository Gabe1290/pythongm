A reference of PyGameMaker's own editing shortcuts. This is about
**building your game in the IDE** — for the keys your *finished game*
reads at runtime (`keyboard_check`, key-press events, etc.), see
[[Events-and-Actions]] instead.

---

## Global (Main Window)

| Shortcut | Action |
|----------|--------|
| Ctrl+N | New Project |
| Ctrl+O | Open Project |
| Ctrl+S | Save Project |
| Ctrl+Shift+S | Save Project As |
| Ctrl+E | Export Project |
| Ctrl+Q | Exit |
| Ctrl+Z | Undo |
| Ctrl+Y | Redo |
| Ctrl+X | Cut |
| Ctrl+C | Copy |
| Ctrl+V | Paste |
| Ctrl+D | Duplicate |
| Ctrl+F | Find |
| Ctrl+H | Find and Replace |
| F1 | Documentation |
| F5 | Test Game |
| F6 | Debug Game |
| F7 | Build Game |
| F8 | Build and Run |

## Sprite Editor

| Shortcut | Tool |
|----------|------|
| P | Pencil |
| E | Eraser |
| I | Color Picker |
| G | Fill (flood fill) |
| L | Line |
| R | Rectangle |
| O | Ellipse |
| S | Select |
| Ctrl+C / Ctrl+X / Ctrl+V | Copy / Cut / Paste (a selection) |
| Del | Delete (a selection) |
| Esc | Deselect |

See [[Sprite-Editor]] for what each tool actually does.

---

## Object Editor

| Shortcut | Action |
|----------|--------|
| Ctrl+S | Save this object (works even while the object editor tab has focus, without triggering the main window's own Save) |
| Ctrl+Up / Ctrl+Down | Move the selected event up/down in the event list |
| Ctrl+C / Ctrl+V | Copy / paste an action |

---

## Room Editor

| Shortcut | Action |
|----------|--------|
| Del | Delete the selected instance(s) |

The Room Editor's own toolbar additionally exposes **Grid**, **Snap**,
**Clear All**, and **Shift All** — see [[Room-Editor]].
