## Вступ

У цьому навчанні ви створите класичну гру **Pong** — одну з перших відеоігор, коли-небудь створених! Pong — це гра для двох гравців, де кожен гравець керує ракеткою і намагається ударити м'яч повз ракетку супротивника, щоб набрати очки.

**Що ви дізнаєтесь:**
- Створення спрайтів для ракеток, м'яча та стін
- Обробка введення з клавіатури для двох гравців
- Відскоки об'єктів один від одного
- Відстеження та відображення очок обох гравців
- Використання глобальних змінних

**Рівень складності:** Для початківців
**Пресет:** Пресет для початківців

## Крок 1: Планування гри

Перед тим як розпочати, давайте розберемось, що нам потрібно:

| Елемент | Призначення |
|---------|---------|
| **М'яч** | Відскакує між гравцями |
| **Ліва ракетка** | Гравець 1 керує клавішами W/S |
| **Права ракетка** | Гравець 2 керує стрілками вгору/вниз |
| **Стіни** | Верхня та нижня межі гри |
| **Цілі** | Невидимі області позаду кожної ракетки для виявлення забитих голів |
| **Відображення очок** | Показує очки обох гравців |

---

## Крок 2: Створення спрайтів

### 2.1 Спрайт м'яча

1. У **Дереві ресурсів** клацніть правою кнопкою миші на **Sprites** і виберіть **Create Sprite**
2. Назвіть його `spr_ball`
3. Клацніть **Edit Sprite**, щоб відкрити редактор спрайтів
4. Намалюйте невелике біле коло (близько 16x16 пікселів)
5. Клацніть **OK**, щоб зберегти

### 2.2 Спрайти ракеток

Ми створимо дві ракетки — по одній для кожного гравця:

**Ліва ракетка (Гравець 1):**
1. Створіть новий спрайт з ім'ям `spr_paddle_left`
2. Намалюйте довгий тонкий прямокутник вигнутої форми, як дужка ")" — рекомендується синій колір
3. Розмір: приблизно 16x64 пікселів

**Права ракетка (Гравець 2):**
1. Створіть новий спрайт з ім'ям `spr_paddle_right`
2. Намалюйте довгий тонкий прямокутник вигнутої форми, як дужка "(" — рекомендується червоний колір
3. Розмір: приблизно 16x64 пікселів

### 2.3 Спрайт стіни

1. Створіть новий спрайт з ім'ям `spr_wall`
2. Намалюйте суцільний прямокутник (сірий або білий)
3. Розмір: 32x32 пікселів (ми розтягнемо його в кімнаті)

### 2.4 Спрайт цілі (невидимий)

1. Створіть новий спрайт з ім'ям `spr_goal`
2. Розмір: 32x32 пікселів
3. Залиште його прозорим або зробіть суцільним кольором (він буде невидимим у грі)

## Крок 3: Створення об'єкту стіни

Об'єкт стіни створює межі вгорі та внизу ігрової площі.

1. Клацніть правою кнопкою миші на **Objects** і виберіть **Create Object**
2. Назвіть його `obj_wall`
3. Встановіть спрайт на `spr_wall`
4. **Встановіть прапорець "Solid"** — це важливо для відскоків!
5. Жодних подій не потрібно — стіна просто перебуває там

---

## Крок 4: Створення об'єктів ракеток

### 4.1 Ліва ракетка (Гравець 1)

1. Створіть новий об'єкт з ім'ям `obj_paddle_left`
2. Встановіть спрайт на `spr_paddle_left`
3. **Встановіть прапорець "Solid"**

**Додавання подій клавіатури для руху:**

**Подія: Key Press W**
1. Add Event → Keyboard → Key Press W
2. Add Action: **Move** → **Set Vertical Speed**
3. Встановіть вертикальну швидкість на `-8` (рух вгору)

**Подія: Key Release W**
1. Add Event → Keyboard → Key Release W
2. Add Action: **Move** → **Set Vertical Speed**
3. Встановіть вертикальну швидкість на `0` (зупинка руху)

**Подія: Key Press S**
1. Add Event → Keyboard → Key Press S
2. Add Action: **Move** → **Set Vertical Speed**
3. Встановіть вертикальну швидкість на `8` (рух вниз)

**Подія: Key Release S**
1. Add Event → Keyboard → Key Release S
2. Add Action: **Move** → **Set Vertical Speed**
3. Встановіть вертикальну швидкість на `0` (зупинка руху)

**Подія: Collision with obj_wall**
1. Add Event → Collision → obj_wall
2. Add Action: **Move** → **Bounce** (налаштування не потрібне —
   завжди відскакує від твердих об'єктів)

### 4.2 Права ракетка (Гравець 2)

1. Створіть новий об'єкт з ім'ям `obj_paddle_right`
2. Встановіть спрайт на `spr_paddle_right`
3. **Встановіть прапорець "Solid"**

**Додавання подій клавіатури для руху:**

**Подія: Key Press Up Arrow**
1. Add Event → Keyboard → Key Press Up
2. Add Action: **Move** → **Set Vertical Speed**
3. Встановіть вертикальну швидкість на `-8`

**Подія: Key Release Up Arrow**
1. Add Event → Keyboard → Key Release Up
2. Add Action: **Move** → **Set Vertical Speed**
3. Встановіть вертикальну швидкість на `0`

**Подія: Key Press Down Arrow**
1. Add Event → Keyboard → Key Press Down
2. Add Action: **Move** → **Set Vertical Speed**
3. Встановіть вертикальну швидкість на `8`

**Подія: Key Release Down Arrow**
1. Add Event → Keyboard → Key Release Down
2. Add Action: **Move** → **Set Vertical Speed**
3. Встановіть вертикальну швидкість на `0`

**Подія: Collision with obj_wall**
1. Add Event → Collision → obj_wall
2. Add Action: **Move** → **Bounce** (налаштування не потрібне —
   завжди відскакує від твердих об'єктів)

## Крок 5: Створення об'єкту м'яча

1. Створіть новий об'єкт з ім'ям `obj_ball`
2. Встановіть спрайт на `spr_ball`

**Подія: Create**
1. Add Event → Create
2. Add Action: **Move** → **Start Moving Direction**
3. Виберіть діагональну клітинку в 3x3-селекторі напрямку (не прямо вгору чи вниз)
4. Встановіть швидкість на `6`

**Подія: Collision with obj_paddle_left**
1. Add Event → Collision → obj_paddle_left
2. Add Action: **Move** → **Bounce** (налаштування не потрібне —
   завжди відскакує від твердих об'єктів)

**Подія: Collision with obj_paddle_right**
1. Add Event → Collision → obj_paddle_right
2. Add Action: **Move** → **Bounce** (налаштування не потрібне —
   завжди відскакує від твердих об'єктів)

**Подія: Collision with obj_wall**
1. Add Event → Collision → obj_wall
2. Add Action: **Move** → **Bounce** (налаштування не потрібне —
   завжди відскакує від твердих об'єктів)

## Крок 6: Створення об'єктів цілей

Цілі — це невидимі області позаду кожної ракетки. Коли м'яч потрапляє в ціль, супротивник набирає очко.

### 6.1 Ліва ціль

1. Створіть новий об'єкт з ім'ям `obj_goal_left`
2. Встановіть спрайт на `spr_goal`
3. **Зніміть прапорець "Visible"** — ціль повинна бути невидимою
4. **Встановіть прапорець "Solid"**

### 6.2 Права ціль

1. Створіть новий об'єкт з ім'ям `obj_goal_right`
2. Встановіть спрайт на `spr_goal`
3. **Зніміть прапорець "Visible"**
4. **Встановіть прапорець "Solid"**

### 6.3 Додавання подій зіткнення цілей до м'яча

`global.p1score`/`global.p2score` — це власні змінні, по одній для
кожного гравця — вбудована дія **Set Score** тут не підходить, бо вона
завжди записує єдиний вбудований рахунок і не має способу вказати на
назву змінної. **Set Variable** — правильна дія для власної змінної, і
вона підтримує область видимості `global`:

Повертаємось до `obj_ball` і додаємо ці події:

**Подія: Collision with obj_goal_left**
1. Add Event → Collision → obj_goal_left
2. Add Action: **Move** → **Jump to Start Position** (перезавантажує м'яч)
3. Add Action: **Control** → **Set Variable**
   - Variable: `p2score`
   - Value: `1`
   - Scope: `global`
   - Встановіть прапорець "Relative" (додає 1 до поточного рахунку)

**Подія: Collision with obj_goal_right**
1. Add Event → Collision → obj_goal_right
2. Add Action: **Move** → **Jump to Start Position**
3. Add Action: **Control** → **Set Variable**
   - Variable: `p1score`
   - Value: `1`
   - Scope: `global`
   - Встановіть прапорець "Relative"

## Крок 7: Створення об'єкту для відображення очок

1. Створіть новий об'єкт з ім'ям `obj_score`
2. Спрайт не потрібен

**Подія: Create**
1. Add Event → Create
2. Add Action: **Control** → **Set Variable**
   - Variable: `p1score`, Value: `0`, Scope: `global`
3. Add Action: **Control** → **Set Variable**
   - Variable: `p2score`, Value: `0`, Scope: `global`

**Подія: Draw**
1. Add Event → Draw
2. Add Action: **Draw** → **Draw Text**
   - Text: `Гравець 1:`
   - X: `10`
   - Y: `10`
3. Add Action: **Draw** → **Draw Variable**
   - Variable: `global.p1score`
   - X: `100`
   - Y: `10`
4. Add Action: **Draw** → **Draw Text**
   - Text: `Гравець 2:`
   - X: `10`
   - Y: `30`
5. Add Action: **Draw** → **Draw Variable**
   - Variable: `global.p2score`
   - X: `100`
   - Y: `30`

## Крок 8: Дизайн кімнати

1. Клацніть правою кнопкою миші на **Rooms** і виберіть **Create Room**
2. Назвіть її `room_pong`
3. Встановіть розмір кімнати (наприклад, 640x480)

**Розміщення об'єктів:**

1. **Стіни**: Розмістіть екземпляри `obj_wall` по верхньому і нижньому краю кімнати
2. **Ліва ракетка**: Розмістіть `obj_paddle_left` біля лівого краю, по центру вертикально
3. **Права ракетка**: Розмістіть `obj_paddle_right` біля правого краю, по центру вертикально
4. **М'яч**: Розмістіть `obj_ball` у центрі кімнати
5. **Цілі**:
   - Розмістіть екземпляри `obj_goal_left` по лівому краю (позаду, де розташована ракетка)
   - Розмістіть екземпляри `obj_goal_right` по правому краю
6. **Відображення очок**: Розмістіть `obj_score` де-небудь (у неї немає спрайту, вона просто малює текст)

**Приклад макету кімнати:**
```
[СТІНА СТІНА СТІНА СТІНА СТІНА СТІНА СТІНА СТІНА СТІНА СТІНА]
[ЦІЛЬ]  [РАКЕТКА_Л]            [М'ЯЧ]            [РАКЕТКА_П]  [ЦІЛЬ]
[ЦІЛЬ]  [РАКЕТКА_Л]                              [РАКЕТКА_П]  [ЦІЛЬ]
[ЦІЛЬ]                                                      [ЦІЛЬ]
[СТІНА СТІНА СТІНА СТІНА СТІНА СТІНА СТІНА СТІНА СТІНА СТІНА]
```

## Крок 9: Тестування гри!

1. Клацніть **Run** або натисніть **F5**, щоб протестувати гру
2. Гравець 1 використовує **W** (вгору) і **S** (вниз)
3. Гравець 2 використовує **стрілку вгору** та **стрілку вниз**
4. Спробуйте ударити м'яч повз ракетку супротивника!

## Вдосконалення (додатково)

### Збільшення швидкості
Зробіть м'яч швидшим кожного разу, коли він вдаряється об ракетку.
`speed` тут не підходить напряму — у цьому рушії це швидкість
*анімації* спрайта, а не швидкість руху — тому швидкість м'яча
відстежуємо у власній змінній:

1. У події **Create** для `obj_ball` додайте **Control** → **Set
   Variable** (Variable: `ball_speed`, Value: `6`) одразу після дії
   Start Moving Direction.
2. У кожній події зіткнення з ракеткою, після дії **Bounce**, додайте
   **Control** → **Set Variable** (Variable: `ball_speed`, Value:
   `0.5`, позначено "Relative"), потім **Move** → **Set Speed** зі
   значенням `self.ball_speed`, щоб застосувати нову швидкість,
   зберігаючи поточний напрямок (Bounce уже його змінив).

### Звукові ефекти
Додайте звуки коли:
- М'яч вдаряється об ракетку
- М'яч вдаряється об стіну
- Гравець забиває гол

### Умова перемоги
Додайте перевірку в подію Draw:
- Якщо `global.p1score >= 10`, відобразіть "Гравець 1 переміг!"
- Якщо `global.p2score >= 10`, відобразіть "Гравець 2 переміг!"

## Усунення неполадок

| Проблема | Рішення |
|---------|----------|
| М'яч проходить крізь ракетку | Переконайтесь, що ракетки мають встановлений прапорець "Solid" |
| Ракетка не зупиняється у стін | Додайте подію зіткнення з obj_wall |
| Очко не оновлюється | Перевірте, що назви змінних збігаються точно (p1score, p2score) |
| М'яч не рухається | Перевірте, що подія Create має дію руху |
