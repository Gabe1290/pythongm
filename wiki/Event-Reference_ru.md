# Справочник Событий

*[Главная](Home_ru) | [Руководство по Пресетам](Preset-Guide_ru) | [Полный Справочник Действий](Full-Action-Reference_ru)*

Эта страница документирует все доступные события в PyGameMaker. События — это триггеры, которые выполняют действия при возникновении определённых условий в вашей игре.

- [События Объекта](#события-объекта) — Create, Step, Destroy
- [События Ввода](#события-ввода) — Клавиатура, Мышь
- [События Столкновений](#события-столкновений) — Столкновения объектов
- [Временные События](#временные-события) — Будильники, Варианты Step
- [События Рисования](#события-рисования) — Пользовательский рендеринг
- [События Комнаты](#события-комнаты) — Переходы между комнатами
- [События Игры](#события-игры) — Начало/Конец игры
- [Другие События](#другие-события) — Границы, Жизни, Здоровье

## События Объекта

### Create
| Свойство | Значение |
|----------|----------|
| **Имя** | `create` |
| **Иконка** | 🎯 |
| **Категория** | Объект |
| **Пресет** | Начинающий |

**Описание:** Выполняется один раз при первом создании экземпляра.

**Когда срабатывает:**
- Когда экземпляр размещается в комнате при запуске игры
- При создании через действие "Create Instance"
- После переходов комнаты для новых экземпляров

**Типичные использования:**
- Инициализация переменных
- Установка начальных значений
- Настройка начального состояния

---

### Step
| Свойство | Значение |
|----------|----------|
| **Имя** | `step` |
| **Иконка** | ⭐ |
| **Категория** | Объект |
| **Пресет** | Начинающий |

**Описание:** Выполняется каждый кадр (обычно 60 раз в секунду).

**Когда срабатывает:** Непрерывно, каждый игровой кадр.

**Типичные использования:**
- Непрерывное движение
- Проверка условий
- Обновление позиций
- Игровая логика

**Примечание:** Будьте осторожны с производительностью — код здесь выполняется постоянно.

---

### Destroy
| Свойство | Значение |
|----------|----------|
| **Имя** | `destroy` |
| **Иконка** | 💥 |
| **Категория** | Объект |
| **Пресет** | Средний |

**Описание:** Выполняется при уничтожении экземпляра.

**Когда срабатывает:** Непосредственно перед удалением экземпляра из игры.

**Типичные использования:**
- Создание эффектов (взрывы, частицы)
- Выпадение предметов
- Обновление счёта
- Воспроизведение звуков

## События Ввода

### Keyboard (Непрерывное)
| Свойство | Значение |
|----------|----------|
| **Имя** | `keyboard` |
| **Иконка** | ⌨️ |
| **Категория** | Ввод |
| **Пресет** | Начинающий |

**Описание:** Срабатывает непрерывно, пока клавиша удерживается.

**Лучше всего для:** Плавного, непрерывного движения

**Поддерживаемые Клавиши:**
- Клавиши со стрелками (вверх, вниз, влево, вправо)
- Буквы (A-Z)
- Цифры (0-9)
- Пробел, Enter, Escape
- Функциональные клавиши (F1-F12)
- Модификаторы (Shift, Ctrl, Alt)

---

### Key Press
| Свойство | Значение |
|----------|----------|
| **Имя** | `keyboard_press` |
| **Иконка** | 🔘 |
| **Категория** | Ввод |
| **Пресет** | Средний |

**Описание:** Срабатывает один раз при первом нажатии клавиши.

**Лучше всего для:** Одиночных действий (прыжок, выстрел, выбор в меню)

**Отличие от Keyboard:** Срабатывает только раз за нажатие, не во время удержания.

---

### Key Release
| Свойство | Значение |
|----------|----------|
| **Имя** | `keyboard_release` |
| **Иконка** | ⬆️ |
| **Категория** | Ввод |
| **Пресет** | Полный (только редакция Development) |

**Описание:** Срабатывает один раз при отпускании клавиши.

**Типичные использования:**
- Остановка движения при отпускании клавиши
- Завершение заряженных атак
- Переключение состояний

---

### Keyboard (No Key)
| Свойство | Значение |
|----------|----------|
| **Имя** | `keyboard_no_key` |
| **Иконка** | ⌨️ |
| **Категория** | Ввод |
| **Пресет** | Начинающий |

**Описание:** Срабатывает каждый кадр, пока **не** удерживается ни одна клавиша.

**Когда срабатывает:** Каждый кадр, когда клавиатура неактивна, *перед* событием Step.

**Типичные использования:**
- Остановка движения, когда игрок отпускает все клавиши (игры на сетке/лабиринты)
- Анимации покоя

---

### Mouse
| Свойство | Значение |
|----------|----------|
| **Имя** | `mouse` |
| **Иконка** | 🖱️ |
| **Категория** | Ввод |
| **Пресет** | Полный (только редакция Development) |

**Описание:** События кнопок мыши и движения.

**Типы Событий:**

| Тип | Описание |
|-----|----------|
| Left Button | Клик левой кнопкой мыши |
| Right Button | Клик правой кнопкой мыши |
| Middle Button | Клик средней кнопкой/колёсиком |

| Global Left Button | Левый клик в любом месте |
| Global Right Button | Правый клик в любом месте |

## События Столкновений

### Collision
| Свойство | Значение |
|----------|----------|
| **Имя** | `collision` |
| **Иконка** | 💥 |
| **Категория** | Столкновение |
| **Пресет** | Начинающий |

**Описание:** Срабатывает, когда этот экземпляр перекрывается с другим типом объекта.

**Настройка:** Выберите, какой тип объекта вызывает это столкновение.

**Специальная переменная:** `other` — Ссылка на столкнувшийся экземпляр.

**Когда срабатывает:** Каждый кадр, пока экземпляры перекрываются.

**Типичные использования:**
- Сбор предметов
- Получение урона
- Удары о стены
- Запуск событий

**Примеры событий столкновений:**
- `collision_with_obj_coin` — Игрок касается монеты
- `collision_with_obj_enemy` — Игрок касается врага
- `collision_with_obj_wall` — Экземпляр ударяется о стену

## Временные События

### Alarm
| Свойство | Значение |
|----------|----------|
| **Имя** | `alarm` |
| **Иконка** | ⏰ |
| **Категория** | Время |
| **Пресет** | Начинающий |

**Описание:** Срабатывает, когда обратный отсчёт будильника достигает нуля.

**Доступные будильники:** 12 независимых будильников (alarm[0] до alarm[11])

**Установка будильников:** Используйте действие "Set Alarm" с шагами (60 шагов ≈ 1 секунда при 60 FPS)

**Типичные использования:**
- Периодическое создание
- Время перезарядки
- Отложенные эффекты
- Повторяющиеся действия (установите будильник снова в событии будильника)

---

### Begin Step
| Свойство | Значение |
|----------|----------|
| **Имя** | `begin_step` |
| **Иконка** | ▶️ |
| **Категория** | Step |
| **Пресет** | Начинающий |

**Описание:** Срабатывает в начале каждого кадра, перед обычными событиями Step.

**Порядок выполнения:** Begin Step → Step → End Step

**Типичные использования:**
- Обработка ввода
- Предварительные расчёты движения

---

### End Step
| Свойство | Значение |
|----------|----------|
| **Имя** | `end_step` |
| **Иконка** | ⏹️ |
| **Категория** | Step |
| **Пресет** | Начинающий |

**Описание:** Срабатывает в конце каждого кадра, после столкновений.

**Типичные использования:**
- Финальные корректировки позиции
- Операции очистки
- Обновления состояния после столкновений

## События Рисования

### Draw
| Свойство | Значение |
|----------|----------|
| **Имя** | `draw` |
| **Иконка** | 🎨 |
| **Категория** | Рисование |
| **Пресет** | Начинающий |

**Описание:** Срабатывает во время фазы рендеринга.

**Важно:** Добавление события Draw отключает автоматическое рисование спрайта. Вы должны рисовать спрайт вручную, если хотите, чтобы он был виден.

**Типичные использования:**
- Пользовательский рендеринг
- Рисование фигур
- Отображение текста
- Полосы здоровья
- Элементы интерфейса

**Доступные действия рисования:**
- Draw Sprite
- Draw Text
- Draw Rectangle
- Draw Circle
- Draw Line
- Draw Health Bar

---

### Draw GUI
| Свойство | Значение |
|----------|----------|
| **Имя** | `draw_gui` |
| **Иконка** | 🖥️ |
| **Категория** | Рисование |
| **Пресет** | Начинающий |

**Описание:** Рисует в **экранном пространстве (GUI)**, поверх комнаты, и не зависит от прокрутки видов/камеры.

**Отличие от Draw:** обычное событие Draw работает в координатах комнаты (прокручивается вместе с видом); Draw GUI остаётся зафиксированным на экране — используйте его для HUD, счёта и меню.

## Порядок Выполнения Событий

Понимание того, когда срабатывают события, помогает создавать
предсказуемое поведение игры (проверено против главного цикла в
`runtime/game_runner.py`):

1. **Begin Step** — Начало кадра
2. **Alarm** — Все сработавшие будильники отсчитывают и активируются
3. **Step** (и **Keyboard (удержание)**) — Основная игровая логика,
   затем непрерывные проверки удерживаемых клавиш для того же экземпляра
4. **Keyboard Press/Release, Mouse** — Накопленные события ввода для
   этого кадра обрабатываются (это происходит *после* Step, а не до
   него — код в Step реагирует на клавиши, нажатые уже *в начале*
   кадра, а не на те, что нажаты в течение него)
5. **Движение, затем Collision** — Применяется физика (гравитация/
   трение/hspeed/vspeed), затем обнаруживаются столкновения и
   запускаются их события
6. **End Step** (и **Destroy**) — После столкновений
7. **Draw** — Фаза рендеринга

## События по Пресету

наполненного каждым реальным пресетом из `config/blockly_config.py` —

проекта, см. [Руководство по Пресетам](Preset-Guide_ru).
