PyGameMaker включает Google Blockly для визуального программирования методом перетаскивания. Вы строите игровую логику, соединяя блоки, вместо написания кода.

---

## Доступ к Blockly

1. Откройте объект в Object Editor
2. Кликните на вкладку **Blockly** (рядом с вкладкой Events)
3. Появится рабочая область Blockly с панелью инструментов слева

**Какие блоки видны, зависит от вашего пресета.**
`Tools > Configure Action Blocks...` (или `Preferences > IDE Edition`,
которая определяет стандартный пресет для новых проектов) управляет
набором блоков — подробности см. в [Руководстве по
Пресетам](Preset-Guide_ru). Таблицы ниже перечисляют все блоки,
существующие в каком-либо пресете; конкретный проект может показывать меньше.

## Рабочая Область Blockly

### Панель Инструментов
Левая панель содержит категории блоков:
- **Events** — Блоки-триггеры событий
- **Control** — Условия, переменные и группировка (условные блоки
  этого проекта — это блоки-складыши, а не классические контейнеры
  If/Else — см. "Типы Блоков" ниже)
- **Movement** — Блоки движения, скорости и физики
- **Timing** — Будильники
- **Drawing** — Блоки текста и фигур
- **Score/Lives/Health** — Блоки состояния игры
- **Instance** — Создание/уничтожение объектов
- **Room** — Навигация между комнатами
- **Values** — Блоки значений (позиция, скорость, счёт, жизни,
  здоровье, мышь)
- **Sound** — Воспроизведение звука
- **Output** — Сообщения и собственный Python-код
- **Game** — Завершить/перезапустить игру, таблица рекордов

Отдельной категории Math, Text или Logic нет — числовые/текстовые
поля заполняются прямо на самом блоке, так же нет общего
логического/сравнительного блока-значения. См. "Типы Блоков" ниже, как
вместо этого работают условия.

### Рабочая Поверхность
Центральная область, где вы строите свою программу:
- Перетаскивая блоки из панели инструментов
- Соединяя блоки между собой
- Настраивая параметры блоков

### Корзина
Перетащите ненужные блоки сюда, чтобы удалить их, или нажмите клавишу Delete.

## Типы Блоков

### Блоки-Шляпы (Events)
Блоки-шляпы имеют закруглённый верх и начинают последовательность. Они представляют события:

```
┌─────────────────┐
│ When Create     │
└─────────────────┘
```

### Блоки-Складыши (Действия)
Блоки-складыши имеют выступы, которые соединяются с другими блоками.
Почти все блоки вне категории Values — блоки-складыши, включая условные:

```
├─────────────────┤
│ Set Horizontal Speed [5] │
├─────────────────┤
```

### Блоки-Значения (Values)
Блоки-значения закруглены и вставляются в числовое поле другого блока
(например, поле скорости Move Direction или поле значения Set
Variable). В этом проекте их 9 — X Position, Y Position, Horizontal
Speed, Vertical Speed, Score, Lives, Health, Mouse X, Mouse Y:

```
( X Position )    ( Score )    ( 100 )
```

Общего блока-значения `( speed )` или `( direction )` нет — этот
движок не отслеживает эти понятия как единое значение
(скорость/направление движения выводятся вместе из Horizontal Speed +
Vertical Speed), так же нет блока-значения для собственных переменных
(вместо этого читайте их через сравнение Test Variable).

### Условия — блоки-складыши, а не C-подобные контейнеры
В отличие от визуальных языков в стиле Scratch, блоки If Condition /
Test Variable этого проекта — это **блоки-складыши с одним слотом
"then"**, а не двусторонние контейнеры If/Else, и нет
шестиугольного логического блока для вставки — сравнение строится
прямо через поля на самом блоке:

```
┌───────────────────────────────────┐
│ If count of [obj_coin] [==] [0]   │
├───────────────────────────────────┤
│  then [действия здесь]            │
└───────────────────────────────────┘
```

Чтобы добавить ветку "else" или выполнить несколько действий с одной
стороны, объедините его ещё с тремя блоками Control:
- **Else** — выполняет свой следующий блок только если предыдущая проверка была ложной
- **Start Block** / **End Block** — группируют несколько действий,
  чтобы предыдущая проверка (или Else) действовала на всю группу, а
  не только на следующий блок

Это тот же плоский, в стиле GM80, поток условий, который использует
структурированная панель Events/Actions (см. [События и
Действия](Sobytiya_i_Deystviya_ru)) — Blockly — это интерфейс
перетаскивания над тем же базовым списком действий, а не отдельная
модель выполнения.

## Блоки Событий

### Событие Create
```
┌─────────────────────┐
│ When Create         │
├─────────────────────┤
│ [действия здесь]     │
└─────────────────────┘
```

### Событие Step
```
┌─────────────────────┐
│ When Step            │
├─────────────────────┤
│ [каждый кадр]         │
└─────────────────────┘
```

### События Клавиатуры
Существует четыре отдельных блока-шляпы для клавиатуры — Held, Press,
Release и No Key — каждый с выпадающим меню названия клавиши (No Key
его не имеет, так как срабатывает, когда ничего не нажато):
```
┌─────────────────────────┐
│ When key [held: left] ▼ │
├─────────────────────────┤
│ [действия здесь]         │
└─────────────────────────┘
```

### События Столкновений
```
┌────────────────────────────┐
│ When colliding with [obj] ▼│
├────────────────────────────┤
│ [действия здесь]            │
└────────────────────────────┘
```

## Блоки Движения

| Блок | Описание |
|------|-------------|
| `Set Horizontal Speed [4]` | Устанавливает скорость X |
| `Set Vertical Speed [-5]` | Устанавливает скорость Y |
| `Stop Movement` | Сбрасывает обе скорости |
| `Move [direction ▼] speed [3]` | Движение в одном из 4 направлений (или по диагонали, или "stop") |
| `Move Free [direction] [speed]` | Движение под произвольным углом и скоростью |
| `Set Speed [5]` | Устанавливает величину скорости, сохраняя текущее направление |
| `Set Direction [90]` | Устанавливает угол направления, сохраняя текущую скорость |
| `Move Towards x:[100] y:[200] speed:[3]` | Движение к точке |
| `Snap to Grid` | Выравнивает позицию по сетке |
| `Jump to Position x:[100] y:[200]` | Мгновенный телепорт |
| `Move Grid [direction]` | Движение точно на одну клетку сетки |
| `Stop if No Keys` / `Check Keys and Move` / `If On Grid` | Вспомогательные блоки для движения по сетке |
| `Set Gravity` | Применяет постоянную силу каждый кадр (вниз или в любом направлении) |
| `Set Friction` | Уменьшает скорость каждый кадр |
| `Reverse Horizontal` / `Reverse Vertical` | Разворачивает направление X или Y |
| `Bounce` | Отскакивает от твёрдых объектов |
| `Wrap Around Room` | Появляется снова с противоположной стороны |
| `Move to Contact` | Движение до контакта с чем-либо |

Блока "Jump to Start Position" или "Jump to Random Position" нет — эти
два действия существуют только в структурированной панели, не в Blockly.

## Блоки Рисования

| Блок | Описание |
|------|-------------|
| `Draw Text [Hello] at x:[10] y:[10]` | Показывает текст |
| `Draw Rectangle from x1,y1 to x2,y2` | Рисует заполненный прямоугольник |
| `Draw Circle at x,y radius [r]` | Рисует заполненный круг |
| `Set Sprite [spr]` | Меняет спрайт экземпляра |
| `Set Transparency [0-1]` | Устанавливает альфа-канал |

Блока "Draw Sprite at Position" или "Set Drawing Color" в Blockly нет
(оба существуют только в структурированной панели). Draw Score/Draw
Lives/Draw Health Bar перечислены ниже под Score/Lives/Health, не здесь.

## Блоки Score/Lives/Health

| Блок | Описание |
|------|-------------|
| `Set Score [100]` | Точно устанавливает счёт |
| `Add to Score [10]` | Увеличивает/уменьшает счёт |
| `Set Lives [3]` | Точно устанавливает жизни |
| `Add to Lives [-1]` | Увеличивает/уменьшает жизни |

| `Add to Health [-25]` | Увеличивает/уменьшает здоровье |

| `Draw Lives` | Показывает жизни как повторяющиеся иконки |
| `Draw Health Bar` | Показывает здоровье как двухцветную полосу |

## Блоки Instance

| Блок | Описание |
|------|-------------|
| `Create Instance [obj] at x:[100] y:[200]` | Создаёт новый экземпляр |
| `Destroy Instance` | Удаляет самого себя |
| `Destroy Other` | Удаляет экземпляр в столкновении (в событии Collision) |
| `Change Instance [obj]` | Превращается в другой тип объекта |
| `If Can Push [obj] [direction]` | Проверка толкания в стиле Sokoban |

Блока "уничтожить все одного типа" или "создать на этой позиции" нет.

## Блоки Комнаты

| Блок | Описание |
|------|-------------|
| `Next Room` | Перейти к следующей комнате |
| `Previous Room` | Вернуться к предыдущей комнате |
| `Restart Room` | Перезапустить текущую комнату |
| `Go to Room [room_name]` | Перейти к конкретной комнате |
| `If Next Room Exists` / `If Previous Room Exists` | Защищают навигацию между несколькими комнатами |

## Блоки Звука

| Блок | Описание |
|------|-------------|
| `Play Sound [snd]` | Воспроизводит звуковой эффект |
| `Play Music [music]` | Воспроизводит фоновую музыку (циклично) |
| `Stop Music` | Останавливает музыку |

Блока "Stop Sound" (для отдельного звука) или "Остановить все звуки" в
Blockly нет (только Stop Music, которая останавливает только музыку).

---

## Блоки Control

| Блок | Описание |
|------|-------------|
| `If count of [obj] [==] [0] then...` | Сравнивает количество экземпляров объекта; выполняет следующий(ие) блок(и), если истинно |
| `If variable [var] [==] [value] then...` | Сравнивает собственную переменную; выполняет следующий(ие) блок(и), если истинно |
| `Set Variable [name] to [value]` | Задаёт переменную экземпляра или глобальную |
| `Check Empty at x,y` | Истинно, если в позиции нет столкновения (движение по сетке) |
| `Exit Event` | Останавливает остальные действия этого события |
| `Else` | Выполняет свой следующий блок, если предыдущая проверка была ложной |
| `Start Block` / `End Block` | Группируют несколько действий под Test/Else |

## Блоки Output и Game

| Блок | Описание |
|------|-------------|
| `Show Message [text]` | Показывает всплывающее сообщение |
| `Execute Code` | Выполняет настоящий Python (см. [События и Действия](Sobytiya_i_Deystviya_ru)) |

## Блоки-Значения

Блоки-значения — вставляйте их в числовое поле другого блока:

| Блок | Описание |
|------|-------------|
| `X Position` | Координата X этого экземпляра |
| `Y Position` | Координата Y этого экземпляра |
| `Horizontal Speed` | Скорость X этого экземпляра |
| `Vertical Speed` | Скорость Y этого экземпляра |
| `Score` | Текущий счёт |
| `Lives` | Текущие жизни |
| `Health` | Текущее здоровье |

## Советы

1. **Начинайте с Events** — Всегда начинайте с блока Event (блок-шляпа)
2. **Соединяйте вертикально** — Блоки-складыши соединяются сверху вниз
3. **Используйте цвета** — Цвет блока обозначает его категорию
4. **Правая кнопка мыши** — Доступ к Duplicate, Delete и Help
5. **Масштаб** — Для больших программ используйте колесо мыши или кнопки масштабирования
6. **Переключайтесь на структурированную панель** — Всё, что умеет
   Blockly, соответствует действию во вкладке Events структурированной
   панели, но не наоборот (например, Jump to Start/Random Position и
   Stop Sound для отдельного звука не имеют блока в Blockly) — в таких
   случаях используйте структурированную панель вместо Blockly.
