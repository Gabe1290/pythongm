## Глобальные (Главное Окно)

| Клавиши | Действие |
|----------|--------|
| Ctrl+N | Новый Проект |
| Ctrl+O | Открыть Проект |
| Ctrl+S | Сохранить Проект |
| Ctrl+Shift+S | Сохранить Проект Как |
| Ctrl+E | Экспортировать Проект |
| Ctrl+Q | Выход |
| Ctrl+Z | Отменить |
| Ctrl+Y | Повторить |
| Ctrl+X | Вырезать |
| Ctrl+C | Копировать |
| Ctrl+V | Вставить |
| Ctrl+D | Дублировать |
| Ctrl+F | Найти |
| Ctrl+H | Найти и Заменить |
| F1 | Документация |
| F5 | Тест Игры |
| F6 | Отладка Игры |
| F7 | Собрать Игру |
| F8 | Собрать и Запустить |

## Редактор Спрайтов

| Клавиша | Инструмент |
|----------|------|
| P | Карандаш |
| E | Ластик |
| I | Пипетка |
| G | Заливка (ведро с краской) |
| L | Линия |
| R | Прямоугольник |
| O | Эллипс |
| S | Выделение |
| Ctrl+C / Ctrl+X / Ctrl+V | Копировать / Вырезать / Вставить (выделение) |
| Del | Удалить (выделение) |
| Esc | Снять выделение |

См. [[Sprite-Editor_ru|Редактор Спрайтов]], чтобы узнать, что именно делает каждый инструмент.

---

## Редактор Объектов

| Клавиши | Действие |
|----------|--------|
| Ctrl+S | Сохраняет этот объект (работает даже когда в фокусе вкладка редактора объектов, не вызывая Сохранить главного окна) |
| Ctrl+Вверх / Ctrl+Вниз | Перемещает выбранное событие вверх/вниз по списку |
| Ctrl+C / Ctrl+V | Копировать / вставить действие |

---

## Редактор Комнат

| Клавиши | Действие |
|----------|--------|
| Del | Удаляет выбранный(е) экземпляр(ы) |

Панель инструментов Редактора Комнат также предоставляет **Сетку**,
**Привязку**, **Очистить Всё** и **Сдвинуть Всё** — см.
[[Redaktor_Komnat_ru|Редактор Комнат]].
