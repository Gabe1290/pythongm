## Справочник Событий

### Событие Create
**Когда:** Один раз, когда экземпляр создан
**Использование:** Инициализация, установка переменных, запуск таймеров

### Событие Destroy
**Когда:** Когда экземпляр уничтожен
**Использование:** Очистка, создание эффектов, начисление очков

### События Step

| Событие | Когда |
|-----------|-------|
| **Шаг** | Каждый кадр (60 раз в секунду) |
| **Начало шага** | Перед проверками столкновений |
| **Конец шага** | После всех остальных событий |

### События Alarm

| Событие | Когда |
|-----------|-------|
| **Alarm[0-11]** | Когда счётчик достигает 0 |

Используйте действие `Set Alarm`, чтобы запустить отсчёт. Значения будильника измеряются в кадрах (60 = 1 секунда при 60 FPS).

### События Клавиатуры

| Событие | Когда |
|-----------|-------|
| **Keyboard [Клавиша]** | Пока клавиша удерживается (повторяется) |
| **Key Press [Клавиша]** | Один раз, когда клавиша нажата |
| **Key Release [Клавиша]** | Один раз, когда клавиша отпущена |
| **No Key** | Когда не нажата ни одна клавиша |

Доступные клавиши: буквы (A-Z), цифры (0-9), клавиши со стрелками, пробел, Enter, Shift, Ctrl, Alt, функциональные клавиши (F1-F12)

### События Мыши

| Событие | Когда |
|-----------|-------|
| **Left Button** | Клик левой кнопкой по экземпляру |
| **Right Button** | Клик правой кнопкой по экземпляру |
| **Middle Button** | Клик средней кнопкой по экземпляру |
| **Left Press** | Нажата левая кнопка (один раз) |
| **Left Release** | Отпущена левая кнопка (один раз) |
| **Mouse Enter** | Курсор входит в экземпляр |
| **Mouse Leave** | Курсор покидает экземпляр |
| **Global Left Button** | Клик левой кнопкой где угодно |
| **Global Right Button** | Клик правой кнопкой где угодно |

### События Столкновений

| Событие | Когда |
|-----------|-------|
| **Collision with [Объект]** | При контакте с указанным объектом |

Проверки столкновений происходят между событиями Step и Draw.

### Другие События

| Событие | Когда |
|-----------|-------|
| **Вне комнаты** | Экземпляр полностью за пределами комнаты |
| **Касание границы комнаты** | Экземпляр касается границы комнаты |
| **Начало игры** | Игра запускается (загружена первая комната) |
| **Конец игры** | Игра завершается |
| **Начало комнаты** | При входе в комнату |
| **Конец комнаты** | При выходе из комнаты |
| **Жизни закончились** | Жизни достигают 0 |
| **Здоровье закончилось** | Здоровье достигает 0 |
| **Конец анимации** | Анимация спрайта завершена |

### События Draw

| Событие | Когда |
|-----------|-------|
| **Рисование** | Во время фазы отрисовки |
| **Рисование интерфейса** | После отрисовки комнаты (в пространстве экрана) |

## Справочник Действий

### Действия Движения

| Действие | Описание | Параметры |
|--------|-------------|------------|
| **Задать скорость** | Устанавливает скорость движения | speed, relative |
| **Задать направление** | Устанавливает направление | direction (0-360), relative |
| **Задать горизонтальную скорость** | Устанавливает hspeed | hspeed, relative |
| **Задать вертикальную скорость** | Устанавливает vspeed | vspeed, relative |
| **Задать гравитацию** | Устанавливает гравитацию | gravity, direction |
| **Задать трение** | Устанавливает трение | friction |
| **Движение к точке** | Движение к координатам | x, y, speed |
| **Start Moving Direction** | Движение в направлении | direction, speed |
| **Перейти к позиции** | Телепорт на координаты | x, y, relative |
| **Перейти к стартовой позиции** | Вернуться на позицию создания | - |
| **Перейти в случайную позицию** | Телепорт на полностью случайную позицию (обе оси; возможность привязки к сетке) | snap_h, snap_v |
| **Отскок** | Отскочить от твёрдых объектов | precise |

### Действия Instance

| Действие | Описание | Параметры |
|--------|-------------|------------|
| **Создать экземпляр** | Создаёт новый объект | object, x, y, relative |
| **Создать движущийся экземпляр** | Создаёт со скоростью | object, x, y, speed, direction |
| **Уничтожить экземпляр** | Удаляет экземпляр | - |
| **Изменить экземпляр** | Превращает в другой объект | object, perform_events |

### Действия Таймера

| Действие | Описание | Параметры |
|--------|-------------|------------|
| **Установить будильник** | Запускает отсчёт | alarm_number, steps |
| **Пауза** | Приостанавливает выполнение | milliseconds |

### Действия Score/Lives/Health

| Действие | Описание | Параметры |
|--------|-------------|------------|
| **Задать счёт** | Меняет счёт | value, relative |
| **Задать жизни** | Меняет жизни | value, relative |
| **Задать здоровье** | Меняет здоровье | value, relative |
| **Нарисовать счёт** | Показывает счёт | x, y, caption |
| **Нарисовать жизни** | Показывает жизни как повторяющиеся изображения спрайта | x, y, sprite, scale, tiled |
| **Нарисовать полосу здоровья** | Показывает здоровье как двухцветную полосу | x1, y1, x2, y2, back_color, bar_color |

### Действия Рисования

| Действие | Описание | Параметры |
|--------|-------------|------------|
| **Нарисовать спрайт** | Рисует спрайт | sprite, x, y, subimage |
| **Нарисовать текст** | Показывает текст | x, y, text |
| **Нарисовать прямоугольник** | Рисует прямоугольник | x1, y1, x2, y2, filled |
| **Нарисовать круг** | Рисует круг | x, y, radius, filled |
| **Нарисовать линию** | Рисует линию | x1, y1, x2, y2 |
| **Задать цвет рисования** | Устанавливает цвет для следующих Draw Text/Draw Rectangle/и т. д. | color |
| **Задать цвет** | Устанавливает тон и прозрачность спрайта (не цвет рисования выше) | color, alpha |
| **Задать шрифт рисования** | Устанавливает шрифт и выравнивание для следующего рисования текста | font, halign, valign |

### Действия Комнаты

| Действие | Описание | Параметры |
|--------|-------------|------------|
| **Следующая комната** | Перейти к следующей комнате | transition |
| **Предыдущая комната** | Перейти к предыдущей комнате | transition |
| **Перезапустить комнату** | Перезапустить комнату | - |
| **Перейти в комнату** | Перейти к конкретной комнате | room, transition |
| **Если следующая комната существует** | Проверяет, существует ли следующая комната | - |
| **Если предыдущая комната существует** | Проверяет, существует ли предыдущая комната | - |

### Действия Звука

| Действие | Описание | Параметры |
|--------|-------------|------------|
| **Воспроизвести звук** | Воспроизводит звуковой эффект | sound, loop |
| **Остановить звук** | Останавливает звук | sound |
| **Проверить воспроизведение звука** | Проверяет, воспроизводится ли звук | sound |
| **Воспроизвести музыку** | Воспроизводит фоновую музыку | music, loop |
| **Остановить музыку** | Останавливает всю музыку | - |

### Действия Переменных

| Действие | Описание | Параметры |
|--------|-------------|------------|
| **Задать переменную** | Задаёт значение | variable, value, relative |
| **Проверить переменную** | Проверяет значение | variable, value, operation |
| **Нарисовать переменную** | Показывает переменную | x, y, variable |

### Действия Управления Потоком

### Прочие Действия

## Встроенные Переменные

Эти переменные доступны для всех экземпляров:

| Переменная | Описание |
|----------|-------------|
| `x` | Горизонтальная позиция |
| `y` | Вертикальная позиция |
| `xstart` | Начальная позиция x |
| `ystart` | Начальная позиция y |
| `hspeed` | Горизонтальная скорость |
| `vspeed` | Вертикальная скорость |
| `speed` | Скорость анимации спрайта (кадров в секунду) — **не** скорость движения. Встроенной переменной для "суммарной скорости" нет; вычислите её сами из `hspeed`/`vspeed`, например `(hspeed**2 + vspeed**2)**0.5` |
| `direction` | Направление движения (0-360) |
| `gravity` | Гравитация |
| `gravity_direction` | Направление гравитации |
| `friction` | Трение движения |
| `image_index` | Текущий кадр анимации |
| `image_speed` | Скорость анимации |
| `image_xscale` | Горизонтальный масштаб |
| `image_yscale` | Вертикальный масштаб |
| `image_angle` | Угол поворота |
| `visible` | Отрисовывается ли |
| `solid` | Твёрдый ли для столкновений |
| `depth` | Глубина отрисовки |
| `sprite_index` | Текущий спрайт |
| `alarm[0-11]` | Таймеры будильников |

### Глобальные Переменные

| Переменная | Описание |
|----------|-------------|
| `score` | Счёт игры |
| `lives` | Жизни игрока |
| `health` | Здоровье игрока (0-100) |
| `room` | Текущая комната |
| `room_width` | Ширина текущей комнаты |
| `room_height` | Высота текущей комнаты |
| `mouse_x` | Позиция X мыши |
| `mouse_y` | Позиция Y мыши |
