## Справочник Событий

### Событие Create
**Когда:** Один раз, когда экземпляр создан
**Использование:** Инициализация, установка переменных, запуск таймеров

### Событие Destroy
**Когда:** Когда экземпляр уничтожен
**Использование:** Очистка, создание эффектов, начисление очков

### События Step

| Событие | Когда |
|-----------|-------|
| **Step** | Каждый кадр (60 раз в секунду) |
| **Begin Step** | Перед проверками столкновений |
| **End Step** | После всех остальных событий |

### События Alarm

| Событие | Когда |
|-----------|-------|
| **Alarm[0-11]** | Когда счётчик достигает 0 |

Используйте действие `Set Alarm`, чтобы запустить отсчёт. Значения будильника измеряются в кадрах (60 = 1 секунда при 60 FPS).

### События Клавиатуры

| Событие | Когда |
|-----------|-------|
| **Keyboard [Клавиша]** | Пока клавиша удерживается (повторяется) |
| **Key Press [Клавиша]** | Один раз, когда клавиша нажата |
| **Key Release [Клавиша]** | Один раз, когда клавиша отпущена |
| **No Key** | Когда не нажата ни одна клавиша |

Доступные клавиши: буквы (A-Z), цифры (0-9), клавиши со стрелками, пробел, Enter, Shift, Ctrl, Alt, функциональные клавиши (F1-F12)

### События Мыши

| Событие | Когда |
|-----------|-------|
| **Left Button** | Клик левой кнопкой по экземпляру |
| **Right Button** | Клик правой кнопкой по экземпляру |
| **Middle Button** | Клик средней кнопкой по экземпляру |
| **Left Press** | Нажата левая кнопка (один раз) |
| **Left Release** | Отпущена левая кнопка (один раз) |
| **Mouse Enter** | Курсор входит в экземпляр |
| **Mouse Leave** | Курсор покидает экземпляр |
| **Global Left Button** | Клик левой кнопкой где угодно |
| **Global Right Button** | Клик правой кнопкой где угодно |

### События Столкновений

| Событие | Когда |
|-----------|-------|
| **Collision with [Объект]** | При контакте с указанным объектом |

Проверки столкновений происходят между событиями Step и Draw.

### Другие События

| Событие | Когда |
|-----------|-------|
| **Outside Room** | Экземпляр полностью за пределами комнаты |
| **Intersect Boundary** | Экземпляр касается границы комнаты |
| **Game Start** | Игра запускается (загружена первая комната) |
| **Game End** | Игра завершается |
| **Room Start** | При входе в комнату |
| **Room End** | При выходе из комнаты |
| **No More Lives** | Жизни достигают 0 |
| **No More Health** | Здоровье достигает 0 |
| **Animation End** | Анимация спрайта завершена |

### События Draw

| Событие | Когда |
|-----------|-------|
| **Draw** | Во время фазы отрисовки |
| **Draw GUI** | После отрисовки комнаты (в пространстве экрана) |

## Справочник Действий

### Действия Движения

| Действие | Описание | Параметры |
|--------|-------------|------------|
| **Set Speed** | Устанавливает скорость движения | speed, relative |
| **Set Direction** | Устанавливает направление | direction (0-360), relative |
| **Set Horizontal Speed** | Устанавливает hspeed | hspeed, relative |
| **Set Vertical Speed** | Устанавливает vspeed | vspeed, relative |
| **Set Gravity** | Устанавливает гравитацию | gravity, direction |
| **Set Friction** | Устанавливает трение | friction |
| **Move Towards Point** | Движение к координатам | x, y, speed |
| **Start Moving Direction** | Движение в направлении | direction, speed |
| **Jump To Position** | Телепорт на координаты | x, y, relative |
| **Jump to Start Position** | Вернуться на позицию создания | - |
| **Jump to Random Position** | Телепорт на полностью случайную позицию (обе оси; возможность привязки к сетке) | snap_h, snap_v |
| **Bounce** | Отскочить от твёрдых объектов | precise |

### Действия Instance

| Действие | Описание | Параметры |
|--------|-------------|------------|
| **Create Instance** | Создаёт новый объект | object, x, y, relative |
| **Create Moving Instance** | Создаёт со скоростью | object, x, y, speed, direction |
| **Destroy Instance** | Удаляет экземпляр | - |
| **Change Instance** | Превращает в другой объект | object, perform_events |

### Действия Таймера

| Действие | Описание | Параметры |
|--------|-------------|------------|
| **Set Alarm** | Запускает отсчёт | alarm_number, steps |
| **Sleep** | Приостанавливает выполнение | milliseconds |

### Действия Score/Lives/Health

| Действие | Описание | Параметры |
|--------|-------------|------------|
| **Set Score** | Меняет счёт | value, relative |
| **Set Lives** | Меняет жизни | value, relative |
| **Set Health** | Меняет здоровье | value, relative |
| **Draw Score** | Показывает счёт | x, y, caption |
| **Draw Lives** | Показывает жизни как повторяющиеся изображения спрайта | x, y, sprite, scale, tiled |
| **Draw Health Bar** | Показывает здоровье как двухцветную полосу | x1, y1, x2, y2, back_color, bar_color |

### Действия Рисования

| Действие | Описание | Параметры |
|--------|-------------|------------|
| **Draw Sprite** | Рисует спрайт | sprite, x, y, subimage |
| **Draw Text** | Показывает текст | x, y, text |
| **Draw Rectangle** | Рисует прямоугольник | x1, y1, x2, y2, filled |
| **Draw Circle** | Рисует круг | x, y, radius, filled |
| **Draw Line** | Рисует линию | x1, y1, x2, y2 |
| **Set Draw Color** | Устанавливает цвет для следующих Draw Text/Draw Rectangle/и т. д. | color |
| **Set Color** | Устанавливает тон и прозрачность спрайта (не цвет рисования выше) | color, alpha |
| **Set Draw Font** | Устанавливает шрифт и выравнивание для следующего рисования текста | font, halign, valign |

### Действия Комнаты

| Действие | Описание | Параметры |
|--------|-------------|------------|
| **Next Room** | Перейти к следующей комнате | transition |
| **Previous Room** | Перейти к предыдущей комнате | transition |
| **Restart Room** | Перезапустить комнату | - |
| **Go to Room** | Перейти к конкретной комнате | room, transition |
| **If Next Room Exists** | Проверяет, существует ли следующая комната | - |
| **If Previous Room Exists** | Проверяет, существует ли предыдущая комната | - |

### Действия Звука

| Действие | Описание | Параметры |
|--------|-------------|------------|
| **Play Sound** | Воспроизводит звуковой эффект | sound, loop |
| **Stop Sound** | Останавливает звук | sound |
| **Check Sound Playing** | Проверяет, воспроизводится ли звук | sound |
| **Play Music** | Воспроизводит фоновую музыку | music, loop |
| **Stop Music** | Останавливает всю музыку | - |

### Действия Переменных

| Действие | Описание | Параметры |
|--------|-------------|------------|
| **Set Variable** | Задаёт значение | variable, value, relative |
| **Test Variable** | Проверяет значение | variable, value, operation |
| **Draw Variable** | Показывает переменную | x, y, variable |

### Действия Управления Потоком

| Действие | Описание | Параметры |
|--------|-------------|------------|
| **Test Expression** | Условная проверка (логическое выражение Python) | expression |
| **Else** | Альтернативная ветка | - |
| **Start Block** | Начинает группу действий | - |
| **End Block** | Завершает группу действий | - |
| **Repeat** | Повторяет N раз | count |
| **Exit Event** | Останавливает текущее событие | - |

### Прочие Действия

| Действие | Описание | Параметры |
|--------|-------------|------------|
| **Show Message** | Показывает всплывающее сообщение | message |
| **Restart Game** | Перезапускает игру | - |
| **End Game** | Закрывает игру | - |

## Встроенные Переменные

Эти переменные доступны для всех экземпляров:

| Переменная | Описание |
|----------|-------------|
| `x` | Горизонтальная позиция |
| `y` | Вертикальная позиция |
| `xstart` | Начальная позиция x |
| `ystart` | Начальная позиция y |
| `hspeed` | Горизонтальная скорость |
| `vspeed` | Вертикальная скорость |
| `speed` | Скорость анимации спрайта (кадров в секунду) — **не** скорость движения. Встроенной переменной для "суммарной скорости" нет; вычислите её сами из `hspeed`/`vspeed`, например `(hspeed**2 + vspeed**2)**0.5` |
| `direction` | Направление движения (0-360) |
| `gravity` | Гравитация |
| `gravity_direction` | Направление гравитации |
| `friction` | Трение движения |
| `image_index` | Текущий кадр анимации |
| `image_speed` | Скорость анимации |
| `image_xscale` | Горизонтальный масштаб |
| `image_yscale` | Вертикальный масштаб |
| `image_angle` | Угол поворота |
| `visible` | Отрисовывается ли |
| `solid` | Твёрдый ли для столкновений |
| `depth` | Глубина отрисовки |
| `sprite_index` | Текущий спрайт |
| `alarm[0-11]` | Таймеры будильников |

### Глобальные Переменные

| Переменная | Описание |
|----------|-------------|
| `score` | Счёт игры |
| `lives` | Жизни игрока |
| `health` | Здоровье игрока (0-100) |
| `room` | Текущая комната |
| `room_width` | Ширина текущей комнаты |
| `room_height` | Высота текущей комнаты |
| `mouse_x` | Позиция X мыши |
| `mouse_y` | Позиция Y мыши |
