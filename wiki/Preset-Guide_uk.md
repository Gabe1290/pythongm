# Посібник з Пресетів

*[Українська](Preset-Guide_uk) | [Повернутися на Головну](Home_uk)*

PyGameMaker пропонує різні пресети, які контролюють, які події та дії
доступні — **як** у візуальній палітрі блоків Blockly, так і в
структурованій панелі Events/Actions ("Add Event"/"Add Action"), яку
використовує кожен посібник у цій вікі. Це допомагає початківцям
зосередитися на основних функціях, дозволяючи досвідченим користувачам
отримати доступ до повного набору інструментів.

Пресет проєкту визначається двома способами:
**`Preferences > IDE Edition`** обирає стандартний пресет для *нових*
проєктів (наявні проєкти ніколи не змінюються при зміні редакції), а
**`Tools > Configure Action Blocks...`** будь-коли змінює пресет
*поточно відкритого* проєкту. Стандартна редакція IDE — Beginner
(Початківець), тож нові проєкти чистої установки вже стартують із
пресетом для початківців.

## Оберіть Свій Рівень

| IDE Edition | Підходить Для | Використаний пресет |
|----------------|-------------|----------|
| **Beginner** (Початківець, за замовчуванням) | Нові користувачі | [Пресет для Початківців](Beginner-Preset_uk) — базовий рух, зіткнення, рахунок, кімнати |
| **Advanced** (Просунутий) | Деякий досвід | [Середній пресет](Intermediate-Preset_uk) — + життя, здоров'я, звук, будильники, рух по сітці |
| **Development** (Розробка) | Досвідчені користувачі | Пресет `full` — усі події та дії доступні |

Зверніть увагу, що назви не збігаються 1:1: редакція "Advanced"
використовує пресет `intermediate` (окремого пресету "advanced" не
існує) — точні та завжди актуальні кількості подій і дій кожного
дивіться на сторінках [Пресет для Початківців](Beginner-Preset_uk)/
[Середній пресет](Intermediate-Preset_uk).

## Приклад Швидкого Старту

Ось проста гра збору монет з використанням лише функцій для Початківців:

### 1. Створіть Об'єкти
- `obj_player` — Керований персонаж
- `obj_coin` — Колекційні предмети
- `obj_wall` — Тверді перешкоди

### 2. Додайте Події до Гравця

**Keyboard (Arrow Keys):**
```
Left Arrow  → Set Horizontal Speed: -4
Right Arrow → Set Horizontal Speed: 4
Up Arrow    → Set Vertical Speed: -4
Down Arrow  → Set Vertical Speed: 4
```

**Collision with obj_coin:**
```
Add Score: 10
Destroy Instance: other
```

**Collision with obj_wall:**
```
Stop Movement
```

### 3. Створіть Кімнату
- Розмістіть гравця
- Додайте кілька монет
- Додайте стіни навколо країв

### 4. Запустіть Гру!
Натисніть кнопку Play, щоб протестувати вашу гру.

## Поради для Успіху

1. **Починайте Просто** — Спочатку використовуйте пресет для Початківців
2. **Тестуйте Часто** — Часто запускайте гру, щоб виявляти проблеми
3. **Одна Річ за Раз** — Додавайте функції поступово
4. **Використовуйте Зіткнення** — Більшість ігрових механік включає події зіткнень
5. **Читайте Документацію** — Перевіряйте довідкові сторінки, коли застрягли
