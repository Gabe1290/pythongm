## Вступ

У цьому посібнику ви створите **Гру Місячний Посадковий Модуль** — класичну аркадну гру, де ви керуєте космічним кораблем, що спускається на посадкову платформу. Ви повинні керувати тягою, щоб протидіяти гравітації та м'яко приземлитися без аварії. Ця гра ідеально підходить для вивчення фізичних концепцій, таких як гравітація, тяга, швидкість та управління паливом.

**Що ви навчитесь:**
- Фізика гравітації та тяги
- Виявлення посадки на основі швидкості
- Система управління паливом
- Контроль обертання або напрямку
- Безпечні зони посадки

**Складність:** Початківець
**Пресет:** Середній пресет (фізика тяги/палива повністю базується на
Execute Code, яка не входить до пресету для початківців)

## Крок 1: Зрозуміти Гру

### Механіки Гри
1. Модуль притягується вниз гравітацією
2. Натискання ВГОРУ застосовує тягу вгору (використовує паливо)
3. ВЛІВО/ВПРАВО керує обертанням або рухом
4. Приземліться м'яко на платформу, щоб виграти
5. Аварія, якщо приземлитесь занадто швидко або промахнетесь
6. Без палива ви не можете сповільнитись!

### Що Нам Потрібно

| Елемент | Призначення |
|---------|-------------|
| **Модуль** | Корабель, яким ви керуєте |
| **Платформа** | Безпечна зона для посадки |
| **Земля** | Місцевість, що спричиняє аварію |
| **Дисплей Палива** | Показує залишок палива |
| **Дисплей Швидкості** | Показує поточну швидкість |

## Крок 5: Створити Об'єкт Модуля

Модуль — головний об'єкт, яким керує гравець. На відміну від інших
посібників з рухом у цій вікі, його керування має поступово
накопичувати швидкість і стежити за запасом палива, тож цей об'єкт
більше спирається на **Control** → **Execute Code** (справжній Python
— `self` — поточний екземпляр, `game` — виконавець гри,
`keyboard.check(name)` повідомляє, чи утримується клавіша), ніж
попередні посібники з рухом, але все ще використовує структуровану
дію, де це можливо.

### 5.1 Гравітація Та Початкові Змінні

**Подія: Create**
1. Дія: **Move** → **Set Gravity** (Direction: `270`, Gravity: `0.05`)
   — легке тяжіння вниз; рушій автоматично додає його до вертикальної
   швидкості модуля щокадру, так само як у посібнику з платформера,
   лише слабше.
2. Дія: **Control** → **Execute Code**:

```python
self.thrust_force = 0.1
self.max_speed = 5
self.fuel = 100
self.fuel_use = 0.5
self.landed = False
self.crashed = False
self.safe_speed = 2
```

Система руху цього рушія вже стежить за швидкістю через
`self.hspeed`/`self.vspeed` і переміщує екземпляр на цю величину
щокадру (з вбудованим твердим зіткненням) — не потрібно створювати
окремі змінні `hsp`/`vsp`, як це робила б ручна фізична симуляція.

### 5.2 Подія Step — Тяга Та Керування

**Подія: Step** — Дія: **Control** → **Execute Code**:

```python
if not self.landed and not self.crashed:
    if keyboard.check('up') and self.fuel > 0:
        self.vspeed -= self.thrust_force
        self.fuel -= self.fuel_use
        if self.fuel < 0:
            self.fuel = 0

    if keyboard.check('left'):
        self.hspeed -= 0.05
    if keyboard.check('right'):
        self.hspeed += 0.05

    # Обмежити максимальну швидкість
    self.hspeed = max(-self.max_speed, min(self.max_speed, self.hspeed))
    self.vspeed = max(-self.max_speed, min(self.max_speed, self.vspeed))

    # Не дати модулю вислизнути за краї або над кімнатою
    room = game.current_room
    if self.x < 16:
        self.x = 16
        self.hspeed = 0
    if self.x > room.width - 16:
        self.x = room.width - 16
        self.hspeed = 0
    if self.y < 16:
        self.y = 16
        self.vspeed = 0
```

Весь блок знаходиться всередині `if not self.landed and not
self.crashed:`, тож тяга та керування зупиняються, щойно гра
закінчується — об'єкт не має способу перервати подію посередині (тут
немає `exit`, як у GML); `if` навколо решти коду виконує те саме
завдання.

### 5.3 Зіткнення З Платформою

**Подія: Collision with obj_pad**
1. Дія: **Control** → **Test Expression**
   - Expression: `(self.hspeed**2 + self.vspeed**2)**0.5 <=
     self.safe_speed` — швидкість посадки — це довжина вектора
     швидкості (теорема Піфагора), а не змінна `speed` (у цьому рушії
     `speed` — це *швидкість анімації* спрайта, а не величина руху —
     справжня пастка для тих, хто прийшов із GameMaker).
   - Then Actions:
     1. **Control** → **Set Variable** (Variable: `landed`, Value: `true`, Scope: `self`)
     2. **Move** → **Stop Movement**
     3. **Move** → **Set Gravity** (Direction: `270`, Gravity: `0`) —
        запобігає тому, щоб гравітація тихо знову накопичувала
        вертикальну швидкість у вже приземленого модуля
     4. **Output** → **Show Message** (Message: `Ідеальна Посадка! Ви Виграли!`)
   - Else Actions:
     1. **Control** → **Set Variable** (Variable: `crashed`, Value: `true`, Scope: `self`)
     2. **Output** → **Show Message** (Message: `Аварія! Занадто швидко!`)
     3. **Room** → **Restart Room**

Текст Show Message — фіксований рядок, він не може показати реальну
швидкість посадки. HUD (Крок 7) уже показує живу швидкість аж до
моменту зіткнення, тож гравець уже бачив це число.

### 5.4 Зіткнення Із Землею

**Подія: Collision with obj_ground**
1. Дія: **Control** → **Set Variable** (Variable: `crashed`, Value: `true`, Scope: `self`)
2. Дія: **Output** → **Show Message** (Message: `Аварія на місцевості!`)
3. Дія: **Room** → **Restart Room**
