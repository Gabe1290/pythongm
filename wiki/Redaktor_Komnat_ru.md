Комнаты — это уровни, экраны или сцены вашей игры. Редактор Комнат
позволяет проектировать эти пространства, размещая объекты и настраивая фоны.

---

## Открытие Редактора Комнат

1. Дважды кликните на существующей комнате в дереве ресурсов, или
2. Кликните правой кнопкой на **Rooms** > **Create Room**

![Редактор Комнат: палитра объектов слева для выбора того, что
размещать, область комнаты в центре с заполненным уровнем платформера

## Свойства Комнаты

| Свойство | Описание |
|-----------|-------------|
| **Name** | Уникальный идентификатор (напр. `room_level1`) |
| **Width** | Ширина комнаты в пикселях |
| **Height** | Высота комнаты в пикселях |
| **Speed** | Скорость игры в кадрах в секунду (по умолчанию: 60) |
| **Persistent** | Сохраняет состояние комнаты при выходе/повторном входе |

### Соглашение об Именовании

Используйте префикс `room_` для комнат:
- `room_menu`
- `room_level1`
- `room_game_over`

## Размещение Объектов

### Добавление Экземпляров

1. Выберите объект в панели **Objects**
2. Кликните в виде комнаты, чтобы разместить экземпляр
3. Кликните и перетаскивайте, чтобы разместить несколько экземпляров

### Выбор Экземпляров

- Кликните на экземпляре, чтобы выбрать его
- Удерживайте **Ctrl** и кликайте, чтобы выбрать несколько
- Нарисуйте прямоугольник, чтобы выбрать все экземпляры внутри него

### Перемещение Экземпляров

- Перетаскивайте выбранные экземпляры мышью
- Используйте клавиши со стрелками для точного перемещения

### Удаление Экземпляров

- Выберите экземпляры и нажмите **Delete**, или
- Кликните правой кнопкой и выберите "Удалить"

## Настройки Сетки

Включите сетку для точного размещения:

1. Перейдите к **View > Show Grid**
2. Установите размер сетки (напр. 32x32)
3. Включите "Snap to Grid"

Распространённые размеры сетки:
- **16x16** — Маленькие плитки
- **32x32** — Стандартные плитки
- **64x64** — Большие плитки

## Фоны

### Настройка Фона

1. Кликните на вкладку **Backgrounds**
2. Выберите ресурс фона
3. Настройте параметры отображения

### Параметры Фона

| Параметр | Описание |
|--------|-------------|
| **Visible** | Показывает/скрывает фон |
| **Foreground** | Рисует перед объектами |
| **Tile Horizontal** | Повторяет по горизонтали |
| **Tile Vertical** | Повторяет по вертикали |
| **Stretch** | Растягивает, чтобы заполнить комнату |
| **Horizontal Speed** | Скорость прокрутки (параллакс) |
| **Vertical Speed** | Скорость прокрутки (параллакс) |

### Слои Фона

Комната поддерживает до **8 слоёв фона**, каждый со своей скоростью
прокрутки для эффектов параллакса. Пример расположения:
- Слой 0: Небо (самое дальнее на фоне)
- Слой 1: Горы (медленнее прокрутка)
- Слой 2: Деревья (средняя прокрутка)
- Слой 3: Земля (без прокрутки)

## Views (Камера)

Views контролируют, какая часть комнаты видна на экране. Для комнаты
можно настроить до **8 views** (View 0 до View 7) — View 0 виден по
умолчанию; дополнительные views включайте для разделённого экрана или
"картинки в картинке".

### Включение Views

1. Выберите "Enable Views" в свойствах комнаты
2. Настройте View 0 (главный view)

### Свойства Views

| Свойство | Описание |
|-----------|-------------|
| **View X/Y** | Верхний левый угол view в комнате |
| **View Width/Height** | Размер видимой области |
| **Port X/Y** | Позиция на экране |
| **Port Width/Height** | Размер на экране (может растягиваться) |
| **Object Following** | Объект, за которым следует view |
| **Border H/V** | Мёртвая зона, прежде чем камера начнёт двигаться |

### Слежение За Объектом

Чтобы камера следила за игроком:
1. Установите "Object Following" на `obj_player`
2. Настройте "Border H" и "Border V" для плавной прокрутки

## Порядок Комнат

Порядок комнат в дереве ресурсов определяет:
1. Какая комната загружается первой (комната сверху = начальная комната)
2. Порядок для действий "Next Room" и "Previous Room"

### Изменение Порядка Комнат

- Перетаскивайте комнаты в дереве ресурсов, чтобы изменить их порядок
- Или кликните правой кнопкой и используйте "Переместить Вверх" / "Переместить Вниз"

## Советы И Лучшие Практики

### Организация
- Давайте комнатам понятные названия в соответствии с их назначением
- Держите главное меню как первую комнату
- Используйте согласованные размеры комнат в игре

### Производительность
- Не размещайте слишком много экземпляров в одной комнате
- Для статичной геометрии уровней используйте плитки
- Когда возможно, уничтожайте экземпляры за пределами экрана
