### Game Start
| Свойство | Значение |
|----------|----------|
| **Имя** | `game_start` |
| **Иконка** | 🎮 |
| **Категория** | Игра |
| **Пресет** | Начинающий |

**Описание:** Срабатывает один раз при первом запуске игры (только в первой комнате).

**Типичные использования:**
- Инициализация глобальных переменных
- Загрузка сохранённых данных
- Воспроизведение вступления

---

### Game End
| Свойство | Значение |
|----------|----------|
| **Имя** | `game_end` |
| **Иконка** | 🎮 |
| **Категория** | Игра |
| **Пресет** | Начинающий |

**Описание:** Срабатывает, когда игра завершается.

**Типичные использования:**
- Сохранение данных игры
- Освобождение ресурсов
