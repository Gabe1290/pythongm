PyGameMaker включає Google Blockly для візуального програмування методом перетягування. Ви будуєте ігрову логіку, з'єднуючи блоки, замість написання коду.

---

## Доступ до Blockly

1. Відкрийте об'єкт у Object Editor
2. Клацніть на вкладку **Blockly** (поруч із вкладкою Events)
3. З'явиться робоча область Blockly з панеллю інструментів зліва

**Які блоки видно, залежить від вашого пресету.**
`Tools > Configure Action Blocks...` (або `Preferences > IDE Edition`,
яка визначає стандартний пресет для нових проєктів) контролює набір
блоків — деталі див. у [Посібнику з Пресетів](Preset-Guide_uk). Таблиці
нижче перелічують усі блоки, що існують у будь-якому пресеті; конкретний
проєкт може показувати менше.

## Робоча Область Blockly

### Панель Інструментів
Лівий панель містить категорії блоків:
- **Events** — Блоки-тригери подій
- **Control** — Умови, змінні та групування (умовні блоки цього проєкту
  — це складальні блоки, а не класичні контейнери If/Else — див. "Типи
  Блоків" нижче)
- **Movement** — Блоки руху, швидкості та фізики
- **Timing** — Будильники
- **Drawing** — Блоки тексту та фігур
- **Score/Lives/Health** — Блоки стану гри
- **Instance** — Створення/знищення об'єктів
- **Room** — Навігація між кімнатами
- **Values** — Блоки значень (позиція, швидкість, рахунок, життя,
  здоров'я, миша)
- **Sound** — Відтворення звуку
- **Output** — Повідомлення та власний Python-код
- **Game** — Завершити/перезапустити гру, таблиця рекордів

Окремої категорії Math, Text або Logic немає — числові/текстові поля
заповнюються прямо на самому блоці, так само немає загального
логічного/порівняльного блока-значення. Див. "Типи Блоків" нижче, як
натомість працюють умови.

### Робоча Поверхня
Центральна область, де ви будуєте свою програму:
- Перетягуючи блоки з панелі інструментів
- З'єднуючи блоки між собою
- Налаштовуючи параметри блоків

### Кошик
Перетягніть непотрібні блоки сюди, щоб видалити їх, або натисніть клавішу Delete.

## Типи Блоків

### Блоки-Капелюхи (Events)
Блоки-капелюхи мають закруглений верх і починають послідовність. Вони представляють події:

```
┌─────────────────┐
│ When Create     │
└─────────────────┘
```

### Складальні Блоки (Дії)
Складальні блоки мають виступи, які з'єднуються з іншими блоками.
Майже всі блоки поза категорією Values — складальні блоки, включно з
умовними:

```
├─────────────────┤
│ Set Horizontal Speed [5] │
├─────────────────┤
```

### Блоки-Значення (Values)
Блоки-значення заокруглені і вставляються в числове поле іншого блока
(наприклад, поле швидкості Move Direction або поле значення Set
Variable). У цьому проєкті їх 9 — X Position, Y Position, Horizontal
Speed, Vertical Speed, Score, Lives, Health, Mouse X, Mouse Y:

```
( X Position )    ( Score )    ( 100 )
```

Загального блока-значення `( speed )` чи `( direction )` немає — цей
рушій не відстежує ці поняття як єдине значення (швидкість/напрямок
руху виводяться разом з Horizontal Speed + Vertical Speed), так само
немає блока-значення для власних змінних (замість цього зчитуйте їх
через порівняння Test Variable).

### Умови — складальні блоки, а не C-подібні контейнери
На відміну від візуальних мов у стилі Scratch, блоки If Condition /
Test Variable цього проєкту — це **складальні блоки з одним слотом
"then"**, а не двосторонні контейнери If/Else, і немає шестикутного
логічного блока для вставки — порівняння будується прямо через поля
на самому блоці:

```
┌───────────────────────────────────┐
│ If count of [obj_coin] [==] [0]   │
├───────────────────────────────────┤
│  then [дії тут]                   │
└───────────────────────────────────┘
```

Щоб додати гілку "else" або виконати кілька дій з одного боку,
поєднайте його ще з трьома блоками Control:
- **Else** — виконує свій наступний блок лише якщо попередній тест був хибним
- **Start Block** / **End Block** — групують кілька дій, щоб
  попередній тест (або Else) діяв на всю групу, а не лише на наступний блок

Це той самий плоский, у стилі GM80, потік умов, який використовує
структурована панель Events/Actions (див. [Події та
Дії](Podii_ta_Dii_uk)) — Blockly — це інтерфейс перетягування над тим
самим базовим списком дій, а не окрема модель виконання.

## Блоки Подій

### Подія Create
```
┌─────────────────────┐
│ When Create         │
├─────────────────────┤
│ [дії тут]            │
└─────────────────────┘
```

### Подія Step
```
┌─────────────────────┐
│ When Step            │
├─────────────────────┤
│ [щокадру]             │
└─────────────────────┘
```

### Події Клавіатури
Існує чотири окремі блоки-капелюхи для клавіатури — Held, Press,
Release і No Key — кожен із випадним меню назви клавіші (No Key його
не має, бо спрацьовує, коли нічого не натиснуто):
```
┌─────────────────────────┐
│ When key [held: left] ▼ │
├─────────────────────────┤
│ [дії тут]                │
└─────────────────────────┘
```

### Події Зіткнень
```
┌────────────────────────────┐
│ When colliding with [obj] ▼│
├────────────────────────────┤
│ [дії тут]                   │
└────────────────────────────┘
```

## Блоки Руху

| Блок | Опис |
|------|-------------|
| `Set Horizontal Speed [4]` | Встановлює швидкість X |
| `Set Vertical Speed [-5]` | Встановлює швидкість Y |
| `Stop Movement` | Скидає обидві швидкості |
| `Move [direction ▼] speed [3]` | Рух в одному з 4 напрямків (або по діагоналі, або "stop") |
| `Move Free [direction] [speed]` | Рух під довільним кутом і швидкістю |
| `Set Speed [5]` | Встановлює величину швидкості, зберігаючи поточний напрямок |
| `Set Direction [90]` | Встановлює кут напрямку, зберігаючи поточну швидкість |
| `Move Towards x:[100] y:[200] speed:[3]` | Рух до точки |
| `Snap to Grid` | Вирівнює позицію по сітці |
| `Jump to Position x:[100] y:[200]` | Миттєвий телепорт |
| `Move Grid [direction]` | Рух точно на одну клітинку сітки |
| `Stop if No Keys` / `Check Keys and Move` / `If On Grid` | Допоміжні блоки для руху по сітці |
| `Set Gravity` | Застосовує сталу силу щокадру (вниз або в будь-якому напрямку) |
| `Set Friction` | Зменшує швидкість щокадру |
| `Reverse Horizontal` / `Reverse Vertical` | Обертає напрямок X або Y |
| `Bounce` | Відскакує від твердих об'єктів |
| `Wrap Around Room` | З'являється знову з протилежного боку |
| `Move to Contact` | Рух до контакту з чимось |

Блока "Jump to Start Position" чи "Jump to Random Position" немає — ці
дві дії існують лише в структурованій панелі, не в Blockly.

## Блоки Малювання

| Блок | Опис |
|------|-------------|
| `Draw Text [Hello] at x:[10] y:[10]` | Показує текст |
| `Draw Rectangle from x1,y1 to x2,y2` | Малює заповнений прямокутник |
| `Draw Circle at x,y radius [r]` | Малює заповнене коло |
| `Set Sprite [spr]` | Змінює спрайт екземпляра |
| `Set Transparency [0-1]` | Встановлює альфа-канал |

Блока "Draw Sprite at Position" чи "Set Drawing Color" в Blockly немає
(обидва існують лише в структурованій панелі). Draw Score/Draw
Lives/Draw Health Bar перелічені нижче під Score/Lives/Health, не тут.

## Блоки Score/Lives/Health

| Блок | Опис |
|------|-------------|
| `Set Score [100]` | Точно встановлює рахунок |
| `Add to Score [10]` | Збільшує/зменшує рахунок |
| `Set Lives [3]` | Точно встановлює життя |
| `Add to Lives [-1]` | Збільшує/зменшує життя |
| `Set Health [100]` | Точно встановлює здоров'я |
| `Add to Health [-25]` | Збільшує/зменшує здоров'я |
| `Draw Score` | Показує текст рахунку |
| `Draw Lives` | Показує життя як повторювані іконки |
| `Draw Health Bar` | Показує здоров'я як двоколірну смугу |

## Блоки Instance

| Блок | Опис |
|------|-------------|
| `Create Instance [obj] at x:[100] y:[200]` | Створює новий екземпляр |
| `Destroy Instance` | Видаляє самого себе |
| `Destroy Other` | Видаляє екземпляр у зіткненні (в події Collision) |
| `Change Instance [obj]` | Перетворюється на інший тип об'єкта |
| `If Can Push [obj] [direction]` | Перевірка штовхання у стилі Sokoban |

Блока "знищити всі одного типу" чи "створити на цій позиції" немає.

## Блоки Кімнати

| Блок | Опис |
|------|-------------|
| `Next Room` | Перейти до наступної кімнати |
| `Previous Room` | Повернутися до попередньої кімнати |
| `Restart Room` | Перезапустити поточну кімнату |
| `Go to Room [room_name]` | Перейти до конкретної кімнати |
| `If Next Room Exists` / `If Previous Room Exists` | Захищають навігацію між кількома кімнатами |

## Блоки Звуку

| Блок | Опис |
|------|-------------|
| `Play Sound [snd]` | Відтворює звуковий ефект |
| `Play Music [music]` | Відтворює фонову музику (циклічно) |
| `Stop Music` | Зупиняє музику |

Блока "Stop Sound" (для окремого звуку) чи "Зупинити всі звуки" в
Blockly немає (лише Stop Music, яка зупиняє тільки музику).

---

## Блоки Control

| Блок | Опис |
|------|-------------|
| `If count of [obj] [==] [0] then...` | Порівнює кількість екземплярів об'єкта; виконує наступний(і) блок(и), якщо істинно |
| `If variable [var] [==] [value] then...` | Порівнює власну змінну; виконує наступний(і) блок(и), якщо істинно |
| `Set Variable [name] to [value]` | Задає змінну екземпляра або глобальну |
| `Check Empty at x,y` | Істинно, якщо в позиції немає зіткнення (рух по сітці) |
| `Exit Event` | Зупиняє решту дій цієї події |
| `Else` | Виконує свій наступний блок, якщо попередній тест був хибним |
| `Start Block` / `End Block` | Групують кілька дій під Test/Else |

## Поради

1. **Починайте з Events** — Завжди починайте з блока Event (блок-капелюх)
2. **З'єднуйте вертикально** — Складальні блоки з'єднуються згори донизу
3. **Використовуйте кольори** — Колір блоку позначає його категорію
4. **Права кнопка миші** — Доступ до Duplicate, Delete та Help
5. **Масштаб** — Для великих програм використовуйте колесо миші або кнопки масштабування
6. **Перемикайтеся на структуровану панель** — Усе, що вміє Blockly,
   відповідає дії у вкладці Events структурованої панелі, але не
   навпаки (наприклад, Jump to Start/Random Position та Stop Sound для
   окремого звуку не мають блока в Blockly) — у таких випадках
   використовуйте структуровану панель замість Blockly.
