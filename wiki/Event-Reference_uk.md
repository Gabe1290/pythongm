## Події Об'єкта

### Create
| Властивість | Значення |
|-------------|----------|
| **Назва** | `create` |
| **Іконка** | 🎯 |
| **Категорія** | Об'єкт |
| **Пресет** | Початківець |

**Опис:** Виконується один раз при першому створенні екземпляра.

**Коли спрацьовує:**
- Коли екземпляр розміщується в кімнаті на старті гри
- При створенні через дію "Create Instance"
- Після переходів кімнати для нових екземплярів

**Типові використання:**
- Ініціалізація змінних
- Встановлення початкових значень
- Налаштування початкового стану

---

### Step
| Властивість | Значення |
|-------------|----------|
| **Назва** | `step` |
| **Іконка** | ⭐ |
| **Категорія** | Об'єкт |
| **Пресет** | Початківець |

**Опис:** Виконується кожен кадр (зазвичай 60 разів на секунду).

**Коли спрацьовує:** Постійно, кожен ігровий кадр.

**Типові використання:**
- Безперервний рух
- Перевірка умов
- Оновлення позицій
- Ігрова логіка

**Примітка:** Будьте обережні з продуктивністю — код тут виконується постійно.

---

### Destroy
| Властивість | Значення |
|-------------|----------|
| **Назва** | `destroy` |
| **Іконка** | 💥 |
| **Категорія** | Об'єкт |
| **Пресет** | Середній |

**Опис:** Виконується, коли екземпляр знищується.

**Коли спрацьовує:** Безпосередньо перед видаленням екземпляра з гри.

**Типові використання:**
- Створення ефектів (вибухи, частинки)
- Випадання предметів
- Оновлення рахунку
- Відтворення звуків

## Події Введення

### Keyboard (Безперервна)
| Властивість | Значення |
|-------------|----------|
| **Назва** | `keyboard` |
| **Іконка** | ⌨️ |
| **Категорія** | Введення |
| **Пресет** | Початківець |

**Опис:** Спрацьовує безперервно, поки клавіша утримується.

**Найкраще для:** Плавного, безперервного руху

**Підтримувані Клавіші:**
- Клавіші зі стрілками (вгору, вниз, вліво, вправо)
- Літери (A-Z)
- Цифри (0-9)
- Пробіл, Enter, Escape
- Функціональні клавіші (F1-F12)
- Модифікатори (Shift, Ctrl, Alt)

### Keyboard (No Key)

## Події Зіткнення

### Collision
| Властивість | Значення |
|-------------|----------|
| **Назва** | `collision` |
| **Іконка** | 💥 |
| **Категорія** | Зіткнення |
| **Пресет** | Початківець |

**Опис:** Спрацьовує, коли цей екземпляр перекривається з іншим типом об'єкта.

**Налаштування:** Виберіть, який тип об'єкта викликає це зіткнення.

**Спеціальна змінна:** `other` — Посилання на екземпляр, що зіткнувся.

**Коли спрацьовує:** Кожен кадр, поки екземпляри перекриваються.

**Типові використання:**
- Збір предметів
- Отримання пошкоджень
- Удари об стіни
- Запуск подій

**Приклади подій зіткнення:**
- `collision_with_obj_coin` — Гравець торкається монети
- `collision_with_obj_enemy` — Гравець торкається ворога
- `collision_with_obj_wall` — Екземпляр вдаряється об стіну

## Події Малювання

### Draw
| Властивість | Значення |
|-------------|----------|
| **Назва** | `draw` |
| **Іконка** | 🎨 |
| **Категорія** | Малювання |
| **Пресет** | Початківець |

**Опис:** Спрацьовує під час фази рендерингу.

**Важливо:** Додавання події Draw вимикає автоматичне малювання спрайту. Ви повинні малювати спрайт вручну, якщо хочете, щоб він був видимим.

**Типові використання:**
- Користувацький рендеринг
- Малювання фігур
- Відображення тексту
- Смуги здоров'я
- Елементи інтерфейсу

**Доступні дії малювання:**
- Draw Sprite
- Draw Text
- Draw Rectangle
- Draw Circle
- Draw Line
- Draw Health Bar

### Draw GUI
| Властивість | Значення |
|-------------|----------|
| **Назва** | `draw_gui` |
| **Іконка** | 🖥️ |
| **Категорія** | Малювання |

## Порядок Виконання Подій

Розуміння, коли спрацьовують події, допомагає створювати передбачувану
поведінку гри (перевірено проти головного циклу в
`runtime/game_runner.py`):

1. **Begin Step** — Початок кадру
2. **Alarm** — Усі будильники, що спрацювали, відраховують і активуються
3. **Step** (та **Keyboard (утримання)**) — Основна ігрова логіка, потім
   безперервні перевірки утримуваних клавіш для того самого екземпляра
4. **Keyboard Press/Release, Mouse** — Накопичені події введення для
   цього кадру обробляються (це відбувається *після* Step, а не до
   нього — код у Step реагує на клавіші, натиснуті вже *на початку*
   кадру, а не на ті, що натиснуті протягом нього)
5. **Рух, потім Collision** — Застосовується фізика (гравітація/тертя/
   hspeed/vspeed), потім виявляються зіткнення й запускаються їхні події
6. **End Step** (та **Destroy**) — Після зіткнень
7. **Draw** — Фаза рендерингу

## Події за Пресетом

Перевірено проти `events.event_types.get_available_events()`,
наповненого кожним реальним пресетом з `config/blockly_config.py` —
про те, що саме обмежує "пресет" (і в селекторі Blockly, і в
структурованій панелі Events/Actions), і як визначається пресет
проєкту, див. [Посібник з Пресетів](Preset-Guide_uk).

| Пресет | Включені Події |
|--------|----------------|
| **Початківець** (19 подій) | Create, Step, Keyboard (утримання), Keyboard \<No Key\>, Collision, Begin Step, End Step, Alarm, Draw, Draw GUI, Room Start, Room End, Game Start, Game End, Outside Room, Intersect Boundary, No More Lives, No More Health, Animation End |
| **Середній** (21 подія) | + Destroy, Keyboard Press |
| **Повний** (лише редакція Development, 23 події) | + Keyboard Release, Mouse |
