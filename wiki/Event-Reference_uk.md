- [Інші Події](#інші-події) - Межі, Життя, Здоров'я

## Події Об'єкта

### Create
| Властивість | Значення |
|-------------|----------|
| **Назва** | `create` |
| **Іконка** | 🎯 |
| **Категорія** | Об'єкт |
| **Пресет** | Початківець |

**Опис:** Виконується один раз при першому створенні екземпляра.

**Коли спрацьовує:**
- Коли екземпляр розміщується в кімнаті на старті гри
- При створенні через дію "Створити Екземпляр"
- Після переходів кімнати для нових екземплярів

**Типові використання:**
- Ініціалізація змінних
- Встановлення початкових значень
- Налаштування початкового стану

---

### Step
| Властивість | Значення |
|-------------|----------|
| **Назва** | `step` |
| **Іконка** | ⭐ |
| **Категорія** | Об'єкт |
| **Пресет** | Початківець |

**Опис:** Виконується кожен кадр (зазвичай 60 разів на секунду).

**Коли спрацьовує:** Постійно, кожен ігровий кадр.

**Типові використання:**
- Безперервний рух
- Перевірка умов
- Оновлення позицій
- Ігрова логіка

**Примітка:** Будьте обережні з продуктивністю - код тут виконується постійно.

---

### Destroy
| Властивість | Значення |
|-------------|----------|
| **Назва** | `destroy` |
| **Іконка** | 💥 |
| **Категорія** | Об'єкт |
| **Пресет** | Середній |

**Опис:** Виконується, коли екземпляр знищується.

**Коли спрацьовує:** Безпосередньо перед видаленням екземпляра з гри.

**Типові використання:**
- Створення ефектів (вибухи, частинки)
- Випадання предметів
- Оновлення рахунку
- Відтворення звуків

## Події Введення

### Клавіатура (Безперервна)
| Властивість | Значення |
|-------------|----------|
| **Назва** | `keyboard` |
| **Іконка** | ⌨️ |
| **Категорія** | Введення |
| **Пресет** | Початківець |

**Опис:** Спрацьовує безперервно, поки клавіша утримується.

**Найкраще для:** Плавного, безперервного руху

**Підтримувані Клавіші:**
- Клавіші зі стрілками (вгору, вниз, вліво, вправо)
- Літери (A-Z)
- Цифри (0-9)
- Пробіл, Enter, Escape
- Функціональні клавіші (F1-F12)
- Модифікатори (Shift, Ctrl, Alt)

---

### Натискання Клавіші
| Властивість | Значення |
|-------------|----------|
| **Назва** | `keyboard_press` |
| **Іконка** | 🔘 |
| **Категорія** | Введення |
| **Пресет** | Початківець |

**Опис:** Спрацьовує один раз при першому натисканні клавіші.

**Найкраще для:** Одиничних дій (стрибок, постріл, вибір у меню)

**Відмінність від Клавіатури:** Спрацьовує лише раз за натискання, не під час утримання.

---

### Відпускання Клавіші
| Властивість | Значення |
|-------------|----------|
| **Назва** | `keyboard_release` |
| **Іконка** | ⬆️ |
| **Категорія** | Введення |
| **Пресет** | Просунутий |

**Опис:** Спрацьовує один раз при відпусканні клавіші.

**Типові використання:**
- Зупинка руху при відпусканні клавіші
- Завершення заряджених атак
- Перемикання станів

---

### Клавіатура (Немає клавіші)
| Властивість | Значення |
|-------------|----------|
| **Назва** | `keyboard_no_key` |
| **Іконка** | ⌨️ |
| **Категорія** | Введення |
| **Пресет** | Просунутий |

**Опис:** Спрацьовує кожен кадр, поки **не** утримується жодна клавіша.

**Коли спрацьовує:** Кожен кадр, коли клавіатура неактивна, *перед* подією Step.

**Типові використання:**
- Зупинка руху, коли гравець відпускає всі клавіші (ігри на сітці/лабіринти)
- Анімації спокою

## Події Зіткнення

### Зіткнення
| Властивість | Значення |
|-------------|----------|
| **Назва** | `collision` |
| **Іконка** | 💥 |
| **Категорія** | Зіткнення |
| **Пресет** | Початківець |

**Опис:** Спрацьовує, коли цей екземпляр перекривається з іншим типом об'єкта.

**Налаштування:** Виберіть, який тип об'єкта викликає це зіткнення.

**Спеціальна змінна:** `other` - Посилання на екземпляр, що зіткнувся.

**Коли спрацьовує:** Кожен кадр, поки екземпляри перекриваються.

**Типові використання:**
- Збір предметів
- Отримання пошкоджень
- Удари об стіни
- Запуск подій

**Приклади подій зіткнення:**
- `collision_with_obj_coin` - Гравець торкається монети
- `collision_with_obj_enemy` - Гравець торкається ворога
- `collision_with_obj_wall` - Екземпляр вдаряється об стіну

## Події Часу

### Будильник
| Властивість | Значення |
|-------------|----------|
| **Назва** | `alarm` |
| **Іконка** | ⏰ |
| **Категорія** | Час |
| **Пресет** | Середній |

**Опис:** Спрацьовує, коли відлік будильника досягає нуля.

**Доступні будильники:** 12 незалежних будильників (alarm[0] до alarm[11])

**Встановлення будильників:** Використовуйте дію "Встановити Будильник" з кроками (60 кроків ≈ 1 секунда при 60 FPS)

**Типові використання:**
- Періодичне створення
- Час перезарядки
- Відкладені ефекти
- Повторювані дії (встановіть будильник знову в події будильника)

---

### Begin Step
| Властивість | Значення |
|-------------|----------|
| **Назва** | `begin_step` |
| **Іконка** | ▶️ |
| **Категорія** | Step |
| **Пресет** | Просунутий |

**Опис:** Спрацьовує на початку кожного кадру, перед звичайними подіями Step.

**Порядок виконання:** Begin Step → Step → End Step

**Типові використання:**
- Обробка введення
- Попередні розрахунки руху

---

### End Step
| Властивість | Значення |
|-------------|----------|
| **Назва** | `end_step` |
| **Іконка** | ⏹️ |
| **Категорія** | Step |
| **Пресет** | Просунутий |

**Опис:** Спрацьовує в кінці кожного кадру, після зіткнень.

**Типові використання:**
- Фінальні коригування позиції
- Операції очищення
- Оновлення стану після зіткнень

## Події Малювання

### Draw
| Властивість | Значення |
|-------------|----------|
| **Назва** | `draw` |
| **Іконка** | 🎨 |
| **Категорія** | Малювання |
| **Пресет** | Середній |

**Опис:** Спрацьовує під час фази рендерингу.

**Важливо:** Додавання події Draw вимикає автоматичне малювання спрайту. Ви повинні малювати спрайт вручну, якщо хочете, щоб він був видимим.

**Типові використання:**
- Користувацький рендеринг
- Малювання фігур
- Відображення тексту
- Смуги здоров'я
- Елементи інтерфейсу

**Доступні дії малювання:**
- Намалювати Спрайт
- Намалювати Текст
- Намалювати Прямокутник
- Намалювати Коло
- Намалювати Лінію
- Намалювати Смугу Здоров'я

---

### Draw GUI
| Властивість | Значення |
|-------------|----------|
| **Назва** | `draw_gui` |
| **Іконка** | 🖥️ |
| **Категорія** | Малювання |
| **Пресет** | Просунутий |

**Опис:** Малює в **екранному просторі (GUI)**, поверх кімнати, і не залежить від прокручування виглядів/камери.

**Відмінність від Draw:** звичайна подія Draw працює в координатах кімнати (прокручується разом із виглядом); Draw GUI залишається зафіксованою на екрані — використовуйте її для HUD, рахунку та меню.

## Порядок Виконання Подій

Розуміння, коли спрацьовують події, допомагає створювати передбачувану поведінку гри:

1. **Begin Step** - Початок кадру
2. **Alarm** - Будь-які спрацьовані будильники
3. **Keyboard/Mouse** - Події введення
4. **Step** - Основна ігрова логіка
5. **Collision** - Після руху
6. **End Step** - Після зіткнень
7. **Draw** - Фаза рендерингу
