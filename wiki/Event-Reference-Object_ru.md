### Create
| Свойство | Значение |
|----------|----------|
| **Имя** | `create` |
| **Иконка** | 🎯 |
| **Категория** | Объект |
| **Пресет** | Начинающий |

**Описание:** Выполняется один раз при первом создании экземпляра.

**Когда срабатывает:**
- Когда экземпляр размещается в комнате при запуске игры
- При создании через действие "Create Instance"
- После переходов комнаты для новых экземпляров

**Типичные использования:**
- Инициализация переменных
- Установка начальных значений
- Настройка начального состояния

### Step
| Свойство | Значение |
|----------|----------|
| **Имя** | `step` |
| **Иконка** | ⭐ |
| **Категория** | Объект |
| **Пресет** | Начинающий |

**Описание:** Выполняется каждый кадр (обычно 60 раз в секунду).

**Когда срабатывает:** Непрерывно, каждый игровой кадр.

**Типичные использования:**
- Непрерывное движение
- Проверка условий
- Обновление позиций
- Игровая логика

**Примечание:** Будьте осторожны с производительностью — код здесь выполняется постоянно.

---

### Destroy
| Свойство | Значение |
|----------|----------|
| **Имя** | `destroy` |
| **Иконка** | 💥 |
| **Категория** | Объект |
| **Пресет** | Средний |

**Описание:** Выполняется при уничтожении экземпляра.

**Когда срабатывает:** Непосредственно перед удалением экземпляра из игры.

**Типичные использования:**
- Создание эффектов (взрывы, частицы)
- Выпадение предметов
- Обновление счёта
- Воспроизведение звуков
