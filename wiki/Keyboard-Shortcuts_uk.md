> [Повернутися на Головну](Home_uk)

Довідник власних гарячих клавіш редагування PyGameMaker. Йдеться про
**створення вашої гри в IDE** — для клавіш, які ваша *готова гра* зчитує
під час виконання (`keyboard_check`, події натискання клавіш тощо),
див. натомість [[Podii_ta_Dii_uk|Події та Дії]].

---

## Глобальні (Головне Вікно)

| Клавіші | Дія |
|----------|--------|
| Ctrl+N | Новий Проєкт |
| Ctrl+O | Відкрити Проєкт |
| Ctrl+S | Зберегти Проєкт |
| Ctrl+Shift+S | Зберегти Проєкт Як |
| Ctrl+E | Експортувати Проєкт |
| Ctrl+Q | Вийти |
| Ctrl+Z | Скасувати |
| Ctrl+Y | Повторити |
| Ctrl+X | Вирізати |
| Ctrl+C | Копіювати |
| Ctrl+V | Вставити |
| Ctrl+D | Дублювати |
| Ctrl+F | Знайти |
| Ctrl+H | Знайти і Замінити |
| F1 | Документація |
| F5 | Тестувати Гру |
| F6 | Налагодити Гру |
| F7 | Зібрати Гру |
| F8 | Зібрати і Запустити |

## Редактор Спрайтів

| Клавіша | Інструмент |
|----------|------|
| P | Олівець |
| E | Гумка |
| I | Піпетка |
| G | Заливка (відро з фарбою) |
| L | Лінія |
| R | Прямокутник |
| O | Еліпс |
| S | Виділення |
| Ctrl+C / Ctrl+X / Ctrl+V | Копіювати / Вирізати / Вставити (виділення) |
| Del | Видалити (виділення) |
| Esc | Зняти виділення |

Див. [[Sprite-Editor_uk|Редактор Спрайтів]], щоб дізнатися, що саме робить кожен інструмент.

---

## Редактор Об'єктів

| Клавіші | Дія |
|----------|--------|
| Ctrl+S | Зберігає цей об'єкт (працює навіть коли в фокусі вкладка редактора об'єктів, не викликаючи Зберегти головного вікна) |
| Ctrl+Вгору / Ctrl+Вниз | Переміщує вибрану подію вгору/вниз списком |
| Ctrl+C / Ctrl+V | Копіювати / вставити дію |

---

## Редактор Кімнат

| Клавіші | Дія |
|----------|--------|
| Del | Видаляє вибраний(і) екземпляр(и) |

Панель інструментів Редактора Кімнат також надає **Сітку**,
**Прив'язку**, **Очистити Все** і **Зсунути Все** — див.
[[Redaktor_Kimnat_uk|Редактор Кімнат]].
