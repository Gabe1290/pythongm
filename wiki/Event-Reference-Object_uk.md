### Create
| Властивість | Значення |
|-------------|----------|
| **Назва** | `create` |
| **Іконка** | 🎯 |
| **Категорія** | Об'єкт |
| **Пресет** | Початківець |

**Опис:** Виконується один раз при першому створенні екземпляра.

**Коли спрацьовує:**
- Коли екземпляр розміщується в кімнаті на старті гри
- При створенні через дію "Create Instance"
- Після переходів кімнати для нових екземплярів

**Типові використання:**
- Ініціалізація змінних
- Встановлення початкових значень
- Налаштування початкового стану

---

### Step
| Властивість | Значення |
|-------------|----------|
| **Назва** | `step` |
| **Іконка** | ⭐ |
| **Категорія** | Об'єкт |
| **Пресет** | Початківець |

**Опис:** Виконується кожен кадр (зазвичай 60 разів на секунду).

**Коли спрацьовує:** Постійно, кожен ігровий кадр.

**Типові використання:**
- Безперервний рух
- Перевірка умов
- Оновлення позицій
- Ігрова логіка

**Примітка:** Будьте обережні з продуктивністю — код тут виконується постійно.

---

### Destroy
| Властивість | Значення |
|-------------|----------|
| **Назва** | `destroy` |
| **Іконка** | 💥 |
| **Категорія** | Об'єкт |
| **Пресет** | Середній |

**Опис:** Виконується, коли екземпляр знищується.

**Коли спрацьовує:** Безпосередньо перед видаленням екземпляра з гри.

**Типові використання:**
- Створення ефектів (вибухи, частинки)
- Випадання предметів
- Оновлення рахунку
- Відтворення звуків
