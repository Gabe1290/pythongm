# Руководство по Пресетам

*[Русский](Preset-Guide_ru) | [Вернуться на Главную](Home_ru)*

PyGameMaker предлагает различные пресеты, которые контролируют, какие
события и действия доступны — **как** в визуальной палитре блоков
Blockly, так и в структурированной панели Events/Actions ("Add
Event"/"Add Action"), которую использует каждое руководство в этой
вики. Это помогает начинающим сосредоточиться на основных функциях,
позволяя опытным пользователям получить доступ к полному набору
инструментов.

Пресет проекта определяется двумя способами:
**`Preferences > IDE Edition`** выбирает стандартный пресет для
*новых* проектов (существующие проекты никогда не меняются при смене
редакции), а **`Tools > Configure Action Blocks...`** в любой момент
меняет пресет *текущего открытого* проекта. Стандартная редакция
IDE — Beginner (Начинающий), поэтому новые проекты чистой установки
уже стартуют с пресетом для начинающих.

## Выберите Свой Уровень

| IDE Edition | Подходит Для | Используемый пресет |
|----------------|-------------|----------|
| **Beginner** (Начинающий, по умолчанию) | Новые пользователи | [Пресет для Начинающих](Beginner-Preset_ru) — базовое движение, столкновения, счёт, комнаты |
| **Advanced** (Продвинутый) | Некоторый опыт | [Средний пресет](Intermediate-Preset_ru) — + жизни, здоровье, звук, будильники, движение по сетке |
| **Development** (Разработка) | Опытные пользователи | Пресет `full` — все события и действия доступны |

Обратите внимание, что названия не совпадают 1:1: редакция "Advanced"
использует пресет `intermediate` (отдельного пресета "advanced" не
существует) — точные и всегда актуальные количества событий и
действий каждого смотрите на страницах [Пресет для
Начинающих](Beginner-Preset_ru)/[Средний пресет](Intermediate-Preset_ru).

## Пример Быстрого Старта

Вот простая игра сбора монет с использованием только функций для Начинающих:

### 1. Создайте Объекты
- `obj_player` — Управляемый персонаж
- `obj_coin` — Коллекционные предметы
- `obj_wall` — Твёрдые препятствия

### 2. Добавьте События к Игроку

**Keyboard (Arrow Keys):**
```
Left Arrow  → Set Horizontal Speed: -4
Right Arrow → Set Horizontal Speed: 4
Up Arrow    → Set Vertical Speed: -4
Down Arrow  → Set Vertical Speed: 4
```

**Collision with obj_coin:**
```
Add Score: 10
Destroy Instance: other
```

**Collision with obj_wall:**
```
Stop Movement
```

### 3. Создайте Комнату
- Разместите игрока
- Добавьте несколько монет
- Добавьте стены вокруг краёв

### 4. Запустите Игру!
Нажмите кнопку Play, чтобы протестировать вашу игру.

## Советы для Успеха

1. **Начинайте Просто** — Сначала используйте пресет для Начинающих
2. **Тестируйте Часто** — Часто запускайте игру, чтобы обнаруживать проблемы
3. **Одна Вещь за Раз** — Добавляйте функции постепенно
4. **Используйте Столкновения** — Большинство игровых механик включает события столкновений
5. **Читайте Документацию** — Проверяйте справочные страницы, когда застряли
