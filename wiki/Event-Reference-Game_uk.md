# Події Гри

*[Головна](Home_uk) | [Довідник Подій](Event-Reference_uk) | [Повний довідник дій](Full-Action-Reference_uk)*

### Game Start
| Властивість | Значення |
|-------------|----------|
| **Назва** | `game_start` |
| **Іконка** | 🎮 |
| **Категорія** | Гра |
| **Пресет** | Початківець |

**Опис:** Спрацьовує один раз при першому запуску гри (тільки в першій кімнаті).

**Типові використання:**
- Ініціалізація глобальних змінних
- Завантаження збережених даних
- Відтворення вступу

---

### Game End
| Властивість | Значення |
|-------------|----------|
| **Назва** | `game_end` |
| **Іконка** | 🎮 |
| **Категорія** | Гра |
| **Пресет** | Початківець |

**Опис:** Спрацьовує, коли гра завершується.

**Типові використання:**
- Збереження даних гри
- Звільнення ресурсів
