# Виды

*[Главная](Home_ru) | [Руководство по пресетам](Preset-Guide_ru) | [Справочник событий](Event-Reference_ru)*

> **Сгенерировано автоматически** из реестра действий IDE с помощью `tools/gen_action_reference.py` — не редактируйте вручную; повторно запустите генератор после изменения действий. Переводы взяты из `tools/action_ref_i18n.py`.

### Включить виды

| Свойство | Значение |
|----------|-------|
| **Имя** | `enable_views` |
| **Значок** | 🎥 |
| **Категория** | Виды |

Включить или выключить систему камеры/вида комнаты (позволяет уровню прокручиваться, когда он больше окна)

| Параметр | Тип | По умолч. | Примечания |
|-----------|------|---------|-------|
| `enable` | Да/Нет | Да | Вкл. = виды камеры; выкл. = рисовать всю комнату сразу |

### Настроить вид

| Свойство | Значение |
|----------|-------|
| **Имя** | `set_view` |
| **Значок** | 🎥 |
| **Категория** | Виды |

Настроить вид камеры: какую часть комнаты он показывает, где рисуется на экране, и объект для слежения

| Параметр | Тип | По умолч. | Примечания |
|-----------|------|---------|-------|
| `view` | Выбор | `0` | Какой из 8 видов настроить; Варианты: `0`, `1`, `2`, `3`, `4`, `5`, `6`, `7` |
| `visible` | Да/Нет | Да | Рисовать этот вид |
| `view_x` | Число | `0` | Левый край показанной области комнаты |
| `view_y` | Число | `0` | Верхний край показанной области комнаты |
| `view_w` | Число | `800` | Ширина показанной области комнаты |
| `view_h` | Число | `600` | Высота показанной области комнаты |
| `port_x` | Число | `0` | Левый край на экране |
| `port_y` | Число | `0` | Верхний край на экране |
| `port_w` | Число | `800` | Ширина, нарисованная на экране |
| `port_h` | Число | `600` | Высота, нарисованная на экране |
| `follow` | Объект | — | Объект, за которым следит камера (пусто = фиксированный вид); необязательно |
| `hborder` | Число | `32` | Горизонтальная граница перед прокруткой камеры |
| `vborder` | Число | `32` | Вертикальная граница перед прокруткой камеры |
| `hspeed` | Число | `-1` | Макс. горизонтальная скорость прокрутки (-1 = мгновенно) |
| `vspeed` | Число | `-1` | Макс. вертикальная скорость прокрутки (-1 = мгновенно) |
