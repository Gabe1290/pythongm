# Счёт

*[Главная](Home_ru) | [Руководство по пресетам](Preset-Guide_ru) | [Справочник событий](Event-Reference_ru)*

> **Сгенерировано автоматически** из реестра действий IDE с помощью `tools/gen_action_reference.py` — не редактируйте вручную; повторно запустите генератор после изменения действий. Переводы взяты из `tools/action_ref_i18n.py`.

### Нарисовать полосу здоровья

| Свойство | Значение |
|----------|-------|
| **Имя** | `draw_health_bar` |
| **Значок** | 🩺 |
| **Категория** | Счёт |

Нарисовать текущее здоровье в виде двухцветной полосы

| Параметр | Тип | По умолч. | Примечания |
|-----------|------|---------|-------|
| `x1` | Число | `0` | Левое X |
| `y1` | Число | `0` | Верхнее Y |
| `x2` | Число | `100` | Правое X |
| `y2` | Число | `20` | Нижнее Y |
| `back_color` | Цвет | `#FF0000` | Цвет фона (пустой) |
| `bar_color` | Цвет | `#00FF00` | Цвет заполнения (здоровье) |

### Нарисовать жизни

| Свойство | Значение |
|----------|-------|
| **Имя** | `draw_lives` |
| **Значок** | 🖍️❤️ |
| **Категория** | Счёт |

Нарисовать текущее количество жизней в виде повторяющихся изображений спрайта

| Параметр | Тип | По умолч. | Примечания |
|-----------|------|---------|-------|
| `x` | Число | `0` | Позиция X |
| `y` | Число | `0` | Позиция Y |
| `sprite` | Спрайт | — | Спрайт, рисуемый один раз на каждую оставшуюся жизнь; необязательно |
| `scale` | Число | `1.0` | Равномерный коэффициент масштаба для иконки жизни (1.0 = родной размер); необязательно |
| `relative` | Да/Нет | Нет | Рисовать относительно позиции этого экземпляра вместо абсолютных экранных координат; необязательно |

### Нарисовать счёт

| Свойство | Значение |
|----------|-------|
| **Имя** | `draw_score` |
| **Значок** | 🖍️🏆 |
| **Категория** | Счёт |

Нарисовать текущий счёт на экране

| Параметр | Тип | По умолч. | Примечания |
|-----------|------|---------|-------|
| `x` | Число | `0` | Позиция X |
| `y` | Число | `0` | Позиция Y |
| `caption` | Текст | `Score: ` | Текст, показываемый перед значением счёта; необязательно |
| `relative` | Да/Нет | Нет | Рисовать относительно позиции этого экземпляра вместо абсолютных экранных координат; необязательно |

### Задать здоровье

| Свойство | Значение |
|----------|-------|
| **Имя** | `set_health` |
| **Значок** | 💚 |
| **Категория** | Счёт |

Задать здоровье или добавить к нему с помощью «Относительно»

| Параметр | Тип | По умолч. | Примечания |
|-----------|------|---------|-------|
| `value` | Число | `100` | Значение здоровья (0-100) |
| `relative` | Да/Нет | Нет | Добавить к текущему здоровью вместо замены |
