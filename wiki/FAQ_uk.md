## Загальні Запитання

### Що таке PyGameMaker?

PyGameMaker — це IDE для розробки ігор з відкритим кодом, натхненний GameMaker 7.0. Він дозволяє створювати 2D-ігри за допомогою візуального програмування (Google Blockly) або системи подій-дій, без написання коду.

### PyGameMaker безкоштовний?

Так! PyGameMaker повністю безкоштовний і з відкритим кодом — вихідний код ліцензовано під MIT, а документацію — під CC BY 4.0.

### Для яких платформ я можу експортувати?

- Windows (автономний .exe)
- HTML5 (веббраузери)
- Linux (нативний бінарний файл)
- Мобільні пристрої (iOS/Android через Kivy)

### Чи потрібен мені досвід програмування?

Ні! PyGameMaker розроблено для початківців. Ви можете створювати ігри за допомогою:
- Блоків Blockly перетягуванням
- Системи подій/дій point-and-click
- Без написання коду

### Чи сумісний він з файлами GameMaker?

PyGameMaker натхненний GameMaker 7.0, але використовує власний формат проєкту. Файли GameMaker не можна імпортувати напряму, але концепції та робочий процес схожі.

## Встановлення

### Які системні вимоги?

- Python 3.10 або новіший
- Windows, Linux або macOS
- Щонайменше 4 ГБ RAM (рекомендовано 8 ГБ)
- ~500 МБ вільного місця на диску

### Як встановити PyGameMaker?

Детальні інструкції з встановлення див. у [[Pochatok_uk]]. Коротка версія:

```bash
git clone https://github.com/Gabe1290/pythongm.git
cd pythongm
python -m venv venv
source venv/bin/activate  # або venv\Scripts\activate на Windows
pip install -r requirements.txt
python main.py
```

### Python не розпізнається / не знайдено

Переконайтеся, що Python встановлено і додано до PATH системи. Перевірте командою:

```bash
python --version
```

Якщо це не спрацьовує, перевстановіть Python і під час встановлення увімкніть "Add Python to PATH".

### Під час запуску виникають помилки імпорту

Спробуйте перевстановити залежності:

```bash
pip install -r requirements.txt --force-reinstall
```

## Проєкти

### Де зберігаються мої проєкти?

Проєкти зберігаються в папках, які ви обираєте самі. Кожен проєкт містить:
- `project.json` — Основний файл проєкту
- Папки для спрайтів, звуків, об'єктів, кімнат тощо

### Чи можу я мати відкритими кілька проєктів одночасно?

Наразі PyGameMaker відкриває один проєкт за раз. Щоб перемкнутися між проєктами, використовуйте **File > Open Project**.

### Як зробити резервну копію проєкту?

Просто скопіюйте всю папку проєкту. Усі ресурси та налаштування містяться в ній. Також розгляньте використання git для контролю версій:

```bash
cd my_project
git init
git add .
git commit -m "Початкова резервна копія"
```

### Мій проєкт не відкривається / пошкоджений

Спробуйте такі кроки:
1. Перевірте, що `project.json` існує і не порожній
2. Відкрийте `project.json` у текстовому редакторі та перевірте на помилки JSON
3. Якщо доступно, відновіть з резервної копії
4. Перевірте вивід консолі на конкретні повідомлення про помилки

## Об'єкти та Події

### У чому різниця між об'єктом та екземпляром?

- **Об'єкт**: Шаблон/модель, що визначає поведінку
- **Екземпляр**: Конкретна копія об'єкта, розміщена в кімнаті

Наприклад, `obj_enemy` — це об'єкт. Розміщення 5 ворогів у кімнаті створює 5 екземплярів об'єкта `obj_enemy`.

### Чому моя подія не спрацьовує?

Поширені причини:
1. **Неправильний тип події**: Переконайтеся, що використовуєте правильну подію (напр. "Key Press", а не "Keyboard")
2. **Немає екземплярів**: Об'єкт повинен мати екземпляри в кімнаті
3. **Об'єкт не видимий**: Перевірте властивість visible
4. **Порядок виконання**: Деякі події виконуються перед іншими

### Як зробити взаємодію між об'єктами?

Використовуйте події зіткнень:
1. Відкрийте об'єкт, який має виявляти зіткнення
2. Додайте подію **Collision with [інший об'єкт]**
3. Додайте дії для того, що відбувається при зіткненні

### Яка різниця між подіями "Keyboard" та "Key Press"?

- **Keyboard [клавіша]**: Спрацьовує щокадру, поки клавіша натиснута
- **Key Press [клавіша]**: Спрацьовує один раз, коли клавішу вперше натиснуто
- **Key Release [клавіша]**: Спрацьовує один раз, коли клавішу відпущено

## Кімнати

### Яка кімната завантажується першою?

Перша кімната в дереві ресурсів (зверху списку) завантажується при старті гри. Перетягуйте кімнати, щоб змінити їх порядок.

### Як змінити кімнату?

Використовуйте дії кімнати:
- **Next Room**: Перейти до наступної кімнати за порядком
- **Previous Room**: Перейти до попередньої кімнати
- **Go to Room**: Перейти до конкретної кімнати

### Об'єкти зникають при зміні кімнати

Об'єкти знищуються при виході з кімнати, якщо тільки вони не позначені як **Persistent** у своїх властивостях.

### Моя кімната завелика/замала на екрані

Розмір вікна гри відповідає розмірам першої кімнати. Ви можете:
- Змінити розмір кімнати відповідно до бажаного розміру вікна
- Використовувати Views, щоб показувати лише частину кімнати

## Графіка Та Спрайти

### Які формати зображень підтримуються?

- PNG (рекомендовано, підтримує прозорість)
- JPEG/JPG
- BMP
- GIF (лише перший кадр)

### Мій спрайт відображається в неправильному місці

Перевірте налаштування **Origin** у редакторі спрайтів. Точка початку координат — це точка прив'язки для розміщення. Поширені налаштування:
- Верхній лівий кут (0, 0): За замовчуванням
- Центр: Добре для об'єктів, що обертаються
- Центр знизу: Добре для персонажів

### Як анімувати спрайт?

1. Створіть спрайт із кількома кадрами (горизонтальна стрічка)
2. У властивостях спрайта встановіть **Number of Frames**
3. Налаштуйте **Animation Speed** (кадрів за секунду)

### Спрайти розмиті

Це трапляється при зміні розміру спрайтів. Для пікс-арту вимкніть інтерполяцію/згладжування в налаштуваннях гри, якщо доступно.

## Звук Та Музика

### Які аудіоформати підтримуються?

- WAV (нестиснений)
- OGG (рекомендовано для музики)
- MP3

### Звук не відтворюється

Перевірте:
1. Чи існує звуковий файл у папці sounds
2. Чи підтримується формат файлу
3. Чи використовуєте ви правильну назву звуку в діях
4. Браузер може вимагати взаємодії користувача (для HTML5)

### Як зробити циклічне відтворення фонової музики?

Використовуйте дію **Play Music** з увімкненою опцією циклу, або **Play Sound** з параметром loop, встановленим на true.

## Експорт

### Моя експортована гра не працює

Поширені проблеми:
- **Windows**: Відсутні DLL — переконайтеся, що включено всю вихідну папку
- **HTML5**: Браузер блокує локальні файли — розмістіть на сервері
- **Відсутні ресурси**: Перевірте, що включено всі файли

### Експортований файл величезний

Розмір гри включає Python та всі бібліотеки. Щоб зменшити:
- Видаліть невикористані ресурси
- Стисніть зображення та звук
- Використовуйте відповідні формати (OGG замість WAV)
- Для збірок Windows увімкніть стиснення UPX

### Чи можу я продавати ігри, зроблені з PyGameMaker?

Так! Ігри, які ви створюєте, повністю ваші, і ви можете їх продавати. Вихідний код PyGameMaker ліцензовано під дозвільною ліцензією MIT, тож ви можете вільно використовувати його в комерційних проєктах — і, на відміну від copyleft-ліцензій, вам не потрібно відкривати код власних змін.

## Blockly / Візуальне Програмування

### Де знайти редактор Blockly?

1. Відкрийте об'єкт
2. У редакторі об'єктів клацніть на вкладку **Blockly**
3. З'явиться робоча область візуального програмування

### Як перемикатися між Blockly та подіями?

Обидві системи працюють з тим самим об'єктом. Вкладки Blockly та Events показують різні представлення тієї самої логіки. Зміни в одній відображаються в іншій.

### Мої блоки Blockly зникли

Перевірте:
1. Чи дивитеся ви на правильний об'єкт
2. Прогорніть робочу область (блоки можуть бути поза екраном)
3. Перевірте рівень масштабування

## Продуктивність

### Моя гра повільна

Поради для кращої продуктивності:
1. Зменшіть кількість екземплярів
2. Уникайте вимогливих обчислень у подіях Step
3. Використовуйте будильники замість підрахунку кадрів
4. Оптимізуйте розміри спрайтів
5. Знищуйте екземпляри, що залишили кімнату

### Подія Step виконується занадто часто

Подія Step виконується щокадру (за замовчуванням 60 разів на секунду). Використовуйте:
- Будильники для відкладених дій
- Умови, що перевіряються перед вимогливими операціями
- Нижчу швидкість кімнати, якщо доречно
