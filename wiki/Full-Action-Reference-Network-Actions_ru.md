# Сеть

> **Сгенерировано автоматически** из реестра действий IDE с помощью `tools/gen_action_reference.py` — не редактируйте вручную; повторно запустите генератор после изменения действий. Переводы взяты из `tools/action_ref_i18n.py`.

### Назначить сетевую клавишу

| Свойство | Значение |
|----------|-------|
| **Имя** | `bind_network_input` |
| **Значок** | ⌨️ |
| **Категория** | Сеть |

Привязывает локальную клавишу к «именованному вводу», о котором сообщается ведущему. Ведущий затем проверяет его действием «Если игрок нажимает». Стрелки и пробел уже привязаны ("left", "right", "up", "down", "space")

| Параметр | Тип | По умолч. | Примечания |
|-----------|------|---------|-------|
| `name` | Текст | — | Название на ваш выбор (например, "jump", "fire") |
| `key` | Текст | — | Имя клавиши: "space", "left", "a", "5", "lshift"... |

### Создать сетевой объект

| Свойство | Значение |
|----------|-------|
| **Имя** | `network_spawn` |
| **Значок** | ✨ |
| **Категория** | Сеть |

Только у ведущего: создаёт экземпляр, который автоматически появляется у всех клиентов как сглаженный «призрак». У клиента ничего не делает. Созданным экземпляром управляет ведущий — защитите его игровую логику условием global.is_host == 1

| Параметр | Тип | По умолч. | Примечания |
|-----------|------|---------|-------|
| `object` | Объект | — | Тип создаваемого объекта |
| `x` | Текст | `0` |  |
| `y` | Текст | `0` |  |
| `owner` | Текст | `0` | Игрок, который управляет этим экземпляром (0 — ведущий). Часто global.network_sender внутри события «Игрок присоединился».; необязательно |
| `relative` | Да/Нет | Нет | Позиция относительно объекта, выполняющего действие; необязательно |

### Создать игру

| Свойство | Значение |
|----------|-------|
| **Имя** | `host_game` |
| **Значок** | 🌐 |
| **Категория** | Сеть |

Делает эту машину ведущей в многопользовательской игре по локальной сети: остальные игроки подключаются к ней. Вызовите один раз (например, в событии Создание контроллера комнаты). Устанавливает global.player_id = 0 и global.network_role = "host"

| Параметр | Тип | По умолч. | Примечания |
|-----------|------|---------|-------|
| `game_name` | Текст | `PyGameMaker` | Имя, отображаемое в списке серверов (обнаружение в сети); необязательно |
| `max_players` | Число | `8` | Наибольшее число игроков, включая ведущего (от 2 до 16); необязательно |
| `port` | Число | `45782` | TCP-порт — должен совпадать у ведущего и у каждого клиента; необязательно |
| `player_name` | Текст | — | Имя этого игрока (пусто — global.player_name, иначе "Player"); необязательно |
| `show_lobby` | Да/Нет | Нет | Показать экран «Ожидание игроков...» с кнопкой запуска перед началом игры; необязательно |

### Если я управляю этим экземпляром

| Свойство | Значение |
|----------|-------|
| **Имя** | `is_instance_owner` |
| **Значок** | ❓ |
| **Категория** | Сеть |

Условие: истинно, когда ЭТА машина владеет синхронизированным экземпляром. Поставьте его перед блоком, чтобы логика управления выполнялась только на машине нужного игрока

*Параметры:* нет

### Если игрок нажимает

| Свойство | Значение |
|----------|-------|
| **Имя** | `remote_input` |
| **Значок** | ❓ |
| **Категория** | Сеть |

Условие на стороне ведущего: истинно, пока указанный игрок удерживает указанный ввод. Позволяет ведущему реагировать на клавиши клиента, не владея его персонажем

| Параметр | Тип | По умолч. | Примечания |
|-----------|------|---------|-------|
| `player` | Текст | `0` | Номер игрока (0 — ведущий) |
| `name` | Текст | — | Проверяемый именованный ввод (например, "jump") |

### Присоединиться к игре

| Свойство | Значение |
|----------|-------|
| **Имя** | `join_game` |
| **Значок** | 🔌 |
| **Категория** | Сеть |

Подключается к многопользовательской игре по локальной сети, запущенной на другой машине. Ведущий задаёт global.player_id (1, 2, ...). Если ведущий недоступен, игра продолжается в одиночном режиме

| Параметр | Тип | По умолч. | Примечания |
|-----------|------|---------|-------|
| `host` | Текст | `127.0.0.1` | IP-адрес ведущего в локальной сети ("auto" открывает встроенный экран подключения); необязательно |
| `port` | Число | `45782` | TCP-порт — должен совпадать с портом ведущего; необязательно |
| `player_name` | Текст | — | Имя этого игрока (пусто — global.player_name, иначе "Player"); необязательно |

### Покинуть игру

| Свойство | Значение |
|----------|-------|
| **Имя** | `leave_game` |
| **Значок** | 🚪 |
| **Категория** | Сеть |

Отключается (или прекращает быть ведущим) и очищает глобальные сетевые переменные

*Параметры:* нет

### Прочитать общую переменную

| Свойство | Значение |
|----------|-------|
| **Имя** | `get_shared_var` |
| **Значок** | 📥 |
| **Категория** | Сеть |

Копирует общую переменную в глобальную, чтобы использовать её в вычислении. То же самое, что прочитать global.<имя> напрямую

| Параметр | Тип | По умолч. | Примечания |
|-----------|------|---------|-------|
| `name` | Текст | — | Имя общей переменной, которую нужно прочитать |
| `into` | Текст | — | Имя глобальной переменной, в которую записывается значение |

### Отправить сетевое сообщение

| Свойство | Значение |
|----------|-------|
| **Имя** | `send_network_message` |
| **Значок** | ✉️ |
| **Категория** | Сеть |

Рассылает собственное сообщение. Вызывает событие «Сетевое сообщение» на соответствующих машинах, с global.network_event / global.network_data / global.network_sender

| Параметр | Тип | По умолч. | Примечания |
|-----------|------|---------|-------|
| `event` | Текст | — | Название на ваш выбор, которое проверяет обработчик (например, "buzz", "answer") |
| `data` | Текст | — | Число, текст, true/false или короткий список; необязательно |
| `target` | Выбор | `all` | all — все; host — только ведущий; Варианты: `all`, `host` |

### Задать сетевой режим (v1)

| Свойство | Значение |
|----------|-------|
| **Имя** | `set_network_mode` |
| **Значок** | 🌐 |
| **Категория** | Сеть |

Устаревшее низкоуровневое действие: запускает комнату в режиме ведущего или клиента (только наблюдение — ввод клиента ни на что не влияет). Лучше использовать «Создать игру» / «Присоединиться к игре». Сохранено ради существующих проектов и ключей --net-host / --net-client

| Параметр | Тип | По умолч. | Примечания |
|-----------|------|---------|-------|
| `mode` | Выбор | `host` | Ведущий — другие подключаются к вам; Клиент — вы подключаетесь к ведущему; Варианты: `host`, `client` |
| `host` | Текст | `127.0.0.1` | IP-адрес ведущего в локальной сети (только в режиме клиента); необязательно |
| `port` | Число | `45782` | TCP-порт — должен совпадать у ведущего и у клиента; необязательно |

### Задать общую переменную

| Свойство | Значение |
|----------|-------|
| **Имя** | `set_shared_var` |
| **Значок** | 📤 |
| **Категория** | Сеть |

Записывает переменную, общую для всех машин. У ведущего она применяется сразу; у клиента это запрос, отправляемый ведущему. Читается везде как global.<имя>

| Параметр | Тип | По умолч. | Примечания |
|-----------|------|---------|-------|
| `name` | Текст | — | Простой идентификатор (буквы, цифры, _) — без пробелов и операторов |
| `value` | Текст | `0` | Число, текст или true/false (составные объекты отклоняются) |

### Задать владельца экземпляра

| Свойство | Значение |
|----------|-------|
| **Имя** | `set_instance_owner` |
| **Значок** | 🎮 |
| **Категория** | Сеть |

Выбирает, какой игрок управляет этим синхронизированным экземпляром (0 — ведущий; 1, 2, ... — клиенты). На машине этого игрока экземпляр просчитывается локально и отзывчиво, а его состояние сообщается ведущему; на остальных это сглаженный призрак. Вызывайте у ведущего, под условием global.is_host == 1

| Параметр | Тип | По умолч. | Примечания |
|-----------|------|---------|-------|
| `player` | Текст | `0` | Номер игрока (0 — ведущий). Часто global.network_sender внутри события «Игрок присоединился». |

### Задать частоту синхронизации

| Свойство | Значение |
|----------|-------|
| **Имя** | `set_sync_rate` |
| **Значок** | ⏱️ |
| **Категория** | Сеть |

Настраивает, как часто ведущий отправляет снимки состояния и с какой задержкой клиенты их отрисовывают. Вызовите один раз у ведущего, а для задержки — и у клиентов

| Параметр | Тип | По умолч. | Примечания |
|-----------|------|---------|-------|
| `hz` | Число | `20` | 10–30 хорошо подходит для локальной сети (по умолчанию 20); необязательно |
| `interp_ms` | Число | `100` | Насколько с запозданием рисуются призраки, в миллисекундах (по умолчанию 100); необязательно |

### Начать сетевую игру

| Свойство | Значение |
|----------|-------|
| **Имя** | `start_networked_game` |
| **Значок** | 🚦 |
| **Категория** | Сеть |

Только у ведущего: выводит всех из комнаты ожидания и начинает игру. Вызывает событие «Сетевая игра началась» на каждой машине

*Параметры:* нет

### Синхронизировать этот экземпляр

| Свойство | Значение |
|----------|-------|
| **Имя** | `sync_instance` |
| **Значок** | 🔗 |
| **Категория** | Сеть |

Помечает экземпляр, выполняющий это действие, как синхронизированный: его позиция, поворот, изображение и видимость копируются на все машины. Вызывайте в событии Создание. По умолчанию им владеет ведущий; чтобы им управлял клиент, используйте «Задать владельца экземпляра»

| Параметр | Тип | По умолч. | Примечания |
|-----------|------|---------|-------|
| `vars` | Текст | — | Имена переменных экземпляра, которые также копируются, через запятую (например, "hp, colour"); необязательно |
