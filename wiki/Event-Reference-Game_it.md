# Eventi di Gioco

*[Home](Home_it) | [Riferimento Eventi](Event-Reference_it) | [Riferimento completo delle azioni](Full-Action-Reference_it)*

### Game Start
| Proprietà | Valore |
|-----------|--------|
| **Nome** | `game_start` |
| **Icona** | 🎮 |
| **Categoria** | Gioco |
| **Preset** | Principiante |

**Descrizione:** Si attiva una volta quando il gioco inizia per la prima volta (solo nella prima stanza).

**Usi comuni:**
- Inizializzare variabili globali
- Caricare dati salvati
- Riprodurre intro

---

### Game End
| Proprietà | Valore |
|-----------|--------|
| **Nome** | `game_end` |
| **Icona** | 🎮 |
| **Categoria** | Gioco |
| **Preset** | Principiante |

**Descrizione:** Si attiva quando il gioco sta terminando.

**Usi comuni:**
- Salvare i dati di gioco
- Liberare risorse
