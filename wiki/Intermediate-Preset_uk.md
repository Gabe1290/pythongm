# Середній Пресет

*[Головна](Home_uk) | [Посібник з Пресетів](Preset-Guide_uk) | [Пресет для Початківців](Beginner-Preset_uk)*

**Середній** пресет базується на [Пресеті для Початківців](Beginner-Preset_uk), додаючи більш просунуті події та дії. Він призначений для користувачів, які освоїли основи і хочуть створювати більш складні ігри з такими функціями, як таймовані події, звук, життя та системи здоров'я.

## Огляд

Середній пресет включає все з Початкового, плюс:
- **4 Додаткові Типи Подій** - Малювання, Знищення, Миша, Будильник
- **12 Додаткових Типів Дій** - Життя, Здоров'я, Звук, Таймер та більше опцій руху
- **3 Додаткові Категорії** - Таймер, Звук, Малювання

---

## Додаткові Події (Понад Початковий)

### Подія Малювання
| Властивість | Значення |
|-------------|----------|
| **Назва Блоку** | `event_draw` |
| **Категорія** | Малювання |
| **Іконка** | 🎨 |
| **Опис** | Спрацьовує, коли об'єкт потрібно відрендерити |

**Коли спрацьовує:** Кожен кадр під час фази малювання, після всіх step подій.

**Важливо:** Коли ви додаєте подію Малювання, стандартне малювання спрайта вимикається. Ви повинні вручну малювати спрайт, якщо хочете, щоб він був видимим.

**Поширені використання:**
- Користувацький рендеринг
- Малювання смуг здоров'я
- Відображення тексту
- Малювання фігур та ефектів
- Елементи інтерфейсу

---

### Подія Знищення
| Властивість | Значення |
|-------------|----------|
| **Назва Блоку** | `event_destroy` |
| **Категорія** | Об'єкт |
| **Іконка** | 💥 |
| **Опис** | Спрацьовує, коли екземпляр знищується |

**Коли спрацьовує:** Безпосередньо перед видаленням екземпляра з гри.

**Поширені використання:**
- Створення ефектів вибуху
- Випадання предметів
- Відтворення звуку смерті
- Оновлення рахунку
- Генерація частинок

---

### Подія Миші
| Властивість | Значення |
|-------------|----------|
| **Назва Блоку** | `event_mouse` |
| **Категорія** | Ввід |
| **Іконка** | 🖱️ |
| **Опис** | Спрацьовує при взаємодії з мишею |

**Типи подій миші:**
- Ліва кнопка (натискання, відпускання, утримання)
- Права кнопка (натискання, відпускання, утримання)
- Середня кнопка (натискання, відпускання, утримання)
- Миша входить (курсор входить в екземпляр)
- Миша виходить (курсор покидає екземпляр)
- Глобальні події миші (будь-де на екрані)

**Поширені використання:**
- Кнопки, що натискаються
- Перетягування
- Ефекти наведення
- Взаємодія з меню

---

### Подія Будильника
| Властивість | Значення |
|-------------|----------|
| **Назва Блоку** | `event_alarm` |
| **Категорія** | Таймер |
| **Іконка** | ⏰ |
| **Опис** | Спрацьовує, коли таймер будильника досягає нуля |

**Коли спрацьовує:** Коли відповідний відлік будильника досягає 0.

**Доступні будильники:** 12 незалежних будильників (0-11)

**Поширені використання:**
- Таймоване створення
- Відкладені дії
- Перезарядка
- Таймінг анімації
- Періодичні події

## Додаткові Дії (Понад Початковий)

### Дії Руху

#### Рух у Напрямку
| Властивість | Значення |
|-------------|----------|
| **Назва Дії** | `move_direction` |
| **Назва Блоку** | `move_direction` |
| **Категорія** | Рух |

**Опис:** Встановити рух за допомогою напрямку (0-360 градусів) та швидкості.

**Параметри:**
| Параметр | Тип | Опис |
|----------|-----|------|
| `direction` | Число | Напрямок у градусах (0=праворуч, 90=вгору, 180=ліворуч, 270=вниз) |
| `speed` | Число | Швидкість руху |

---

#### Рух До Точки
| Властивість | Значення |
|-------------|----------|
| **Назва Дії** | `move_towards_point` |
| **Назва Блоку** | `move_towards_point` |
| **Категорія** | Рух |

**Опис:** Рухатися до певної позиції.

**Параметри:**
| Параметр | Тип | Опис |
|----------|-----|------|
| `x` | Число/Вираз | Цільова координата X |
| `y` | Число/Вираз | Цільова координата Y |
| `speed` | Число | Швидкість руху |

---

### Дії Таймера

#### Встановити Будильник
| Властивість | Значення |
|-------------|----------|
| **Назва Дії** | `set_alarm` |
| **Назва Блоку** | `set_alarm` |
| **Категорія** | Таймер |
| **Іконка** | ⏰ |

**Опис:** Встановити будильник для спрацювання через певну кількість кроків.

**Параметри:**
| Параметр | Тип | Опис |
|----------|-----|------|
| `alarm` | Число | Номер будильника (0-11) |
| `steps` | Число | Кроки до спрацювання будильника (при 60 FPS, 60 кроків = 1 секунда) |

**Приклад:** Встановіть будильник 0 на 180 кроків для 3-секундної затримки.

## Приклад: Гра-Стрілялка з Життями

### Об'єкт Гравця

**Create:**
- Set Lives: 3

**Keyboard Press (Пробіл):**
- Create Instance: obj_bullet в (x, y-20)
- Set Alarm: 0 до 15 (перезарядка)

**Зіткнення з obj_enemy:**
- Add Lives: -1
- Play Sound: snd_hurt
- Jump to Position: (320, 400)

**No More Lives:**
- Show Message: "Game Over!"
- Restart Room

### Об'єкт Ворога

**Create:**
- Set Alarm: 0 до 60

**Alarm 0:**
- Create Instance: obj_enemy_bullet в (x, y+20)
- Set Alarm: 0 до 60 (повторити)

**Зіткнення з obj_bullet:**
- Add Score: 100
- Play Sound: snd_explosion
- Destroy Instance: self
