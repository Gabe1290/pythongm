Une référence des raccourcis d'édition propres à PyGameMaker. Il s'agit
de **construire votre jeu dans l'IDE** — pour les touches que votre *jeu
terminé* lit à l'exécution (`keyboard_check`, événements de touche
pressée, etc.), voir plutôt [[Evenements_Actions_fr|Événements et Actions]].

---

## Global (Fenêtre Principale)

| Raccourci | Action |
|----------|--------|
| Ctrl+N | Nouveau Projet |
| Ctrl+O | Ouvrir un Projet |
| Ctrl+S | Enregistrer le Projet |
| Ctrl+Maj+S | Enregistrer le Projet Sous |
| Ctrl+E | Exporter le Projet |
| Ctrl+Q | Quitter |
| Ctrl+Z | Annuler |
| Ctrl+Y | Rétablir |
| Ctrl+X | Couper |
| Ctrl+C | Copier |
| Ctrl+V | Coller |
| Ctrl+D | Dupliquer |
| Ctrl+F | Rechercher |
| Ctrl+H | Rechercher et Remplacer |
| F1 | Documentation |
| F5 | Tester le Jeu |
| F6 | Déboguer le Jeu |
| F7 | Compiler le Jeu |
| F8 | Compiler et Exécuter |

## Éditeur de Sprites

| Raccourci | Outil |
|----------|------|
| P | Crayon |
| E | Gomme |
| I | Pipette |
| G | Remplissage (pot de peinture) |
| L | Ligne |
| R | Rectangle |
| O | Ellipse |
| S | Sélection |
| Ctrl+C / Ctrl+X / Ctrl+V | Copier / Couper / Coller (une sélection) |
| Suppr | Supprimer (une sélection) |
| Échap | Désélectionner |

Voir [[Sprite-Editor_fr|Éditeur de Sprites]] pour ce que fait chaque outil.

---

## Éditeur d'Objets

| Raccourci | Action |
|----------|--------|
| Ctrl+S | Enregistre cet objet (fonctionne même quand l'onglet de l'éditeur d'objet a le focus, sans déclencher l'Enregistrer de la fenêtre principale) |
| Ctrl+Haut / Ctrl+Bas | Déplace l'événement sélectionné vers le haut/bas dans la liste |
| Ctrl+C / Ctrl+V | Copier / coller une action |

---

## Éditeur de Salles

| Raccourci | Action |
|----------|--------|
| Suppr | Supprime l'instance/les instances sélectionnée(s) |

La barre d'outils de l'Éditeur de Salles expose également **Grille**,
**Aimantation**, **Tout Effacer** et **Tout Décaler** — voir
[[Editeur_Salles_fr|Éditeur de Salles]].
