# Вигляди

*[Головна](Home_uk) | [Посібник із пресетів](Preset-Guide_uk) | [Довідник подій](Event-Reference_uk)*

> **Згенеровано автоматично** з реєстру дій IDE за допомогою `tools/gen_action_reference.py` — не редагуйте вручну; повторно запустіть генератор після зміни дій. Переклади взято з `tools/action_ref_i18n.py`.

### Увімкнути вигляди

| Властивість | Значення |
|----------|-------|
| **Назва** | `enable_views` |
| **Значок** | 🎥 |
| **Категорія** | Вигляди |

Увімкнути або вимкнути систему камери/вигляду кімнати (дозволяє рівню прокручуватися, коли він більший за вікно)

| Параметр | Тип | За замовч. | Примітки |
|-----------|------|---------|-------|
| `enable` | Так/Ні | Так | Увімк. = вигляди камери; вимк. = малювати всю кімнату одразу |

### Налаштувати вигляд

| Властивість | Значення |
|----------|-------|
| **Назва** | `set_view` |
| **Значок** | 🎥 |
| **Категорія** | Вигляди |

Налаштувати вигляд камери: яку частину кімнати він показує, де малюється на екрані, і об'єкт для стеження

| Параметр | Тип | За замовч. | Примітки |
|-----------|------|---------|-------|
| `view` | Вибір | `0` | Який із 8 виглядів налаштувати; Варіанти: `0`, `1`, `2`, `3`, `4`, `5`, `6`, `7` |
| `visible` | Так/Ні | Так | Малювати цей вигляд |
| `view_x` | Число | `0` | Лівий край показаної області кімнати |
| `view_y` | Число | `0` | Верхній край показаної області кімнати |
| `view_w` | Число | `800` | Ширина показаної області кімнати |
| `view_h` | Число | `600` | Висота показаної області кімнати |
| `port_x` | Число | `0` | Лівий край на екрані |
| `port_y` | Число | `0` | Верхній край на екрані |
| `port_w` | Число | `800` | Ширина, намальована на екрані |
| `port_h` | Число | `600` | Висота, намальована на екрані |
| `follow` | Об'єкт | — | Об'єкт, за яким стежить камера (порожньо = фіксований вигляд); необов'язково |
| `hborder` | Число | `32` | Горизонтальна межа перед прокручуванням камери |
| `vborder` | Число | `32` | Вертикальна межа перед прокручуванням камери |
| `hspeed` | Число | `-1` | Макс. горизонтальна швидкість прокручування (-1 = миттєво) |
| `vspeed` | Число | `-1` | Макс. вертикальна швидкість прокручування (-1 = миттєво) |
