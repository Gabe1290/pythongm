Una referencia de los atajos de edición propios de PyGameMaker. Se trata
de **construir tu juego en el IDE** — para las teclas que tu *juego
terminado* lee en tiempo de ejecución (`keyboard_check`, eventos de
tecla presionada, etc.), consulta en su lugar
[[Eventos_y_Acciones_es|Eventos y Acciones]].

---

## Global (Ventana Principal)

| Atajo | Acción |
|----------|--------|
| Ctrl+N | Nuevo Proyecto |
| Ctrl+O | Abrir Proyecto |
| Ctrl+S | Guardar Proyecto |
| Ctrl+Mayús+S | Guardar Proyecto Como |
| Ctrl+E | Exportar Proyecto |
| Ctrl+Q | Salir |
| Ctrl+Z | Deshacer |
| Ctrl+Y | Rehacer |
| Ctrl+X | Cortar |
| Ctrl+C | Copiar |
| Ctrl+V | Pegar |
| Ctrl+D | Duplicar |
| Ctrl+F | Buscar |
| Ctrl+H | Buscar y Reemplazar |
| F1 | Documentación |
| F5 | Probar Juego |
| F6 | Depurar Juego |
| F7 | Compilar Juego |
| F8 | Compilar y Ejecutar |

## Editor de Sprites

| Atajo | Herramienta |
|----------|------|
| P | Lápiz |
| E | Borrador |
| I | Cuentagotas |
| G | Relleno (bote de pintura) |
| L | Línea |
| R | Rectángulo |
| O | Elipse |
| S | Selección |
| Ctrl+C / Ctrl+X / Ctrl+V | Copiar / Cortar / Pegar (una selección) |
| Supr | Eliminar (una selección) |
| Esc | Deseleccionar |

Consulta [[Sprite-Editor_es|Editor de Sprites]] para saber qué hace exactamente cada herramienta.

---

## Editor de Objetos

| Atajo | Acción |
|----------|--------|
| Ctrl+S | Guarda este objeto (funciona incluso con la pestaña del editor de objetos enfocada, sin activar el Guardar de la ventana principal) |
| Ctrl+Arriba / Ctrl+Abajo | Mueve el evento seleccionado hacia arriba/abajo en la lista |
| Ctrl+C / Ctrl+V | Copiar / pegar una acción |

---

## Editor de Salas

| Atajo | Acción |
|----------|--------|
| Supr | Elimina la(s) instancia(s) seleccionada(s) |

La barra de herramientas del Editor de Salas también expone
**Cuadrícula**, **Ajuste**, **Borrar Todo** y **Desplazar Todo** —
consulta [[Editor_Salas_es|Editor de Salas]].
