Eine Referenz von PyGameMakers eigenen Bearbeitungs-Tastenkürzeln. Es
geht hier um das **Bauen Ihres Spiels in der IDE** — für die Tasten, die
Ihr *fertiges Spiel* zur Laufzeit abfragt (`keyboard_check`,
Tastendruck-Ereignisse usw.), siehe stattdessen
[[Events_und_Aktionen_de|Ereignisse und Aktionen]].

---

## Global (Hauptfenster)

| Tastenkürzel | Aktion |
|----------|--------|
| Strg+N | Neues Projekt |
| Strg+O | Projekt öffnen |
| Strg+S | Projekt speichern |
| Strg+Umschalt+S | Projekt speichern unter |
| Strg+E | Projekt exportieren |
| Strg+Q | Beenden |
| Strg+Z | Rückgängig |
| Strg+Y | Wiederholen |
| Strg+X | Ausschneiden |
| Strg+C | Kopieren |
| Strg+V | Einfügen |
| Strg+D | Duplizieren |
| Strg+F | Suchen |
| Strg+H | Suchen und Ersetzen |
| F1 | Dokumentation |
| F5 | Spiel testen |
| F6 | Spiel debuggen |
| F7 | Spiel erstellen |
| F8 | Erstellen und Ausführen |

## Sprite-Editor

| Tastenkürzel | Werkzeug |
|----------|------|
| P | Stift |
| E | Radiergummi |
| I | Pipette |
| G | Füllen (Eimer) |
| L | Linie |
| R | Rechteck |
| O | Ellipse |
| S | Auswahl |
| Strg+C / Strg+X / Strg+V | Kopieren / Ausschneiden / Einfügen (einer Auswahl) |
| Entf | Löschen (einer Auswahl) |
| Esc | Auswahl aufheben |

Siehe [[Sprite-Editor_de|Sprite-Editor]] für die genaue Funktion jedes Werkzeugs.

---

## Objekt-Editor

| Tastenkürzel | Aktion |
|----------|--------|
| Strg+S | Speichert dieses Objekt (funktioniert auch, wenn der Objekt-Editor-Tab fokussiert ist, ohne das Speichern des Hauptfensters auszulösen) |
| Strg+Hoch / Strg+Runter | Verschiebt das ausgewählte Ereignis in der Liste nach oben/unten |
| Strg+C / Strg+V | Eine Aktion kopieren / einfügen |

---

## Raum-Editor

| Tastenkürzel | Aktion |
|----------|--------|
| Entf | Löscht die ausgewählte(n) Instanz(en) |

Die Symbolleiste des Raum-Editors bietet zusätzlich **Raster**,
**Einrasten**, **Alles löschen** und **Alles verschieben** — siehe
[[Raum_Editor_de|Raum-Editor]].
