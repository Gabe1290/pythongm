### Draw
| Свойство | Значение |
|----------|----------|
| **Имя** | `draw` |
| **Иконка** | 🎨 |
| **Категория** | Рисование |
| **Пресет** | Начинающий |

**Описание:** Срабатывает во время фазы рендеринга.

**Важно:** Добавление события Draw отключает автоматическое рисование спрайта. Вы должны рисовать спрайт вручную, если хотите, чтобы он был виден.

**Типичные использования:**
- Пользовательский рендеринг
- Рисование фигур
- Отображение текста
- Полосы здоровья
- Элементы интерфейса

**Доступные действия рисования:**
- Draw Sprite
- Draw Text
- Draw Rectangle
- Draw Circle
- Draw Line
- Draw Health Bar

---

### Draw GUI
| Свойство | Значение |
|----------|----------|
| **Имя** | `draw_gui` |
| **Иконка** | 🖥️ |
| **Категория** | Рисование |
| **Пресет** | Начинающий |

**Описание:** Рисует в **экранном пространстве (GUI)**, поверх комнаты, и не зависит от прокрутки видов/камеры.

**Отличие от Draw:** обычное событие Draw работает в координатах комнаты (прокручивается вместе с видом); Draw GUI остаётся зафиксированным на экране — используйте его для HUD, счёта и меню.
