## [2026-10-04] User

> when running the raycast games, is it possible to have written text or signs on the walls like for naming certain corridors

### Claude

Yes — the easiest way today is a **billboard sign**: drop a non-solid instance with a sprite that has your corridor name drawn into it (e.g. "WEST WING") near the wall. The raycast renderer already draws any non-solid sprited instance as a camera-facing, distance-scaled, properly-occluded billboard, so this works with zero engine changes — just author the sprite and place the instance in the room editor.

What *isn't* supported is actual text painted onto the wall texture itself, perspective-mapped like the walls are — wall texturing is one global `wall_texture` setting per room (`extensions/raycast_2_5d/renderer.py`), not per-wall-cell, so you can't currently give just one wall segment a different "sign" texture. Doing that properly would mean extending wall rendering to support per-instance textures across all three renderers (desktop, HTML5, Kivy) to keep parity — a bigger change, not something to take on unless the billboard approach doesn't look right for your use case.
