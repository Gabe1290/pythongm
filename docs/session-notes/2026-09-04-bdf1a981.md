## [2026-09-04] User

> The terminal in VS Code shows white text on white background. How do I fix that?

### Claude

Almost always this is a theme/contrast issue in VS Code itself, not your shell. Try these in order:

## 1. Reset the color theme
`Ctrl+K Ctrl+T` → pick **Dark Modern** (or **Light Modern**). A half-loaded or broken theme extension is the most common cause — the terminal falls back to unstyled colors that collide with the background.

## 2. Restore the contrast auto-fix
VS Code normally auto-adjusts unreadable terminal colors. If someone lowered it, put it back in `settings.json`:
```json
"terminal.integrated.minimumContrastRatio": 4.5
```
Setting this to `7` forces even more aggressive correction — a good quick test.

## 3. Force terminal colors explicitly
If the theme is fine elsewhere but the terminal is still bad:
```json
"workbench.colorCustomizations": {
  "terminal.background": "#1e1e1e",
  "terminal.foreground": "#d4d4d4",
  "terminalCursor.foreground": "#ffffff"
}
```

## 4. If only *some* output is invisible (e.g. pytest, git, ls)
That's a program emitting ANSI colors assuming a dark background. Fix the specific palette entries instead:
```json
"workbench.colorCustomizations": {
  "terminal.ansiWhite": "#cccccc",
  "terminal.ansiBrightWhite": "#ffffff"
}
```
Or neutralize it at the source: `export NO_COLOR=1` / `alias ls='ls --color=never'`.

## 5. Rendering glitch (text truly invisible until selected)
```json
"terminal.integrated.gpuAcceleration": "off"
```

Start with #1 and #2 — that resolves it the vast majority of the time.
