## [2026-08-11] User

> is it possible in a .md file to have anchors like in .html files?

### Claude

Yes — GitHub-flavored Markdown (and most renderers) support anchors two ways:

1. **Auto-generated anchors from headings.** Any `## Some Heading` gets an implicit anchor slug, usually lowercase-with-hyphens (e.g. `## My Section` → `#my-section`). GitHub's slugger keeps accented/unicode characters as-is (you've hit this directly in the wiki work — `## Časovni Dogodki` → `#časovni-dogodki`).

2. **Explicit HTML anchors.** You can drop a raw `<a id="some-name"></a>` tag right in the Markdown (Markdown renderers pass through inline HTML), then link to it with `[text](#some-name)`. This is what `tools/gen_action_reference.py` does before each category header so `#3d-view`-style links survive translated headings.

The landmine from the wiki work: don't add an ASCII `<a id>` next to a heading whose text is already accented — GitHub's auto-slug preserves the accents, so the auto-generated anchor already matches an accented ToC link, and adding a redundant ASCII id just creates a second, unused anchor.
