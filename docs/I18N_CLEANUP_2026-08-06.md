# i18n cleanup: propagate the 2026-08-06 doc-accuracy fixes + dead-file removal

Companion registry to `docs/AI_SLOP_CLEANUP_2026-08-06.md`. That pass fixed
English and French; this one is the queue for the other 7 supported
languages (de/it/es/pt/sl/uk/ru), plus a narrow dead-file cleanup found
along the way. See `CLAUDE.md`'s session notes for the full narrative of
what was found/fixed in EN/FR — this doc only tracks the propagation work.

**Read before starting any section:** the AI_SLOP registry's own Update
12 lesson applies here too — a docstring or one grep is not verification;
trace real call sites and check `tools/action_ref_i18n.py` (the
authoritative source for what a translated action/event name should read)
before writing a translated technical claim.

## Update 1 (2026-08-06) — registry created, scope decided

User chose the maximal scope: wiki pages + sample READMEs + in-app
Tutorials HTML, all 7 languages. Given the true size (147 wiki-page
updates + 119 net-new sample guides + 6 curriculum refreshes + 1 curriculum
built from scratch), this is a multi-session roadmap. This session's own
deliverable is: this registry, Section G (dead files), Section H (pt/ja/zh
compilation), and Section I (generator-covered pages, all 7 languages).
Sections J/K/L are queued for future sessions, worked language-by-language,
one unit per commit.

**Key inventory facts** (full detail in the planning session's Explore
agent reports, not reproduced here):
- wiki/: all 147 files (21 pages × 7 languages) already exist — this is a
  content-update job, not file creation. 6 pages use transliterated slugs
  instead of `_<lang>` suffixes (Getting-Started, Creating-Your-First-Game,
  Events-and-Actions, Visual-Programming, Object-Editor, Room-Editor) —
  same pattern French already uses (e.g. `Demarrage_fr.md`).
- samples/\*/README.\<lang\>.md: 0/119 exist for the 7 languages.
- Tutorials/\<lang\>/: de/es/it/ru/sl/uk have a real, correctly-indexed
  8-lesson/57-file curriculum (verified byte-for-byte against each
  language's own `index.json` — not orphaned, just missing the
  `09_catch_the_coins` lesson EN/FR got in the "progressive play-early"
  rewrite, commit `f1c8d42`). `Tutorials/pt/` doesn't exist at all.
- `tools/action_ref_i18n.py`'s `LANGS` table already has complete
  `chrome`/`categories`/`types`/`actions`/`notes` for all 7 languages —
  only `events` (this session's addition, `EVENTS_FR`) is French-only.
