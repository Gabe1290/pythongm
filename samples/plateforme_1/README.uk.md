# Платформер — Рівень 1

Мінімальний бічний скролінг-платформер, імпортований з GameMaker 8.x
(`samples/plateforme_1.gmk`). М'ячик, керований гравцем
(`obj_balle`), піднімається одним екраном цегляних платформ
(`obj_brique`), використовуючи проби `if_collision` у стилі
GameMaker для руху кроками 4px/кадр і падає під дією гравітації
лише тоді, коли безпосередньо під ним немає нічого твердого — схема
руху AABB, написана вручну, а не вбудована фізика рушія.

**Куди це вписується:** частина родини `plateforme_*`, але у своєму
мінімумі — на відміну від `plateforme_2`/`plateforme_3`, цей рівень
не має фонового зображення й **не має тайлового фону** (масив `tiles`
кімнати порожній); побудований лише з GameObjects + спрайтів, так
само як `maze_1`. Див.
[`../README.md`](../README.md#progression-how-each-family-is-built-not-just-how-it-plays)
щодо порівняння всієї родини з `maze_*` і `match3_*`.

**Звук і музика:** відсутні — жодного звукового файлу не додано до цього зразка.

## Як грати

- **Стрілка ліворуч / праворуч** — рухає м'ячик на 4px за натискання
  клавіші, заблоковано твердою цеглою.
- **Стрілка вгору** — стрибок (встановлює `vspeed` на -10), лише
  стоячи на твердій цеглині.
- У цьому рівні немає явного об'єкта цілі, монети чи виходу — це
  вертикальний цегляний лабіринт для підйому. Також немає об'єкта
  монстра/небезпеки, тому немає умови програшу; це вільне
  дослідження механіки зіткнення/гравітації.

## Структура проєкту

| Файл | Призначення |
|---|---|
| `project.json` | Маніфест проєкту — налаштування вікна/кімнати, вбудовані копії ресурсів (див. примітку нижче). |
| `rooms/niveau_01.json` | Єдина кімната: 800×640, 120 екземплярів (переважно стіни/платформи `obj_brique` плюс одна `obj_balle`). |
| `objects/obj_balle.json` | Логіка м'ячика гравця (рух, гравітація, стрибок). |
| `objects/obj_brique.json` | Статична тверда цегла, без подій. |
| `sprites/` | `spr_balle.png` (м'ячик) і `spr_32x32_noir.png` (цегла), кожен зі своїм супутнім файлом `.json`. |

`objects/*.json` і `rooms/niveau_01.json` — поточні бічні файли для
кожного ресурсу; їхній вміст відповідає тому, що вбудовано в
`project.json` для цього зразка (розбіжностей не виявлено), але за
конвенцією репозиторію бічні файли — джерело істини, якщо вони колись
розійдуться.

## Об'єкти

| Об'єкт | Роль | Ключові події |
|---|---|---|
| `obj_balle` | М'ячик, керований гравцем; гравітація, рух з урахуванням зіткнень, стрибок | create (нічого не визначено), step, collision_with_obj_brique, keyboard (left, right, up) |
| `obj_brique` | Статична тверда платформа/плитка стіни | *(немає — жодних визначених подій)* |

## Ресурси

2 спрайти (`spr_balle`, `spr_32x32_noir`), 0 звуків. Обидва спрайти —

## Що можна налаштувати

- Подія step `obj_balle`: гравітація становить `0.45` px/кадр², а
  vspeed обмежений `24` — підвищіть/знизьте будь-яке для зміни ваги
  падіння та кінцевої швидкості.
- Імпульс стрибка — фіксований `vspeed = -10` (клавіатура "вгору")
  — більша величина стрибає вище.
- Крок горизонтального руху становить `4` px на натискання клавіші
  (клавіатура "ліворуч"/"праворуч") — більші кроки відчуваються
  чутливіше, але можуть проходити крізь тонкі проміжки.
- Кімната має розмір 800×640 при `room_speed: 30`; макет цегли в
  `rooms/niveau_01.json` можна вільно переупорядковувати, оскільки
  `obj_brique` не має власної логіки.
