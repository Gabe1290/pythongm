# Сокровище

Погоня в лабиринте в стиле Pac-Man: **исследователь** блуждает по
лабиринту, ограниченному стенами, собирая **очки сокровища**,
преследуемый **монстрами**, выбирающими новое направление на каждом
перекрёстке. Схватите **таблетку силы** (`pil`), и стол
переворачивается — каждый монстр становится **напуганным** и может
быть съеден за бонусные очки, пока эффект не пройдёт. Это родной
проект pygm2, импортированный из `treasure.gmk` (GameMaker 8.x); сам
проект написан/сохранён в собственном формате JSON pygm2.

**Куда это вписывается:** `treasure` располагается рядом с семьёй
`maze_*` — построен с GameObjects + встроенными действиями и
визуальным редактором событий — но добавляет **скрипт на уровне
проекта** (`adapt_direction`, ИИ монстра на перекрёстках) и цикл
состояний в стиле GM **"погоня / усиление / бегство"** через свои
объекты. Он был одним из двух образцов, удалённых в rc.12 из-за
ошибок импорта GMK, и **возвращён после укрепления импортера**
(16.07.2026); см.
[`../../docs/GMK_IMPORTER_HARDENING_PLAN.md`](../../docs/GMK_IMPORTER_HARDENING_PLAN.md)
и [`../../docs/treasure_testing_pass.md`](../../docs/treasure_testing_pass.md).

**Звук и музыка:** добавлены 6 звуковых эффектов (подбор, таблетка
силы, поедание-монстра, смерть, …). Одна устаревшая дорожка эпохи
GM8 (`music`) находится в формате, который pygame не может
загрузить, и пропускается во время выполнения — так же, как фоновая
музыка в других образцах лабиринта; игра не пострадала.

## Как играть

- **Клавиши со стрелками** перемещают исследователя через лабиринт;
  стены блокируют движение.
- Соберите каждое **очко сокровища**, чтобы завершить уровень
  (всего 4 комнаты).
- **Монстры** преследуют вас; касание одного обычно стоит жизни.
- Схватите **таблетку силы**, и монстры становятся **напуганными**
  (их спрайт меняется) на несколько секунд — прикоснитесь тогда к
  напуганному монстру, чтобы **съесть** его (+очки; он телепортируется
  обратно к своему началу как обычный монстр). Эффект проходит после
  таймера.

## ИИ монстра (скрипт `adapt_direction`)

Каждый монстр вызывает скрипт проекта `adapt_direction` из своих
событий step/столкновения. Это настоящий Python код pygm2 — на
потенциальном перекрёстке он случайно рассматривает поворот, проверяя
`game.check_collision_at_position(...)` на предмет стены перед тем,
как совершить шаг, поэтому монстры блуждают по лабиринту, а не бегают
по прямой. Откройте ресурс **Scripts**, чтобы прочитать его; действие
`execute_script` в событиях монстра показывает, где он вызывается.

## Структура проекта

| Файл | Назначение |
|---|---|
| `project.json` | Манифест — настройки окна/комнаты, встроенные ресурсы, скрипт `adapt_direction`, и порядок комнат |
| `rooms/room0..3.json` | Четыре уровня лабиринта (экземпляры по комнатам) |
| `objects/*.json` | 7 определений объектов (источник истины; объединяется со встроенными копиями при загрузке) |
| `sprites/` | 10 файлов спрайтов PNG + метаданные `.json` |
| `sounds/` | 6 звуковых эффектов |
| `backgrounds/` | 1 фон |
| `CREDITS.txt` | Уведомление о лицензировании ресурсов |

## Объекты

| Объект | Роль |
|---|---|
| `explorer` | Персонаж игрока; собирает сокровища, съедает напуганных монстров, умирает при контакте с обычными |
| `monster` | Преследователь; блуждает через `adapt_direction`; превращается в `scared` с таблеткой силы |
| `scared` | Монстр в состоянии бегства; съедобен; возвращается в `monster` после таймера |
| `pil` | Таблетка силы — пугает каждого монстра при сборе |
| `point` | Сокровище для сбора |
| `bonus` | Дополнительный предмет для сбора |
| `wall` | Статичная твёрдая стена лабиринта |

## Ресурсы

10 спрайтов, 6 звуков, 1 фон — всё импортировано из `treasure.gmk`.
О происхождении см. `CREDITS.txt` и

## Что можно настроить

- **Продолжительность страха** — тревога таблетки силы составляет
  `160` шагов в событии `collision_with_pil` `explorer`; увеличьте её
  для более долгой фазы бегства.
- **Вероятность поворота монстра** — проверки `random.random() * 3 <
  1` в скрипте `adapt_direction` определяют, как часто монстры
  поворачивают на перекрёстке.
- **Значения очков** — очки сокровища и поедания-монстра — это
  действия `set_score` (относительные) в соответствующих событиях
  столкновения.

## Повторная генерация из оригинала `.gmk`

Сопутствующий файл `../treasure.gmk` — источник GameMaker 8.x. Для повторной генерации:

```bash
python3 -c "from importers.gmk_importer import import_gmk_detailed; \
  import_gmk_detailed('samples/treasure.gmk', '/tmp/treasure_reimport')"
```

Свежий импорт точен к оригинальной игре после укрепления импортера в
июле 2026 (никаких ручных исправлений к этому образцу не применено).
