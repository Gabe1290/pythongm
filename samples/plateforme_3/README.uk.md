# Платформер — Рівень 3

Бічний скролінг-платформер, імпортований з GameMaker 8.x
(`samples/plateforme_3.gmk`). Це найбільший з трьох зразків
платформера з великим відривом: 2 об'єкти (plateforme_1) → 4 об'єкти
(plateforme_2) → **15 об'єктів** тут, додаючи наземних і літаючих
монстрів, що патрулюють (з вбивством стрибком-на-голову та
варіантами трупа/плями, породжуваними під час виконання), невидиму
небезпеку миттєвої смерті, два типи предметів для збору, та об'єкт
виходу, що переходить до наступної кімнати або показує таблицю
найкращих результатів і перезапускає гру.

**Куди це вписується:** частина родини `plateforme_*` — як
`plateforme_2`, використовує **тайловий фон** (125 шматків плиток під
твердими об'єктами цегли, плюс градієнтне зображення `fond_degrade`),
крок, який ця родина додає понад `maze_*`. Див.
[`../README.md`](../README.md#progression-how-each-family-is-built-not-just-how-it-plays)
для повного прогресу.

**Звук і музика:** 4 звукові файли, по-справжньому підключені: 7
місць виклику `play_sound` для `son_bonus` (підбір),
`son_monstre_mort` (вбивство стрибком), `son_personnage_mort` (смерть
гравця), і `son_niveaufini` (завершення рівня).

## Як грати

- **Стрілка ліворуч / праворуч** — рухає Пінгуса (`obj_pingus`)
  ліворуч/праворуч.
- **Стрілка вгору** — стрибок, але лише стоячи на чомусь твердому
  (перевіряється на один піксель нижче гравця).
- **Мета** — зберіть предмети `obj_bonus` (+5 очок) і `obj_power`
  (+20 очок), перетинаючи `niveau_01`, щоб досягти `obj_sortie`;
  дотик до нього відтворює мелодію й або переходить до наступної
  кімнати (жодної не існує в цьому зразку, тому падає до гілки
  найкращого-результату/перезапуску), або показує таблицю найкращих
  результатів і перезапускає гру.
- **Монстри** — приземлення зверху на `obj_monstre` чи
  `obj_monstre_volant` (`vspeed > 0` і над монстром) вбиває його й
  приносить 50 очок; удар по ньому збоку чи знизу коштує життя й
  перезапускає кімнату. Примітка: зіткнення з `obj_monstre_volant`
  не має ефекту (літаючий монстр не може завдати шкоди чи бути
  вбитим), доки не зібрано `obj_power` — див. Що можна налаштувати.
- **Умова програшу** — дотик до `obj_mortel` (невидима зона
  миттєвої смерті) чи неправильний дотик до монстра коштує життя й
  перезапускає кімнату; закінчення життів (`no_more_lives`) показує
  таблицю найкращих результатів і перезапускає всю гру. Початкові
  життя: 3 (налаштування `project.json`).

## Структура проєкту

| Файл | Призначення |
| --- | --- |
| `project.json` | Маніфест проєкту — налаштування вікна/кімнати, вбудовані копії ресурсів. |
| `rooms/niveau_01.json` | Єдина кімната: 800×640, 194 екземпляри + 125 плиток фону. Джерело істини для вмісту кімнати (вбудований список `instances` `project.json` порожній, той самий шаблон, що й у plateforme_2). |
| `objects/*.json` | Бічні файли для всіх 15 об'єктів; на момент написання ідентичні вбудованим копіям `project.json` (перевірено побайтно, на відміну від файлу кімнати plateforme_2). |
| `sprites/` | 18 спрайт-ресурсів (стрічки ходьби/польоту, спрайти смерті, платформенні блоки, предмети для збору, вихід, маркер). |
| `sounds/` | 4 звукові ефекти (смерть монстра, смерть гравця, підбір бонусу, завершення рівня). |
| `backgrounds/` | Сніговий набір тайлів (`tuiles_neige.png`, джерело автотайлу для 125 плиток кімнати) і вертикальний градієнт (`fond_degrade.png`) як фон кімнати. |
| `CREDITS.txt` | Повідомлення про ліцензування мистецтва спрайтів/фону (див. Ресурси нижче). |

## Об'єкти

15 об'єктів, згруповані за роллю. Показано кількість розміщень у
кімнаті (з 194 екземплярів), де об'єкт з'являється в `niveau_01`;
об'єкти "породжені під час виконання" з'являються лише через
`change_instance` під час гри.

| Об'єкт | Роль | Ключові події |
| --- | --- | --- |
| `obj_pingus` | Гравець — рух, стрибок, гравітація, вся обробка зіткнень/програшу/перемоги | create, step, keyboard (left/right/up), keyboard_release, collision_with_obj_brique/obj_monstre/obj_monstre_volant/obj_mortel/obj_bonus/obj_power/obj_sortie/obj_marqueur, game_start, no_more_lives |
| `obj_brique` | Базовий твердий платформенний блок, 32×32 (109 розміщено) | немає (лише прапорець solid) |
| `obj_brique_h` | Широкий варіант платформи, 32×16, дитина `obj_brique` (15 розміщено) | немає |
| `obj_brique_v` | Вузький варіант платформи, 16×32, дитина `obj_brique`; визначена, але не розміщена в `niveau_01` | немає |
| `obj_brique_c` | Малий варіант платформи, 16×16, дитина `obj_brique` (1 розміщено) | немає |
| `obj_monstre` | Наземний монстр — патрулює ліворуч/праворуч, розвертається при контакті зі стіною (3 розміщено) | create, collision_with_obj_brique |
| `obj_monstre_mort` | Труп монстра, породжений під час виконання після вбивства стрибком; успадковує `obj_brique` (стає твердою сходинкою) | create |
| `obj_monstre_volant` | Літаючий монстр — патрулює праворуч, відскакує від стін (2 розміщено) | create, collision_with_obj_brique |
| `obj_monstre_volant_mort` | Труп літаючого монстра, породжений під час виконання; падає з обмеженою гравітацією, приземляється на платформах/маркерах | step, collision_with_obj_brique, collision_with_obj_marqueur |
| `obj_mortel` | Невидима зона небезпеки миттєвої смерті (4 розміщено) | немає (обробляється з події зіткнення `obj_pingus`) |
| `obj_splat` | Анімація смерті гравця, породжена під час виконання, перезапускає кімнату наприкінці анімації | create, animation_end |
| `obj_bonus` | Малий предмет для збору, +5 очок, випадковий кадр очікування (52 розміщено) | create |
| `obj_power` | Великий предмет для збору, +20 очок; також визначає, чи можуть літаючі монстри завдавати шкоди/бути вбитими (1 розміщено) | create |
| `obj_sortie` | Вихід рівня — відтворює мелодію, потім наступна кімната або найкращий результат + перезапуск (1 розміщено) | немає (обробляється з події зіткнення `obj_pingus`) |
| `obj_marqueur` | Невидимий, нетвердий маркер дизайну кімнати; зіткнення явно не мають ефекту (5 розміщено) | немає |

## Ресурси

18 спрайтів, 4 звуки, 2 фони. Мистецтво спрайтів/фону адаптоване з
проєкту Pingus (GPL-3.0-or-later) — див. `CREDITS.txt` для повної
вказівки авторства та умов ліцензії; цей README не повторює й не
додає до цих тверджень.

## Що можна налаштувати

- Тест стрибка-на-голову `obj_pingus` проти `obj_monstre`/
  `obj_monstre_volant` раніше був `vspeed > 0 and y < other.y+8`, що
  міг перевищити швидке падіння (вікно 8px перевірялося відносно
  позиції *після руху*) і коштувати життя за начебто чистого
  стрибка. Тепер це `vspeed > 0 and y - vspeed < other.y+8`, що
  перевіряє вікно відносно позиції перед рухом натомість.
- Підбір `obj_power` тихо визначає всю взаємодію з
  `obj_monstre_volant` (через `if_object_exists(obj_power,
  not_flag=true)` навколо логіки стрибка/смерті в `obj_pingus`) —
  варто зробити це видимим для гравців (наприклад, зміна
  спрайту/палітри), а не невидиме правило.
- Горизонтальна швидкість гравця фіксована `hspeed = 4`; імпульс
  стрибка становить `vspeed = -10`; гравітація падіння становить
  `0.5` з обмеженням кінцевої швидкості `vspeed = 24`.
- Розмір кімнати — 800×640 при `room_speed = 30`.
