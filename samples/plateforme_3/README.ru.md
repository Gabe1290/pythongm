# Платформер — Уровень 3

Боковой скролл-платформер, импортированный из GameMaker 8.x
(`samples/plateforme_3.gmk`). Это самый большой из трёх образцов
платформера с большим отрывом: 2 объекта (plateforme_1) → 4 объекта
(plateforme_2) → **15 объектов** здесь, добавляя наземных и летающих
монстров, патрулирующих (с убийством прыжком-на-голову и вариантами
трупа/пятна, порождаемыми во время выполнения), невидимую опасность
мгновенной смерти, два типа предметов для сбора, и объект выхода,
переходящий к следующей комнате или показывающий таблицу лучших
результатов и перезапускающий игру.

**Куда это вписывается:** часть семьи `plateforme_*` — как
`plateforme_2`, использует **тайловый фон** (125 кусков плиток под
твёрдыми объектами кирпича, плюс градиентное изображение
`fond_degrade`), шаг, который эта семья добавляет сверх `maze_*`. См.
[`../README.md`](../README.md#progression-how-each-family-is-built-not-just-how-it-plays)
для полного прогресса.

**Звук и музыка:** 4 звуковых файла, по-настоящему подключены: 7
мест вызова `play_sound` для `son_bonus` (подбор), `son_monstre_mort`
(убийство прыжком), `son_personnage_mort` (смерть игрока), и
`son_niveaufini` (завершение уровня).

## Как играть

- **Стрелка влево / вправо** — двигает Пингуса (`obj_pingus`)
  влево/вправо.
- **Стрелка вверх** — прыжок, но только стоя на чём-то твёрдом
  (проверяется на один пиксель ниже игрока).
- **Цель** — соберите предметы `obj_bonus` (+5 очков) и `obj_power`
  (+20 очков), пересекая `niveau_01`, чтобы достичь `obj_sortie`;
  касание его воспроизводит мелодию и либо переходит к следующей
  комнате (ни одной не существует в этом образце, поэтому падает в
  ветку лучшего-результата/перезапуска), либо показывает таблицу
  лучших результатов и перезапускает игру.
- **Монстры** — приземление сверху на `obj_monstre` или
  `obj_monstre_volant` (`vspeed > 0` и над монстром) убивает его и
  приносит 50 очков; удар по нему сбоку или снизу стоит жизни и
  перезапускает комнату. Примечание: столкновение с
  `obj_monstre_volant` не имеет эффекта (летающий монстр не может
  нанести урон или быть убитым), пока не собран `obj_power` — см.
  Что можно настроить.
- **Условие проигрыша** — касание `obj_mortel` (невидимая зона
  мгновенной смерти) или неправильное касание монстра стоит жизни и
  перезапускает комнату; закончившиеся жизни (`no_more_lives`)
  показывают таблицу лучших результатов и перезапускают всю игру.
  Начальные жизни: 3 (настройки `project.json`).

## Структура проекта

| Файл | Назначение |
| --- | --- |
| `project.json` | Манифест проекта — настройки окна/комнаты, встроенные копии ресурсов. |
| `rooms/niveau_01.json` | Единственная комната: 800×640, 194 экземпляра + 125 плиток фона. Источник истины для содержимого комнаты (встроенный список `instances` `project.json` пуст, тот же шаблон, что и у plateforme_2). |
| `objects/*.json` | Боковые файлы для всех 15 объектов; на момент написания идентичны встроенным копиям `project.json` (проверено побайтно, в отличие от файла комнаты plateforme_2). |
| `sprites/` | 18 спрайт-ресурсов (ленты ходьбы/полёта, спрайты смерти, платформенные блоки, предметы для сбора, выход, маркер). |
| `sounds/` | 4 звуковых эффекта (смерть монстра, смерть игрока, подбор бонуса, завершение уровня). |
| `backgrounds/` | Снежный набор тайлов (`tuiles_neige.png`, источник автотайла для 125 плиток комнаты) и вертикальный градиент (`fond_degrade.png`) как фон комнаты. |
| `CREDITS.txt` | Уведомление о лицензировании искусства спрайтов/фона (см. Ресурсы ниже). |

## Объекты

15 объектов, сгруппированных по роли. Показано количество размещений
в комнате (из 194 экземпляров), где объект появляется в `niveau_01`;
объекты "порождённые во время выполнения" появляются только через
`change_instance` во время игры.

| Объект | Роль | Ключевые события |
| --- | --- | --- |
| `obj_pingus` | Игрок — движение, прыжок, гравитация, вся обработка столкновений/проигрыша/победы | create, step, keyboard (left/right/up), keyboard_release, collision_with_obj_brique/obj_monstre/obj_monstre_volant/obj_mortel/obj_bonus/obj_power/obj_sortie/obj_marqueur, game_start, no_more_lives |
| `obj_brique` | Базовый твёрдый платформенный блок, 32×32 (109 размещено) | нет (только флаг solid) |
| `obj_brique_h` | Широкий вариант платформы, 32×16, дочерний объект `obj_brique` (15 размещено) | нет |
| `obj_brique_v` | Узкий вариант платформы, 16×32, дочерний объект `obj_brique`; определён, но не размещён в `niveau_01` | нет |
| `obj_brique_c` | Малый вариант платформы, 16×16, дочерний объект `obj_brique` (1 размещён) | нет |
| `obj_monstre` | Наземный монстр — патрулирует влево/вправо, разворачивается при контакте со стеной (3 размещены) | create, collision_with_obj_brique |
| `obj_monstre_mort` | Труп монстра, порождаемый во время выполнения после убийства прыжком; наследует `obj_brique` (становится твёрдой ступенькой) | create |
| `obj_monstre_volant` | Летающий монстр — патрулирует вправо, отскакивает от стен (2 размещены) | create, collision_with_obj_brique |
| `obj_monstre_volant_mort` | Труп летающего монстра, порождаемый во время выполнения; падает с ограниченной гравитацией, приземляется на платформах/маркерах | step, collision_with_obj_brique, collision_with_obj_marqueur |
| `obj_mortel` | Невидимая зона опасности мгновенной смерти (4 размещены) | нет (обрабатывается из события столкновения `obj_pingus`) |
| `obj_splat` | Анимация смерти игрока, порождаемая во время выполнения, перезапускает комнату в конце анимации | create, animation_end |
| `obj_bonus` | Малый предмет для сбора, +5 очков, случайный кадр ожидания (52 размещены) | create |
| `obj_power` | Крупный предмет для сбора, +20 очков; также определяет, могут ли летающие монстры наносить урон/быть убитыми (1 размещён) | create |
| `obj_sortie` | Выход уровня — воспроизводит мелодию, затем следующая комната или лучший результат + перезапуск (1 размещён) | нет (обрабатывается из события столкновения `obj_pingus`) |
| `obj_marqueur` | Невидимый, нетвёрдый маркер дизайна комнаты; столкновения явно не имеют эффекта (5 размещены) | нет |

## Ресурсы

18 спрайтов, 4 звука, 2 фона. Искусство спрайтов/фона адаптировано из
проекта Pingus (GPL-3.0-or-later) — см. `CREDITS.txt` для полного
указания авторства и условий лицензии; этот README не повторяет и не
добавляет к этим утверждениям.

## Что можно настроить

- Тест прыжка-на-голову `obj_pingus` против `obj_monstre`/
  `obj_monstre_volant` ранее был `vspeed > 0 and y < other.y+8`, что
  мог превысить быстрое падение (окно 8px проверялось относительно
  позиции *после движения*) и стоить жизни за якобы чистый прыжок.
  Теперь это `vspeed > 0 and y - vspeed < other.y+8`, что проверяет
  окно относительно позиции перед движением вместо этого.
- Подбор `obj_power` тихо определяет всё взаимодействие с
  `obj_monstre_volant` (через `if_object_exists(obj_power,
  not_flag=true)` вокруг логики прыжка/смерти в `obj_pingus`) —
  стоило бы сделать это видимым для игроков (например, изменение
  спрайта/палитры), а не невидимое правило.
- Горизонтальная скорость игрока фиксирована `hspeed = 4`; импульс
  прыжка составляет `vspeed = -10`; гравитация падения составляет
  `0.5` с ограничением конечной скорости `vspeed = 24`.
- Размер комнаты — 800×640 при `room_speed = 30`.

## Статус экспорта

Этот образец указан в списке `SAMPLES` `tools/smoke_run_samples.py`,
поэтому при каждом запуске этого набора он получает безголовый
smoke-проход (настоящий игровой цикл запускается на ~180 кадров со
встроенным вводом клавиатуры). Проверки для конкретной цели экспорта
(Kivy/HTML5) для этого образца не выполнялось. Выставлено на вкладке
Welcome редактора как "Platform — Level 3" (`widgets/welcome_tab.py`).
