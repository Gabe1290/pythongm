# Лабіринт — Рівень 2

Гра-лабіринт у сітці з видом зверху з двома ігровими лабіринтами
плюс титульним екраном: збирайте цукерки для очок, потім досягайте
виходу, щоб перейти далі. Це розбудовує цикл лабіринт/ціль з однією
кімнатою з `maze_1` за допомогою стартового екрана, предмета для
збору (цукерка за очки) та замкнених дверей, що відкриваються лише
після того, як усі цукерки в кімнаті зібрано. Це рідний проєкт pygm2
(без супутнього файлу `.gmk` — його ресурси були спочатку принесені
через імпорт GameMaker 8.x, згідно з `CREDITS.txt`, але сам проєкт
написаний/збережений у власному форматі JSON pygm2).

**Куди це вписується:** частина родини `maze_*` — GameObjects +
спрайти, плюс (на відміну від `maze_1`) статичне **фонове
зображення** на кожну кімнату (`background_main`), без плиток на
рівні кімнати. Див.
[`../README.md`](../README.md#progression-how-each-family-is-built-not-just-how-it-plays)
щодо порівняння з `plateforme_*` (додає тайлові фони) та `match3_*`
(чистий скрипт, без вбудованих дій).

**Звук і музика:** додано 4 звукові файли (`sound_background.ogg`,
`sound_diamond`/`door`/`goal.wav`), але **жоден з них насправді не
підключений** — жоден об'єкт ніде не посилається на
`play_sound`/`play_music`, тому гра насправді безмовна, попри
наявність аудіоресурсів. (На відміну від `maze_3`, де такий самий за
формою набір звуків справді відтворюється.)

## Як грати

- **Титульний екран (`room_start`):** натисніть **ПРОБІЛ**, щоб
  почати (дія `keyboard_press` об'єкта `controller_start` викликає
  `next_room`).
- **Клавіші зі стрілками** (вгору/вниз/ліворуч/праворуч) переміщують
  гравця на одну клітинку сітки (32px) за раз; рух прив'язаний до
  сітки через `test_alignment`/`snap_to_grid` (сітка 32×32), той
  самий шаблон, що й `maze_1`.
- **Мета:** зберіть цукерки (`obj_diamond`, спрайт `sprite_bonbon`),
  розкидані по кожному лабіринту — кожна варта +10 очок — потім
  досягніть цілі (`obj_goal`). У `room2` вихід додатково заблоковано
  замкненими дверима (`obj_door`), які самознищуються лише коли
  зникає кожна `obj_diamond` у кімнаті.
- Дотик до цілі переводить до наступної кімнати (+100 очок), якщо
  вона існує; дотик у останній кімнаті (`room2`) присуджує +100,
  відкриває екран введення найкращого результату, і завершує гру.
- **Без умови програшу:** у об'єктах цього зразка ніде не з'являється
  дія, що впливає на життя/здоров'я — `starting_lives: 3`
  встановлено в налаштуваннях проєкту, але ніколи не відображається й
  не зменшується.

## Структура проєкту

| Файл | Призначення |

| `rooms/room_start.json` | Титульний екран — 1 екземпляр (`controller_start`) |
| `rooms/room1.json` | Перший лабіринт — 134 екземпляри (стіни, гравець, ціль, 4 цукерки, `controller_main`) |
| `rooms/room2.json` | Другий лабіринт — 112 екземплярів (стіни, гравець, ціль, 21 цукерка, замкнені двері, `controller_main`) |
| `objects/*.json` | 9 визначень об'єктів — перевірено відносно вбудованих копій `project.json` й ідентичні в цьому зразку (застарілості не виявлено) |
| `sprites/` | 7 спрайтів (`sprite_person`, `sprite_bonbon`, `sprite_door`, `sprite_goal`, `sprite_wall_corner`, `sprite_wall_horizontal`, `sprite_wall_vertical`) + метадані; `tiles.json` — осиротілий бічний файл (не зареєстрований у `project.json`, файл зображення відсутній — не використовується) |
| `backgrounds/` | `background_start.png` (титульний екран), `background_tiles.png` (тайлована підлога лабіринту) |
| `sounds/` | 4 звукові файли (див. Ресурси нижче) |
| `CREDITS.txt` | Повідомлення про ліцензування ресурсів для цього зразка |

## Об'єкти

| Об'єкт | Роль | Ключові події |
|---|---|---|
| `obj_person` | Персонаж, керований гравцем; рух на основі сітки | keyboard (down, right, up, left, nokey), collision_with_wall_corner |
| `wall_corner` | Базова тверда стіна лабіринту; батьківський об'єкт для двох інших типів стін | (немає — лише пасивний колайдер) |
| `wall_horizontal` | Твердий горизонтальний сегмент стіни (успадковує від `wall_corner`) | (немає — лише пасивний колайдер) |
| `wall_vertical` | Твердий вертикальний сегмент стіни (успадковує від `wall_corner`) | (немає — лише пасивний колайдер) |
| `obj_diamond` | Цукерка для збору; додає очки при підборі | destroy, collision_with_obj_person |
| `obj_door` | Замкнені вихідні ворота (лише room2); відкриваються, коли всі цукерки зникли | step |
| `obj_goal` | Вихід рівня; переходить до наступної кімнати або завершує гру | collision_with_obj_person |
| `controller_start` | Контролер титульного екрана; чекає, поки гравець почне | create, keyboard_press (ПРОБІЛ) |
| `controller_main` | Контролер HUD усередині лабіринту; малює очки | draw |

## Ресурси

7 спрайтів (32×32, один кадр, точне до пікселя зіткнення, крім
`sprite_goal`, який не має явного прапорця `precise`), 2 фони, 4
звуки (`sound_background.ogg`, `sound_diamond.wav`, `sound_door.wav`,
`sound_goal.wav`). Ліцензування/походження всіх ресурсів цього
зразка **не задокументовано** — див. `CREDITS.txt` у цій папці, який
вказує на TODO "Remaining maze assets" у `docs/ASSET_LICENSES.md`. Не
припускайте CC0 чи будь-яку іншу ліцензію для цих файлів.

## Що можна налаштувати

- Швидкість руху гравця становить `4` (клітинки сітки/крок), тоді як
  зупинка при зіткненні зі стіною використовує швидкість `8` — обидва
  жорстко закодовані параметри дії на натискання клавіші в
  `obj_person`, так само як і `maze_1`.
- Усі 4 додані звукові файли не використовуються — жоден об'єкт
  наразі не викликає `play_sound`; підключення одного для підбору
  цукерки / відкриття дверей / досягнення цілі було б природним
  наступним кроком.
- Кімнати мають розмір `480×480`–`480×512` при `room_speed: 30` —
  маленькі лабіринти з одним екраном, без прокрутки.
- `sprites/tiles.json` — залишковий бічний файл, не зареєстрований як
  ресурс проєкту (його `sprites/tiles.png` не існує) — можна безпечно
  видалити або ігнорувати.
