# Лабиринт — Уровень 2

Игра-лабиринт в сетке с видом сверху с двумя игровыми лабиринтами
плюс титульным экраном: собирайте конфеты для очков, затем достигайте
выхода, чтобы перейти дальше. Это развивает цикл лабиринт/цель с
одной комнатой из `maze_1` с помощью стартового экрана, предмета для
сбора (конфета за очки) и запертой двери, которая открывается лишь
после того, как все конфеты в комнате собраны. Это родной проект
pygm2 (без сопутствующего файла `.gmk` — его ресурсы изначально были
принесены через импорт GameMaker 8.x, согласно `CREDITS.txt`, но сам
проект написан/сохранён в собственном формате JSON pygm2).

**Куда это вписывается:** часть семьи `maze_*` — GameObjects +
спрайты, плюс (в отличие от `maze_1`) статичное **фоновое
изображение** на каждую комнату (`background_main`), без плиток на
уровне комнаты. См.
[`../README.md`](../README.md#progression-how-each-family-is-built-not-just-how-it-plays)
о сравнении с `plateforme_*` (добавляет тайловые фоны) и `match3_*`
(чистый скрипт, без встроенных действий).

**Звук и музыка:** добавлены 4 звуковых файла
(`sound_background.ogg`, `sound_diamond`/`door`/`goal.wav`), но
**ни один из них фактически не подключён** — ни один объект нигде
не ссылается на `play_sound`/`play_music`, поэтому игра на практике
безмолвна, несмотря на наличие аудиоресурсов. (В отличие от
`maze_3`, где такой же по форме набор звуков действительно
воспроизводится.)

## Как играть

- **Титульный экран (`room_start`):** нажмите **ПРОБЕЛ**, чтобы
  начать (действие `keyboard_press` объекта `controller_start`
  вызывает `next_room`).
- **Клавиши со стрелками** (вверх/вниз/влево/вправо) перемещают
  игрока на одну клетку сетки (32px) за раз; движение привязано к
  сетке через `test_alignment`/`snap_to_grid` (сетка 32×32), тот же
  шаблон, что и `maze_1`.
- **Цель:** соберите конфеты (`obj_diamond`, спрайт `sprite_bonbon`),
  разбросанные по каждому лабиринту — каждая стоит +10 очков — затем
  достигните цели (`obj_goal`). В `room2` выход дополнительно
  заблокирован запертой дверью (`obj_door`), которая самоуничтожается
  лишь когда исчезает каждая `obj_diamond` в комнате.
- Касание цели переводит к следующей комнате (+100 очков), если она
  существует; касание в последней комнате (`room2`) присуждает +100,
  открывает экран ввода лучшего результата, и завершает игру.
- **Без условия проигрыша:** в объектах этого образца нигде не
  появляется действие, влияющее на жизни/здоровье —
  `starting_lives: 3` установлено в настройках проекта, но никогда
  не отображается и не уменьшается.

## Структура проекта

| Файл | Назначение |
|---|---|
| `project.json` | Манифест проекта — настройки окна/комнаты и встроенные копии всех ресурсов |
| `rooms/room_start.json` | Титульный экран — 1 экземпляр (`controller_start`) |
| `rooms/room1.json` | Первый лабиринт — 134 экземпляра (стены, игрок, цель, 4 конфеты, `controller_main`) |
| `rooms/room2.json` | Второй лабиринт — 112 экземпляров (стены, игрок, цель, 21 конфета, запертая дверь, `controller_main`) |
| `objects/*.json` | 9 определений объектов — проверены относительно встроенных копий `project.json` и идентичны в этом образце (устаревания не обнаружено) |
| `sprites/` | 7 спрайтов (`sprite_person`, `sprite_bonbon`, `sprite_door`, `sprite_goal`, `sprite_wall_corner`, `sprite_wall_horizontal`, `sprite_wall_vertical`) + метаданные; `tiles.json` — осиротевший боковой файл (не зарегистрирован в `project.json`, файл изображения отсутствует — не используется) |
| `backgrounds/` | `background_start.png` (титульный экран), `background_tiles.png` (тайловый пол лабиринта) |
| `sounds/` | 4 звуковых файла (см. Ресурсы ниже) |
| `CREDITS.txt` | Уведомление о лицензировании ресурсов для этого образца |

## Объекты

| Объект | Роль | Ключевые события |
|---|---|---|
| `obj_person` | Персонаж, управляемый игроком; движение на основе сетки | keyboard (down, right, up, left, nokey), collision_with_wall_corner |
| `wall_corner` | Базовая твёрдая стена лабиринта; родительский объект для двух других типов стен | (нет — только пассивный коллайдер) |
| `wall_horizontal` | Твёрдый горизонтальный сегмент стены (наследует от `wall_corner`) | (нет — только пассивный коллайдер) |
| `wall_vertical` | Твёрдый вертикальный сегмент стены (наследует от `wall_corner`) | (нет — только пассивный коллайдер) |
| `obj_diamond` | Конфета для сбора; добавляет очки при подборе | destroy, collision_with_obj_person |
| `obj_door` | Запертые выходные ворота (только room2); открываются, когда все конфеты исчезли | step |
| `obj_goal` | Выход уровня; переходит к следующей комнате или завершает игру | collision_with_obj_person |
| `controller_start` | Контроллер титульного экрана; ждёт, пока игрок начнёт | create, keyboard_press (ПРОБЕЛ) |
| `controller_main` | Контроллер HUD внутри лабиринта; рисует очки | draw |

## Ресурсы

7 спрайтов (32×32, один кадр, точное до пикселя столкновение, кроме
`sprite_goal`, у которого нет явного флага `precise`), 2 фона, 4
звука (`sound_background.ogg`, `sound_diamond.wav`, `sound_door.wav`,
`sound_goal.wav`). Лицензирование/происхождение всех ресурсов этого
образца **не задокументировано** — см. `CREDITS.txt` в этой папке,
который указывает на TODO "Remaining maze assets" в
`docs/ASSET_LICENSES.md`. Не предполагайте CC0 или любую другую
лицензию для этих файлов.

## Что можно настроить

- Скорость движения игрока составляет `4` (клетки сетки/шаг), тогда
  как остановка при столкновении со стеной использует скорость `8` —
  оба жёстко закодированных параметра действия на нажатие клавиши в
  `obj_person`, так же как и `maze_1`.
- Все 4 добавленных звуковых файла не используются — ни один объект
  в настоящее время не вызывает `play_sound`; подключение одного для
  подбора конфеты / открытия двери / достижения цели было бы
  естественным следующим шагом.
- Комнаты имеют размер `480×480`–`480×512` при `room_speed: 30` —
  маленькие лабиринты с одним экраном, без прокрутки.
- `sprites/tiles.json` — остаточный боковой файл, не
  зарегистрированный как ресурс проекта (его `sprites/tiles.png` не
  существует) — можно безопасно удалить или игнорировать.
