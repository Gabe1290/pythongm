# Платформер — Уровень 2

Боковой скролл-платформер, импортированный из GameMaker 8.x
(`samples/plateforme_2.gmk`). По сравнению с минималистичным первым
уровнем, этот повышает реестр объектов с одинокого игрока + одного
блока до четырёх объектов (базовая платформа плюс горизонтальный и
вертикальный варианты размера, наследующие от неё), расположенных в
комнате со 126 экземплярами, построенной из снежного набора автотайлов,
а не нескольких вручную размещённых блоков.

**Куда это вписывается:** часть семьи `plateforme_*`, и — в отличие
от минималистичного `plateforme_1` — здесь появляется **тайловый
фон**: 127 отдельно размещённых кусков плиток фона (массив `tiles`
комнаты) плюс градиентное фоновое изображение (`fond_degrade`),
наложенное под твёрдыми *объектами* кирпича, которые всё ещё
обрабатывают столкновения. Это шаг, который `plateforme_*` добавляет
сверх `maze_*`; см.
[`../README.md`](../README.md#progression-how-each-family-is-built-not-just-how-it-plays)
для полного прогресса.

**Звук и музыка:** отсутствуют — ни одного звукового файла не
добавлено к этому образцу.

## Как играть

- **Стрелка влево / вправо** — двигает пингвина
  (`obj_personnage`) влево/вправо.
- **Стрелка вверх** — прыжок, но только стоя на твёрдой платформе
  (проверяется тестом столкновения на один пиксель ниже игрока).
- **Цель** — в этом образце нет объекта цели/флага; это
  платформенный макет для исследования/прохождения по платформам
  `obj_brique*`.
- **Условие проигрыша** — не определено (нет опасностей, нет
  убийственных объектов, нет проверки смерти от падения); нижний ряд
  кирпичей комнаты действует как пол.

## Структура проекта

| Файл | Назначение |
| --- | --- |
| `project.json` | Манифест проекта — настройки окна/комнаты, встроенные копии ресурсов. |
| `rooms/niveau_01.json` | Единственная комната: 800×640, 126 экземпляров + 127 плиток фона. Источник истины для содержимого комнаты (встроенный список `instances` `project.json` пуст). |
| `objects/*.json` | Боковые файлы для каждого из 4 объектов; на момент написания идентичны встроенным копиям `project.json`. |
| `sprites/` | 5 спрайт-ресурсов (ленты ходьбы игрока + твёрдые платформенные блоки). |
| `backgrounds/` | Снежный набор тайлов (`tuiles_neige.png`, используется как источник автотайла) и небольшой вертикальный градиент (`fond_degrade.png`), растянутый как фон комнаты. |
| `CREDITS.txt` | Уведомление о лицензировании искусства спрайтов/фона (см. Ресурсы ниже). |

## Объекты

| Объект | Роль | Ключевые события |
| --- | --- | --- |
| `obj_personnage` | Игрок (пингвин) — движение, прыжок, гравитация, обнаружение земли | create, step, collision_with_obj_brique, keyboard (left, right, up), keyboard_release (LEFT, RIGHT) |
| `obj_brique` | Базовый твёрдый платформенный блок (32×32) | нет (никаких событий; только флаг solid) |
| `obj_brique_h` | Широкий вариант твёрдой платформы (32×16), дочерний объект `obj_brique` | нет |
| `obj_brique_v` | Узкий вариант твёрдой платформы (8×16), дочерний объект `obj_brique`; определён, но не размещён в `niveau_01` | нет |

## Ресурсы

5 спрайтов (ленты ходьбы `spr_pingus_dr`/`spr_pingus_ga` с 8
кадрами, плюс три заглушки сплошного цвета размером 32×32 / 32×16 /
8×16) и 2 фона; без звуков. Искусство спрайтов и фона адаптировано из
проекта Pingus (GPL-3.0-or-later) — см. `CREDITS.txt` для полного
указания авторства и условий лицензии; этот README не повторяет и не
добавляет к этим утверждениям.

## Что можно настроить

- Горизонтальная скорость игрока фиксирована `hspeed = 4` в событиях
  клавиатуры.
- Импульс прыжка составляет `vspeed = -10`; гравитация падения
  составляет `0.45` (применяется только в воздухе), с ограничением
  конечной скорости на `vspeed = 24`.
- Размер комнаты — 800×640 при `room_speed = 30`.

## Статус экспорта

Этот образец указан в списке `SAMPLES` `tools/smoke_run_samples.py`,
поэтому при каждом запуске этого набора он получает безголовый
smoke-проход (настоящий игровой цикл запускается на ~180 кадров со
встроенным вводом клавиатуры). Проверки для конкретной цели экспорта
(Kivy/HTML5) для этого образца не выполнялось. Выставлено на вкладке
Welcome редактора как "Platform — Level 2" (`widgets/welcome_tab.py`).
