# Платформер — Рівень 2

Бічний скролінг-платформер, імпортований з GameMaker 8.x
(`samples/plateforme_2.gmk`). Порівняно з мінімальним першим рівнем,
цей підвищує реєстр об'єктів з самотнього гравця + одного блоку до
чотирьох об'єктів (базова платформа плюс горизонтальний і
вертикальний варіанти розміру, що успадковують від неї),
розташованих у кімнаті з 126 екземплярами, побудованій зі снігового
набору автотайлів, а не кількох вручну розміщених блоків.

**Куди це вписується:** частина родини `plateforme_*`, і — на
відміну від мінімального `plateforme_1` — тут з'являється **тайловий
фон**: 127 окремо розміщених шматків плиток фону (масив `tiles`
кімнати) плюс градієнтне фонове зображення (`fond_degrade`),
накладене під твердими *об'єктами* цегли, які досі обробляють
зіткнення. Це крок, який `plateforme_*` додає понад `maze_*`; див.
[`../README.md`](../README.md#progression-how-each-family-is-built-not-just-how-it-plays)
для повного прогресу.

**Звук і музика:** відсутні — жодного звукового файлу не додано до цього зразка.

## Як грати

- **Стрілка ліворуч / праворуч** — рухає пінгвіна
  (`obj_personnage`) ліворуч/праворуч.
- **Стрілка вгору** — стрибок, але лише стоячи на твердій платформі
  (перевіряється тестом зіткнення на один піксель нижче гравця).
- **Мета** — у цьому зразку немає об'єкта цілі/прапорця; це
  платформерний макет для дослідження/проходження по платформах
  `obj_brique*`.
- **Умова програшу** — не визначена (немає небезпек, немає
  вбивчих об'єктів, немає перевірки смерті від падіння); нижній ряд
  цегли кімнати діє як підлога.

## Структура проєкту

| Файл | Призначення |
| --- | --- |
| `project.json` | Маніфест проєкту — налаштування вікна/кімнати, вбудовані копії ресурсів. |
| `rooms/niveau_01.json` | Єдина кімната: 800×640, 126 екземплярів + 127 плиток фону. Джерело істини для вмісту кімнати (вбудований список `instances` `project.json` порожній). |
| `objects/*.json` | Бічні файли для кожного з 4 об'єктів; на момент написання ідентичні вбудованим копіям `project.json`. |
| `sprites/` | 5 спрайт-ресурсів (стрічки ходьби гравця + тверді платформенні блоки). |
| `backgrounds/` | Сніговий набір тайлів (`tuiles_neige.png`, використовується як джерело автотайлу) і невеликий вертикальний градієнт (`fond_degrade.png`), розтягнутий як фон кімнати. |
| `CREDITS.txt` | Повідомлення про ліцензування мистецтва спрайтів/фону (див. Ресурси нижче). |

## Об'єкти

| Об'єкт | Роль | Ключові події |
| --- | --- | --- |
| `obj_personnage` | Гравець (пінгвін) — рух, стрибок, гравітація, виявлення землі | create, step, collision_with_obj_brique, keyboard (left, right, up), keyboard_release (LEFT, RIGHT) |
| `obj_brique` | Базовий твердий платформенний блок (32×32) | немає (жодних подій; лише прапорець solid) |
| `obj_brique_h` | Широкий варіант твердої платформи (32×16), дитина `obj_brique` | немає |
| `obj_brique_v` | Вузький варіант твердої платформи (8×16), дитина `obj_brique`; визначена, але не розміщена в `niveau_01` | немає |

## Ресурси

5 спрайтів (стрічки ходьби `spr_pingus_dr`/`spr_pingus_ga` з 8
кадрами, плюс три заглушки суцільного кольору розміром 32×32 /
32×16 / 8×16) і 2 фони; без звуків. Мистецтво спрайтів і фону
адаптоване з проєкту Pingus (GPL-3.0-or-later) — див. `CREDITS.txt`
для повної вказівки авторства та умов ліцензії; цей README не
повторює й не додає до цих тверджень.

## Що можна налаштувати

- Горизонтальна швидкість гравця фіксована `hspeed = 4` у подіях
  клавіатури.
- Імпульс стрибка становить `vspeed = -10`; гравітація падіння
  становить `0.45` (застосовується лише в повітрі), з обмеженням
  кінцевої швидкості на `vspeed = 24`.
- Розмір кімнати — 800×640 при `room_speed = 30`.
